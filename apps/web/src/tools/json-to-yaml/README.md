# JSON 转 YAML

把 JSON 转成可读的 YAML（block 风格），纯本地序列化，不依赖 `js-yaml` 等第三方库。

## 用途

写配置文件（CI、Kubernetes、docker-compose 等）时把现成的 JSON 片段转成更易读的 YAML；
嵌套对象缩进、数组转块序列、有歧义的字符串自动加双引号。

## 输入

| 字段   | 类型   | 约束                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 最大 2,000,000 字符，任意合法 JSON |

## 输出

| 字段   | 类型   | 说明                      |
| ------ | ------ | ------------------------- |
| `text` | string | YAML 文本；空输入返回空串 |

## 选项

| 选项     | 取值         | 默认     | 说明                                          |
| -------- | ------------ | -------- | --------------------------------------------- |
| `indent` | 2 / 4        | `2`      | 每层缩进空格数                                |
| `quote`  | needed / all | `needed` | needed 仅有歧义字符串加引号；all 全部加双引号 |

## 序列化规则

- 对象按 `key: value`；嵌套对象缩进一层；空对象输出 `{}`
- 数组转块序列 `- item`；对象数组首键与 `- ` 同行，后续键与首键对齐
- 空数组输出 `[]`；`null / true / false` 输出 `null / true / false`
- 以下字符串自动双引号：空串、首尾空白、形似布尔/数字/空值（`true`、`123`、`yes`、`null`…）、
  含 `: # [ ] { }` 等 YAML 指示符或以这些字符开头、含冒号空格 / 尾随冒号
- 双引号转义复用 JSON 规则（`"`、`\`、控制字符），在 YAML 双引号标量中同样合法

## 限制

- 全部逻辑为纯 TS 自研的 YAML **发射器**（只出不进），不依赖 `js-yaml`，行为以本文档为准
- 仅输出 block 风格（嵌套数组的极深层级仍保证合法）；不输出锚点 / 别名 / 多文档 `---` / 注释
- 不做 YAML 1.1 复杂类型（时间戳、二进制标签）；数字统一按 JSON 数值字面量写出
- 输入上限 2,000,000 字符，超限抛 `JsonToYamlError`

## 数据流向

**纯本地处理。** 输入仅在浏览器内存中处理，不发送网络请求，不写入服务端。`meta.api = false`。

## 示例

输入：

```json
{ "id": 1, "name": "工具库", "tags": ["json", "yaml"], "meta": { "stars": 870 } }
```

输出：

```yaml
id: 1
name: 工具库
tags:
  - json
  - yaml
meta:
  stars: 870
```
