# URL 编解码

URL 百分号编码与解码，区分组件与整串两种口径。

## 用途

把中文、空格、`&`、`=` 等字符转成 URL 里能安全传输的百分号形式，或把抓到的请求还原成可读文本。
调试接口、拼 query、读日志里那条超长 URL 时最常用。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                             |
| ------ | ------ | -------------------------------- |
| `text` | string | 编码后为百分号形式；解码后为原文 |

## 选项

| 选项        | 取值            | 默认      | 说明                                                  |
| ----------- | --------------- | --------- | ----------------------------------------------------- |
| `direction` | encode / decode | encode    | 编码或解码                                            |
| `mode`      | component / uri | component | component 转义 `/ ? & =` 等全部结构字符；uri 保留它们 |

## 限制

- 两种模式都额外补转义 `!'()*`——`encodeURIComponent` 原生不处理它们，但 RFC 3986 要求转义
- 解码时会把 `+` 当作空格（表单 `application/x-www-form-urlencoded` 语义）。
  若原文里确实有加号，请先自行替换成 `%2B`
- 解码遇到残缺的百分号序列（如 `%E5%B7`）会明确报错，不输出乱码

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
https://example.com/搜索?q=工具库&page=1
```

输出（component / encode）：

```text
https%3A%2F%2Fexample.com%2F%E6%90%9C%E7%B4%A2%3Fq%3D%E5%B7%A5%E5%85%B7%E5%BA%93%26page%3D1
```
