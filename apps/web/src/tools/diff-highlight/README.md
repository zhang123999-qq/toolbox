# 文本对比高亮

差异高亮显示。

## 用途

把两份文本的差异直接画出来：新增绿色删除线删除（`<ins>` / `<del>`），复制按钮给出的是同一份差异的纯文本 +/- 版本。

## 输入

| 字段    | 类型   | 约束                    |
| ------- | ------ | ----------------------- |
| `text`  | string | 最大 100,000 字符       |
| `textB` | string | 新版，最大 100,000 字符 |

两份平级文本：原文填在上面，新版填在下面的框里。

## 输出

| 字段   | 类型   | 说明                                                                     |
| ------ | ------ | ------------------------------------------------------------------------ |
| `text` | string | 行级按整段着色，字符级连行内改动也标出来；纯文本版沿用 #35 的 +/- 约定。 |

## 选项

| 选项   | 取值            | 默认   | 说明                  |
| ------ | --------------- | ------ | --------------------- |
| `mode` | `line` / `char` | `line` | 行级对比 / 字符级对比 |

## 限制

- 字符级对比在长文本上会很密，而且 jsdiff 的字符级结果是「先删后增」，同一处修改会被拆成删除 + 新增两段
- 字符级模式把空格渲染成 `⋅`、制表符渲染成 `→`，这是**显示层**的替换，复制出来的纯文本版不含这些符号
- 输出不是可直接 `git apply` 的补丁，需要补丁请用 #35 文本 Diff 的产物另做处理
- 输入上限 100,000 字符（每个框）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
第一行
第二行
第三行
```

新版：

```text
第一行
第二行改了
第三行
```

输出：

```text
  第一行
- 第二行
+ 第二行改了
  第三行
```
