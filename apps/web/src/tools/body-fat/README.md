# 体脂计算

输入腰围、颈围、身高（女性还需臀围）与性别，用**美国海军法**估算体脂率，并按性别标准分级。

## 用途

- 无体脂秤时的体脂估算
- 减脂 / 健身进度的跟踪参考

## 输入

| 字段    | 类型   | 约束                              |
| ------- | ------ | --------------------------------- |
| `text`  | string | 腰围（cm），>0，最大 200,000 字符 |
| `textB` | string | 颈围（cm），>0                    |
| `textC` | string | 身高（cm），>0                    |
| `textD` | string | 臀围（cm），女性必填，男性忽略    |

## 输出

```text
体脂率：16.9%
分级：健康（男性标准）
```

## 选项

| 选项     | 类型   | 说明            |
| -------- | ------ | --------------- |
| `gender` | select | 性别：`男` `女` |

## 算法

美国海军法（单位 cm，`log10`）：

- 男：`495 / (1.0324 − 0.19077 × log10(腰 − 颈) + 0.15456 × log10(身高)) − 450`
- 女：`495 / (1.29579 − 0.35004 × log10(腰 + 臀 − 颈) + 0.22100 × log10(身高)) − 450`
- 结果保留 1 位小数（`toFixed(1)`）

分级（分界值归入更健康一档）：

- 男：`<14` 偏低 / `14–18` 健康 / `18–25` 超重 / `>25` 肥胖
- 女：`<21` 偏低 / `21–25` 健康 / `25–32` 超重 / `>32` 肥胖

## 边界

- 腰围留空 → 输出空串
- 四项各自非数字 → 中文报错「X请输入有效的数字」；≤0 → 「X必须大于 0」（X=腰围/颈围/身高/臀围）
- 性别非法 → 「性别非法」
- 男：腰围 ≤ 颈围 → 「腰围必须大于颈围」（臀围不校验）
- 女：臀围留空 → 「女性需填写臀围」；腰围 + 臀围 ≤ 颈围 → 「腰围与臀围之和必须大于颈围」
- 输入 > 200,000 字符 → 报错

## 示例

男，腰围 `85`，颈围 `38`，身高 `175`：

```text
体脂率：16.9%
分级：健康（男性标准）
```

## English

A body fat percentage estimator using the U.S. Navy method. Input: `text` (waist, cm), `textB` (neck, cm), `textC` (height, cm), `textD` (hip, cm, required for women); option: gender. Output: e.g. `体脂率：16.9%` + classification.
