# 证书解析

粘贴 PEM 格式的 X.509 证书，本地解析出主体、签发者、有效期、公钥、SAN 与指纹。

## 用途

拿到一张 `.crt` / `.pem` 证书想快速看清「它签给谁、谁签的、什么时候过期、覆盖哪些域名」。
本工具用 node-forge 在浏览器内离线解析，不上传证书。

## 输入

| 字段   | 类型   | 约束                                                 |
| ------ | ------ | ---------------------------------------------------- |
| `text` | string | `-----BEGIN CERTIFICATE-----` PEM，最大 100,000 字符 |

## 输出

| 字段        | 说明                         |
| ----------- | ---------------------------- |
| 主体/签发者 | `CN=…, O=…, C=…`             |
| 生效/过期   | ISO 时间 + 剩余天数          |
| 序列号      | 十六进制                     |
| 签名算法    | 如 `sha256WithRSAEncryption` |
| 公钥        | RSA 位数 / 指数，或 EC       |
| SAN         | 所有 DNS / IP 别名           |
| 指纹        | SHA-256 证书指纹（冒号分隔） |

## 与「SSL 证书体检」(#130) 的区别

#130 侧重**问题检查**（过期/弱算法/缺 SAN）；本工具侧重**完整字段展示**。

## 限制

- 只解析单张证书，不解析证书链（含多段 PEM 时取第一张）
- 不做信任链校验，只看证书本身字段
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** node-forge 动态加载，证书不上传。`meta.api = false`。
