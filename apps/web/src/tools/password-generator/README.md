# 密码生成

用 CSPRNG 生成随机密码，可排除易混字符、可要求每类字符至少出现一次。

## 用途

给新账号、测试环境、本地数据库挑一个随机口令。
所有随机数来自浏览器的 `crypto.getRandomValues`（加密安全伪随机数发生器），
不用 `Math.random`；生成过程完全在本地，不会把口令发给任何服务。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

**输入框只作触发用**，内容本身不参与生成：留空时不产出任何内容，
点「示例」或随手输入任意字符即生成一条密码；之后点「运行」可以再摇一条。

## 输出

| 字段   | 类型   | 说明                             |
| ------ | ------ | -------------------------------- |
| `text` | string | 一条随机密码，**每次结果都不同** |

## 选项

| 选项             | 取值                  | 默认 | 说明                                               |
| ---------------- | --------------------- | ---- | -------------------------------------------------- |
| `length`         | 8 / 12 / 16 / 24 / 32 | 16   | 密码长度                                           |
| `noAmbiguous`    | 勾选 / 取消           | 取消 | 剔除 `I` `l` `1` `O` `0` `o`，避免手抄或肉眼认错   |
| `eachClass`      | 勾选 / 取消           | 勾选 | 保证每个已勾选的字符类至少出现一次                 |
| `includeLower`   | 勾选 / 取消           | 勾选 | 小写字母 `a-z`                                     |
| `includeUpper`   | 勾选 / 取消           | 勾选 | 大写字母 `A-Z`                                     |
| `includeNumbers` | 勾选 / 取消           | 勾选 | 数字 `0-9`                                         |
| `includeSymbols` | 勾选 / 取消           | 勾选 | 符号 `!@#$%^&*()-_=+[]{}<>?/~`（不含引号与反斜杠） |

字符集默认 26+26+10+24 = 86 个字符，16 位约 103 bit 熵；勾选「排除易混字符」后为 80 个字符，约 101 bit 熵。

## 限制

- 输入框内容**不参与**生成，只是为了适配 T2 双栏模板的交互（留空即不产出）
- 至少得勾选一类字符；一类都不勾选会明确报错
- 密码不会自动复制：点「复制」按钮才写入剪贴板
- 生成的是随机口令，不做「是否出现在泄露库中」的检查，也不做强度评分
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 随机数取自 `crypto.getRandomValues`，输入与结果都只在内存里，
不发送任何网络请求，不写入服务端。`meta.api = false`，无需自备 API/Key。
（本工具不写 `localStorage`，刷新即丢。）

## 示例

输入（触发用）：

```text
generate
```

输出（16 位、全部字符类，**每次点「运行」都不一样**）：

```text
K7$mQ2p!Rt9Wz@4x
```

形状固定为 `^[!-~]{16}$`；把长度改成 32 就得到 32 位。
单测里用「注入固定随机源」的方式验证过：长度 8、仅小写、随机源恒为 0 时必得 `aaaaaaaa`。
