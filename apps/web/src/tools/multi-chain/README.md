# 多链地址（#707）

以太坊 hex 地址与 TRON base58 地址互转，纯前端本地计算，无需联网。

## 输入格式

每行一个地址，支持批量：

- ETH 地址：`0x` + 40 位 hex（大小写均可，可省略 `0x`）
- TRON 地址：`T` 开头的 base58 字符串

转换方向可选：自动识别 / ETH → TRON / TRON → ETH。

## 示例

```
0xa614f803b6fd780986a42c78ec9c7f77e6ded13c
→ TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t
```

## 原理

TRON 地址 = `0x41` 前缀 + 20 字节 ETH 地址体 + 双 SHA-256 前 4 字节校验和，整体 base58 编码（比特币字母表）。
解码时校验长度（25 字节）、前缀与校验和，任一不符即报错。

## 限制

- 仅支持 ETH ↔ TRON 两种地址体系，不支持比特币等其他链。
- 输出 ETH 地址为小写 hex（不做 EIP-55 大小写编码），如需 checksum 地址请用 #691 地址校验。
