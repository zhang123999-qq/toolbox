# 单位换算

输入数值并选择源单位与目标单位，一站式完成长度、重量、面积、体积、温度、速度六个类别的单位换算。

## 用途

- 长度 / 重量 / 面积 / 体积 / 速度单位互转
- 温度单位互转（摄氏度 / 华氏度 / 开尔文，附绝对零度校验）
- 一个页面覆盖全部常用单位换算

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待换算的数值，最大 200,000 字符 |

## 输出

单行文本：`输入值 源单位 = 结果 目标单位`

```text
100 km/h = 27.7777777778 m/s
100 C = 212 F
```

## 选项

| 字段   | 类型   | 说明     | 可选值                      |
| ------ | ------ | -------- | --------------------------- |
| `from` | select | 源单位   | 全部 36 个单位 id（见下表） |
| `to`   | select | 目标单位 | 同左                        |

### 单位表

| 类别           | 单位（基准）                       |
| -------------- | ---------------------------------- |
| 长度（米）     | mm、cm、m、km、in、ft、yd、mi、nmi |
| 重量（千克）   | mg、g、kg、t、斤、oz、lb           |
| 面积（平方米） | cm²、m²、ha、km²、亩、ft²、acre    |
| 体积（升）     | ml、l、m³、gal、fl-oz              |
| 速度（米/秒）  | m/s、km/h、mph、ft/s、knot         |
| 温度           | C、F、K                            |

## 算法

- 非温度单位：以各类别基准单位为中转，`结果 = 数值 × from.factor / to.factor`
- 温度：以**摄氏度**为中转，专用公式
  - C→F: `v*9/5+32`；F→C: `(v-32)*5/9`；C→K: `v+273.15`；K→C: `v-273.15`
- 输出用 `Number(n.toPrecision(12)).toString()` 格式化，去浮点噪声、去尾零

## 边界

- 空输入 → 输出为空（不报错）
- 非数字输入 → 中文报错「请输入有效的数字」
- from 与 to 类别不一致 → 中文报错「单位类别不一致：X单位不能换算为Y单位」（如长度单位不能换算为重量单位）
- 未知单位 id → 中文报错「未知单位」
- 低于绝对零度（C < -273.15 / F < -459.67 / K < 0）→ 中文报错「低于绝对零度，物理上不可能」
- 输入 > 200,000 字符 → 报错

## 示例

输入数值：`100`，从 `C` 到 `F`

输出：`100 C = 212 F`

## English

All-in-one unit converter: length, weight, area, volume, temperature, speed.

- Input: a numeric string.
- Output: one line, e.g. `100 C = 212 F`.
- Options: `from` / `to` selects over 36 unit ids across 6 categories; temperature goes through Celsius with absolute-zero validation.
