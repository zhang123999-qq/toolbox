# 校验和

多种轻量校验和算法：8/16/32 位累加和、异或、补码校验和、Luhn 校验位。

## 用途

核对一段内容在传输或录入过程中有没有出错：串口帧尾校验、配置文件比对、
银行卡号 / 身份证号的校验位计算。

## 输入

| 字段   | 类型   | 约束              | 说明                                   |
| ------ | ------ | ----------------- | -------------------------------------- |
| `text` | string | 最大 200,000 字符 | 待计算的内容；Luhn 算法只接受数字      |

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 校验值 + 算法说明 + 字节数（UTF-8）       |

## 选项

| 选项        | 取值                                              | 默认 | 说明                   |
| ----------- | ------------------------------------------------- | ---- | ---------------------- |
| `algorithm` | sum8 / sum16 / sum32 / xor8 / mod256 / luhn        | sum8 | 校验算法               |
| `uppercase` | 开 / 关                                           | 关   | 十六进制是否大写       |

## 限制

- 这些都是**非加密校验和**：只能发现「无意出错」，防不住故意篡改。
  需要防篡改请用 CRC（另有「CRC」工具）或 SHA-256 / BLAKE3
- 多字节算法按**大端**（网络序）组合字节，末字节不足时补 0；
  与你的设备不一致时先确认字节序
- 中文按 UTF-8 计字节（一个汉字 3 字节），输出里会写明字节数，便于对账
- Luhn 只吃数字：带空格可以，带字母或符号会报错

## 数据流向

**纯本地处理。** 内容只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
hello
```

输出（sum8）：

```text
14

8 位累加和（sum8）｜8 位累加和（各字节相加后 mod 256）｜5 字节（UTF-8）
```
