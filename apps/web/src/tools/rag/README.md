# RAG 问答（rag）

极简的"检索增强"问答演示：把长文档切成片段，检索最相关的几段，拼接成抽取式答案。

## 功能

- 纯本地：滑窗分块 → TF-IDF 检索 top-k → 原句抽取拼接
- 可调参数：块大小、块重叠、检索片段数 k
- 答案下方展示命中的原始片段及其相似度，可核验
- 无需网络、无需 Key

## 使用

1. 在左侧粘贴长文档
2. 在「问题」中输入你的问题，调整 k（如需）
3. 点「提问」，上方显示拼接答案，下方列出依据片段

## 重要说明（请先读）

- **本工具不含大模型（LLM）**：答案只是把原文句子抽出来拼接，不会"组织语言"也不会推理
- 中文用单字 + 二元词切分，可能出现误命中（如问题里的单字恰好在无关片段中高频出现）
- 问文档中没有明确写出的内容时，答案会是"未找到相关内容"，不会编造
- 适合：理解 RAG 原理、文档定位；不适合：开放问答、总结推理
