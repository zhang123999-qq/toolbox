# 重复代码检测

按行级 hash 检测重复代码行与重复块，给出重复率与最频繁的重复行。

## 用途

重构前快速找出「这段 `console.log` / 这个 if 块在文件里抄了几遍」。

## 输入

| 字段   | 类型   | 约束                      |
| ------ | ------ | ------------------------- |
| `text` | string | 源代码，最大 200,000 字符 |

## 选项

| 选项 key   | 界面         | 说明                              |
| ---------- | ------------ | --------------------------------- |
| `minBlock` | 最小重复次数 | 一行出现 ≥ N 次才计入重复，默认 3 |

## 方法

1. 逐行去掉首尾空白，空行跳过
2. 对每行做 djb2 hash
3. 统计每个 hash 的出现次数，≥ 阈值的行计入「重复行」
4. 重复率 = 重复行 / 非空行

## 限制

- **行级 hash**，不做「跨行连续重复块」识别；只统计逐行重复
- 变量名 / 缩进不同会被视为不同行（只 trim 首尾，不做规范化）
- 不是真正的复制粘贴检测器（无 token 级对比），仅供快速体检

## 数据流向

**纯本地处理。** 无网络请求。`meta.api = false`。
