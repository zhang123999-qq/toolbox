# 收据生成 · Receipt Generator

填写付款人、收款人、金额与事由，右侧实时预览规范收据，点击「导出 PNG」生成收据图片。
纯前端处理，不上传数据。

Enter payer, payee, amount and purpose; a proper receipt previews live on the right.
Click "Export PNG" to download it as an image. All processing is local; nothing is uploaded.

## 用途 / Purpose

- 房东 / 商户快速开具收款收据
- 个人间借款、还款留存凭证

## 输入 / Inputs

| 字段               | 类型   | 约束                                        |
| ------------------ | ------ | ------------------------------------------- |
| `text`（事由）     | string | 可选，多行，≤ 500 字符                      |
| `payer`（付款人）  | string | 可选，≤ 40 字符                             |
| `payee`（收款人）  | string | 可选，≤ 40 字符                             |
| `amount`（金额）   | string | 必填（填了其他字段时），有限正数，≤ 20 字符 |
| `date`（日期）     | string | 可选，`YYYY-MM-DD`，≤ 20 字符               |
| `number`（收据号） | string | 可选，≤ 40 字符                             |

## 输出 / Outputs

- 右侧预览：虚线边框收据单据（大写金额区、付款/收款人、支付方式）
- 「导出 PNG」按钮：2x 倍率导出，文件名 `receipt-<收据号>.png`
- 复制 / 下载：收据的纯文本版本（`.txt`）

## 选项 / Options

| 选项     | 类型   | 说明                                |
| -------- | ------ | ----------------------------------- |
| `method` | select | 支付方式：现金 / 转账 / 刷卡 / 其他 |

## 限制 / Limits

- 金额须为有限正数：非数字、0、无穷大 → 「金额无效」；负数 → 「金额不能为负数」
- 金额请直接输入数字（如 `3500`），不支持千分位逗号
- 日期须为合法的 `YYYY-MM-DD`（含闰年校验）
- 不加载外部图片与外部字体，避免跨域导致导出失败
- 导出依赖浏览器 Canvas；失败时显示双语错误提示

## 数据流向 / Data flow

纯本地计算与渲染，不调用外部接口，不上传任何数据。

## 示例 / Example

输入：付款人 `张三`、金额 `3500`、事由 `2026 年 9 月房屋租金`

输出预览：

```text
收据生成
R-2026-0001 · 2026-09-27
3,500.00
付款人：张三
支付方式：现金
事由：2026 年 9 月房屋租金
```

## 边界行为 / Edge cases

- 全部留空 → 空态提示，不报错
- 金额为空但填了其他字段 → 报错「请填写金额」
- 金额非数字 / 为 0 → 「金额无效」；为负 → 「金额不能为负数」
- HTML 特殊字符 → 预览中自动转义
