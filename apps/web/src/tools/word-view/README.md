# Word 文档预览

上传 `.docx` 文档，在浏览器本地渲染为可阅读的 HTML 预览，图片内嵌显示。

## 用途

快速查看 Word 文档内容而不打开 Word：上传文档，直接在页面里阅读。

## 输入

| 字段   | 类型 | 约束        | 说明                                     |
| ------ | ---- | ----------- | ---------------------------------------- |
| `file` | File | 最大 50 MiB | 输出区顶部「选择 Word 文档」，**不上传** |

## 输出

| 字段   | 类型 | 说明                                                    |
| ------ | ---- | ------------------------------------------------------- |
| `html` | HTML | 清洗后的 HTML 预览（标题 / 段落 / 列表 / 表格保留语义） |

图片默认转为 data URI 内嵌显示。「下载」导出为带基础排版的独立网页文件。

## 选项

无。

## 限制

- **文件上限 50 MiB**
- 转换由 mammoth（纯 JS，本地运行）完成；旧版 `.doc` 暂不支持，会提示先另存为 `.docx`
- 预览 HTML 经过白名单清洗：只保留内容标签，`javascript:` 等危险链接会被中和
- 损坏 / 非 docx 文件会直接报中文错误

## 数据流向

**纯本地处理。** 文件不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 实现说明

规划原要求 `@neo-office/renderer` 做高保真排版预览，但该包把 WASM
初始化地址硬编码为 `/wasm/init.js`，而仓库约束「只允许修改工具目录、
不得复制静态资源」，无法实际初始化。故回退为 mammoth 的 HTML 语义预览
（`feasibility='A'`、`wasm=false`）。

## 示例

输入：包含一级标题「Hello」和段落「world」的 `.docx`

输出：输出区渲染出标题与段落，文件名旁显示「demo.docx」。

## 元信息

| 项       | 值                     |
| -------- | ---------------------- |
| 全局编号 | #501                   |
| 域       | `media`（媒体 / 文档） |
| 大组     | `office`               |
| 优先级   | P0                     |
| 可行性   | A（纯 JS）             |
| 模板     | T3（输出区自定义渲染） |
