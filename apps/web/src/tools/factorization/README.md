# 因数分解（Prime Factorization）

将一个整数分解为质因数，附质因数个数、因数个数与因数和。

## 用途

- 把整数写成质因数连乘形式
- 顺带得到因数个数 d(n) 与因数和 σ(n)

## 输入

| 字段   | 类型   | 约束               |
| ------ | ------ | ------------------ |
| `text` | string | 整数，\|n\| ≤ 10¹² |

## 输出

```text
n = 360
360 = 2³ × 3² × 5
质因数个数（含重复）：6
不同质因数个数：3
因数个数：24
因数和：1,170
注：本工具支持 |n| ≤ 10¹²（性能上限）。
```

## 选项

本工具无选项。

## 算法

- **分解**：用筛到 10⁶ 的素数表（约 7.8 万个）试除；n ≤ 10¹² 时最坏约 7.8 万次除法，毫秒级完成。剩余 > 1 的部分必为质数。
- **因数个数**：d(n) = ∏(eᵢ + 1)
- **因数和**：σ(n) = ∏((pᵢ^(eᵢ+1) − 1) / (pᵢ − 1))
- 负数按 |n| 分解，分解式前加 `−1 ×`；因数个数 / 因数和按 |n| 的正因数计。

## 边界

- 空输入 → 输出空
- 非整数（小数 / 字母）→ 中文报错
- |n| > 10¹² → 中文报错（性能上限：试除次数随 √n 增长）
- n = 0 → 中文报错（0 有无穷多个因数，无法分解）
- n = ±1 → 提示「±1 没有质因数」

## 示例

输入：`360` → `360 = 2³ × 3² × 5`，因数 24 个，和 1,170。

## 数据流向

纯本地计算，不上传任何数据。

## English

Factor an integer into primes (|n| ≤ 10¹²) by trial division with a prime table sieved to 10⁶, plus divisor count d(n) and divisor sum σ(n). Negative inputs are factored by absolute value (prefixed with −1). All computation is done locally in the browser; no data is uploaded.
