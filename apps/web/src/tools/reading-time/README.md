# 阅读时间

按字数估算阅读时长。

## 用途

给文章、文档、README 标注「约需 X 分钟读完」，也用于估算配音或朗读时长。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本，中英混排均可。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                         |
| ------ | ------ | -------------------------------------------- |
| `text` | string | 字数、字符数、所用速度、阅读时长与朗读时长。 |

## 选项

| 选项    | 取值            | 默认 | 说明                                   |
| ------- | --------------- | ---- | -------------------------------------- |
| `speed` | 200 / 300 / 500 | 300  | 阅读速度（字/分钟）；中文常取 300～500 |

## 限制

- 英文单词按 1.5 个「字」折算，是为了与中文速度共用一把尺子，非精确换算
- 朗读时长固定按 250 字/分钟估算，不可调
- 结果不含图片、代码块的停留时间，实际阅读往往更长

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具库 toolbox
```

输出：

```text
工具箱是一个纯前端在线工具库，所有计算都在浏览器本地完成，数据不会上传服务器。
```
