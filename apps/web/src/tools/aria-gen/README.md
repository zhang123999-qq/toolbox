# ARIA 生成

输入组件名称、选择组件类型（按钮 / 输入框 / 对话框 / 导航 / 选项卡 / 开关 / 滑块 / 提示框），生成符合无障碍实践的 HTML 代码片段，并附带使用说明（如对话框的焦点管理、选项卡的键盘交互）。

## 用途

- 快速起草无障碍组件的 HTML 骨架
- 学习各组件必需的 ARIA 属性与关联关系
- 走查已有组件缺了哪些属性

## 输入

| 字段                 | 类型   | 约束                    |
| -------------------- | ------ | ----------------------- |
| `text`               | string | 组件名称（label）       |
| 选项 `type`          | string | 组件类型（8 选 1）      |
| 选项 `id`            | string | 元素 id（可选）         |
| 选项 `describedBy`   | string | 补充说明元素 id（可选） |
| 选项 `min/max/value` | string | 滑块数值（滑块必填）    |

## 说明

- 纯本地生成，无网络请求。
- 用户输入的名称会被 HTML 转义，可放心粘贴任意文本。
- 片段是起点模板：选项卡的键盘方向键逻辑、对话框的 focus trap 等 JS 行为仍需自行实现，使用说明中有提示。
