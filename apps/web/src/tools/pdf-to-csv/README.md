# PDF 转 CSV

提取 PDF 的文本层，按行列启发式转为 CSV：同一列的文本按 x 坐标聚类，
同一行按 y 坐标聚类，每页独立检测列（各页版式可能不同）。

## 用途

把 PDF 里的表格（报表、清单、名录）转成 CSV，粘贴到 Excel / WPS /
Google Sheets 继续处理。

## 输入

| 字段   | 类型 | 约束                  | 说明                                 |
| ------ | ---- | --------------------- | ------------------------------------ |
| `file` | File | PDF，≤100 MiB，≤50 页 | 通过左下「选择文件」选取，**不上传** |

## 输出

| 字段   | 类型   | 说明                              |
| ------ | ------ | --------------------------------- |
| `text` | string | CSV 文本（行间 `\r\n`，RFC 4180） |

```csv
姓名,备注
张三,"喜欢,逗号"
李四,'=SUM(A1)
```

## 选项

| 选项        | 取值            | 默认 | 说明     |
| ----------- | --------------- | ---- | -------- |
| `delimiter` | `,` / `;` / tab | `,`  | 列分隔符 |

## 转义规则（RFC 4180 + 安全）

- 单元格含分隔符、双引号、换行 → 整体加双引号，内部双引号翻倍（`"` → `""`）
- 单元格以 `=` `+` `-` `@` 开头 → 前缀单引号，防止粘贴进 Excel 后被当成公式执行（公式注入防护）
- 行之间用 `\r\n` 分隔

## 限制

- **只处理文本层**：扫描版 PDF 没有文字可提，整篇无文本时会报错并建议用
  #500「PDF 文字识别（OCR）」
- **加密 PDF 不支持**：中文提示请先去除密码
- **页数上限 50 页**，文件上限 100 MiB
- 列识别是启发式（x 坐标聚类，容差 5pt）：对不齐的散排文本可能分列不准，
  复杂表格建议先用 #536 转 HTML 检查结构

## 数据流向

**纯本地处理。** pdfjs-dist 在浏览器里解析 PDF 并提取文本项，全程无网络请求
（`meta.api = false`），文件不上传。
