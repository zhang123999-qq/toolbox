# 正则生成 Regex Generator（#608）

BYOK 模式：用自然语言描述匹配规则，请大模型生成 JavaScript 正则表达式
并逐段解释含义，附纯本地测试区验证匹配效果。

## 使用方法

1. 左侧输入自然语言需求（如"匹配中国大陆手机号"）；
2. 右侧配置接口地址、模型名、API Key；
3. 点「生成正则」，正则正文与逐段解释展示在下方；
4. 在测试区粘贴测试文本，点「测试匹配」即时看命中结果。

## 本地测试

测试区是纯 JS 本地计算（`new RegExp` + `matchAll`），不经过网络、
不消耗 Key；正则框可手动修改后再测。非法正则会报中文错。

## BYOK 说明

- API Key 只保存在内存中，刷新/关闭页面即清除，不写 localStorage；
- Key 只出现在请求头中，本站不经手、不记录；
- 接口需兼容 OpenAI 的 `POST {baseURL}/chat/completions` 格式。

## 错误处理

- 需求为空 / 超长显示中文错误；
- 401 / 403 / 404 / 429 / 5xx 翻译为中文提示。
