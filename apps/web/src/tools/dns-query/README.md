# DNS 查询

通过公共 DNS-over-HTTPS（Google `dns.google`）在浏览器内直接查域名记录。

## 用途

不想 dig / nslookup 时，直接在网页上查某个域名现在解析到哪、有哪些 MX / TXT / NS 记录。
走 DoH 是加密的 DNS 查询，且浏览器直连，无需本地装工具。

## 输入

| 字段   | 类型   | 约束                                      |
| ------ | ------ | ----------------------------------------- |
| `text` | string | 域名，如 `example.com`，最大 200,000 字符 |

## 选项

| 选项     | 取值                                         |
| -------- | -------------------------------------------- |
| 记录类型 | `A` / `AAAA` / `CNAME` / `MX` / `TXT` / `NS` |

## 输出

```text
状态码：0 NOERROR（无错误）
Answer（2 条）：
  example.com.  TTL=300  A  93.184.216.34
  example.com.  TTL=300  A  93.184.216.35
```

## 浏览器边界说明

- 数据来自 `https://dns.google/resolve`，若该域名在你的网络被污染 / 被 CORS 插件拦截，
  会报网络错误——这不是工具的 bug，换网络或关闭拦截插件重试
- DoH 结果是查询时刻的实时值，不做缓存

## 限制

- 只查公共记录，不能查反查（PTR）、DNSSEC 细节
- 超长 / 非法域名在发请求前就会报错

## 数据流向

**浏览器发起 fetch（C 类）。** 查询经 Google DoH 出口，不经过本工具后端。`meta.api = false`（固定公共端点，无需 Key）。
