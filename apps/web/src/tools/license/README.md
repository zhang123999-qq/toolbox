# License 生成

选一个开源许可证，填作者与年份，生成可直接落盘为 `LICENSE` 的文本。

## 用途

开仓时不用每次去 choosealicense.com 复制粘贴再手改版权行。

## 输入

| 字段   | 类型   | 约束                        |
| ------ | ------ | --------------------------- |
| `text` | string | 最大 200,000 字符（触发用） |

## 选项

| 选项 key      | 界面   | 取值                                                        |
| ------------- | ------ | ----------------------------------------------------------- |
| `licenseType` | 许可证 | MIT / Apache-2.0 / GPL-3.0 / BSD-3-Clause / ISC / Unlicense |
| `author`      | 作者   | 版权署名                                                    |
| `year`        | 年份   | 4 位数字                                                    |

## 支持的许可证

| 许可证       | 输出内容                         |
| ------------ | -------------------------------- |
| MIT          | 完整 MIT 全文                    |
| ISC          | 完整 ISC 全文                    |
| BSD-3-Clause | 完整三条款 BSD 全文              |
| Apache-2.0   | 版权头 + 许可声明 + 官方正文链接 |
| GPL-3.0      | 版权头 + 授权声明 + 官方正文链接 |
| Unlicense    | 完整 Unlicense 声明              |

> Apache-2.0 / GPL-3.0 正文很长，这里只生成版权头与授权声明，并附官方全文链接；
> 完整文本建议直接从官网下载。

## 数据流向

**纯本地处理。** 无网络请求。`meta.api = false`。

## 示例

MIT，作者 `张三`，年份 `2026`：

```text
MIT License

Copyright (c) 2026 张三

Permission is hereby granted, free of charge, ...
```
