# 文本转二维码

文本生成二维码。

## 用途

把一段文本编成二维码：页面上直接显示 SVG 图，复制 / 下载拿到的是等宽字体下能看出形状的文本块。

## 输入

| 字段   | 类型   | 约束            |
| ------ | ------ | --------------- |
| `text` | string | 最大 2,000 字符 |

要编码的文本（URL、Wi-Fi 配置、纯文本都行）。

## 输出

| 字段   | 类型   | 说明                                                               |
| ------ | ------ | ------------------------------------------------------------------ |
| `text` | string | 页面为 SVG 二维码 + 版本/尺寸/容错等级；复制与下载给出文本块版本。 |

## 选项

| 选项    | 取值                  | 默认 | 说明                             |
| ------- | --------------------- | ---- | -------------------------------- |
| `level` | `L` / `M` / `Q` / `H` | `M`  | 容错等级：越高越抗污损，但也越密 |

## 限制

- **容量有限**：等级 M 下最多约 2331 个 ASCII 字符（中文约 800 字上下），超出会直接报错；本工具把输入上限设在 2,000 字符
- 内容越长二维码越密，扫码器越难识别；URL 建议先做短链
- 中文按 UTF-8 编码进二维码，个别老扫码器可能解不出，需要时先转 Percent-Encoding
- 复制 / 下载拿到的是**文本块**而不是图片；要 SVG 请从页面元素里另存，或用浏览器开发者工具复制
- SVG 用 `image-rendering: pixelated`，放大时保持硬边，不会糊成一团

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
https://example.com/hello
```

输出：

```text
（25×25 的文本块二维码，等宽字体下可直接看出形状）
```
