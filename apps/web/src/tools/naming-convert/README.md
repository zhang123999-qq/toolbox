# 命名转换

驼峰、下划线、中划线、常量、帕斯卡互转。

## 用途

在代码命名风格之间互转：后端 snake_case、前端 camelCase、常量 SCREAMING_SNAKE 等。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

一行一个标识符；空行保留。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                 |
| ------ | ------ | -------------------- |
| `text` | string | 逐行转换后的标识符。 |

## 选项

| 选项   | 取值                                      | 默认  | 说明         |
| ------ | ----------------------------------------- | ----- | ------------ |
| `mode` | camel / pascal / snake / kebab / constant | camel | 目标命名风格 |

## 限制

- 切词基于大小写边界与分隔符，纯中文标识符会被当作一个词（无空格即不拆分）
- 连续缩写（如 HTTPServer → HttpServer）在 pascal 下会变成 HttpServer 而非 HTTPServer
- 数字单独成词（userID2 → user Id 2），如需合并请手动调整

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
hello toolbox world
```

输出：

```text
hello toolbox world
```
