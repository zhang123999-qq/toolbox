# MAC 地址

MAC 地址工具：校验并归一化各种写法，查前 3 字节 OUI 对应的厂商，或随机生成一个
本地管理 MAC。

## 用途

看交换机转发表 / 虚拟机网卡配置时，`b8:27:eb` 是哪家的？
需要给容器 / 测试机器造一个不跟真实网卡冲突的 MAC 时，一键生成。

## 输入

| 字段   | 类型   | 约束                                        |
| ------ | ------ | ------------------------------------------- |
| `text` | string | MAC 串（生成模式下忽略），最大 200,000 字符 |

支持写法：`AA:BB:CC:DD:EE:FF`、`AA-BB-CC-DD-EE-FF`、`AABB.CCDD.EEFF`、`AABBCCDDEEFF`。

## 选项

| 选项   | 标签 | 值                   | 说明                |
| ------ | ---- | -------------------- | ------------------- |
| `mode` | 模式 | `parse` / `generate` | 解析输入 / 随机生成 |

## 输出（解析模式）

```text
标准形式：B8:27:EB:12:34:56
紧凑形式：B827EB123456
OUI：B8:27:EB
厂商：Raspberry Pi
```

## OUI 表

内置约 30 条常见 OUI（Cisco / VMware / VirtualBox / QEMU / Raspberry Pi /
Intel / Dell / Microsoft / Google 等）。未收录的厂商需查 IEEE 官方 OUI 注册表。

## 随机 MAC 说明

生成的 MAC 把首字节设为**本地管理位（bit1=1，组播位 bit0=0）**，即 `x2`/`x6`/`xa`/`xe`
开头，不会与 IEEE 分配的真实网卡冲突，适合 Docker / 虚拟机 / 测试场景。

## 限制

- OUI 表为内置常用项，不是完整 IEEE 注册表
- 生成模式输出含 `Math.random()`，不可复现
- 空输入返回空串；非法格式抛中文错误

## 数据流向

**纯本地处理。** 不发送网络请求。`meta.api = false`。

## 示例

输入：

```text
b8-27-eb-12-34-56
```

输出：

```text
标准形式：B8:27:EB:12:34:56
紧凑形式：B827EB123456
OUI：B8:27:EB
厂商：Raspberry Pi
```
