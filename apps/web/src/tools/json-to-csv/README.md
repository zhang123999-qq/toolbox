# JSON 转 CSV

把对象数组（或单个对象）扁平化为 CSV / TSV，纯本地转换。

## 用途

把接口返回的 JSON 列表导成可在 Excel / Numbers / 数据库里打开的表格；
嵌套对象与数组会按路径摊平成列，多个对象字段不一致时自动取列并集。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 2,000,000 字符 |

支持对象数组 `[{...},{...}]` 或单个对象 `{...}`；不支持标量数组（如 `[1,2]`）。

## 输出

| 字段   | 类型   | 说明                                  |
| ------ | ------ | ------------------------------------- |
| `text` | string | CSV/TSV 文本；空输入 / 空数组返回空串 |

## 选项

| 选项         | 取值                           | 默认      | 说明                                            |
| ------------ | ------------------------------ | --------- | ----------------------------------------------- |
| `delimiter`  | comma / semicolon / tab / pipe | `comma`   | 列分隔符（逗号 / 分号 / Tab / 竖线）            |
| `withHeader` | boolean                        | `true`    | 是否输出首行表头                                |
| `quote`      | needed / all / none            | `needed`  | needed 仅必要时加引号；all 全部加；none 不加    |
| `style`      | flatten / nested               | `flatten` | flatten 摊平嵌套；nested 非标量值 JSON 化进一格 |

## 摊平规则

- 嵌套对象：`{"meta":{"stars":1}}` → 列 `meta.stars`
- 嵌套数组：`{"tags":["a","b"]}` → 列 `tags[0]`、`tags[1]`
- `null`、空对象、空数组 → 空单元格
- 多行列不一致时按首次出现顺序取并集，缺失列为空
- 单元格含分隔符、双引号或换行时按 RFC 4180 用双引号包裹并把 `"` 双写
- 行尾固定 `\n`（如需 Excel 友好的 `\r\n`，可在表格软件里另存）

## 限制

- 全部逻辑为纯 TS 自研，不依赖 npm CSV / json-2-csv 库，行为以本文档为准
- 不做流式处理，2,000,000 字符以上的输入会被拒绝（超大文件请走命令行 / #177）
- 不反向合并重复摊平路径；`nested` 风格里复合值是紧凑 JSON（无空格）
- 输入上限 2,000,000 字符，超限抛 `JsonToCsvError`

## 数据流向

**纯本地处理。** 输入仅在浏览器内存中处理，不发送网络请求，不写入服务端。`meta.api = false`。

## 示例

输入：

```json
[
  { "id": 1, "name": "工具库", "meta": { "stars": 870 } },
  { "id": 2, "name": "另一个", "meta": { "stars": 5 } }
]
```

输出：

```csv
id,name,meta.stars
1,工具库,870
2,另一个,5
```
