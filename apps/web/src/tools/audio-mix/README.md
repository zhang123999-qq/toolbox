# 音频混音

把多路音频按音量配比叠加混音，对齐方式可选，导出为 16 位 PCM WAV。

## 用途

配音叠背景音乐、人声叠和声、多个录音片段叠成一层——需要把几路声音按比例混成一路时用它。

## 输入

| 字段   | 类型   | 约束    | 说明                                           |
| ------ | ------ | ------- | ---------------------------------------------- |
| `file` | File   | 2～8 路 | 通过「添加音频文件」选取（可多选），**不上传** |
| `text` | string | —       | 左侧文本区仅作备注，不参与处理                 |

每路文件用浏览器 Web Audio API 本地解码（支持 wav / mp3 / ogg / m4a 等浏览器可解格式）。

## 输出

| 字段    | 类型   | 说明                             |
| ------- | ------ | -------------------------------- |
| `audio` | WAV    | 混音后的音频，可试听并下载       |
| `text`  | string | 处理报告：各路音轨 / 音量 / 对齐 |

## 选项

| 选项    | 类型 | 默认     | 说明                                                    |
| ------- | ---- | -------- | ------------------------------------------------------- |
| `音量`  | 数字 | 1        | 每路音轨的音量配比，0～2（1 = 100%，可放大到 200%）     |
| `align` | 下拉 | 最短对齐 | 时长对齐：最短对齐 / 最长对齐（补零）/ 最长对齐（循环） |

混音把同采样点的各路声音按音量相加，超出 [-1, 1] 的部分钳制，防止爆音削波。

## 限制

- 参与混音的音频采样率、声道数必须一致，否则中文提示
- 音轨少于 2 路或多于 8 路不能混音
- 输出固定为 16 位 PCM WAV
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音轨（440Hz 与 660Hz 各 3 秒，音量 100% / 50%），默认最短对齐：

```text
音轨 1：示例-440Hz.wav（音量 100%）
音轨 2：示例-660Hz.wav（音量 50%）
对齐方式：最短对齐
输出：3.00 秒　采样率：44100 Hz　声道：1
```

## 数据流向

**纯本地处理。** 解码与混音都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
