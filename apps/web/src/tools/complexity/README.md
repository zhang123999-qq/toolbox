# 代码复杂度

统计 JS / TS / Python 代码的**圈复杂度**（cyclomatic complexity），给出整体分与函数级评级。

## 用途

快速识别「哪个函数太绕、该拆」。圈复杂度 = 1 + 决策点数。

## 输入

| 字段   | 类型   | 约束                      |
| ------ | ------ | ------------------------- |
| `text` | string | 源代码，最大 200,000 字符 |

## 选项

| 选项 key   | 界面 | 取值                             |
| ---------- | ---- | -------------------------------- |
| `language` | 语言 | javascript / typescript / python |

## 计入决策点的语法

- JS/TS：`if` / `else if` / `for` / `while` / `case` / `catch` / 三元 `?` / `&&` / `||` / `??`
- Python：`if` / `elif` / `for` / `while` / `except` / `return`（近似出口计数）

## 评级

| 分数  | 评级               |
| ----- | ------------------ |
| ≤ 5   | A 清晰             |
| 6–10  | B 可接受           |
| 11–20 | C 复杂，考虑拆分   |
| > 20  | D 高风险，必须重构 |

## 限制

- **正则粗扫**，不是完整 AST：字符串 / 注释里的关键字也会被计数，结果偏高
- 函数切分用正则，箭头函数与方法的识别不完整，仅供快速体检
- 不做行数 / 维护指数等其它指标

## 数据流向

**纯本地处理。** 无网络请求。`meta.api = false`。
