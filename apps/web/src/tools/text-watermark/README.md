# 文本水印

零宽字符隐藏水印。

## 用途

把一小段标识（作者、分发对象、时间）编成零宽字符藏进正文：肉眼看不出变化，复制粘贴时会跟着走，需要时用「读水印」把它解回来。

## 输入

| 字段        | 类型   | 约束                        |
| ----------- | ------ | --------------------------- |
| `text`      | string | 最大 100,000 字符           |
| `watermark` | string | 水印内容，最大 100,000 字符 |

正文 + 水印内容。加水印模式用得到水印内容，读水印模式只读正文。

## 输出

| 字段   | 类型   | 说明                                                 |
| ------ | ------ | ---------------------------------------------------- |
| `text` | string | 加水印输出藏好水印的正文；读水印输出解出的水印原文。 |

## 选项

| 选项   | 取值                | 默认    | 说明            |
| ------ | ------------------- | ------- | --------------- |
| `mode` | `embed` / `extract` | `embed` | 加水印 / 读水印 |

## 限制

- **是隐写不是加密**：任何人用 #58 文本去水印或 #42 零宽字符都能把水印抹掉，也能用本工具的 `extract` 读出来；它只用于追溯来源，不能防篡改
- 水印编码用 U+200C（位 0）与 U+200D（位 1），每个字节占 8 个零宽字符，所以长水印会明显拉长文本
- 水印插在**正文末尾**：中间插入可能打断连字与双向文本排版
- 复制经过「自动清洗」的渠道（部分富文本编辑器、聊天软件、OCR）会丢掉零宽字符，水印随之丢失
- 位流不是 8 的整数倍或解不出合法 UTF-8 时，一律报「没有解出隐藏内容」
- 输入上限 100,000 字符；水印内容上限 200 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
这是一段需要追溯来源的内部文本。
```

水印内容：

```text
alice@example.com
```

输出：

```text
（肉眼看与输入完全一致，实际末尾多出 136 个零宽字符）
```
