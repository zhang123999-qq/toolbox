# JSON 格式化

格式化、压缩、校验 JSON，支持树形查看。

## 用途

将压缩或混乱的 JSON 文本重新排版，便于阅读与排查；也可按键名排序、切换缩进档位。

## 输入

| 字段 | 类型 | 约束 |
|---|---|---|
| `text` | string | 最大 5,000,000 字符 |

## 输出

| 字段 | 类型 | 说明 |
|---|---|---|
| `text` | string | 格式化后的 JSON；输入为空时返回空字符串 |

## 选项

| 选项 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `indent` | `2` / `4` | `2` | 缩进空格数 |
| `sortKeys` | boolean | `false` | 是否按键名递归排序 |

## 限制

- 输入上限 5MB，超出抛出 `JsonFormatError`
- 超大 JSON 未接入 Web Worker（可行性 A，阶段 0 直接在主线程处理）
- 不支持 JSONC（注释）与尾随逗号

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```json
{"name":"工具库","tools":870,"local":true}
```

输出（indent=2）：

```json
{
  "name": "工具库",
  "tools": 870,
  "local": true
}
```
