# CSV 转 TSV

CSV 与 TSV 互转。

## 用途

在 CSV 与 TSV 之间互转：Excel 用 CSV、命令行与数据库导入常用 TSV（字段里不易出现制表符）。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

CSV 或 TSV 文本（首行可含表头）。最大 200,000 字符。

## 输出

| 字段   | 类型   | 说明                                            |
| ------ | ------ | ----------------------------------------------- |
| `text` | string | 转换后的文本，引号与转义由 papaparse 统一处理。 |

## 选项

| 选项   | 取值              | 默认    | 说明     |
| ------ | ----------------- | ------- | -------- |
| `mode` | csv2tsv / tsv2csv | csv2tsv | 转换方向 |

## 限制

- 依赖 papaparse，按 RFC 4180 处理引号转义；行列不规则时以最长行为准
- 不校验表头与类型，纯文本层面转换
- 字段内的换行会被保留（被引号包裹），转 TSV 后仍是多行字段

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
name,tools
工具库,870
```

输出：

```text
name,tools,local
工具库,870,true
"含,逗号",1,false
```
