# 抄袭检测 Plagiarism Check（#605）

多篇文档两两比对文本相似度，标出高度相似的片段。
算法：字符级 shingle n-gram（n=5）+ Jaccard 相似度，中英文通用。

## 使用方法

1. 左侧粘贴文档 A，附加输入框粘贴文档 B（可选文档 C），每篇至少 20 字符；
2. 右上角选择相似度阈值（默认 0.3）；
3. 点「开始比对」：文档对按相似度降序列出，达到阈值的对会标出相似句子及各自相似度。

## 诚实说明

- 只做**文档之间**的两两比对，**不做全网查重**；
- 相似度是文本重合度的度量，不是法律意义上的"抄袭"判定；
- 全部计算在浏览器本地完成，不上传任何内容。

## 相似度等级

- ≥60%：高度相似
- ≥30%：中度相似
- > 0%：轻微相似
- 0%：无相似
