# 时间戳生成

把一个日期时间（可指定它落在哪个时区）换算成 Unix 秒 / 毫秒时间戳。

## 用途

和「时间戳转换」方向相反：排接口、写脚本时手里是一个可读时间，需要它对应的 Unix 时间戳。
关键是要说明这个时间是「哪个时区看到的」——同样写 `15:30:00`，上海时间和纽约时间对应的时间戳差了 12 小时。

## 输入

| 字段   | 类型   | 约束                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 日期时间串，最大 200,000 字符 |

支持 `YYYY-MM-DD`、`YYYY/MM/DD`，可附 `HH:mm[:ss]`。

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 输入回显、Unix 秒 / 毫秒、UTC 时间 |

```text
输入：2026-09-27 15:30:00（Asia/Shanghai）
Unix 秒：1790494200
Unix 毫秒：1790494200000
UTC：2026-09-27 07:30:00
```

## 选项映射

| 选项 key | 界面标签           | 语义                                               |
| -------- | ------------------ | -------------------------------------------------- |
| `zone`   | 时区（留空为本地） | 输入墙上时间所在的 IANA 时区；留空按浏览器本地时区 |

## 实现规则 / 算法

1. 解析出墙上时间分量；带时区时，用「墙上时间 → UTC 反推偏移」得到真实 UTC 毫秒时刻：
   - 先把分量当作 UTC 猜一个时刻，查该时区此时偏移并修正；
   - DST 跳变日再按修正后时刻复查一次偏移（两次迭代即收敛）。
2. 不带时区时，直接用本地 `Date(y, m-1, d, h, mi, s)` 解释。
3. 秒 = `floor(ms/1000)`，毫秒 = `ms`。

## 浏览器 / 运行时边界

- 时区规则来自运行时 ICU；各国改 DST 后需升级浏览器/Node。
- 留空时区时依赖浏览器本地时区；服务器渲染或 CI 环境下本地时区可能与你预期不同。
- 必须用 IANA 名，不接受 `GMT+8` 这类固定偏移。
- 非法日期（如 2 月 30 日）直接报错，不静默进位。

## 示例

输入：

```text
2026-09-27 15:30:00
```

选项：时区 `Asia/Shanghai`。

输出：

```text
输入：2026-09-27 15:30:00（Asia/Shanghai）
Unix 秒：1790494200
Unix 毫秒：1790494200000
UTC：2026-09-27 07:30:00
```
