# 批量重命名

批量为文件加前缀、按序号或查找替换改名，导出对照表与重命名包。

## 用途

相册里几百张 `IMG_001.jpg` 要统一改成 `trip_001.jpg`；下载的一批文件名前缀杂乱要统一；文件名里有错字要批量替换。

## 输入

| 字段   | 类型   | 约束                 | 说明                       |
| ------ | ------ | -------------------- | -------------------------- |
| `file` | File[] | 多选，总量 ≤ 200 MiB | 待重命名的文件，**不上传** |

## 输出

| 字段   | 类型   | 说明                                          |
| ------ | ------ | --------------------------------------------- |
| `text` | string | 重命名对照表：`原名 → 新名`                   |
| `file` | binary | `renamed.zip`：重命名后的文件 + `mapping.txt` |

## 选项

| 选项      | 取值                      | 默认   | 说明                                       |
| --------- | ------------------------- | ------ | ------------------------------------------ |
| `rule`    | prefix / number / replace | prefix | 加前缀 / 按序号 / 查找替换                 |
| `prefix`  | string                    | `IMG_` | 前缀（加前缀规则必填；序号规则作编号前缀） |
| `find`    | string                    | 空     | 查找内容（查找替换规则必填）               |
| `replace` | string                    | 空     | 替换为                                     |
| `start`   | number                    | 1      | 起始编号                                   |
| `digits`  | number                    | 3      | 编号位数（补零，如 `001`）                 |

## 限制

- **文件总量上限 200 MiB**；单次最多 2000 个文件
- 重名自动消解：同名新文件追加 ` (2)` / ` (3)`
- 非法文件名（`/:*?"<>|`）自动替换为下划线
- 扩展名保留，原样跟随
- 全程本地处理，`renamed.zip` 用 fflate 无压缩打包

## 数据流向

**纯本地处理。** 文件只在浏览器内存里读字节、打包，`meta.api = false`，无需自备 API/Key。

## 示例

输入：`photo1.jpg`、`photo2.jpg`，规则加前缀 `trip_`。

输出：

```text
批量重命名对照表

1. photo1.jpg → trip_photo1.jpg
2. photo2.jpg → trip_photo2.jpg
```

同时下载 `renamed.zip`（内含 `trip_photo1.jpg`、`trip_photo2.jpg`、`mapping.txt`）。
