# 页面标题检查

检查页面标题的 SEO 质量：计算显示宽度、模拟 Google SERP 截断、检测目标关键词是否前置、找出重复词，并给出中文优化建议。纯前端本地计算，无网络请求。

## 用途

写文章 / 产品页标题时，先看它在搜索结果里会不会被截断、关键词有没有放前面、有没有啰嗦的重复词，一次给出可执行的优化建议。

## 显示宽度规则

- 半角字符（U+0000–U+00FF，如英文、数字、半角标点）计 **1**
- 其余字符（中文、全角标点、emoji 等）计 **2**，按 Unicode 码点遍历统计

## 评级标准

| 显示宽度 | 评级 | 说明                                  |
| -------- | ---- | ------------------------------------- |
| < 30     | 过短 | 信息量不足，建议扩充到 30–60 显示宽度 |
| 30–60    | 合适 | SERP 内完整展示                       |
| > 60     | 过长 | Google 约 60 宽度后截断，重要信息前置 |

## 输入

| 字段   | 类型   | 约束                        |
| ------ | ------ | --------------------------- |
| `text` | string | 页面标题，最大 200,000 字符 |

## 选项

| 选项       | 类型   | 说明                                            |
| ---------- | ------ | ----------------------------------------------- |
| 目标关键词 | string | 可选；检测是否出现在标题前半部分（前 50% 字符） |

## 输出示例

```text
标题：2026年最好的10款无线耳机推荐：实测对比与选购指南
字符数：27
显示宽度：48
评级：合适
目标关键词：无线耳机
关键词前置：否
重复词：无
含数字：是
含年份：是
建议：
- 目标关键词未前置，建议放到标题前部
```

## 限制

- SERP 截断宽度（60）是经验值，不同设备 / 语言实际截断点略有差异
- 中文按单字分词找重复词，不做语义去重（如「耳机」与「耳麦」视为不同词）
- 关键词前置只看前 50% 字符是否包含，不做分词匹配

## 数据流向

**纯本地计算（A 类）。** 无 fetch、无 WASM、无 Worker。`meta.api = false`。
