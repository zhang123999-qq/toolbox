# 发票生成

填写购销双方、发票号、日期与项目明细，实时预览样式化发票；可复制纯文本、下载独立 HTML 文档，或导出 PNG 图片。

## 用途

- 自由职业者 / 小微企业给客户开形式发票（proforma invoice）
- 报价单、结算单的快速排版与存档
- 需要把费用明细做成图片发给对方的场景

## 输入

| 字段     | 类型   | 约束                                  |
| -------- | ------ | ------------------------------------- |
| 购买方   | string | 最多 200 字符，可空                   |
| 销售方   | string | 最多 200 字符，可空                   |
| 发票号   | string | 最多 100 字符，可空                   |
| 日期     | string | 日期选择器，默认今天，可空            |
| 项目明细 | string | 每行一项，格式 `名称,数量,单价`，必填 |
| 备注     | string | 最多 1000 字符，可空                  |

明细行分隔符支持半角逗号 `,`、全角逗号 `，`、空格、制表符（可混用）；
名称本身不能包含这些分隔符。

## 输出

右列实时预览样式化发票；「复制」与「下载 HTML」使用下面的纯文本 / HTML 版本。

```text
发票
发票号：INV-20260927-001
日期：2026-09-27
购买方：示例科技有限公司
销售方：某某服务有限公司
--------------------------------
1. 咨询服务 × 2 @ ¥500.00 = ¥1,000.00
2. 技术支持 × 1 @ ¥1,200.00 = ¥1,200.00
--------------------------------
共 2 项
小计：¥2,200.00
税额（6%）：¥132.00
总额：¥2,332.00
备注：示例备注
```

## 选项

| 选项      | 类型   | 说明                            |
| --------- | ------ | ------------------------------- |
| `taxRate` | select | 税率：`0` `3` `6` `9` `13`（%） |

## 算法

- 明细解析：按行切分，空行跳过；每行按 `/[ \t]+|[,，]/` 切分（空白连写折叠、逗号连写保留空段）→ 名称 / 数量 / 单价
- 小计：每行 `数量 × 单价` 先转「分」四舍五入、用整数求和再转回元，避免 `0.1 × 3 ≠ 0.3` 类浮点误差
- 税额 = 小计 × 税率 / 100；总额 = 小计 + 税额
- 金额格式化：`¥` + 千分位 + 2 位小数（手动实现，不用 `Intl`，保证各环境一致）
- PNG 导出：`html-to-image` 的 `toPng` 对预览区 DOM 截图后触发下载

## 边界

- 明细为空 → 输出区显示 idle 提示，不进错误态
- 行格式不对 → 中文报错「第 N 行格式错误，应为"名称,数量，单价"」（N 为原文物理行号）
- 名称为空 → 「第 N 行名称不能为空」；数量 ≤ 0 或非数字 → 「第 N 行数量必须大于 0」；
  单价为负或非数字 → 「第 N 行单价不能为负数」；全部空行 → 「请至少填写一项明细」
- 数量支持小数（如 `2.5`），单价为 `0` 允许（赠品行）
- PNG 导出失败不弹 `alert`，错误显示在输出区（`role="alert"`）

## 示例

购买方 `示例科技有限公司`，明细：

```text
咨询服务,2,500
技术支持,1,1200
```

税率 `6%` → 小计 ¥2,200.00，税额 ¥132.00，总额 **¥2,332.00**。

## English

An invoice generator: fill in buyer/seller, invoice number, date and line items
(`name,qty,unit-price` per line), get a live styled preview, then copy as text,
download a standalone HTML document, or export a PNG image via `html-to-image`.
Subtotals are summed in integer cents to avoid floating-point errors;
tax = subtotal × rate / 100.
