# 情感分析

本地轻量情感倾向分析。

## 用途

批量看评论、反馈、问卷的文本倾向，先粗筛再看原文，不适合作为唯一判定依据。

## 输入

| 字段   | 类型   | 约束             |
| ------ | ------ | ---------------- |
| `text` | string | 最大 50,000 字符 |

英文或中文短文本；建议一次一段。最大 50,000 字符。

## 输出

| 字段   | 类型   | 说明                                                |
| ------ | ------ | --------------------------------------------------- |
| `text` | string | 总体倾向与得分（-1～1）、褒贬词计数、逐句得分明细。 |

## 选项

| 选项       | 取值           | 默认 | 说明                              |
| ---------- | -------------- | ---- | --------------------------------- |
| `language` | auto / en / zh | auto | 语言口径；auto 按中文字符占比判断 |

## 限制

- 基于内置小型褒贬词表（各约 20 条），只做词面匹配，不理解否定、反讽与上下文
- 中文按子串包含匹配，无分词器；英文按非字母切词
- 得分只反映命中词的相对比例，不代表强度；褒贬数量相同即为中性
- 文档把本工具标为可行性 B（WASM），当前实现在 JS 侧完成，接口保持一致

## 数据流向

**纯本地处理。** 词表与计算都在浏览器内，不发送任何网络请求。`meta.api = false`，无需自备 API/Key。

> 文档把本工具标为可行性 B，`meta.wasm = true` 表示该位已预留；当前实现用 compromise
> 完成英文分句与词形归一，后续若换成 WASM 词典，输入输出接口不变。

## 示例

输入：

```text
This toolbox is great and fast.
```

输出：

```text
This toolbox is great and fast. But the settings are confusing and slow.
```
