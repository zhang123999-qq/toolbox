# 私钥生成（#692）

生成以太坊 secp256k1 私钥：32 字节密码学安全随机数（`crypto.getRandomValues`），范围校验 `1 ≤ k < n`，支持批量（1–100）与 `0x` 前缀开关。

## 安全警告

- **浏览器生成的私钥仅供学习与测试**，请勿用于存放真实资金。
- 生产环境请使用硬件钱包或受审计的专业工具生成并保管私钥。
- 私钥只存在于当前页面内存中，不上传、不写入任何存储；关闭/刷新页面即丢失，请自行妥善备份测试用私钥。

## 输出

每行一个私钥，64 位十六进制（可选 `0x` 前缀）：

```
0x3a7bd3e2360a3d29a3dd...（64 位）
```

## 说明

- 纯前端实现，不联网，随机源为 Web Crypto API。
- 生成时做 secp256k1 曲线阶范围校验，无效值自动重采。
