# 行号添加

每行添加行号，支持格式。

## 用途

给代码、日志、清单加上行号，方便在文档或讨论里指认「第几行」；也用来把带编号的文本整理整齐。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

多行文本。行号从 1 开始，按总行数决定补位宽度。

## 输出

| 字段   | 类型   | 说明                                                   |
| ------ | ------ | ------------------------------------------------------ |
| `text` | string | 加了行号的文本，行号与原文之间用所选样式的分隔符连接。 |

## 选项

| 选项        | 取值                                      | 默认                   | 说明                         |
| ----------- | ----------------------------------------- | ---------------------- | ---------------------------- |
| `format`    | `dot`（1. ） / `colon`（1: ） / `pipe`（1 | ） / `bracket`（[1] ） | `dot`                        | 行号样式 |
| `align`     | 勾选 / 取消                               | 勾选                   | 行号按最大位数左补空格对齐   |
| `skipEmpty` | 勾选 / 取消                               | 取消                   | 跳过空行不编号（编号仍连续） |

## 限制

- 只做添加，不提供「去掉行号」的反向操作（可用「正则替换」#34 用 `^\d+\.\s*` 替换为空）
- 不识别原文里已有的行号：已带编号的文本会被再加一层
- 对齐用**半角空格**补位，等宽字体下才对齐；中日韩字符占两个字符宽，混排时仍可能对不齐
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
第一行
第二行
第三行
```

输出：

```text
第一行
第二行
第三行
```
