# 文件切分

按指定大小或数量把大文件切成多个分片，逐个下载。

## 用途

网盘 / 邮件附件有单文件大小限制时，把大文件切成 10MB 一片分批传；对方按顺序拼接即可还原。

## 输入

| 字段   | 类型   | 约束           | 说明                                                     |
| ------ | ------ | -------------- | -------------------------------------------------------- |
| `file` | File   | 单个 ≤ 200 MiB | 待切分的文件，**不上传**                                 |
| `text` | string | 切分参数       | 按大小：`10MB` / `512KB` / `1.5GB` / `1024`；按数量：`5` |

## 输出

| 字段   | 类型   | 说明                                            |
| ------ | ------ | ----------------------------------------------- |
| `file` | binary | 分片文件，命名如 `report.part001.pdf`，逐个下载 |
| `text` | string | 切分报告：模式、片数、分片清单                  |

## 选项

| 选项   | 取值         | 默认 | 说明                |
| ------ | ------------ | ---- | ------------------- |
| `mode` | size / count | size | 按大小 / 按数量切分 |

## 限制

- **单个文件上限 200 MiB**（需整体读进内存）；**空文件直接报错**
- 分片数上限 10000：按大小算出更多片会中文报错，请调大分片大小
- 参数格式不对（`zzz`、`-5MB`）中文报错并给示例
- 分片序号按总片数对齐（`part001`…`part120`），无扩展名的文件也支持
- 还原：按文件名顺序把分片二进制拼接即可（`cat x.part* > x`）

## 数据流向

**纯本地处理。** 文件只在浏览器内存里切分，`meta.api = false`，无需自备 API/Key。

## 示例

输入：`demo.bin`（16 字节），按大小 `4B`。

输出：

```text
切分完成（按大小）：demo.bin
原文件 16 B → 4 个分片

分片清单：
1. demo.part1.bin（4 B）
2. demo.part2.bin（4 B）
3. demo.part3.bin（4 B）
4. demo.part4.bin（4 B）
```
