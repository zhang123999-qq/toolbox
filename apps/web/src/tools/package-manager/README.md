# 包管理命令

在 npm / yarn / pnpm 三者之间切换时，子命令名经常记混。本工具按你选的包管理器输出一张常用命令对照表。

## 用途

把「安装 / 卸载 / 运行脚本 / 发布 / 审计」等 20 个高频动作翻译成当前包管理器的具体命令，
不用再去翻文档。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作触发用，内容不参与生成。

## 选项

| 选项 key | 界面     | 取值                    |
| -------- | -------- | ----------------------- |
| `pm`     | 包管理器 | `npm` / `yarn` / `pnpm` |

## 输出

一张 Markdown 表格：动作 → 当前包管理器的命令。

## 数据流向

**纯本地处理。** 无网络请求。`meta.api = false`。

## 示例

输入（触发用）：`cheatsheet`，包管理器选 `pnpm`：

```text
# pnpm 常用命令速查

| 动作 | 命令 |
| ---- | ---- |
| 安装全部依赖 | `pnpm install` |
| 安装依赖包 | `pnpm add <pkg>` |
…
```
