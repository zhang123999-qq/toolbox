# 纹理打包（#787）

用 shelf 装箱算法把多张小图打包成一张纹理图集（Texture Atlas），计算每个矩形的布局坐标、图集尺寸与空间利用率，并可导出图集 JSON。

## 输入

JSON 对象：

```json
{
  "rects": [
    { "id": "hero", "w": 64, "h": 64 },
    { "id": "coin", "w": 16, "h": 16 }
  ],
  "maxWidth": 128
}
```

- `rects`：矩形列表，`id` 唯一且非空，`w`/`h` 为正整数
- `maxWidth`：图集最大宽度（px），矩形宽度不得超过它

## 功能

- **计算布局**：按高度降序排列，逐行（shelf）放置，输出每块的 `x/y/w/h`
- **导出图集 JSON**：`{ meta: { size, utilization }, frames: { id: {x,y,w,h} } }`，可下载 `atlas.json`
- **下载布局预览**：生成图集布局示意图 PNG

## 说明

- 纯前端本地计算，不发送任何网络请求
- shelf 算法为启发式装箱，不保证理论最优，但确定性强、速度快
