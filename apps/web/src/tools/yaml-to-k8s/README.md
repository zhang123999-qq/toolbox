# YAML 转 K8s

粘贴一段 K8s 资源 YAML，做必需字段校验并重新格式化输出。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 校验项

- `apiVersion`
- `kind`
- `metadata.name`

## 说明

- 用自研轻量 YAML 解析器（支持 `key: value`、列表、2-3 层嵌套），**未引入 js-yaml**
- 解析失败抛中文错误（缩进异常 / 行无法解析）
- 输出 = 校验结果 + 2 空格缩进的格式化 YAML

## 限制

- 不支持锚点 `&`/`*`、多行块标量 `|`/`>`、flow 风格 `{}`/`[]`
- 只校验三个必需字段，不做完整 schema 校验

## 数据流向

**纯本地处理。** `meta.api = false`。
