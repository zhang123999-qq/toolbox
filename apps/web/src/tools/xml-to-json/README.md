# XML 转 JSON

把 XML 转成 JSON，属性前缀、文本节点键名与数组归一策略可配。

## 用途

把接口返回的 XML、配置文件、RSS / SVG 元数据等转成 JSON，便于在 JS 里直接消费。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 2,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                      |
| ------ | ------ | ------------------------- |
| `text` | string | JSON 文本；空输入返回空串 |

最外层键为根元素名（与 xml2js 默认行为一致）。

## 选项

| 选项      | 取值                        | 默认    | 说明                         |
| --------- | --------------------------- | ------- | ---------------------------- |
| `prefix`  | `@` / `_` / `$`             | `@`     | 属性名前缀，用于和子元素区分 |
| `mode`    | `auto` / `always` / `never` | `auto`  | 同名子元素的数组归一策略     |
| `textKey` | `#text` / `value` / `text`  | `#text` | 混合内容里文本节点使用的键名 |
| `indent`  | `0` / `2` / `4`             | `2`     | JSON 缩进，`0` 为单行压缩    |

`mode` 的三种取值：

- `auto`：同名子元素出现多次才归一成数组，单个时直接输出标量
- `always`：一律输出成数组，方便下游无脑遍历
- `never`：不做归一，同名重复时后出现的覆盖前面的

## 转换规则

1. 没有属性、也没有子元素的元素，直接退化成字符串：`<a>hello</a>` → `{"a":"hello"}`
2. 有属性或有子元素时输出对象：属性键加 `prefix`，文本节点落在 `textKey` 上
3. 标签之间的缩进空白视为排版噪音，会被丢弃；CDATA 内容原样保留
4. 注释、处理指令（`<?xml ... ?>`）、DOCTYPE 不进入 JSON
5. 所有值都是字符串，不做数字 / 布尔的类型推断（XML 本身没有类型信息）

## 限制

- 输入上限 2,000,000 字符，超出抛出 `XmlToJsonError`
- 不解析 DTD 内部子集声明的实体，只认 XML 预定义的 5 个实体与数字字符引用
- 不做命名空间处理，`xsi:type` 这类带冒号的属性名会原样保留
- 混合内容（文本与子元素交错）会把所有文本拼接成一个值，不保留原始顺序

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```xml
<catalog>
  <book id="1"><title>工具库</title><price>29.9</price></book>
  <book id="2"><title>XML 入门</title><price>39</price></book>
</catalog>
```

输出（`indent=2`）：

```json
{
  "catalog": {
    "book": [
      { "@id": "1", "title": "工具库", "price": "29.9" },
      { "@id": "2", "title": "XML 入门", "price": "39" }
    ]
  }
}
```
