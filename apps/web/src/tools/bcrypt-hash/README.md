# Bcrypt 哈希

用 bcrypt 给口令生成哈希并校验，cost（轮数）可调。

## 用途

生成可直接存库的 bcrypt 哈希（`$2b$10$…`），或拿一个已有哈希验证某段口令是否匹配。
适合排查「登录总是失败」——把库里的哈希和用户输入丢进来比对一次就知道是口令错还是哈希错。

## 输入

| 字段   | 类型   | 约束              | 说明                            |
| ------ | ------ | ----------------- | ------------------------------- |
| `text` | string | 最大 200,000 字符 | 口令（哈希时）或待验证的口令    |
| `hash` | string | bcrypt 哈希串     | 仅校验方向使用，形如 `$2b$10$…` |

## 输出

| 字段   | 类型   | 说明                                                     |
| ------ | ------ | -------------------------------------------------------- |
| `text` | string | 哈希串（60 字符），或校验结论（`校验通过` / `校验失败`） |

## 选项

| 选项        | 取值                | 默认 | 说明                              |
| ----------- | ------------------- | ---- | --------------------------------- |
| `direction` | hash / verify       | hash | 生成哈希或校验口令                |
| `cost`      | 4 / 6 / 8 / 10 / 12 | 8    | 2^cost 轮扩展；每 +1 大约翻倍耗时 |

## 限制

- **bcrypt 只处理口令前 72 字节**，超长口令会被截断（UTF-8 中文按 3 字节计）
- 盐是随机生成的：**同一口令每次哈希结果都不同**，这是设计如此，不能用来判断实现是否一致
- cost 越大越慢：浏览器里纯 JS 实现在 cost=12 时需数秒，故默认取 8
- `verify` 方向要求哈希串严格合法（`$2a$` / `$2b$` / `$2y$` + 两位 cost + 53 字符），
  否则报错而不是给出「校验失败」的假结论
- 校验失败是**结论**而不是异常，输出 `校验失败：…`

## 数据流向

**纯本地处理。** 口令只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（哈希方向）：

```text
P@ssw0rd-demo
```

输出（cost=8，每次不同）：

```text
$2b$08$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
```
