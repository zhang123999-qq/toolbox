# 视频格式识别

读取文件头魔数，识别视频文件真实格式（扩展名可伪造，魔数不会）。

## 用途

下载的视频扩展名不对、播放器打不开时，先看看到底是什么格式，再决定用什么软件打开或转码。

## 输入

| 字段   | 类型   | 约束 | 说明                                 |
| ------ | ------ | ---- | ------------------------------------ |
| `file` | File   | 任意 | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —    | 左侧文本区仅作备注，不参与处理       |

只读取文件前 64 字节头做识别，不解码整文件，速度极快。

## 输出

| 字段   | 类型   | 说明                                  |
| ------ | ------ | ------------------------------------- |
| `text` | string | 识别报告：文件名 / 大小 / 格式 / 依据 |

## 支持的格式

| 格式      | 魔数依据                              |
| --------- | ------------------------------------- |
| MP4 视频  | `ftyp` 主品牌（isom/mp42/avc1 等）    |
| MOV 视频  | `ftyp` 主品牌 `qt`（QuickTime）       |
| 3GP 视频  | `ftyp` 主品牌（3gp4/3gp5 等）         |
| WebM 视频 | EBML 头 + DocType=webm                |
| MKV 视频  | EBML 头 + DocType=matroska            |
| AVI 视频  | `RIFF....AVI `                        |
| FLV 视频  | `FLV` + 版本 0x01                     |
| TS 视频流 | `0x47` 同步字节（188 字节包对齐确认） |
| WMV 视频  | ASF 容器 GUID                         |
| Ogg 视频  | `OggS`（Theora 等）                   |

识别不出、文件头截断、空文件都会给出中文说明，不会静默失败。

## 限制

- 只看魔数不校验文件完整性：头对但内容损坏的文件仍会显示"识别成功"
- 输出为识别报告文本，不做转码

## 示例

载入示例视频（最小 MP4 ftyp 头）：

```text
文件：示例.mp4
大小：24 B
识别结果：MP4 视频
依据：ftyp 主品牌：isom
```

## 数据流向

**纯本地处理。** 只读文件头 64 字节，`meta.api = false`，无需自备 API/Key。
