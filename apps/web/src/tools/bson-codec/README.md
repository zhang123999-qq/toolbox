# BSON 编解码

BSON（MongoDB 的二进制 JSON）常用类型编解码：JSON 与 BSON 字节互转，输出 hex / base64 与 JSON 预览。

编解码由本工具自己实现的纯 TS 代码完成，不依赖 `bson` 这个 npm 包。

## 用途

- 看一条 MongoDB 文档打成 BSON 后长什么样（对比 JSON 的体积差异）
- 拿到一段 BSON 字节（抓包、oplog、导出文件片段），还原成可读的 JSON
- 对照字段类型号学习 BSON 的编码布局

## 输入

| 字段   | 类型   | 约束                                                                       |
| ------ | ------ | -------------------------------------------------------------------------- |
| `text` | string | 编码模式为 JSON 对象；解码模式为字节串（hex 或 base64）；最大 500,000 字符 |

## 输出

| 字段   | 类型   | 说明                                                                            |
| ------ | ------ | ------------------------------------------------------------------------------- |
| `text` | string | 编码结果（hex/base64 + JSON 预览）或解码结果（JSON + 类型统计）；空输入返回空串 |

## 选项

| 选项     | 取值                | 默认     | 说明                                       |
| -------- | ------------------- | -------- | ------------------------------------------ |
| `mode`   | `encode` / `decode` | `encode` | 编码（JSON → 字节）还是解码（字节 → JSON） |
| `format` | `hex` / `base64`    | `hex`    | 编码结果用哪种形式展示                     |

## 支持的元素类型

| 类型号 | 名称     | JSON 侧写法                                     |
| ------ | -------- | ----------------------------------------------- |
| `0x01` | double   | 非整数数字，或 `{"$numberDouble": "1.5"}`       |
| `0x02` | string   | 字符串                                          |
| `0x03` | document | 嵌套对象                                        |
| `0x04` | array    | 数组（内部按 `0`、`1`、`2`… 为键的文档存）      |
| `0x05` | binary   | `{"$binary": {"subType": 0, "data": "0a0b"}}`   |
| `0x07` | objectId | `{"$oid": "507f1f77bcf86cd799439011"}`          |
| `0x08` | boolean  | `true` / `false`                                |
| `0x09` | datetime | `{"$date": 1700000000000}`（毫秒时间戳）        |
| `0x0A` | null     | `null`                                          |
| `0x10` | int32    | 落在 int32 范围内的整数，或 `{"$numberInt": 1}` |
| `0x12` | int64    | `{"$numberLong": "9007199254740993"}`           |

## 限制

- **只实现上面 11 种常用类型**。不支持的类型（编码时按类型遇到、解码时按类型号识别）会直接抛错并给出类型号，包括：
  - `0x0B` regex、`0x0C` dbpointer、`0x0D` javascript、`0x0E` symbol、`0x0F` code w/ scope
  - `0x11` timestamp、`0x13` decimal128、`0x7F` min key、`0xFF` max key
  - 已废弃的 `0x06` undefined
- 数组解码时按数字键排序还原；键不是连续数字的「伪数组」会按文档键序输出
- ObjectId 只做 24 位十六进制的形式校验，不校验其时间戳 / 机器码语义
- binary 的 `subType` 只给可读说明（generic / uuid / user-defined 等），不做 UUID 解析
- 顶层必须是 BSON 文档（JSON 对象），数组 / 标量顶层会报错
- 解码要求字节串是**完整文档**：声明长度必须等于实际字节数，否则报「长度不一致」
- 输入上限 500,000 字符，嵌套上限 64 层；非法输入抛出 `BsonCodecError`（中文提示）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（编码模式）：

```json
{ "hello": "world" }
```

输出：

```
# BSON 编码

hex   : 160000000268656c6c6f0006000000776f726c640000
字节数: 22

分组视图：
  16 00 00 00 02 68 65 6c 6c 6f 00 06 00 00 00 77 6f 72 6c 64 00 00

解码回读（JSON 预览）：
{
  "hello": "world"
}
```
