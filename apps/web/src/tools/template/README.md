# 模板变量替换

用变量替换模板占位符。

## 用途

把「模板 + 变量表」渲染成最终文本：批量生成邮件、通知、SQL、配置片段时，改一遍变量就能出一批文案。

## 输入

| 字段   | 类型   | 约束             |
| ------ | ------ | ---------------- |
| `text` | string | 最大 50,000 字符 |

上半部分是模板正文，中间用**独占一行的 `---`** 分隔，下半部分是变量定义（每行一条 `key=value`；值两端的空白会被去掉，需要保留首尾空格请用引号包裹）。

## 输出

| 字段   | 类型   | 说明                                                         |
| ------ | ------ | ------------------------------------------------------------ |
| `text` | string | 替换后的文本。未提供的变量按「保留未提供的占位符」选项处理。 |

## 选项

| 选项          | 取值                                             | 默认       | 说明                               |
| ------------- | ------------------------------------------------ | ---------- | ---------------------------------- |
| `syntax`      | `mustache`（`{{name}}`） / `dollar`（`${name}`） | `mustache` | 占位符语法                         |
| `keepMissing` | 勾选 / 取消                                      | 勾选       | 未提供的变量是保留原样还是替换为空 |

## 限制

- 变量名只允许字母、数字、下划线、点、连字符，且必须以字母或下划线开头
- 不支持过滤器、条件、循环等模板语法，只做纯变量替换
- 变量值不做转义：放进 HTML / SQL 场景请自行转义
- 模板里若本身含独占一行的 `---`，会被当成变量区的分隔线，请改用其他分隔方式
- 输入上限 50,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
你好 {{name}}，欢迎使用 {{product}}！
---
name=张三
product=工具箱
```

输出：

```text
你好 {{name}}，欢迎使用 {{product}}！
---
name=张三
product=工具箱
```
