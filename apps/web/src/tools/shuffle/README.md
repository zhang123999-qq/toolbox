# 文本乱序

按行、按词随机打乱。

## 用途

把清单、抽签名单、单词表随机打乱：背书顺序、抽奖名单、测试用例排序都能用；勾选「可复现」可以让同一份输入每次得到同一结果。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

多行文本。按词模式逐行打乱，行数保持不变。

## 输出

| 字段   | 类型   | 说明                                   |
| ------ | ------ | -------------------------------------- |
| `text` | string | 打乱后的文本，行数与行内结构保持不变。 |

## 选项

| 选项     | 取值                                      | 默认   | 说明                               |
| -------- | ----------------------------------------- | ------ | ---------------------------------- |
| `mode`   | `line`（按行） / `word`（按词，逐行打乱） | `line` | 打乱粒度                           |
| `stable` | 勾选 / 取消                               | 取消   | 用内容哈希做种子，同输入必得同输出 |

## 限制

- 按词模式用空白 + 汉字块切词，**会丢掉标点与原始空白**，词之间统一用一个空格连接
- 中文未做分词，连续的汉字会被当成一个词块，建议中文内容按行打乱
- 未勾选「可复现」时每次点击运行都可能得到不同结果
- 只做随机置换，不做加权随机、不保证不出现相邻重复
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
第一行
第二行
第三行
```

输出：

```text
第一行
第二行
第三行
```
