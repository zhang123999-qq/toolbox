# 物理参数（#791）

计算游戏开发中常用的物理参数，纯本地公式计算。

## 模式与参数

| 模式     | 参数 JSON                         | 输出                     |
| -------- | --------------------------------- | ------------------------ |
| 斜抛     | `{"v0":10,"angleDeg":45,"g":9.8}` | 射程、最大高度、飞行时间 |
| 自由落体 | `{"h":4.9,"g":9.8}`               | 下落时间                 |
| 跳跃初速 | `{"h":1.2,"g":9.8}`               | 达到目标高度所需的初速度 |
| 摩擦滑行 | `{"v0":10,"mu":0.5,"g":9.8}`      | 滑行距离、停止时间       |
| 弹性碰撞 | `{"m1":1,"v1":5,"m2":1,"v2":-3}`  | 一维完全弹性碰撞后速度   |
| 圆周运动 | `{"v":10,"r":5}`                  | 向心加速度、周期         |

- `g` 默认为 9.8 m/s²（月球可填 1.62）
- 角度单位为度，取值范围 (0, 90)
- 摩擦系数 mu 取值范围 (0, 1]

## 说明

纯前端本地计算，不发送任何网络请求。
