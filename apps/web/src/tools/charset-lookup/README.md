# 字符集查询

查询字符所属字符集。

## 用途

查一个字符的家底：码点、UTF-8 字节数、Unicode 区块、以及它可能属于哪些常见字符集。中文编码的乱码排查里最常用的一步。

## 输入

| 字段   | 类型   | 约束            |
| ------ | ------ | --------------- |
| `text` | string | 最大 1,000 字符 |

一个或多个字符；空格与换行会被跳过，其余逐个字符出一份报告。

## 输出

| 字段   | 类型   | 说明                             |
| ------ | ------ | -------------------------------- |
| `text` | string | 每个字符一段报告，段之间空一行。 |

## 选项

该工具无选项。

## 限制

- **是粗判，不是全表比对**：GB2312 / Big5 / Shift_JIS / EUC-KR 在 Unicode 里的映射并不连续，本工具按「是否落在该字符集主要收录的 Unicode 区块」判断
- **GB 系列与 Big5 无法区分**：两者都收汉字，Unicode 区间完全重叠，工具会把两个都列出来；想知道某个字具体被哪套编码收录，请查编码表或用 #40 编码检测
- 「是否属于 Shift_JIS」只看假名与日文专用符号，**日文汉字会被判成 GB / Big5 一侧**，因为 Unicode 的汉字区是中日韩统一的
- Unicode 区块表只收录了常见的一段（约 27 个区块），未收录的会直接报码点
- 一次最多查 1,000 字符，超出请分批
- 组合字符（如「é」的 e + U+0301 写法）会被当成两个字符分别报告

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
中
```

输出：

```text
字符：中
码点：U+4E2D
UTF-8 字节：3（e4 b8 ad）
UTF-16 码元：1
Unicode 区块：CJK Unified Ideographs（中日韩统一汉字）
所属字符集：GB2312 / GBK / GB18030、Big5
```
