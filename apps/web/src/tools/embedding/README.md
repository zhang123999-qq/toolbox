# 文本嵌入 Text Embedding（#596）

用**特征哈希（feature hashing）**在浏览器本地把文本转成固定维度的归一化向量，
可对比两段文本的余弦相似度。纯 JS 实现，不联网、不调用任何模型 API。

## 原理

1. **分词**：英文按连续字母数字切词（转小写），中文按单字切分；
2. **哈希映射**：每个词用 FNV-1a 哈希映射到 `[0, dim)` 的下标，
   用哈希最高位决定 `+1` / `-1` 符号（抵消碰撞偏差）；
3. **累加 + L2 归一化**：同一文本永远得到同一向量（确定性）。

## 局限（必读）

- 这是**词袋式哈希嵌入，不是语义嵌入**：「汽车」和「轿车」在向量空间中并不更接近；
- 词序信息完全丢失；「猫追狗」与「狗追猫」向量相同；
- 不同词可能哈希碰撞到同一维度（维度越大碰撞概率越低）；
- 相似度数值只反映**用词重叠程度**，不能作为语义相似依据；
- 如需真正的语义向量，请使用 #597 的可视化对比观察，或调用大模型的 Embedding API。

## 选项

- 维度：64 / 128 / 256 / 512 / 1024，越大碰撞越少、计算越慢；
- 文本 B：填写后计算两段文本的余弦相似度（范围 -1～1）。
