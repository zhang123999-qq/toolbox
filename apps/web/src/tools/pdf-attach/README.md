# PDF 加附件

选择 PDF 文件，填写附件文件名与文本内容，把文本作为文件附件嵌入 PDF
（Catalog → Names → EmbeddedFiles 名字树），生成新 PDF 下载。纯本地处理。

## 用途

给 PDF 附上说明文档、数据源文本，阅读器附件面板可直接查看/另存。

## 输入

| 字段       | 类型   | 约束             | 说明                       |
| ---------- | ------ | ---------------- | -------------------------- |
| `file`     | File   | ≤ 100 MiB        | 输出区文件选择框上传的 PDF |
| `text`     | string | 最大 100000 字符 | 附件文本内容               |
| `filename` | string | 最大 200 字符    | 附件文件名（如 notes.txt） |

文件、内容、文件名必填；文件名不能包含路径分隔符（`/` `\`）。
下载文件名为原文件名加 `-attach` 后缀（如 `demo-attach.pdf`）。

## 输出

| 字段   | 类型       | 说明                                 |
| ------ | ---------- | ------------------------------------ |
| `file` | PDF 二进制 | 嵌入附件后的新 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「复制/下载」按钮操作的是附件文本内容（`.txt`）。

## 选项

无。

## 限制

- **暂不支持中文字符**：附件文件名与内容走 PDFString，只支持 Latin-1，含中文时会直接报错，
  不会生成乱码 PDF。
- 附件为纯文本（UTF-8 编码存入），不支持二进制附件上传。
- 多次操作同一文件时附件追加保留，不会覆盖同名附件。
- 文件全程在浏览器内存里处理，不发任何请求。

## 数据流向

**纯本地处理。** PDF 文件与生成结果都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

1 页 PDF，附件 `notes.txt` 内容 `These are the release notes.` →
输出区显示如 `已生成 PDF：1 页，2.0 KB`，下载 `demo-attach.pdf`。
