# 文本摘要

提取式或生成式摘要。

## 用途

把长文压成几句话：默认走本地提取式（从原文挑关键句，不联网、不虚构），需要更自然的表达时切成生成式，调你自备的模型接口。

## 输入

| 字段      | 类型   | 约束                                   |
| --------- | ------ | -------------------------------------- |
| `text`    | string | 最大 20,000 字符                       |
| `apiBase` | string | 接口地址（Base URL），最大 20,000 字符 |
| `apiKey`  | string | API Key，最大 20,000 字符              |
| `model`   | string | 模型名，最大 20,000 字符               |

正文 + 接口信息（生成式模式必填：接口地址、API Key、模型名）。提取式模式不需要接口信息。

## 输出

| 字段   | 类型   | 说明                                                     |
| ------ | ------ | -------------------------------------------------------- |
| `text` | string | 摘要文本。提取式是原文里的原句，生成式是模型重写的内容。 |

## 选项

| 选项     | 取值                                                   | 默认         | 说明     |
| -------- | ------------------------------------------------------ | ------------ | -------- |
| `mode`   | `extractive`（本地抽句） / `abstractive`（调模型生成） | `extractive` | 摘要方式 |
| `length` | `1` / `3` / `5`                                        | `3`          | 摘要句数 |

## 限制

- 提取式按**词频加权**挑句，不是语义理解：它不理解内容，只是统计哪些词出现得多
- 提取式对中文按连续汉字块切词（未做分词），长句与专业术语的打分会有偏差
- 生成式需要你自备 OpenAI 兼容接口，费用与可用性由该接口决定
- 生成式可能写出原文没有的信息（模型幻觉），重要场景请核对原文
- 输入上限 20,000 字符：超长内容请先自己截取，接口按 token 计费

## 数据流向

**会向外部接口发送数据。** 本工具需要你自备大模型接口（OpenAI 兼容的 `/chat/completions`）：

- 请求由**浏览器直接**发往你填写的接口地址，**不经本项目任何服务器**
- 发送内容：待处理的正文 + 一段指令（prompt），以及你填的模型名
- 凭据：API Key 放在 `Authorization` 请求头里，只存在于当前页面的输入框中，
  **不写入 localStorage**，也不会随页面分享带走
- 超时 60 秒；返回结构按 OpenAI 的 `choices[0].message.content` 解析

`meta.api = true`。没填接口信息就点运行时，工具会给出缺项提示而不会发请求。

## 示例

输入：

```text
文本摘要可以从长文里提炼出最关键的信息。提取式摘要直接从原文挑选句子，好处是绝不虚构内容，缺点是读起来可能不够连贯。生成式摘要由模型重写，表达更自然，但需要调用外部接口，并且可能写出原文没有的信息。
```

输出：

```text
（提取式输出原文中的关键句；生成式输出由你接入的模型返回，此处不预设内容）
```
