# TOML 解析

TOML 与 JSON 双向互转，支持表、数组表与内联表。

## 用途

读 / 写 Cargo.toml、pyproject.toml 这类 TOML 配置：转成 JSON 便于程序处理，
改完再转回 TOML。语法错误时给出带行列位置的中文提示，直接跳到出错行。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 转换后的 JSON / TOML；空输入返回空串 |

## 选项

| 选项        | 取值                      | 默认        | 说明                             |
| ----------- | ------------------------- | ----------- | -------------------------------- |
| `direction` | `toml2json` / `json2toml` | `toml2json` | 转换方向                         |
| `indent`    | `2` / `4`                 | `2`         | JSON 侧缩进档位（TOML 侧不使用） |

## 支持范围

- 键值对（`key = value`）、点号键路径（`a.b.c = 1`）、引号键名
- 标准表 `[a.b]`、数组表 `[[a]]`、`[a]` 出现在 `[[a]]` 之后
- 内联表 `{a = 1, b = "x"}`、数组 `[1, 2, 3]`（**可跨行书写**）
- 四类字符串：基本 `"…"`、多行基本 `"""…"""`、字面 `'…'`、多行字面 `'''…'''`
- 转义 `\b \t \n \f \r \" \\ \uXXXX \UXXXXXXXX`
- 整数（十进制 / `0x` / `0o` / `0b` / 下划线分隔）、浮点、科学计数法、`inf` / `nan`
- 日期时间：偏移日期时间、本地日期时间、本地日期、本地时间

## 限制

- **注释会丢失**：JSON 没有注释语法，TOML → JSON 时注释被丢弃
- **日期时间按字符串输出**：JSON 没有该类型，保留原始字面量（如 `2024-01-02T03:04:05Z`）
- **`inf` / `nan` 转成 JSON 后为 `null`**（`JSON.stringify` 的规定行为）
- **不支持 TOML 1.1 草稿特性**（如 `\e` 转义、尾随逗号之外的放宽语法）
- 不支持多行数组元素里再嵌多行基本字符串的复杂组合（会按多行字符串优先处理）
- JSON → TOML 时：**顶层必须是对象**；**`null` 无法表达**（会报错，请先去掉该键）
- JSON → TOML 时：只有顶层及表下的**纯对象数组**会转成 `[[key]]`，数组里混有对象会报错
- 数字超 `Number.MAX_SAFE_INTEGER` 时按双精度处理，可能丢失末位精度
- 重复定义同一个表 / 键会报错（TOML 规范行为）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（TOML）：

```toml
title = "工具库"
port = 8080
debug = false

[server]
host = "127.0.0.1"

[[tags]]
name = "yaml"
```

输出（JSON，`indent = 2`）：

```json
{
  "title": "工具库",
  "port": 8080,
  "debug": false,
  "server": {
    "host": "127.0.0.1"
  },
  "tags": [
    {
      "name": "yaml"
    }
  ]
}
```
