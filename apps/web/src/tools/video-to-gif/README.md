# 视频转GIF

上传视频，用 ffmpeg.wasm 在浏览器本地截取片段并转换为 GIF 动图（**不**使用 gif.js，编码全部由 ffmpeg 的 gif 复用器完成）。

## 用途

把视频里的精彩片段转成 GIF，用于聊天、帖子、文档配图：设好起始时间、片段时长、帧率与输出宽度，一键转换后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                        |
| ------- | ------ | ------------------------------------------- |
| `image` | GIF    | 转换后的动图，可预览并下载                  |
| `text`  | string | 处理报告：片段区间 / 帧率 / 宽度 / 输出大小 |

## 选项

| 选项       | 类型 | 默认 | 说明                                  |
| ---------- | ---- | ---- | ------------------------------------- |
| `start`    | 数字 | 0    | 起始时间（秒），不能为负              |
| `duration` | 数字 | 3    | 片段时长（秒），0.1–30                |
| `fps`      | 整数 | 10   | 帧率，1–30                            |
| `width`    | 整数 | 480  | 输出宽度（像素），64–1280，高度按比例 |

## 限制

- 参数非法（起始时间为负、时长超限、帧率/宽度越界）会给出中文错误提示
- GIF 片段最长 30 秒，避免体积失控
- 转换在浏览器本地完成（ffmpeg.wasm），首次使用需从 CDN 下载 wasm 内核
- 文件全程留在浏览器内存里，不发任何请求

## 示例

`movie.mp4`，从 1.0 秒起截 3 秒，10 fps、宽 480 px：

```text
输入：movie.mp4
截取片段：1.00 秒 起，时长 3.00 秒
帧率：10 fps　输出宽度：480 px
输出大小：xxx KiB
```

## 数据流向

**纯本地处理。** 转码在浏览器内完成，`meta.api = false`，无需自备 API/Key。
