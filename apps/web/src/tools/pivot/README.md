# 数据透视

粘贴 CSV 数据，按行维度 / 列维度分组，对值列做聚合（求和 / 计数 / 平均 / 最大 / 最小），纯 JS 在浏览器本地计算，结果表格展示并支持导出 CSV。

## 用途

- 销售数据按地区 × 季度汇总
- 问卷数据交叉统计
- 替代 Excel 数据透视表的轻量场景

## 输入

| 字段       | 类型   | 约束                               |
| ---------- | ------ | ---------------------------------- |
| `text`     | string | CSV 文本，首行为表头（留空用示例） |
| 行维度列名 | 文本   | 须为表头中的列名                   |
| 列维度列名 | 文本   | 须为表头中的列名                   |
| 值列名     | 文本   | 须为表头中的列名                   |

CSV 解析支持引号包裹字段（`""` 转义为 `"`），兼容 `\r\n`，空行自动跳过。

输入格式示例：

```csv
地区,季度,销售额
华东,Q1,120
华东,Q2,150
华南,Q1,200
华南,Q2,180
华北,Q1,90
```

## 选项

| 选项     | 默认值 | 说明                                                             |
| -------- | ------ | ---------------------------------------------------------------- |
| 聚合方式 | `sum`  | `sum` 求和 / `count` 计数 / `avg` 平均 / `max` 最大 / `min` 最小 |

- `count` 统计分组内行数，忽略值列内容
- 其余聚合要求值列为有效数字，否则报错并指出行号
- 平均值保留 4 位小数

## 输出

透视表（含行合计 / 列合计 / 总计），空单元格表示该行列组合无数据，可「导出 CSV」下载。
