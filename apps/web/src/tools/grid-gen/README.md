# 网格生成

生成网格背景纹理 SVG，支持点阵 / 直线网格 / 斜纹三种图案，可调间距、尺寸与前景 / 背景色，可复制 / 下载（`.svg`）。

## 用途

- 给网页 / 图表 / 设计稿生成背景纹理
- 快速得到占位网格、图纸底纹、斜纹填充
- 导出 SVG 源码复用

## 输入

| 字段   | 类型   | 约束                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 留空（本工具不依赖文本输入） |

## 选项

| 选项   | 默认值    | 范围 / 约束             | 说明               |
| ------ | --------- | ----------------------- | ------------------ |
| 图案   | `dots`    | dots / lines / diagonal | 点阵 / 直线 / 斜纹 |
| 间距   | `30`      | 5–100                   | 网格元素间距       |
| 宽度   | `400`     | 1–2000                  | 画布宽度（px）     |
| 高度   | `300`     | 1–2000                  | 画布高度（px）     |
| 前景色 | `#e5e7eb` | `#rgb` / `#rrggbb`      | 网格线条 / 圆点色  |
| 背景色 | `#ffffff` | `#rgb` / `#rrggbb`      | 画布底色           |

## 输出

- 右侧预览区：渲染后的 SVG 网格
- 复制 / 下载：SVG 源码（`.svg` 文件）

## 边界

- 图案类型非 dots / lines / diagonal → 中文报错
- 间距 / 尺寸越界 → 中文报错
- 颜色非法 → 中文报错

## 示例

默认参数即生成浅灰点阵白底图；把「图案」切到 `lines` 得到直角网格，切到 `diagonal` 得到 45 度斜纹。

## 数据流向

纯本地：SVG 由浏览器内纯函数生成，不上传服务器。

# Grid Generator (English)

Generate grid background SVG textures: dots / lines / diagonal. Tune spacing, size and foreground/background colors. Copy or download (`.svg`).

## Purpose

- Produce background textures for pages / charts / designs
- Quick placeholder grids, blueprint backgrounds, diagonal fills
- Export SVG source for reuse

## Input

| Field  | Type   | Constraint                          |
| ------ | ------ | ----------------------------------- |
| `text` | string | Leave empty (not used by this tool) |

## Options

| Option     | Default   | Constraint              | Description           |
| ---------- | --------- | ----------------------- | --------------------- |
| Pattern    | `dots`    | dots / lines / diagonal | Dot / line / diagonal |
| Spacing    | `30`      | 5–100                   | Grid element spacing  |
| Width      | `400`     | 1–2000                  | Canvas width (px)     |
| Height     | `300`     | 1–2000                  | Canvas height (px)    |
| Foreground | `#e5e7eb` | `#rgb` / `#rrggbb`      | Line / dot color      |
| Background | `#ffffff` | `#rgb` / `#rrggbb`      | Canvas fill           |

## Output

- Right preview panel: rendered SVG grid
- Copy / download: SVG source (`.svg` file)

## Edge cases

- Unknown pattern → Chinese error
- Out-of-range spacing/size → Chinese error
- Invalid color → Chinese error

## Data flow

Fully local: SVG generated by pure functions in the browser.
