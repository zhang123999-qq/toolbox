# BLAKE2 哈希

计算文本的 BLAKE2b / BLAKE2s 摘要（内置纯 JS 实现）。

## 用途

BLAKE2（RFC 7693）是比 MD5/SHA-1 更快、强度不低于 SHA-3 的现代哈希，常用于校验内容完整性、比对两段内容是否一致、生成去重键（`b2sum`、密码库、内容寻址存储等都大量使用）。
两个家族与常见强度：

| 变体        | 字长  | 块大小   | 输出   |
| ----------- | ----- | -------- | ------ |
| BLAKE2b-512 | 64 位 | 128 字节 | 512 位 |
| BLAKE2b-384 | 64 位 | 128 字节 | 384 位 |
| BLAKE2b-256 | 64 位 | 128 字节 | 256 位 |
| BLAKE2s-256 | 32 位 | 64 字节  | 256 位 |
| BLAKE2s-128 | 32 位 | 64 字节  | 128 位 |

`BLAKE2b-512("abc") = ba80a53f981c4d0d6a2797b69f12f6e94c212f14685ac4b74b12bb6fdbffa2d1...`
`BLAKE2s-256("abc") = 508c5e8c327c14e2e1a72ba34eeb452f37458b209ed63a294d999b4c86675982`

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

任意文本（中英混排、emoji 均可），按 UTF-8 编码参与计算。

## 输出

| 字段   | 类型   | 说明                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 十六进制摘要；选 Base64 时为其编码值 |

## 选项

| 选项        | 取值                                                                | 默认          | 说明     |
| ----------- | ------------------------------------------------------------------- | ------------- | -------- |
| `algorithm` | BLAKE2b-512 / BLAKE2b-384 / BLAKE2b-256 / BLAKE2s-256 / BLAKE2s-128 | `BLAKE2b-512` | 变体     |
| `format`    | hex / base64                                                        | hex           | 输出格式 |

## 限制

- **WebCrypto 没有 BLAKE2**：`subtle.digest` 的算法集合里不存在 BLAKE2，本工具因此**使用内置的纯 JS 实现**（按 RFC 7693 编写），而不是浏览器原生能力。
- **不是加密**：哈希不可逆，不能用来「解密」。
- **不做加盐**：存口令请用带盐的 KDF，不要直接存摘要。
- 本工具只实现**无密钥**模式（keyLength = 0），不提供带密钥的 BLAKE2 / 密钥化参数。
- 输入上限 200,000 字符；耗时随输入线性增长（纯 JS，比原生 SHA 慢）。

## 数据流向

**纯本地处理。** 摘要完全在当前页面的内存里用内置算法算出，文本不写入 localStorage、不发送、不上传，无任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
abc
```

输出（BLAKE2b-512 / hex）：

```text
ba80a53f981c4d0d6a2797b69f12f6e94c212f14685ac4b74b12bb6fdbffa2d17d87c5392aab792dc252d5de4533cc9518d38aa8dbf1925ab92386edd4009923
```
