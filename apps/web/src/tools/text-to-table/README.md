# 文本转表格

分隔文本转表格。

## 用途

把分隔文本排成等宽对齐的表格，直接贴进终端、日志、README 或等宽字体的文档里看，不必再开 Excel。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

分隔文本（TSV / CSV / 分号 / 竖线 / 多空格均可）。空行会被丢弃；单元格可用双引号包裹，引号内的分隔符不参与切分。

## 输出

| 字段   | 类型   | 说明                              |
| ------ | ------ | --------------------------------- |
| `text` | string | 对齐后的表格文本，换行统一用 LF。 |

## 选项

| 选项        | 取值                                                      | 默认   | 说明                               |
| ----------- | --------------------------------------------------------- | ------ | ---------------------------------- |
| `delimiter` | `auto` / `comma` / `tab` / `semicolon` / `pipe` / `space` | `auto` | 输入分隔符，auto 按每行出现次数猜  |
| `style`     | `plain`（空格对齐） / `grid`（ASCII 边框）                | `grid` | 表格版式                           |
| `header`    | 勾选 / 取消                                               | 勾选   | 首行是否作为表头（为真时加分隔线） |

## 限制

- 对齐按「显示宽度」计算（中日韩字符算 2），但**渲染仍依赖等宽字体**；比例字体下还是会对不齐
- `space` 分隔符按「两个及以上空白」切分，单空格分隔的文本请改用其他分隔符或先预处理
- 宽表格不会自动折行，超出终端宽度的行会溢出
- 不含 Markdown / HTML 输出，需要结构化格式请用「表格转文本」（#22）
- 输入上限 100,000 字符，超出请分批

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
name	age	city
张三	28	北京
李四	31	上海
```

输出：

```text
name	age	city
张三	28	北京
李四	31	上海
```
