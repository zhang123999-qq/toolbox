# 网站截图

调用浏览器原生 `navigator.mediaDevices.getDisplayMedia`，截取你选择的屏幕 / 窗口 / 标签页，
用 `<video>` + `<canvas>` 截一帧导出 PNG dataURL。

> 这是降级方案：原规划需要服务端无头浏览器截图（E）。浏览器端无法任意抓取别人的网站，
> 只能**让用户自己授权共享屏幕**后截取一帧。

## 用途

- 临时截当前屏幕 / 某个窗口 / 某个标签页，不依赖系统截图工具
- 拿到 PNG dataURL 后可直接粘到地址栏查看、或存成文件

## 输入

本工具**不需要文本输入**。点「运行」即触发浏览器的屏幕共享授权弹窗。

## 浏览器边界（重要）

- **必须用户授权**：浏览器会弹窗让你选择「整个屏幕 / 某个窗口 / 某个标签页」，
  必须手动点「允许」；取消授权会给出中文错误提示
- **只截一帧**：拿到视频流后立刻截一帧并停止所有轨道，不录屏、不留存
- **需要 HTTPS 或 localhost**：`getDisplayMedia` 在普通 http 页面下不可用
- **不支持的浏览器**（如 Firefox 旧版 / 手机浏览器）会提示「请改用最新版 Chrome / Edge」
- 本测试 / E2E **不会真的调起授权弹窗**，只验证纯函数与界面 testid

## 输出

一段说明 + PNG dataURL。把 dataURL 粘到浏览器地址栏即可查看图片并另存。

## 数据流向

**纯浏览器本地。** 不上传任何像素，`meta.api = false`。截帧发生在你自己的浏览器里。
