# 嵌入可视化 Embedding Visualization（#597）

把多段文本转成向量（与 #596 文本嵌入相同的特征哈希算法，此处自包含实现），
用 PCA 降到 2D 后画散点图，悬停可查看每段文本的标签。纯本地计算，不联网。

## 使用方法

左侧每行输入一条 `标签：文本`（冒号支持中英文；不写冒号则标签自动编号），
右侧自动渲染散点图；可切换嵌入维度（64 / 128 / 256 / 512 / 1024）。

## 原理

1. 文本 → 特征哈希向量（FNV-1a 哈希 → 固定维度 → L2 归一化）；
2. PCA：对中心化向量的 Gram 矩阵做幂迭代，求前两个主成分，
   样本在主成分上的坐标为 `√λ·u[i]`；
3. echarts 散点图展示，tooltip 显示标签。

## 局限（必读）

- 向量来自**特征哈希（词袋统计），不是语义嵌入**：散点的聚集只反映用词重叠，
  不能解读为语义相似；
- PCA 是线性降维，2D 投影会丢失信息，点的相对位置仅供直观参考；
- 退化情形（只有一条文本 / 所有文本向量相同）下所有点会落在原点，
  这是正常的数学结果，不是 bug。
