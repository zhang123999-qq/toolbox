# 词云

统计文本词频，用 Canvas 在浏览器本地绘制词云，支持画布尺寸、字号区间与 PNG 导出。

## 用途

- 文本关键词可视化：文章、评论、问卷反馈的高频词一览
- 演示文稿配图：导出 PNG 用于文档、海报
- 中英文混合文本均可处理

## 输入

| 字段   | 类型   | 约束                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 待统计文本（留空用内置示例） |

分词规则：

- 英文按单词切分（≥2 个字母，转小写）
- 中文按单字切分
- 过滤中英文停用词（the、的、了…），长度不足的片段丢弃

## 选项

| 选项     | 默认值 | 范围 / 约束 | 说明                         |
| -------- | ------ | ----------- | ---------------------------- |
| 显示词数 | `80`   | 1–500 整数  | 取词频 Top N                 |
| 宽度     | `600`  | 100–2000    | 画布宽（px）                 |
| 高度     | `400`  | 100–2000    | 画布高（px）                 |
| 最小字号 | `14`   | 6–200       | 词频最低的词的字号（px）     |
| 最大字号 | `64`   | 6–200       | 词频最高的词的字号（px），须 ≥ 最小字号 |

## 布局说明

- 字号按词频在最小–最大字号之间线性映射
- 采用阿基米德螺旋布局，词按词频从大到小依次放置，自动避让已放置的词
- 颜色从 8 色固定调色板按词频顺序循环取色
- 相同文本布局固定（内置固定随机种子），可复现
- 画布放不下时，靠后的低频词会被跳过

## 示例

输入：

```
数据可视化让信息更直观，词云是文本可视化的经典形式。
Word cloud visualizes text data.
```

输出：词云画布 + 「下载 PNG」按钮。

## 限制

- 纯前端实现，不引入 `echarts-wordcloud` 等重型依赖
- 中文按单字统计（不做分词库），英文按单词统计
