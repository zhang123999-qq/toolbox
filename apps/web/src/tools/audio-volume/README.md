# 音量调节

上传音频，用 Web Audio API 解码，在浏览器本地调节音量并导出为 WAV。

## 用途

录音太轻或太大：输入增益倍数或 dB 值，放大/缩小后下载，超 0 dBFS 会做硬削波并报告。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                          |
| ------- | ------ | --------------------------------------------- |
| `audio` | WAV    | 调整后的音频（16 位 PCM），可试听并下载       |
| `text`  | string | 处理报告：增益倍数 / dB / 是否削波 / 输出时长 |

## 选项

| 选项     | 类型 | 默认 | 说明                               |
| -------- | ---- | ---- | ---------------------------------- |
| `gainDb` | 数字 | 0    | 增益（dB，-60～+60），0 为保持不变 |

## 限制

- 增益超出 -60～+60 dB 会给出中文错误提示
- 信号超出 [-1, 1] 时做硬削波，报告会标注「已削波」
- 不支持 Web Audio API 的旧浏览器会给出中文错误提示
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（4 秒 440Hz 正弦波），增益 +6dB：

```text
输入：示例-440Hz正弦波.wav
增益：+6.00 dB（×1.995）
削波：否　输出时长：4.00 秒
```

## 数据流向

**纯本地处理。** 解码与音量变换全在浏览器内完成，`meta.api = false`，无需自备 API/Key。
