# 文件哈希

计算文件或文本的 MD5 / SHA-1 / SHA-256 / SHA-384 / SHA-512 摘要，用于校验下载文件的完整性。

## 用途

下载安装包、镜像、归档后，用它算出摘要与官方公布的值比对，确认文件没被篡改或传输出错。

## 输入

| 字段   | 类型   | 约束              | 说明                                   |
| ------ | ------ | ----------------- | -------------------------------------- |
| `text` | string | 最大 200,000 字符 | 待哈希的文本，按 UTF-8 编码            |
| `file` | File   | 最大 200 MiB      | 通过左下的「选择文件」选取，**不上传** |

两条路径互斥：选了文件就以文件为准，输出区显示文件结果；点「运行」则以文本区为准。

## 输出

| 字段   | 类型   | 说明                                    |
| ------ | ------ | --------------------------------------- |
| `text` | string | 报告文本：来源与体积 + 每个算法一行摘要 |

```text
文件：demo.bin
大小：3 字节

MD5     900150983cd24fb0d6963f7d28e17f72
SHA-1   a9993e364706816aba3e25717850c26c9cd0d89d
SHA-256 ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

## 选项

| 选项        | 取值                                        | 默认 | 说明           |
| ----------- | ------------------------------------------- | ---- | -------------- |
| `algorithm` | all / md5 / sha1 / sha256 / sha384 / sha512 | all  | 算哪些算法     |
| `format`    | hex / base64                                | hex  | 摘要的输出编码 |

## 限制

- **文件上限 200 MiB**：本工具一次性把文件读进内存再哈希，不做分块流式处理；
  更大的文件请用命令行 `sha256sum` / `certutil -hashfile`
- **MD5 用 spark-md5**（WebCrypto 不提供 MD5），SHA 系列走浏览器原生 WebCrypto
- MD5 与 SHA-1 已不抗碰撞，**仅可用于校验传输完整性，不能用于安全签名**
- 文件全程留在浏览器内存里，不发任何请求
- 文本模式对 200,000 字符以上的输入直接报错

## 数据流向

**纯本地处理。** 文件与文本都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入（文本）：

```text
hello world
```

输出：

```text
输入：11 字符 / 11 字节

MD5     5eb63bbbe01eeed093cb22bb8f5acdc3
SHA-1   2aae6c35c94fcfb415dbe95f408b9ce91ee846ed
SHA-256 b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9
```
