# IP 查询

输入一个 IPv4 或 IPv6 地址，校验合法性并给出分类（公网 / 私网 / 环回 / 组播 /
链路本地等），同时输出二进制、十六进制与整数表示。

## 用途

看日志里的 IP 判断它是内网还是外网、是否环回、是不是组播；
或在网络编程时把 IP 转成整数做位运算 / 比较。

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | IPv4 或 IPv6，最大 200,000 字符 |

IPv6 支持 `::` 压缩（如 `2001:db8::1`），不支持内嵌 IPv4 映射形式。

## 输出（IPv4 示例）

```text
格式：IPv4
点分十进制：192.168.1.1
分类：私网地址（192.168/16）
二进制：11000000.10101000.00000001.00000001
十六进制：0xC0A80101
整数表示：3232235777
```

## 分类规则

| IPv4 段                           | 分类              |
| --------------------------------- | ----------------- |
| 127.0.0.0/8                       | 环回              |
| 10.0.0.0/8、172.16/12、192.168/16 | 私网              |
| 169.254/16                        | 链路本地（APIPA） |
| 224.0.0.0/4                       | 组播              |
| 240.0.0.0/4                       | 保留              |
| 其余                              | 公网              |

| IPv6 段   | 分类             |
| --------- | ---------------- |
| ::1       | 环回             |
| fe80::/10 | 链路本地         |
| fc00::/7  | 唯一本地（私网） |
| ff00::/8  | 组播             |
| 其余      | 公网             |

## 限制

- IPv6 不支持 `::` 内嵌 IPv4（如 `::ffff:1.2.3.4`）
- 整数表示 IPv6 用 128 位 BigInt，可能很长
- 空输入返回空串；非法格式抛中文错误

## 数据流向

**纯本地处理。** 位运算，不发送网络请求，也不做 GeoIP 归属地查询。`meta.api = false`。

## 示例

输入：

```text
8.8.8.8
```

输出：

```text
格式：IPv4
点分十进制：8.8.8.8
分类：公网地址
…
```
