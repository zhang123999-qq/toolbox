# 空白字符清理

去首尾空格、多空格合并、去空行。

## 用途

把复制粘贴带进来的一堆乱空白收拾干净：行首尾的空格、连续的好几个空格、夹在中间的空行，一次清完。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

多行文本。换行统一识别 LF / CRLF，输出统一用 LF。

## 输出

| 字段   | 类型   | 说明                                                               |
| ------ | ------ | ------------------------------------------------------------------ |
| `text` | string | 清理后的文本。三个开关分别对应去首尾空格、合并连续空白、删除空行。 |

## 选项

| 选项          | 取值        | 默认 | 说明                         |
| ------------- | ----------- | ---- | ---------------------------- |
| `trimLines`   | 勾选 / 取消 | 勾选 | 去掉每行首尾空白             |
| `collapse`    | 勾选 / 取消 | 勾选 | 把行内连续空白合并成一个空格 |
| `removeEmpty` | 勾选 / 取消 | 勾选 | 删除空行                     |

## 限制

- 合并空白会把制表符与不换行空格一起换成普通空格；**代码缩进别用这个开关**
- 合并发生在去首尾之后：关掉「去首尾空格」时，行首的连续空白会被合并成一个空格
- 不识别全角空格 U+3000（它是可见宽度的字符，不算多余空白）
- 不做 Unicode 正规化，也不处理零宽字符（请用「零宽字符」#42）
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
  第一行

  第二行   有   多余空格
第三行
```

输出：

```text
第一行
第二行 有 多余空格
第三行
```
