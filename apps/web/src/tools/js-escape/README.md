# JS 转义

文本与 JavaScript 字符串转义序列互转，支持单双引号。

## 用途

把一段文本转义成能安全嵌进 JavaScript 字符串字面量的形式——换行、制表符、
反斜杠、引号这些字符直接写进去会把代码截断或改义；反向则用于把日志、
报错信息、接口返回里的 `\u4E2D\u6587`、`\n` 还原成人能读的文字。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 转义后为转义序列；还原后为原始文本 |

转义结果**不含首尾引号**，方便直接拼进已有的单引号或双引号字面量里。

## 选项

| 选项        | 取值              | 默认   | 说明                                   |
| ----------- | ----------------- | ------ | -------------------------------------- |
| `direction` | escape / unescape | escape | 转义或还原                             |
| `quote`     | single / double   | double | 按哪种定界引号转义，只转义当前那种引号 |

## 限制

- 转义只处理会让字面量「断掉」的字符：反斜杠、当前定界引号、控制字符；
  中文、emoji 等非 ASCII 字符保持原样（现代 JS 源文件按 UTF-8 存）
- 控制字符的覆盖范围：`\0` `\b` `\t` `\n` `\v` `\f` `\r` 用专用写法，
  其余（`\u0001` 这种）统一落到 `\uXXXX`
- 还原识别专用转义、`\uXXXX` 与 `\xHH`；未知转义按 JS 语义取字符本身
  （`'\z' === 'z'`），而 `\u12`、`\x1` 这种位数不足的写法会**报错**
- 不处理八进制转义（`\012`）与模板字符串的反引号，需要时请先自行替换

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
He said: "it's fine"
```

输出（escape / double）：

```text
He said: \"it's fine\"
```
