# 屏幕阅读器预览

粘贴 HTML，模拟屏幕阅读器视角输出**朗读大纲**（标题层级、地标、链接、按钮、图片、表单控件）与**无障碍问题列表**：标题层级跳跃、多个 h1、无意义链接文本（"点击这里"）、缺 alt 图片、无 label 表单控件、无名称按钮等。

## 用途

- 上线前走查页面无障碍问题
- 学习屏幕阅读器如何"看"页面
- 给出朗读顺序的大纲视图

## 输入

| 字段   | 类型   | 约束       |
| ------ | ------ | ---------- |
| `text` | string | HTML 片段  |

## 说明

- 纯浏览器内 DOMParser 解析，无网络请求。
- 大纲按"标题 → 地标 → 链接 → 按钮 → 图片 → 表单"分组，而非严格 DOM 顺序，便于逐类检查。
- 这是静态分析，只能发现结构性问题；真实朗读体验仍建议用 NVDA / VoiceOver 验证。
