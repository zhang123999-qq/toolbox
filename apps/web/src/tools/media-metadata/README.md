# 媒体元数据

读取音视频文件的元信息：容器格式、时长、编码、分辨率、码率等。优先纯 JS 解析文件头，读不到的时长用浏览器解码兜底探测。

## 用途

快速查看一个音视频文件的基本信息，无需安装 ffprobe 之类的工具。

## 输入

| 字段   | 类型   | 约束   | 说明                                                 |
| ------ | ------ | ------ | ---------------------------------------------------- |
| `file` | File   | 音视频 | 通过「选择音视频文件」选取，只读文件头部，**不上传** |
| `text` | string | —      | 左侧文本区仅作备注，不参与处理                       |

## 输出

| 字段   | 类型 | 说明           |
| ------ | ---- | -------------- |
| `text` | 文本 | 多行元信息报告 |

按容器类型输出不同字段：

- WAV：采样率 / 声道数 / 位深 / 时长 / 音频数据大小（纯 JS 解析）
- MP3：MPEG 版本 / Layer III / 码率 / 采样率 / 声道数 / 时长（帧头解析 + 浏览器兜底）
- MP4：主品牌 / 时长（mvhd）/ 分辨率（首个 tkhd），读不到时浏览器兜底
- WebM / Ogg / FLAC：文件头识别 + 浏览器兜底时长

## 限制

- 仅支持 Layer III 的 MP3 帧头解析；其他 Layer 会明确提示
- MP4 的 moov 若在文件尾且超出头部读取范围，时长/分辨率走浏览器兜底
- 无法识别的文件头给出中文错误提示
- 全程本地处理，不发任何请求

## 示例

```text
文件名：song.mp3
文件大小：4.21 MiB
容器格式：MP3（音频）
MPEG 版本：1
编码层：Layer III
码率：128 kbps
采样率：44100 Hz
声道数：2
时长：180.50 秒
```

## 数据流向

**纯本地处理。** `meta.api = false`，无需自备 API/Key。
