# 仪表盘

输入当前值与区间，用 ECharts 在浏览器本地渲染仪表盘，刻度盘按值区间三段着色，支持标题、画布尺寸与 PNG 导出。

## 用途

- 完成度 / 达标率的可视化展示
- 系统指标（CPU、内存、磁盘）的仪表盘呈现
- 导出 PNG 图片用于汇报、文档

## 输入

| 字段   | 类型 | 约束                        |
| ------ | ---- | --------------------------- |
| 当前值 | 文本 | 数字，须在最小值–最大值之间 |
| 最小值 | 文本 | 数字，须小于最大值          |
| 最大值 | 文本 | 数字，须大于最小值          |

示例：当前值 `75`，最小值 `0`，最大值 `100`。

## 选项

| 选项 | 默认值 | 范围 / 约束 | 说明         |
| ---- | ------ | ----------- | ------------ |
| 标题 | （空） | 任意文本    | 留空则无标题 |
| 宽度 | `600`  | 100–2000    | 画布宽（px） |
| 高度 | `400`  | 100–2000    | 画布高（px） |

## 三段色

刻度盘按区间位置着色：

- 0–33%：青色 `#67e0e3`
- 33–67%：蓝色 `#37a2da`
- 67–100%：红色 `#fd666d`
