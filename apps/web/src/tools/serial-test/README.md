# 串口测试（Serial Test）

全局编号：#870｜域：教育趣味｜优先级：P3｜可行性：C（Web API）

## 功能

- **检测能力**：判断当前浏览器是否支持 Web Serial
- **请求串口**：弹出浏览器串口选择器，选择后展示端口信息（USB 厂商/产品 ID）
- **列出已授权串口**：展示已授权的串口列表（未授权时如实提示空列表）
- **打开/关闭串口**：选择 9600–921600 标准波特率，打开与关闭已选择的串口

## 注意事项

- 需要 **HTTPS** 环境，并在**用户手势**（点击按钮）中调用
- 仅 Chrome / Edge 等支持 Web Serial 的浏览器可用
- 仅列出已授权的端口；用户取消选择时显示浏览器返回的错误
- 本工具仅做能力检测与连接管理，不传输业务数据
