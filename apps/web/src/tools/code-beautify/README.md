# 代码美化

把压成一团的源码按缩进与换行重新排版，支持 JS / CSS / HTML / JSON / SQL 五种语言。

## 用途

替代 Prettier 的轻量自研格式化：在浏览器本地把没排版的代码整理成可读缩进，
不依赖任何外部库，不上传代码。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                   |
| ------ | ------ | ---------------------- |
| `text` | string | 按所选语言排版后的代码 |

## 选项

| 选项 key   | 界面标签 | 说明                                   |
| ---------- | -------- | -------------------------------------- |
| `language` | 语言     | `js` / `css` / `html` / `json` / `sql` |
| `indent`   | 缩进     | `2` 两空格 / `4` 四空格 / `tab` 制表符 |

## 各语言排版规则

- **JS**：按 `{ }` 块缩进，分号后换行；字符串与块注释内的括号不参与缩进判断
- **CSS**：选择器与 `{` 同行，每条声明独占一行，`}` 退回零缩进
- **HTML**：块级标签逐层缩进，文本节点随父级缩进
- **JSON**：交给原生 `JSON.parse` / `stringify`，非法 JSON 直接报错
- **SQL**：`SELECT / FROM / WHERE / GROUP BY / ORDER BY` 等子句关键字各自成行

## 限制

- 是「受控轻量格式化」，不做语义级修复（不会补全缺失的分号或引号）
- JSON 模式对非法输入抛错，其它模式尽力排版、不报错
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 全部为字符串处理，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
function add(a,b){return a+b;}
```

输出（JS，2 空格）：

```text
function add(a,b) {
  return a+b;
}
```
