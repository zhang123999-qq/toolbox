# 番茄钟

按「工作一段时间 → 休息一段时间」循环的专注计时器，默认 25 分钟工作 + 5 分钟休息，可配置时长，并统计完成了几个完整番茄。

## 用途

经典番茄工作法：专注 25 分钟，然后强制休息 5 分钟，循环往复。
全部在浏览器本地运行，刷新页面即停止。

## 操作方式

| 按钮 | data-testid  | 作用                   |
| ---- | ------------ | ---------------------- |
| 开始 | `pomo-start` | 从当前阶段开始倒计时   |
| 暂停 | `pomo-pause` | 冻结当前读数           |
| 复位 | `pomo-reset` | 回到工作阶段、清零轮次 |

## 状态机

```
        ┌────────── 工作(work) ──────────┐
        │  倒计时到 0 → 轮次 +1           │
        ▼                                │
     休息(break) ──倒计时到 0──▶ 回到 工作(work)
```

- 工作段走到 0：记一个完成的番茄，自动进入休息段。
- 休息段走到 0：自动进入下一个工作段，重新开始。
- 全程自动循环，不需要手动切换；「开始 / 暂停」只控制走动与否。
- 组件卸载（切选项、离开页面）时清除定时器。

## 选项

| 选项           | 默认 | 说明               |
| -------------- | ---- | ------------------ |
| `workMinutes`  | 25   | 每个工作段多少分钟 |
| `breakMinutes` | 5    | 每个休息段多少分钟 |

取值范围 1–180 分钟。运行中修改不会打断当前循环；暂停 / 复位后按新值走。

## 输出

右侧面板渲染当前阶段（工作中 / 休息中）、倒计时 `mm:ss`、已完成番茄数。
「复制 / 下载」拿到配置摘要：

```text
番茄钟：工作 25 分钟 + 休息 5 分钟，循环进行
```

## 限制

- 精度 1 秒；不播放提示音，只靠界面阶段文字切换提示。
- 不持久化刷新后的进度。

## 数据流向

**纯本地处理。** 阶段机、时长换算、格式化都是纯函数（`utils.ts`），计时循环在组件内持有并随卸载清理。`meta.api = false`。
