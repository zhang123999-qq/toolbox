# 混合内容检测

扫描网页 HTML，找出 `http://` 资源引用，按主动 / 被动内容评估混合内容风险等级。

## 用途

网站切到 https 后，页面里残留的 `http://` 图片、脚本、样式会导致浏览器告警甚至
拦截。把页面源码粘进来，一眼看清哪些资源还没改。

## 输入

| 字段      | 类型   | 约束                          |
| --------- | ------ | ----------------------------- |
| `text`    | string | 网页 HTML 源码，最大 500,000 字符 |
| `pageUrl` | string | 页面 URL，用于判定页面本身是否为 https |

## 输出

```text
页面 URL：https://example.com/（https）
风险等级：风险
结论：发现 1 个主动混合内容（script/iframe 等），浏览器会直接拦截导致功能异常，必须改为 https 引用
http:// 资源：2 个（主动 1 / 被动 1）

明细：
  [主动] <script> src = http://cdn.example.com/app.js
  [被动] <img> src = http://example.com/logo.png

按标签统计：script×1、img×1
```

## 风险分级

- **风险**：存在主动混合内容（`script` / `iframe` / `embed` / `object`），浏览器直接拦截
- **警告**：仅被动混合内容（图片 / 音视频 / 样式），或页面本身就是 http（全站明文）
- **安全**：未发现 `http://` 资源引用

## 限制

- 只识别带引号的属性值（`src="..."`）；无引号写法极少见，暂不支持
- 识别 `srcset` 多候选与 CSS `url()`；JS 动态拼接的 URL 扫不到
- 纯静态分析，不判断资源是否真实可访问

## 数据流向

**纯前端本地计算（A 类）。** HTML 不上传，分析全在浏览器内完成。
