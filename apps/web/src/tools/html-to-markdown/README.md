# HTML 转 Markdown

网页/HTML 转 Markdown。

## 用途

把网页片段或富文本编辑器导出的 HTML 转成 Markdown，便于迁到文档站、博客或仓库。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

HTML 片段（不需要完整文档）。最大 200,000 字符。

## 输出

| 字段   | 类型   | 说明                                              |
| ------ | ------ | ------------------------------------------------- |
| `text` | string | Markdown 文本：ATX 标题、围栏代码块、短横线列表。 |

## 选项

该工具无选项。

## 限制

- 依赖 turndown，它在 Node 与浏览器都自带 DOM 实现，不依赖页面 DOM
- 不处理 <table> 等复杂结构的完美还原，表格会退化为纯文本排布
- 行内样式、class、data-* 属性都会被丢弃（Markdown 没有对应语法）
- 脚本与样式标签的内容会被忽略

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
<h2>工具库</h2>
<p>本地<strong>优先</strong></p>
```

输出：

```text
<h2>工具库</h2>
<p>本地<strong>优先</strong>，共 <em>870</em> 个。</p>
<ul><li>文本</li><li>编码</li></ul>
```
