# 季度查询

输入一个日期，输出它属于哪个季度（Q1–Q4）、该季度的起止日期、距季度末还有几天，以及当年进度百分比。

## 用途

财务对账、项目排期、报表周期里快速判断某日期落在哪个季度、本季度还剩多少时间。

## 输入

| 字段   | 类型   | 约束                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 日期 `YYYY-MM-DD`，最大 200,000 字符 |

空输入返回空串；非法日期中文报错。

## 输出

```text
日期：2026-09-27
所属季度：Q3
季度起止：2026-07-01 ~ 2026-09-30
距季度末：4 天
当年进度：74.0%
```

| 季度 | 起止          |
| ---- | ------------- |
| Q1   | 01-01 ~ 03-31 |
| Q2   | 04-01 ~ 06-30 |
| Q3   | 07-01 ~ 09-30 |
| Q4   | 10-01 ~ 12-31 |

- 「距季度末」含当天（季度末当天 = 1 天）
- 「当年进度」= 年积日 / 当年总天数

## 数据流向

**纯本地处理。** 不发送网络请求，`meta.api = false`。

## 示例

输入：

```text
2026-09-27
```

输出：

```text
日期：2026-09-27
所属季度：Q3
季度起止：2026-07-01 ~ 2026-09-30
距季度末：4 天
当年进度：74.0%
```
