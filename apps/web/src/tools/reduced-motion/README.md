# 减少动画

生成 `@media (prefers-reduced-motion: reduce)` 减少动画 CSS：可分别关闭 animation 动画、transition 过渡与平滑滚动，并可追加额外选择器；同时扫描现有 CSS，列出其中的 animation / transition / @keyframes 声明，供决定关闭哪些动画。

## 用途

- 为偏好减少动画的用户（系统设置）提供无障碍友好的样式兜底
- 审查现有样式表中的动画声明，逐一评估是否需要关闭

## 输入

| 字段   | 类型   | 约束                             |
| ------ | ------ | -------------------------------- |
| `text` | string | 待扫描的 CSS（用于检测动画声明） |

在页面内设置：关闭动画 / 关闭过渡 / 关闭平滑滚动、额外选择器（逗号分隔）。

## 说明

- 纯前端生成与扫描，无网络请求，零依赖。
- 关闭动画采用 `animation-duration: 0.01ms` 而非 `none`，可保留动画结束状态，避免布局跳变。
- 额外选择器仅允许常规 CSS 选择器字符，非法输入会被拒绝。
