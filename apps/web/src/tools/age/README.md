# 年龄计算

输入出生日期（可选参考日期，默认今天），输出精确到天的年龄、生肖、星座和距下一个生日的天数。

## 用途

- 查自己 / 他人的周岁、月龄、天数
- 查生肖（干支年）与西方星座
- 算还有几天到下一个生日

## 输入

| 字段    | 类型   | 约束                        |
| ------- | ------ | --------------------------- |
| `text`  | string | 出生日期，最大 200,000 字符 |
| `textB` | string | 参考日期（可空，默认今天）  |

## 输出

```text
出生日期：1990-05-20
参考日期：2026-09-27
年龄：36 岁 4 个月 7 天
（约 13278 天）
生肖：马
星座：金牛座
距下一个生日：236 天（2027-05-20）
```

## 选项

本工具无选项。

## 算法

- **周岁**：参考年 - 出生年；若参考月日早于出生月日，周岁减 1；再按月 / 日借位得月龄与天数。
- **生肖**：`(year - 4) % 12`，0=鼠、1=牛 … 11=猪（公元 4 年为鼠年）。
- **星座**：按 (月, 日) 区间表（见下），边界日期落在后一个星座。
- **距下一个生日**：取今年生日，若已过则取下一年；2 月 29 日出生在平年回退到 2 月 28 日。

### 星座区间

| 星座 | 日期范围      |
| ---- | ------------- |
| 摩羯 | 12-22 ~ 01-19 |
| 水瓶 | 01-20 ~ 02-18 |
| 双鱼 | 02-19 ~ 03-20 |
| 白羊 | 03-21 ~ 04-19 |
| 金牛 | 04-20 ~ 05-20 |
| 双子 | 05-21 ~ 06-21 |
| 巨蟹 | 06-22 ~ 07-22 |
| 狮子 | 07-23 ~ 08-22 |
| 处女 | 08-23 ~ 09-22 |
| 天秤 | 09-23 ~ 10-23 |
| 天蝎 | 10-24 ~ 11-22 |
| 射手 | 11-23 ~ 12-21 |

## 边界

- 出生日期晚于参考日期 → 中文报错
- 2 月 29 日出生：平年生日按 2 月 28 日算，输出会加注
- 越界日期 / 非法格式 → 中文报错
- 输入 > 200,000 字符 → 报错

## 示例

输入出生日期：`2000-02-29`，参考日期：`2026-09-27`

输出年龄：`26 岁 6 个月 29 天`；生肖：龙；距下一个生日按 2027-02-28 计算。
