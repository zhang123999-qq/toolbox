# 卡路里计算

输入身高（cm）、体重（kg）、性别、年龄、活动强度，算每日所需热量（TDEE），并给出减重 / 增重建议。

## 用途

- 减脂 / 增肌期的每日热量预算
- 饮食计划的热量锚点

## 输入

| 字段    | 类型   | 约束                                  |
| ------- | ------ | ------------------------------------- |
| `text`  | string | 身高（cm），50–300，最大 200,000 字符 |
| `textB` | string | 体重（kg），>0 且 ≤1000               |

## 输出

```text
基础代谢（BMR）：1648.8 kcal/天
每日所需（TDEE，中度活动）：2556 kcal/天
减重建议：约 2056 kcal/天　增重建议：约 3056 kcal/天
```

## 选项

| 选项       | 类型   | 说明                                                         |
| ---------- | ------ | ------------------------------------------------------------ |
| `gender`   | select | 性别：`男` `女`                                              |
| `age`      | text   | 年龄：1–120 的整数                                           |
| `activity` | select | 活动强度：`久坐` `轻度活动` `中度活动` `高度活动` `极高强度` |

## 算法

- BMR 用 Mifflin-St Jeor（与 bmr 工具各自实现，不跨工具引用）：
  男 `10w + 6.25h − 5a + 5`；女 `10w + 6.25h − 5a − 161`
- 活动系数：久坐 `1.2` / 轻度活动 `1.375` / 中度活动 `1.55` / 高度活动 `1.725` / 极高强度 `1.9`
- `TDEE = BMR × 系数`；减重建议 `TDEE − 500`；增重建议 `TDEE + 500`
- BMR 保留 1 位小数（`toFixed(1)`），TDEE 与建议值取整（`Math.round`）

## 边界

- 身高留空 → 输出空串
- 身高非数字 → 中文报错「身高请输入有效的数字」；<50 或 >300 → 「身高应在 50–300 cm 之间」
- 体重非数字 → 「体重请输入有效的数字」；≤0 → 「体重必须大于 0」；>1000 → 「体重超出合理范围」
- 年龄留空 → 「年龄不能为空」；非数字 / 非整数 / <1 / >120 → 「年龄应为 1–120 的整数」
- 性别非法 → 「性别非法」；活动强度非法 → 「活动强度非法」
- 输入 > 200,000 字符 → 报错

## 示例

身高 `175`，体重 `70`，男，30 岁，中度活动：

```text
基础代谢（BMR）：1648.8 kcal/天
每日所需（TDEE，中度活动）：2556 kcal/天
减重建议：约 2056 kcal/天　增重建议：约 3056 kcal/天
```

## English

A daily calorie needs (TDEE) calculator with weight-goal advice. BMR via Mifflin-St Jeor, multiplied by an activity factor (1.2–1.9); ±500 kcal for loss/gain advice. Input: `text` (height in cm), `textB` (weight in kg); options: gender, age, activity.
