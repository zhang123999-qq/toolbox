# 视频转音频

上传视频，用 ffmpeg.wasm 在浏览器本地提取音轨，导出为 MP3 / WAV / OGG / FLAC 音频。

## 用途

只想保留视频里的声音（配乐、讲座、采访）：选输出格式，一键提取音轨下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                   |
| ------- | ------ | -------------------------------------- |
| `audio` | 音频   | 提取的音轨，可试听并下载               |
| `text`  | string | 处理报告：输出格式 / 比特率 / 输出大小 |

## 选项

| 选项          | 类型 | 默认 | 说明                                            |
| ------------- | ---- | ---- | ----------------------------------------------- |
| `format`      | 下拉 | mp3  | 输出音频格式：mp3 / wav / ogg / flac            |
| `bitrateKbps` | 整数 | 192  | 比特率（kbps），32–320，仅 mp3 / ogg 有损格式用 |

## 限制

- 比特率越界会给出中文错误提示
- 提取在浏览器本地完成（ffmpeg.wasm），首次使用需从 CDN 下载 wasm 内核
- 文件全程留在浏览器内存里，不发任何请求

## 示例

`movie.mp4` → MP3 192 kbps：

```text
输入：movie.mp4
输出格式：MP3　比特率：192 kbps
输出大小：xxx MiB
```

## 数据流向

**纯本地处理。** 提取在浏览器内完成，`meta.api = false`，无需自备 API/Key。
