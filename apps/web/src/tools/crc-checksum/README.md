# CRC 校验

计算 CRC-32 / CRC-32C / CRC-16 校验和，查表法实现，输出十六进制或十进制。

## 用途

核对固件、压缩包、网络帧、串口报文是否完整：CRC 是通信与存储里最常见的完整性校验。
本工具能一次算出协议里最常用的四种参数组，直接拿去和抓包结果比对。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入文本会按 **UTF-8 编码成字节**后再计算；中文、emoji 都按多字节参与。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 校验和，十六进制（带 `0x` 前缀）或十进制 |

## 选项

| 选项        | 取值                                        | 默认  | 说明                                  |
| ----------- | ------------------------------------------- | ----- | ------------------------------------- |
| `algorithm` | crc32 / crc32c / crc16-modbus / crc16-ccitt | crc32 | 参数组（见下表）                      |
| `mode`      | hex / dec                                   | hex   | 输出进制；hex 会按位宽补零到 8 / 4 位 |

各算法的参数组（都是完全确定的，**不需要**「字节反射 / XOR 初值」这类可调选项）：

| 取值           | 别名               | 宽度 | 多项式       | 反射 | init         | xorout       | 常见用途                   |
| -------------- | ------------------ | ---- | ------------ | ---- | ------------ | ------------ | -------------------------- |
| `crc32`        | CRC-32/IEEE 802.3  | 32   | `0x04C11DB7` | 是   | `0xFFFFFFFF` | `0xFFFFFFFF` | zlib / gzip / PNG / ZIP    |
| `crc32c`       | CRC-32/Castagnoli  | 32   | `0x1EDC6F41` | 是   | `0xFFFFFFFF` | `0xFFFFFFFF` | iSCSI / ext4 / SSE4.2 指令 |
| `crc16-modbus` | CRC-16/MODBUS      | 16   | `0x8005`     | 是   | `0xFFFF`     | `0x0000`     | Modbus RTU 串口帧          |
| `crc16-ccitt`  | CRC-16/CCITT-FALSE | 16   | `0x1021`     | 否   | `0xFFFF`     | `0x0000`     | X.25 / 部分蓝牙与 NFC 报文 |

## 限制

- 只处理**文本**输入，按 UTF-8 取字节。要校验十六进制报文（如 `01 03 00 00`），
  请先用十六进制工具转成字节再贴进来，或直接用命令行
- 校验和不是密码学哈希：它能发现随机错误，**不能**防篡改，安全场景请用 SHA-256 之类摘要
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（各算法文档通用的 check 值样本）：

```text
123456789
```

输出：

| 算法            | hex          | dec          |
| --------------- | ------------ | ------------ |
| `crc32`（默认） | `0xCBF43926` | `3421780262` |
| `crc32c`        | `0xE3069283` | `3808858755` |
| `crc16-modbus`  | `0x4B37`     | `19255`      |
| `crc16-ccitt`   | `0x29B1`     | `10673`      |
