# 转义反转义

JS、HTML、CSS、JSON、SQL 转义。

## 用途

在写模板、拼 SQL、贴代码片段时做转义或还原，避免引号与尖括号破坏语法。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                   |
| ------ | ------ | ---------------------- |
| `text` | string | 转义或反转义后的文本。 |

## 选项

| 选项   | 取值                         | 默认   | 说明             |
| ------ | ---------------------------- | ------ | ---------------- |
| `type` | js / html / css / json / sql | html   | 按哪套规则处理   |
| `mode` | escape / unescape            | escape | 方向：转义或还原 |

## 限制

- 各语言的转义规则并不统一（如 MySQL 与 PostgreSQL 对反斜杠的处理不同），本工具只做最通用的形式
- JS 反转义只还原 \n \r \t \\ \' \"，八进制与 \u 序列不在范围内
- CSS 用反斜杠 + \A 表示换行的等价写法，未实现完整的 CSS 标识符转义
- JSON 转义输出带外层引号；反转义遇到非法 JSON 会报错

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
<div class="a">工具库 & 870</div>
```

输出：

```text
<div class="a">工具库 & 870</div>
```
