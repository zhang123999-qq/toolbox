# 小数转换

高精度小数运算：用 decimal.js 算出精确结果，与 JS 原生浮点结果对照，并转换为科学计数法与分数表示。

## 用途

- 验证浮点陷阱：`0.1 + 0.2` 精确值是 `0.3`，JS 浮点是 `0.30000000000000004`
- 高精度四则运算（默认 20 位有效数字）
- 小数 ↔ 分数 ↔ 科学计数法互转：`2.5` → `5/2`、`2.5e0`

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 数字或四则表达式，最大 200,000 字符 |

表达式语法：数字（小数、整数、科学计数法如 `1.5e-3`）、运算符 `+ - * / ^`、括号 `()`。

## 输出

```text
表达式：0.1 + 0.2
精确结果：0.3
JS 浮点结果：0.30000000000000004
科学计数法：3e-1
分数：3/10
（decimal.js 默认 20 位有效数字）
```

## 选项

本工具无选项。

## 算法

- 同一套递归下降解析器（优先级：括号 > 一元符号 > `^` > `*` `/` > `+` `-`）分别跑在两种算术上：
  - 精确：decimal.js（十进制任意精度，`0.1 + 0.2 = 0.3`）
  - 对照：JS 原生 `number`（IEEE 754 双精度，`0.1 + 0.2 = 0.30000000000000004`）
- 分数行由 `Decimal#toFraction()` 给出精确表示

## 边界

- 除数为 0 → 中文报错（精确模式；浮点模式会得 `Infinity`，但精确模式先报错）
- 结果非有限数值（如 `0/0`）→ 中文报错
- 无法识别的字符 / 括号未闭合 → 中文报错
- 输入 > 200,000 字符 → 报错

## 示例

输入 `1.1^2`：精确结果 `1.21`，JS 浮点结果 `1.2100000000000002`。

## 数据流向

纯前端本地计算（decimal.js 在浏览器内运行），不调用外部接口、不上传数据。
