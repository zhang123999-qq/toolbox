# 列提取

从文本提取指定列。

## 用途

从分隔文本里只取出要用的那几列：从日志里摘字段、从导出表挑几列、把宽表裁窄，比在表格软件里点选更快。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

分隔文本（CSV / TSV / 分号 / 竖线 / 多空格均可）。空行丢弃，双引号内的分隔符不切分。

## 输出

| 字段   | 类型   | 说明                                                 |
| ------ | ------ | ---------------------------------------------------- |
| `text` | string | 只含所选列的文本，列之间用连接符连接（默认制表符）。 |

## 选项

| 选项          | 取值                                                      | 默认   | 说明                                              |
| ------------- | --------------------------------------------------------- | ------ | ------------------------------------------------- |
| `delimiter`   | `auto` / `comma` / `tab` / `semicolon` / `pipe` / `space` | `auto` | 输入分隔符，auto 按每行出现次数猜                 |
| `columns`     | 列号表达式                                                | `1`    | 支持 `1`、`1,3`、`1-3`、`2-`、`-2`；列号从 1 开始 |
| `joiner`      | 任意字符串                                                | 制表符 | 提取出的列之间的连接符                            |
| `skipMissing` | 勾选 / 取消                                               | 取消   | 某行没有该列时跳过而不是填空串                    |

## 限制

- 列号去重后按**升序**输出，与书写顺序无关（写 `3,1` 得到的是第 1、3 列）
- 不支持按列名提取：表头在首行时本工具把它当普通数据行，请先用「文本分列」（#38）确认列号
- 开放范围 `2-` 取到「本批次最大列数」，各行列数不一致时以最大值为准
- 不做类型转换与去空白，取出的值原样保留
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
name,age,city
Bob,7,Beijing
Amy,9,Shanghai
```

输出：

```text
name
Bob
Amy
```
