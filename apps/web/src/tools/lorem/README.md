# Lorem 生成

生成乱数假文，支持中英文。

## 用途

给排版、原型、演示数据造占位文本：可选中文、英文或拉丁词库，按段、句或词为单位生成，也可以换成自己的词库。

## 输入

| 字段   | 类型   | 约束            |
| ------ | ------ | --------------- |
| `text` | string | 最大 5,000 字符 |

可选：自定义词库（按空白、逗号、顿号、分号分隔）。**留空则使用内置词库**，这就是最常用的用法。

## 输出

| 字段   | 类型   | 说明                                                                                     |
| ------ | ------ | ---------------------------------------------------------------------------------------- |
| `text` | string | 生成的假文。中文词之间不加空格、以。结尾；英文 / 拉丁以空格分词、首字母大写并以 . 结尾。 |

## 选项

| 选项       | 取值                                                   | 默认        | 说明     |
| ---------- | ------------------------------------------------------ | ----------- | -------- |
| `language` | `zh` / `en` / `latin`                                  | `zh`        | 词库语言 |
| `unit`     | `paragraph`（3–6 句） / `sentence`（5–15 词） / `word` | `paragraph` | 生成单位 |
| `count`    | `1` / `2` / `3` / `5`                                  | `1`         | 生成数量 |

## 限制

- 每次生成都是随机的，**不提供种子与复现能力**，刷新即变
- 中文词库是常见双字词的随机拼接，不是语法正确的自然语言，仅用于占位
- 只生成纯文本，不含 HTML 标签、标题层级或列表结构
- 自定义词库一旦填写就完全替代内置词库，若只有一个词会输出重复内容
- 内置词库规模有限（中文 30 词 / 英文 40 词 / 拉丁 30 词），长文本重复度较高

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
（留空，使用内置中文词库；如需自定义可填「春风 秋月 江山」）
```

输出：

```text

```
