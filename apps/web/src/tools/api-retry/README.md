# 接口重试策略（#760）

A 级工具：纯前端本地计算，无网络、无第三方 API。

## 功能

- **三种策略**：指数退避（`base × multiplierⁿ`）、线性递增（`base × (n+1)`）、固定间隔。
- **上限截断**：单次等待不超过 `maxDelayMs`。
- **抖动**：可选 ±50% 随机区间，输出标称值与上下界。
- **累计等待**：逐次累计，给出最坏总等待时间。

## 输入配置（JSON）

```json
{
  "baseDelayMs": 1000,
  "multiplier": 2,
  "maxDelayMs": 8000,
  "maxRetries": 5,
  "jitter": true,
  "strategy": "exponential"
}
```

## 说明

- 参数非法时报中文错（如初始延迟必须为正整数、重试次数上限 20）。
- 抖动区间仅作规划参考，实际等待由调用方在区间内随机取。
- 所有计算在浏览器本地完成，不发送任何网络请求。
