# 文本填充

左右填充字符到指定长度。

## 用途

把每行用指定字符填到固定长度：编号补零、对齐定宽字段、给文本加装饰边框都靠它。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

多行文本；逐行独立处理。

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 填充后的文本；已够长的行原样保留。 |

## 选项

| 选项     | 取值                                 | 默认   | 说明                              |
| -------- | ------------------------------------ | ------ | --------------------------------- |
| `mode`   | `left` / `right` / `both` / `center` | `left` | 左填充 / 右填充 / 两边都填 / 居中 |
| `length` | `8` / `16` / `32` / `64`             | `8`    | 目标长度                          |
| `filler` | 字符串（最多 4 字符）                | `0`    | 填充字符                          |

## 限制

- **按字符数算长度，不是显示列宽**：中文一个字算 1，与 #61 对齐 / #62 折行的「列宽」不是同一把尺子；混排中日韩时视觉上会不齐
- `both` 模式的长度是**每一侧**的长度，因此总长是 `原文长度 + 2 × 长度`
- 已够长的行原样保留，不会被截断（要截断请用 #63 文本截断）
- 多字符 filler 会循环取用后按需要截断，因此可能出现半个填充单元
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
1
42
512
```

输出：

```text
00000001
00000042
00000512
```
