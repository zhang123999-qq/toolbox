# 精灵图切割（#786）

A 级工具：纯前端本地处理，无网络、无第三方 API。

## 功能

- **计算帧列表**：输入切割参数，计算雪碧图中每帧的坐标与尺寸；
- **切割并下载**：上传精灵图后，按帧逐张导出 PNG（`frame-0.png` …）。

## 输入参数（JSON）

```json
{ "imgW": 256, "imgH": 128, "cols": 4, "rows": 2, "margin": 0, "spacing": 0 }
```

- `imgW` / `imgH`：原图宽高（像素）；
- `cols` / `rows`：列数 / 行数；
- `margin`：外边距（可选，默认 0）；
- `spacing`：帧间距（可选，默认 0）。

上传图片后，「切割并下载」使用图片真实尺寸（忽略参数中的 `imgW`/`imgH`）。

## 约束

- 原图宽高减去边距与间距后必须能被行列整除，否则报错；
- 所有图片处理均在浏览器本地完成，不上传服务器。
