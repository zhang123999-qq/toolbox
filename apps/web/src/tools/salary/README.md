# 工资计算

输入税前月薪，选择社保 / 公积金个人缴纳比例，算出五险一金个人部分、应纳税所得额、个人所得税与税后到手工资。

## 用途

- 发 offer / 谈薪时估算到手工资
- 核对工资条上的社保、公积金与个税扣款
- 对比不同城市社保公积金比例下的收入差异

## 输入

| 字段   | 类型   | 约束                                        |
| ------ | ------ | ------------------------------------------- |
| `text` | string | 税前月薪（元），必须 > 0，最大 200,000 字符 |

## 输出

```text
税前月薪：15000.00 元
社保个人缴纳（10.5%）：1575.00 元
公积金个人缴纳（12%）：1800.00 元
应纳税所得额：6625.00 元
个人所得税：452.50 元
税后到手：11172.50 元
```

> 上例对应输入 15000、社保 10.5%、公积金 12% 的真实计算结果。

## 选项

| 选项         | 类型   | 说明                          |
| ------------ | ------ | ----------------------------- |
| `socialRate` | select | 社保个人比例%：`8` `10.5`     |
| `fundRate`   | select | 公积金个人比例%：`5` `7` `12` |

## 算法

- 社保个人缴纳 = 税前月薪 × 社保比例 / 100
- 公积金个人缴纳 = 税前月薪 × 公积金比例 / 100
- 应纳税所得额 = 税前月薪 − 社保 − 公积金 − 5000（起征点）；≤ 0 时个税为 0
- 个税按中国个税月度税率表计算：应纳税所得额 × 税率 − 速算扣除数

| 应纳税所得额   | 税率 | 速算扣除数 |
| -------------- | ---- | ---------- |
| ≤ 3000         | 3%   | 0          |
| (3000, 12000]  | 10%  | 210        |
| (12000, 25000] | 20%  | 1410       |
| (25000, 35000] | 25%  | 2660       |
| (35000, 55000] | 30%  | 4410       |
| (55000, 80000] | 35%  | 7160       |
| > 80000        | 45%  | 15160      |

- 税后到手 = 税前月薪 − 社保 − 公积金 − 个税
- 金额格式化：`n.toFixed(2)`

## 边界

- 空输入 → 输出空串
- 非数字 → 中文报错「税前月薪请输入有效的数字」
- ≤ 0 → 中文报错「税前月薪必须大于 0」
- \> 10000000 → 中文报错「金额超出合理范围」
- 比例 NaN / < 0 / \> 100 → 中文报错「社保/公积金比例非法」
- 输入 > 200,000 字符 → 报错

## 示例

输入 `15000`，社保 `10.5%`，公积金 `12%`：

```text
税前月薪：15000.00 元
社保个人缴纳（10.5%）：1575.00 元
公积金个人缴纳（12%）：1800.00 元
应纳税所得额：6625.00 元
个人所得税：452.50 元
税后到手：11172.50 元
```

## English

A salary calculator: enter gross monthly salary, pick personal social-insurance and housing-fund rates, and get the personal contributions, taxable income, individual income tax (China monthly brackets) and take-home pay. Input: `text` (gross monthly salary in CNY). Output: e.g. `税后到手：11072.50 元`.
