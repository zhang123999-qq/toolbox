# 语义搜索（semantic-search）

在本地文档库中按"相关度"排序检索：粘贴多篇文档（每行一篇），输入查询语句，返回按相似度排序的结果。

## 功能

- 纯本地 TF-IDF + 余弦相似度，无需网络、无需 Key
- 英文按单词切分，中文按单字 + 二元词（n-gram）切分
- 结果按相似度从高到低排序，并显示每篇的相似度分数

## 使用

1. 在左侧粘贴文档库，每行一篇文档
2. 在「查询语句」中输入要查的内容
3. 点「搜索」，右侧按相关度列出排序结果

## 重要说明（请先读）

- **这不是真正的"语义理解"**：底层是词袋（bag-of-words）模型，只看词频重合，不理解含义
- 中文切分是简易的字符 n-gram（单字 + 相邻二元词），没有分词词典，长词、专有名词可能被拆散
- 同义词（如"手机"与"电话"）会被当成完全不同的词，查不到
- 适合：关键词检索、文档初筛；不适合：语义问答、推理
