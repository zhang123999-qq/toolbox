# 网速测试（#837）

测量网络带宽（下载 / 上传速率，单位 Mbps）并评级。D 级工具：浏览器 fetch 直连你填写的测速端点，无后端、无 Key。

## 功能

- 输入测速端点 URL，选择「下载 / 上传 / 双模式」，点「运行」即在浏览器内测量。
- 下载：GET 整个响应体并计时；上传：POST 指定大小的数据并计时。
- 评级：<10 Mbps 较慢，10–100 Mbps 良好，>100 Mbps 优秀。

## 局限

- **CORS**：跨域端点若未返回 `Access-Control-Allow-Origin`，浏览器会拦截请求导致测速失败。请使用允许跨域的测速端点（如自建同源端点）。
- **端点要求**：下载需要端点返回一定体积的响应体（越大越准）；上传需要端点接受 POST 请求。
- **近似性**：浏览器计时包含 JS 开销，结果为近似值；如需精确测量请使用系统级测速工具。
- 与 #648「网站速度测试」的区别：#648 测的是单个页面的加载耗时（总耗时/TTFB），本工具测的是网络带宽。
