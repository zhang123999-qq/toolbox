# SQL 转义

SQL 字符串转义与还原，区分 MySQL / PostgreSQL / SQL Server。

## 用途

把用户输入、文本内容转义成能安全拼进 SQL 字符串字面量的形式，避免单引号、
反斜杠把语句截断（也就是常说的 SQL 注入的字符层成因）；反向则用于把日志、
慢查询里带 `\'`、`''` 的字面量还原成人能读的原文。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                                      |
| ------ | ------ | ----------------------------------------- |
| `text` | string | 转义后为 SQL 字面量内容；还原后为原始文本 |

## 选项

| 选项        | 取值                         | 默认   | 说明                     |
| ----------- | ---------------------------- | ------ | ------------------------ |
| `direction` | escape / unescape            | escape | 转义或还原               |
| `type`      | mysql / postgres / sqlserver | mysql  | 按哪个数据库的转义规则   |
| `quote`     | 布尔                         | 开     | 是否给结果套上首尾单引号 |

## 限制

- **MySQL**：默认开启反斜杠转义，`\` `'` `"` `\0` `\b` `\t` `\n` `\r` `\Z`(Ctrl-Z)
  都写成 `\x` 形式，因此单引号输出 `\'`
- **PostgreSQL**：默认 `standard_conforming_strings = on`，反斜杠是普通字符，
  单引号写成两个（`''`）；不带 `E'...'` 前缀的反斜杠不会被转义
- **SQL Server**：同样用两个单引号表示单引号，反斜杠是普通字符；
  因此纯引号场景下 PostgreSQL 与 SQL Server 的输出一致，差别只在文档口径
- 这是**字符层转义，不能替代参数化查询**——正确做法永远是预处理语句 / 绑定变量，
  本工具只用于生成脚本、构造测试数据或排查日志
- 还原时会自动剥掉首尾的单引号（兼容 SQL Server 的 `N'...'` 前缀），
  带引号和不带引号的输入都能直接粘贴

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
O'Brien
```

输出（escape / mysql / 加引号）：

```text
'O\'Brien'
```
