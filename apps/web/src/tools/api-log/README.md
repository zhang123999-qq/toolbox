# 接口日志分析（#765）

A 级工具：纯前端本地计算，无网络、无第三方 API。

## 功能

- **解析**：Apache / Nginx combined 格式访问日志，
  尾部可选 `request_time`（秒）作为耗时字段。
- **统计**：状态码分布（2xx/3xx/4xx/5xx）、错误率（5xx 占比）、
  热点路径 Top 10（含平均耗时与 5xx 数）、峰值小时。
- **容错**：非法行自动跳过并计数提示；空行忽略。

## 说明

- 日志只在浏览器本地解析，不上传到任何服务器。
- 无耗时字段时平均耗时列显示为 `—`（nginx 可在格式尾追加 `$request_time`）。
- 峰值小时按 UTC 输出（`YYYY-MM-DDTHH:00`）。
