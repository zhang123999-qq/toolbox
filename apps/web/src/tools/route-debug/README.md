# 路由调试

输入路由规则与测试路径，看是否匹配，并提取出路径参数。

## 用途

写前端路由（React Router / Vue Router）或后端路由时，不确定 `:id` `*` `?` 到底怎么匹配。
在这里贴规则和路径，立刻看到命中结果与提取到的参数。

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 测试路径，如 `/users/123/posts/456` |

## 输出

| 字段   | 类型   | 说明                        |
| ------ | ------ | --------------------------- |
| `text` | string | 匹配结果 + 提取到的命名参数 |

## 选项

| 选项 key  | 界面标签 | 说明                          |
| --------- | -------- | ----------------------------- |
| `pattern` | 路由规则 | 如 `/users/:id/posts/:postId` |

## 支持的语法

| 写法        | 含义                        | 示例规则          | 示例路径                 |
| ----------- | --------------------------- | ----------------- | ------------------------ |
| `:name`     | 命名参数                    | `/users/:id`      | `/users/123` → id=123    |
| `:name(re)` | 带正则约束的参数            | `/users/:id(\d+)` | `/users/abc` 不匹配      |
| `:name?`    | 可选段                      | `/users/:id?`     | `/users` 也匹配          |
| `*`         | 通配，捕获剩余整段（splat） | `/files/*`        | `/files/a/b` → splat=a/b |

## 限制

- 不支持查询串 `?foo=bar` 的解析（只匹配路径部分）
- 不支持 `+` 多段重复参数等高级语法
- 不做路由优先级排序，单条规则单条测
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** `meta.api = false`。

## 示例

输入路径 `/users/123/posts/456`，规则 `/users/:id/posts/:postId`：

```text
匹配成功

路径: /users/123/posts/456
规则: /users/:id/posts/:postId

提取到的参数：
  id: 123
  postId: 456
```
