# 瓦片地图（#788）

游戏瓦片地图编辑器：在画布上点击绘制瓦片，支持多图层数据结构、矩形填充、地图缩放，并可导出/导入地图 JSON。

## 功能

- **新建地图**：指定列数/行数，瓦片 32px
- **笔刷绘制**：选择瓦片 id（0-9），点击画布绘制
- **全图填充**：一键用当前笔刷填满
- **导入/导出 JSON**：地图数据结构 `{ cols, rows, tileSize, layers }`，`layers[l][y][x]` 为瓦片 id（0 = 空）
- **文本预览**：ASCII 字符展示地图布局

## 说明

- 纯前端本地处理，不发送任何网络请求
- 导出 JSON 可直接用于游戏引擎加载
