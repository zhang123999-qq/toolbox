# JSON 树形查看

把 JSON 展开成**缩进树形文本**，每一行标注节点类型与取值；也可切成平铺的路径列表。

## 用途

读别人给的接口响应时不用来回翻 JSON：`name`、`tools`、`tags[0]` 各是什么类型、值是多少，
一眼扫到。切换「模式」还能把整棵树的路径摊平成可搜索、可喂给脚本的列表。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 树形文本或路径列表；空输入返回空串 |

树形（`mode = tree`）：

```
$ <object> 3 项
  name <string> "工具库"
  tools <number> 870
  tags <array> 2 项
    [0] <string> "json"
    [1] <string> "static"
```

平铺路径（`mode = path`）：

```
$.name = "工具库"
$.tools = 870
$.tags[0] = "json"
$.tags[1] = "static"
```

## 选项

| 选项       | 取值             | 默认    | 说明                     |
| ---------- | ---------------- | ------- | ------------------------ |
| `mode`     | `tree` \| `path` | `tree`  | 缩进树 / 平铺路径列表    |
| `sortKeys` | boolean          | `false` | 对象键按字典序排（递归） |

## 限制

- **不是可点击折叠的 UI**：本工具走 T2 双栏模板，输出必须是纯文本，
  因此「可折叠」由阅读者借助编辑器折叠完成，这里保证的是层级与类型可见
- 超过 200,000 个节点会抛 `JsonTreeError`（树太长没有可读性，请先取子集）
- 嵌套超过 2,000 层抛错（递归展开受调用栈限制）
- 长度超过 80 字符的字符串截断预览，并给出原始字符数
- 输入上限 1,000,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```json
{
  "name": "工具库",
  "tools": 870,
  "tags": ["json", "static"]
}
```

输出（`tree`）：

```
$ <object> 3 项
  name <string> "工具库"
  tools <number> 870
  tags <array> 2 项
    [0] <string> "json"
    [1] <string> "static"
```
