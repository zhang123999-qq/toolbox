# 经验曲线（#805）

等级经验曲线：生成 1..N 级升级所需经验表（含累计），支持由累计经验反查等级。

## 模式与公式

| 模式        | 参数 JSON                    | 单级所需经验                |
| ----------- | ---------------------------- | --------------------------- |
| linear      | `{"base":100,"growth":50}`   | `base + growth × (level-1)` |
| exponential | `{"base":100,"growth":1.15}` | `base × growth^(level-1)`   |

- `base`：1 级升 2 级所需经验（> 0）
- `growth`：线性为每级增量（≥ 0），指数为每级成长系数（> 0）

## 功能

- **生成经验表**：每级升级所需经验 + 从 1 级起的累计经验
- **反查等级**：输入累计经验，返回当前等级（不超过表上限）

## 说明

纯前端本地计算，不发送任何网络请求。输入校验失败时中文报错。
