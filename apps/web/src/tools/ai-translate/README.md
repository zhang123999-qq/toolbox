# AI 翻译（ai-translate）

调用大模型做多语言互译，语言列表使用中文友好名称。

## 功能

- 支持中文、英语、日语、韩语、法语、德语、西班牙语、俄语、葡萄牙语、阿拉伯语等
- 源语言可选「自动检测」，源语言与目标语言相同时会中文提示
- BYOK：使用你自己的 API Key，兼容 OpenAI 接口格式
- 服务地址、模型均可修改（默认 `https://api.openai.com/v1` / `gpt-4o-mini`）
- 超时（60 秒）、401、429、网络失败都有中文提示

## 使用

1. 在「API Key」中填写你的 Key（密码框，可一键清除）
2. 输入待翻译文本，选择源语言与目标语言
3. 点「开始翻译」，结果可复制

## 隐私说明

- **Key 只保存在你浏览器的 localStorage，不会发送到除你填写的服务地址之外的任何地方**
- 翻译请求直接从浏览器发往你填写的服务地址，本工具服务器不经手
- 不记录、不硬编码任何 Key
