# 文本换行

按宽度自动换行。

## 用途

按指定的显示列宽自动折行：`auto` 让英文按词断、中文按字断，`word` 只按词断，`char` 直接按字符断。写 README、终端输出、代码注释时常用。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

一段文本；逐行独立处理，不重排段落。

## 输出

| 字段   | 类型   | 说明                                                                 |
| ------ | ------ | -------------------------------------------------------------------- |
| `text` | string | 折行后的文本，每行显示宽度不超过设定值（除非遇到关掉硬切的超长词）。 |

## 选项

| 选项        | 取值                     | 默认   | 说明                                          |
| ----------- | ------------------------ | ------ | --------------------------------------------- |
| `mode`      | `auto` / `word` / `char` | `auto` | 自动（英文按词、中文按字）/ 只按词 / 只按字符 |
| `width`     | `40` / `60` / `80`       | `40`   | 目标显示列宽                                  |
| `breakLong` | 布尔                     | `true` | 单个词超过宽度时是否硬切（长 URL 需要）       |

## 限制

- **按显示列宽算**：中日韩全角字符占 2 列、emoji 估算为 2 列；等宽字体下准确，比例字体下会有偏差
- **不会重排段落**：逐行独立折行，把一个长段落粘成一行进来才会折成多行；已经是多行的文本保持原有行结构
- 折行后**行首空白被丢弃**（原文缩进在折行后没有意义），需要保留缩进请改用其他方式
- `auto` 模式靠「拉丁词 / CJK 单字」两套单元切分，遇到泰文、阿拉伯文这类无空格连写文字会退化为按字断
- `breakLong` 关闭时，超长词会独占一行并超出设定宽度
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
这是一段需要按宽度自动换行的中文文本，用来验证换行工具在等宽字体下的表现。
```

输出：

```text
这是一段需要按宽度自动换行的中文文本，用
来验证换行工具在等宽字体下的表现。
```
