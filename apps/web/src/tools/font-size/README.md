# 字体大小

字体排印工具三件套：按最小 / 最大字号与视口宽度生成 `clamp()` 流式字号 CSS；px 与 rem 互转（根字号 16px，可验证）；按字号、行宽（字符数）、行高评估正文可读性并给出改进建议。

## 用途

- 生成响应式流式字号，避免多断点媒体查询
- 检查正文排版是否符合可读性舒适区间
- px / rem 快速换算

## 输入

| 字段   | 类型   | 约束                 |
| ------ | ------ | -------------------- |
| `text` | string | 未使用（参数在页面表单中） |

在页面内设置：最小/最大字号、最小/最大视口宽度；评估用的字号、行宽、行高；换算数值与方向。

## 说明

- 纯前端计算，无网络请求，零依赖。
- 可读性评分：字号 ≥ 16px、行宽 45–75 字符、行高 1.4–1.8 为满分区间，偏离时给出具体建议。
- 流式字号公式：clamp(最小字号, 截距 + 斜率×100vw, 最大字号)。
