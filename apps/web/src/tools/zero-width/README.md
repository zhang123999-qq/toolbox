# 零宽字符

检测零宽字符、水印。

## 用途

揪出文本里的零宽字符：它们看不见、不影响排版，却常被用来做隐藏水印（追踪复制来源）或让复制出来的代码失效。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本。

## 输出

| 字段   | 类型   | 说明                                                                                               |
| ------ | ------ | -------------------------------------------------------------------------------------------------- |
| `text` | string | detect 给出位置、码位、名称与统计（连续较多时会提示疑似水印）；remove 删除；extract 输出码位序列。 |

## 选项

| 选项   | 取值                                                            | 默认     | 说明     |
| ------ | --------------------------------------------------------------- | -------- | -------- |
| `mode` | `detect`（检测） / `remove`（删除） / `extract`（抽出码位序列） | `detect` | 处理方式 |

## 限制

- **只检测，不解密**：不把零宽序列还原成隐藏文本，因为隐写编码没有统一标准，各家实现不同
- 连续 8 个及以上零宽字符才提示「疑似水印」，短序列可能是正常的排版 / 双向文字控制符
- 只覆盖零宽与方向控制字符，不换行空格、软连字符等其它不可见字符请用「不可见字符」（#41）
- 删除会同时去掉正常的方向控制符，从右到左文字（阿拉伯语、希伯来语）中请谨慎使用
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
普通␣文␣本␣带␣水印（四个 ␣ 依次是 U+200B / U+200C / U+200D / U+2060）
```

输出：

```text
第 1 行第 3 列：U+200B 零宽空格
第 1 行第 5 列：U+200C 零宽非连接符
第 1 行第 7 列：U+200D 零宽连接符
第 1 行第 9 列：U+2060 词连接符
共 4 处
```
