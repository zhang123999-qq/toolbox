# 文本哈希

文本哈希值。

## 用途

算一段文本的哈希摘要，用于校验完整性、比对内容是否一致、或生成去重键。支持 SHA-1 与 SHA-256/384/512。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

一段文本；按 UTF-8 编码参与计算。

## 输出

| 字段   | 类型   | 说明                 |
| ------ | ------ | -------------------- |
| `text` | string | 十六进制摘要字符串。 |

## 选项

| 选项        | 取值                                        | 默认      | 说明               |
| ----------- | ------------------------------------------- | --------- | ------------------ |
| `algorithm` | `SHA-1` / `SHA-256` / `SHA-384` / `SHA-512` | `SHA-256` | 摘要算法           |
| `uppercase` | 布尔                                        | `false`   | 十六进制是否用大写 |

## 限制

- **不是加密**：哈希不可逆，也不能用来「解密」；要加解密请用 #56 文本加密
- **不做加盐**：校验用可以，存口令不行——明文口令的 SHA-256 能被彩虹表反查
- 依赖浏览器的 WebCrypto，需要 HTTPS 或 localhost；不安全上下文会直接报错
- WebCrypto 只提供 SHA 家族，没有 MD5 / CRC32 / Blake3；要这些请换工具
- SHA-1 已不适合做安全校验，列出来只是为了兼容旧系统
- 输入上限 1,000,000 字符

## 数据流向

**不联网。** 全部由浏览器本地完成：数据只在当前页面的输入框与输出框之间流转，不写入 localStorage、不发送、不上传。

- 摘要计算由浏览器的 WebCrypto 在本地完成，文本不离开当前页面

## 示例

输入：

```text
abc
```

输出：

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
