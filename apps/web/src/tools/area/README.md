# 面积换算

输入数值并选择源单位与目标单位，即时得到面积换算结果（含亩、公顷）。

## 用途

- 亩 / 公顷 / 平方千米与英亩 / 平方英尺互转
- 土地、房产场景的面积单位对照

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待换算的数值，最大 200,000 字符 |

## 输出

单行文本：`输入值 源单位 = 结果 目标单位`

```text
1 亩 = 666.6666667 m²
```

## 选项

| 字段   | 类型   | 说明     | 可选值                          |
| ------ | ------ | -------- | ------------------------------- |
| `from` | select | 源单位   | cm²、m²、ha、km²、亩、ft²、acre |
| `to`   | select | 目标单位 | 同左                            |

## 算法

- 以**平方米**为基准：`结果 = 数值 × from.factor / to.factor`
- 输出用 `Number(n.toPrecision(12)).toString()` 格式化，去浮点噪声、去尾零

## 边界

- 空输入 → 输出为空（不报错）
- 非数字输入 → 中文报错「请输入有效的数字」
- 未知单位 id → 中文报错「未知单位」
- 输入 > 200,000 字符 → 报错

## 示例

输入数值：`1`，从 `acre` 到 `m²`

输出：`1 acre = 4046.8564224 m²`

## English

Convert between area units (incl. mu and hectare).

- Input: a numeric string.
- Output: one line, e.g. `1 acre = 4046.8564224 m²`.
- Options: `from` / `to` selects over cm², m², ha, km², 亩 (mu), ft², acre.
