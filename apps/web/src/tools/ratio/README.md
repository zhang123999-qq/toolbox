# 比例计算

化简比例（如 `12:18 → 2:3`）、解比例方程（`a:b = c:x` 求 x）、按比例分配总数。

## 用途

- 化简比例：`12:18` → `2:3`
- 解方程：已知 `2:3 = 10:x`，求 x
- 分钱 / 分任务：1000 元按 `2:3:5` 分给三人

## 输入

| 字段    | 类型   | 约束                                            |
| ------- | ------ | ----------------------------------------------- |
| `text`  | string | 比例串，冒号分隔，如 `12:18`，最大 200,000 字符 |
| `textB` | string | 第二个值：解方程模式=已知项 c，分配模式=总数    |

## 输出

化简模式（输入 `12:18`）：

```text
12 : 18 = 2 : 3
最简比例：2 : 3
```

解方程模式（输入 `2:3`，第二个值 `10`）：

```text
2 : 3 = 10 : x
x = 3 × 10 ÷ 2 = 15
```

分配模式（输入 `2:3:5`，总数 `1000`）：

```text
总数 1000 按 2 : 3 : 5 分配：
第 1 项：200
第 2 项：300
第 3 项：500
```

## 选项

| 选项   | 取值                           | 说明                                            |
| ------ | ------------------------------ | ----------------------------------------------- |
| `mode` | `simplify` / `solve` / `split` | 化简 / 解比例方程 / 按比例分配，默认 `simplify` |

## 算法

- **化简**：小数项按最大小数位数放大为整数，再求全部项的最大公约数（GCD）约分，如 `1.5:2.5 → 3:5`
- **解方程**：`x = b × c ÷ a`
- **分配**：`份额 = 该项 ÷ 各项之和 × 总数`

## 边界

- 冒号支持半角 `:` 与全角 `：`
- 比例至少两项；解方程模式要求恰好两项
- 各项不能全为 0；分配模式各项之和不能为 0
- 非数字输入 → 中文报错；输入 > 200,000 字符 → 报错

## 示例

输入 `12:18`，化简模式：输出 `12 : 18 = 2 : 3`。

## 数据流向

纯前端本地计算，不调用外部接口、不上传数据。
