# 安全头检测

把一段 HTTP **响应头**粘进来，离线检测常见安全响应头是否齐全、配置是否安全，
输出逐项结论（风险 / 缺失 / 提示 / 通过）与总评级。纯本地规则判断，不发网络请求。

## 用途

上线前自查站点安全基线：HSTS 是否生效、CSP 是否过宽、能否被 iframe 嵌套（点击劫持）、
是否禁用 MIME 嗅探、Referer 与权限策略、以及是否泄露了服务端技术栈。

## 输入

| 字段   | 类型   | 约束                                                  |
| ------ | ------ | ----------------------------------------------------- |
| `text` | string | 最大 200,000 字符；每行一个 `Name: value`，可含状态行 |

## 检测的响应头

| 响应头                                                         | 主要判定                                                                                              |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `Strict-Transport-Security`                                    | 缺失 → 风险；`max-age=0` → 风险；过短（< 6 个月）→ 提示；含 includeSubDomains/preload 标注            |
| `Content-Security-Policy`                                      | 缺失 → 缺失；含 `unsafe-inline` / `unsafe-eval` / 通配来源 → 风险                                     |
| `X-Frame-Options`                                              | DENY/SAMEORIGIN → 通过；ALLOWALL → 风险；缺失时若 CSP 含 `frame-ancestors` 也算通过，否则提示点击劫持 |
| `X-Content-Type-Options`                                       | `nosniff` → 通过；缺失 → 提示（MIME 嗅探）                                                            |
| `Referrer-Policy`                                              | `unsafe-url` → 风险；缺失 → 提示（Referer 泄露）                                                      |
| `Permissions-Policy`                                           | 缺失 → 提示（未收敛摄像头 / 定位等能力）                                                              |
| `X-XSS-Protection`                                             | 已废弃：建议设为 `0`，不设也可                                                                        |
| `Server` / `X-Powered-By` / `X-AspNet-Version` / `X-Generator` | 出现即提示（信息泄露）                                                                                |

## 与「实时 fetch 检测」的区别（重要）

规划中本工具为 D 级（浏览器 `fetch` 实测任意 URL），实际落地改为**离线规则分析**：
浏览器侧难以稳定、跨域地读取任意站点完整响应头，且结果受网络与目标站策略影响、不可复现。
本工具只分析你**粘贴进来的真实响应头**，结论确定、可单测，不替目标站发请求。

## 限制

- 静态规则判断，覆盖的是业界通用基线（OWASP / securityheaders.com 常见项的简化版），不针对具体业务威胁建模
- 不深度解析 CSP 每条指令的来源合法性，只识别典型放宽项；不校验证书、Cookie 属性
- 输入上限 200,000 字符；解析不到任何头时抛 `SecurityHeadersError`

## 数据流向

**纯本地处理。** 响应头仅在浏览器内存中分析，不发送网络请求，不写入服务端。`meta.api = false`。
