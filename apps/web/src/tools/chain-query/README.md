# 链上查询

经公共 JSON-RPC 查询以太坊主网：地址余额 / 交易详情 / 区块信息。只读查询，不签名、不发送交易。

## 用途

查某个地址有多少 ETH、某笔交易是否上链、某个区块的基本信息，不用装节点也不用开 etherscan。

## 输入

| 字段   | 类型   | 约束                                                                          |
| ------ | ------ | ----------------------------------------------------------------------------- |
| `text` | string | 查询内容：地址（0x+40 hex）/ 交易哈希（0x+64 hex）/ 区块号，最大 200,000 字符 |

## 选项

| 选项     | 取值                                                         |
| -------- | ------------------------------------------------------------ |
| 查询类型 | `余额查询` / `交易查询` / `区块查询`                         |
| RPC 地址 | JSON-RPC 地址，留空用默认公共节点 `https://eth.llamarpc.com` |

区块号支持 `latest` / `earliest` / `pending`、十进制（如 `21000000`）、`0x` hex（如 `0x1406f40`）。

## 输出（余额查询）

```text
余额：1 ETH
    = 1000000000 gwei
    = 1000000000000000000 wei
```

## 说明

- 依赖公共 RPC 节点，可能限流、超时或被浏览器 CORS 限制；失败会明确报错，可自填其他 RPC 地址重试（地址只保存在页面 state，不写入任何存储）。
- 只做链上原生单位展示，不做 USD 等法币换算。
