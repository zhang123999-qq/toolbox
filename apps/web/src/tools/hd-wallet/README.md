# HD 钱包

BIP32 / BIP44 分层确定性钱包：从种子按路径批量推导私钥与以太坊地址。

## 用途

输入种子（hex，可用 #702 助记词「转种子」得到），按 BIP44 以太坊路径批量生成地址，用于测试与学习。

## 输入

| 字段   | 类型   | 约束                                    |
| ------ | ------ | --------------------------------------- |
| `text` | string | 种子 hex，16–64 字节，最大 200,000 字符 |

## 选项

| 选项     | 默认值           | 说明                                   |
| -------- | ---------------- | -------------------------------------- |
| 基础路径 | `m/44'/60'/0'/0` | BIP32 路径，`'` 表示硬化，序号自动追加 |
| 起始序号 | `0`              | 含                                     |
| 结束序号 | `4`              | 含，最多一次 20 个                     |

输出每项：序号、完整路径、EIP-55 地址、私钥（hex）。

## 安全

- 仅供学习测试使用；生产环境请使用硬件钱包。
- 私钥只显示在页面内存中，不写入任何存储、不上传网络；切勿截图外发。
- HMAC-SHA-512 / secp256k1 均为本工具内手写实现，无第三方依赖。
