# 折扣计算

按折扣率（如 8.5 折）或折后价反推折扣，算出折后价与节省金额。

## 用途

- 电商大促：满减 / 打折时快速算实付价
- 门店核价：顾客报折后价，反推是几折
- 比价：不同折扣方案下哪个更划算

## 输入

| 字段    | 类型   | 约束                                  |
| ------- | ------ | ------------------------------------- |
| `text`  | string | 原价（必须大于 0），最大 200,000 字符 |
| `textB` | string | 折扣（如 8.5）或折后价（由选项决定）  |

## 输出

```text
原价：100.00 元
折扣：8.5 折
折后价：85.00 元
节省：15.00 元
```

## 选项

| 选项   | 类型   | 说明                              |
| ------ | ------ | --------------------------------- |
| `mode` | select | 计算方式：`按折扣率` / `按折后价` |

## 算法

- 按折扣率：`折后价 = 原价 × 折扣 / 10`，`节省 = 原价 − 折后价`
- 按折后价：`折扣 = 折后价 / 原价 × 10`，`节省 = 原价 − 折后价`
- 金额保留 2 位小数；折扣行用 12 位有效数字格式化（去浮点尾巴）

## 边界

- 空输入 → 输出空串
- 原价非数字 / ≤ 0 → 中文报错
- 折扣为空 / 非数字 / 不在 (0, 10] 区间 → 中文报错
- 折后价为空 / 非数字 / ≤ 0 / 高于原价 → 中文报错
- 未知计算方式 → 中文报错「未知计算方式」

## 示例

原价 `100`，折扣 `8.5`，方式 `按折扣率`：

```text
原价：100.00 元
折扣：8.5 折
折后价：85.00 元
节省：15.00 元
```

## English

A discount calculator: compute the final price and savings from a discount rate (e.g. 8.5 = 85% off), or reverse-calculate the discount rate from a final price. Input: `text` (original price), `textB` (rate or final price). Output: e.g. `折后价：85.00 元` / `节省：15.00 元`.
