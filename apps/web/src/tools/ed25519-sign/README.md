# Ed25519 签名

Ed25519（EdDSA）签名与验签，基于浏览器 WebCrypto。

## 用途

给一段文本做 Edwards 曲线签名并验证。Ed25519 签名短（64 字节）、快，并且**确定性**——
同样的密钥与数据永远得到同样的签名，因此可以直接用已知值核对其它实现（SSH、minisign、Go/Node）。

## 输入

| 字段         | 类型   | 约束              | 说明           |
| ------------ | ------ | ----------------- | -------------- |
| `text`       | string | 最大 200,000 字符 | 待签数据或原文 |
| `privateKey` | string | PEM（PKCS#8）     | 签名时使用     |
| `publicKey`  | string | PEM（SPKI）       | 验签时使用     |
| `signature`  | string | Base64 / hex      | 验签时使用     |

## 输出

| 字段   | 类型   | 说明                                                             |
| ------ | ------ | ---------------------------------------------------------------- |
| `text` | string | 64 字节签名（按选项编码），或验签结论（`验签通过` / `验签失败`） |

## 选项

| 选项        | 取值          | 默认   | 说明                                 |
| ----------- | ------------- | ------ | ------------------------------------ |
| `direction` | sign / verify | sign   | 签名或验签                           |
| `encoding`  | base64 / hex  | base64 | 签名的呈现编码，验签时按同一编码读取 |

## 限制

- Ed25519 内部固定使用 SHA-512，**不提供摘要选项**（不像 RSA / ECDSA）
- 需要较新的浏览器：Chrome 137+、Edge 137+、Safari 17+；旧浏览器会提示不支持 WebCrypto Ed25519
- 只支持 PKCS#8 私钥与 SPKI 公钥；OpenSSH 的 `BEGIN OPENSSH PRIVATE KEY` 需先转换
- 页面内置的演示密钥对仅供试用，**不要**用于真实数据

## 数据流向

**纯本地处理。** 私钥与数据只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（签名方向，演示私钥）：

```text
这是一段需要 Ed25519 签名的数据。
```

输出（base64）：

```text
fxcfs39OTMuwxhNoTJX7rABccmrrbdmoiN6B2a+paUlL98jEN3HENSNE6hnLWJGuH+glNm4ldFMP/6k6EXO5Dw==
```
