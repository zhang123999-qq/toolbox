# ISO 周格式

把日期转成 ISO 8601 周日期格式（如 `2026-W39-7`），同时给出 ISO 周年与星期。

与「周数」类工具不同：本工具输出**完整 ISO 周日期字符串**（年-周-星期），而不只是周数。

## 用途

周报、迭代排期、日志按周聚合时，用 ISO 周日期统一标识「哪一周的哪一天」。

## 输入

| 字段   | 类型   | 约束                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 日期 `YYYY-MM-DD`，最大 200,000 字符 |

## 输出

```text
日期：2026-09-27
ISO 周日期：2026-W39-7
ISO 周年：2026
周数：W39
星期：周日
```

格式 `YYYY-Www-d`：

- `ww` 为 ISO 周数（`W01`~`W53`，两位补零）
- `d` 为星期：周一=1 … 周日=7

## 规则（自研 ISO 8601 算法）

- 周一为一周起点
- **W01 = 含当年第一个周四的那一周**
- 因此 1 月初或 12 月末的日期，其「ISO 周年」可能与公历年份不同：
  - `2024-12-31` → `2025-W01-2`
  - `2025-12-29` → `2026-W01-1`
  - `2023-01-01`（周日）→ `2022-W52-7`

## 数据流向

**纯本地处理。** 不发送网络请求，`meta.api = false`。

## 示例

输入：

```text
2026-09-27
```

输出：

```text
日期：2026-09-27
ISO 周日期：2026-W39-7
ISO 周年：2026
周数：W39
星期：周日
```
