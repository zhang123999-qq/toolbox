# Query String 解析

查询串与对象互转，支持重复键与键名排序。

## 用途

调试接口参数、还原签名前的原始参数顺序、把 JSON 配置快速拼成 URL 查询串。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

解析模式接受：查询串（`a=1&b=2`）、带 `?` 前缀的串、完整 URL（自动截取查询部分）。
生成模式要求：JSON 对象文本（值为字符串 / 数字 / 布尔 / 数组）。

## 输出

| 字段   | 类型   | 说明                                       |
| ------ | ------ | ------------------------------------------ |
| `text` | string | 解析模式为缩进 2 的 JSON；生成模式为查询串 |

## 选项

| 选项       | 取值              | 默认    | 说明                             |
| ---------- | ----------------- | ------- | -------------------------------- |
| `mode`     | `parse` / `build` | `parse` | 方向：串转对象 / 对象转串        |
| `sortKeys` | boolean           | `false` | 是否按键名排序（对两模式都生效） |

## 限制

- 解析依赖标准库 `URLSearchParams`，遵循 WHATWG 规范：`+` 视为空格，百分号编码自动解码
- 非法百分号序列（如 `a=%%%`）不会报错，会按字面量保留
- 生成模式下输入数组以外的值会被 `String()` 转换，`null` 转为空串

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

解析（`mode=parse`）：

```text
name=%E5%B7%A5%E5%85%B7%E5%BA%93&tools=870&tag=a&tag=b
```

```json
{
  "name": "工具库",
  "tools": "870",
  "tag": ["a", "b"]
}
```

生成（`mode=build`）：

```json
{ "tag": ["a", "b"], "tools": 870 }
```

```text
tag=a&tag=b&tools=870
```
