# 提示词模板（prompt-template）

内置 8 个常用提示词模板，填变量即生成可直接复制的提示词。

## 功能

- 8 个内置模板：翻译、代码解释、SQL 生成、写作润色、正则生成、周报、面试题、头脑风暴
- 支持自定义模板：用 `{{变量名}}` 定义变量，自动生成填写表单
- 变量实时填充预览，缺失变量会中文提示
- 纯本地，无需网络

## 使用

1. 选择一个模板（或粘贴自己的模板）
2. 在变量表单中填写各变量
3. 右侧实时预览填充结果，点「复制结果」

## 变量语法

- `{{变量名}}`：在模板中用双花括号标记变量
- 同一变量在模板中出现多次只需填一次
- 变量名去重显示，缺失的变量会列出提示
