# 字幕合并

合并多个 SRT / VTT / ASS 字幕文件：自动识别格式，按时间轴排序、去重、去重叠，可整体偏移（毫秒，可为负），输出 SRT 或 VTT。

## 用途

多份字幕（比如中英双语、多个片段）合成一份：上传多个文件或粘贴文本，一键合并排序。

## 输入

| 字段   | 类型   | 约束            | 说明                                                       |
| ------ | ------ | --------------- | ---------------------------------------------------------- |
| `file` | File[] | 每个最大 20 MiB | 通过「选择字幕文件」多选 `.srt` / `.vtt` / `.ass` / `.ssa` |
| `text` | string | —               | 左侧文本区可粘贴一段字幕，作为额外文件参与合并             |

点「载入示例字幕」可填入两份示例（SRT + VTT，时间有重叠）直接试。

## 输出

| 字段   | 类型   | 说明                                      |
| ------ | ------ | ----------------------------------------- |
| `text` | string | 合并后的字幕文本 + 合并统计，可复制或下载 |

## 选项

| 选项       | 类型 | 默认 | 说明                                         |
| ---------- | ---- | ---- | -------------------------------------------- |
| `format`   | 下拉 | srt  | 输出格式：srt / vtt                          |
| `offsetMs` | 数字 | 0    | 时间轴整体偏移（毫秒），可为负，负值钳制到 0 |

## 合并规则

1. 逐个解析，自动识别 SRT / VTT / ASS；单个文件解析失败会标注文件名并给出中文错误
2. 先做整体偏移（负值钳制到 0，偏移后时长 ≤ 0 的条目丢弃）
3. 按开始时间排序
4. 起止时间与文本完全相同的条目去重
5. 时间重叠的条目：后一条的开始时间截到前一条的结束时间，截空则丢弃

## 限制

- 至少提供一个字幕文件（上传或粘贴），否则提示
- 纯本地处理，不发任何请求

## 示例

示例 A（SRT，1–4s / 5–8s）与示例 B（VTT，3–6s / 10–12s）合并：

```text
参与文件：2 个，共解析 4 条
合并后：4 条
去重：0 条　去重叠修正：2 条　丢弃空条目：0 条
```

## 数据流向

**纯本地处理。** 解析与合并都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
