# 音频淡入淡出

上传音频，对首尾应用淡入 / 淡出曲线（线性 / 指数可选），导出为 16 位 PCM WAV。

## 用途

让音频开头不再"戛然而始"、结尾不再"戛然而止"：播客片头、铃声、混音工程里给片段加淡入淡出是最常用的手法。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

文件用浏览器 Web Audio API 本地解码（支持 wav / mp3 / ogg / m4a 等浏览器可解格式）。

## 输出

| 字段    | 类型   | 说明                             |
| ------- | ------ | -------------------------------- |
| `audio` | WAV    | 加完淡入淡出的音频，可试听并下载 |
| `text`  | string | 处理报告：淡入 / 淡出时长 / 曲线 |

## 选项

| 选项      | 类型 | 默认 | 说明                                       |
| --------- | ---- | ---- | ------------------------------------------ |
| `fadeIn`  | 数字 | 1.0  | 淡入时长（秒），0～3600                    |
| `fadeOut` | 数字 | 1.0  | 淡出时长（秒），0～3600                    |
| `curve`   | 下拉 | 线性 | 曲线：线性（直线增益）/ 指数（起音更柔和） |

淡入让开头音量从 0 平滑升到正常，淡出让结尾音量平滑降到 0；两者时长之和不能超过音频总时长。

## 限制

- 淡入 + 淡出超过音频总时长会中文提示
- 时长为 0 表示不做该端处理
- 输出固定为 16 位 PCM WAV
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（4 秒 440Hz 正弦波），默认淡入 / 淡出各 1 秒、线性曲线：

```text
输入：示例-440Hz正弦波.wav
原时长：4.00 秒　采样率：44100 Hz　声道：1
淡入：1.00 秒　淡出：1.00 秒　曲线：线性
输出时长：4.00 秒
```

## 数据流向

**纯本地处理。** 解码与淡入淡出都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
