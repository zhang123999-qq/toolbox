# 字幕提取

上传视频，用 ffmpeg.wasm 在浏览器本地探测并提取内嵌字幕流，导出为 SRT / WebVTT / ASS。

## 用途

MKV/MP4 里常内嵌多路字幕（中英双语、导演评论音轨字幕等），想单独拿出来用、校对或压制时用它提取。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 300 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

选择文件后自动探测字幕流（`ffmpeg -i` 列流信息），列出全部字幕流供选择。

## 输出

| 字段   | 类型     | 说明                                  |
| ------ | -------- | ------------------------------------- |
| `text` | 字幕文件 | 提取的字幕文本，可下载                |
| `text` | string   | 处理报告：字幕流 / 编码 / 语言 / 格式 |

## 选项

| 选项     | 类型 | 默认 | 说明                             |
| -------- | ---- | ---- | -------------------------------- |
| `format` | 下拉 | SRT  | 输出字幕格式：SRT / WebVTT / ASS |

提取时用 `-map 0:s:N` 选中第 N 路字幕流，按目标格式转码（如源是 ASS、目标是 SRT 会自动转换）。

## 限制

- 只能提取**内嵌字幕流**：烧录在画面里的硬字幕无法提取
- 视频不含字幕流时会中文提示
- 首次使用需从 CDN 加载 ffmpeg.wasm 内核（约几十 MB），之后缓存复用
- 文件全程留在浏览器内存里，不发任何请求（CDN 加载 wasm 内核除外）

## 示例

上传带 2 路字幕的 `movie.mkv`，探测结果示例：

```text
输入：movie.mkv（时长 83.45 秒）
字幕流：第 1 路（Stream #0:2，编码 subrip，语言 eng，default）
输出格式：SRT 输出大小：1.20 KiB
```

下载得到 `movie-sub0.srt`。

## 数据流向

**纯本地处理。** 探测与提取都在浏览器内经 ffmpeg.wasm 完成，`meta.api = false`，
无需自备 API/Key；`meta.wasm = true`，`meta.deps = ['@ffmpeg/ffmpeg']`（动态导入，不进首屏包）。
