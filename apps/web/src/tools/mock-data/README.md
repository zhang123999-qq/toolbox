# Mock 数据

按给定 JSON 模板批量生成 Mock 数据：姓名、邮箱、电话、地址、日期、UUID 等。

> 规划表里的依赖是 `faker`，但本项目禁止新增 npm 依赖，因此这里的生成器
> **全部用纯 TS 自实现**（详见「限制」一节）。

## 用途

接口还没好时先造一批数据喂给前端列表；给压测脚本准备入参；给单测夹具生成结构一致、
内容丰富的样例。模板写一次，改「数量」就能反复出数据。

## 输入

| 字段   | 类型   | 约束               |
| ------ | ------ | ------------------ |
| `text` | string | 模板，≤20,000 字符 |

模板是**一份 JSON**（对象或数组都行），值为字符串时支持占位符：

- `@占位符` / `@占位符(参数1,参数2)`
- 一个值里可以有多个占位符：`"备注：@cname 于 @date 下单"`
- **整串只有一个占位符时输出原生类型**：`"age": "@number(18,60)"` 得到 JSON 数字 `42`，
  `"vip": "@boolean"` 得到布尔值；混排时一律按字符串拼接。
- 认不出的 `@xxx` 在混排文本里原样保留（`user@example.com` 不会被误伤）；
  独立成串时报错并列出所有可用占位符。
- 键名同样支持占位符。

## 输出

| 字段   | 类型   | 说明                           |
| ------ | ------ | ------------------------------ |
| `text` | string | `count` 条数据组成的 JSON 数组 |

## 选项

| 选项     | 取值                   | 默认   | 说明                                               |
| -------- | ---------------------- | ------ | -------------------------------------------------- |
| `count`  | `1`/`5`/`10`/`20`/`50` | `5`    | 生成条数（内部再钳到 1–200）                       |
| `stable` | boolean                | `true` | 可复现：种子只由模板文本派生，同一模板每次结果一致 |

关掉 `stable` 后每次输入变化 / 点「运行」都会换一批数据。

## 占位符一览

| 占位符                               | 说明                                         |
| ------------------------------------ | -------------------------------------------- |
| `@cname`                             | 中文姓名（张伟 / 陈雨桐）                    |
| `@name`                              | 英文姓名（James Smith）                      |
| `@surname` / `@firstname`            | 中文姓氏                                     |
| `@lastname`                          | 中文名（单字）                               |
| `@givenname`                         | 中文名（双字）                               |
| `@email`                             | 邮箱                                         |
| `@phone`                             | 中国手机号 `1[3-9]xxxxxxxxx`                 |
| `@telephone`                         | 座机号                                       |
| `@address`                           | 中文地址（省市区 + 街道 + 门牌）             |
| `@province` / `@city` / `@street`    | 地址片段                                     |
| `@company`                           | 公司名                                       |
| `@department`                        | 部门名                                       |
| `@title`                             | 职位名                                       |
| `@date`                              | `YYYY-MM-DD`，参数给跨度天数（默认 365）     |
| `@datetime`                          | `YYYY-MM-DD HH:mm:ss`                        |
| `@time`                              | `HH:mm:ss`                                   |
| `@timestamp`                         | Unix 毫秒时间戳（数字）                      |
| `@number`                            | `@number(min,max,digits)`，digits=0 时为整数 |
| `@int` / `@float`                    | 整数 / 浮点                                  |
| `@boolean`                           | 布尔值                                       |
| `@uuid`                              | UUID v4                                      |
| `@id` / `@index`                     | 行序号（1 起 / 0 起）                        |
| `@url` / `@ip` / `@ipv6`             | URL / IPv4 / IPv6                            |
| `@word` / `@sentence` / `@paragraph` | 技术名词 / 句 / 段                           |
| `@username`                          | 小写字母用户名                               |
| `@gender`                            | 男 / 女                                      |
| `@hex`                               | 十六进制串，参数为字符数（默认 8）           |
| `@pick`                              | `@pick(男                                    | 女)`，用 ` | `或`/` 分隔候选 |
| `@skip`                              | 生成 `null`                                  |

## 限制

- **不是 faker**：中文词库只有几十条（30 个姓氏、25 个单字名、14 个双字名、10 个省级行政区等），
  随机组合不等于真实姓名分布，重复度高；不能指定 `locale`、不支持地址层级联动、
  不支持做生意人名、`@date` 不做时区与闰秒处理。
- **时间基准固定**：`@date` / `@datetime` 的取值范围起点是 **2023-01-01**，
  默认跨度 365 天。要别的区间就给参数（如 `@date(1000)`）。
- 占位符解析基于正则，`@` 后必须是 `[a-z_]` 开头的标识符；不支持转义写法（`@@`）。
- 模板必须是合法 JSON，不接受 JSON5 / YAML；JSON 解析失败直接报错。
- 随机数用自实现的 mulberry32，**不是密码学安全**的随机数，别拿它生成密钥或令牌。
- 生成条数上限 200（即使绕过下拉框也钳到这个数）。

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

模板：

```json
{
  "id": "@uuid",
  "name": "@cname",
  "email": "@email",
  "phone": "@phone",
  "gender": "@pick(男|女)",
  "age": "@number(18,60)",
  "city": "@city",
  "company": "@company",
  "score": "@float(0,100,1)",
  "vip": "@boolean",
  "createdAt": "@datetime"
}
```

输出（`count=1`）：

```json
[
  {
    "id": "63831907-58cb-4d8d-9bd8-27eef6266696",
    "name": "王伟",
    "email": "linda123@qq.com",
    "phone": "13812345678",
    "gender": "女",
    "age": 34,
    "city": "海淀区",
    "company": "星辰科技有限公司",
    "score": 82.4,
    "vip": true,
    "createdAt": "2023-05-19 08:12:44"
  }
]
```
