# 短链生成

粘贴一条长 URL，**本地**按内容 hash 派生一个短码，并附两套自建短链的重定向方案。

> 这是降级演示：原规划需要后端发码（E）。本工具**不起服务、不真缩短**，
> 只做「内容 → 短码」的确定性映射，并给出你自己部署时可直接用的 Nginx / Worker 配置。

## 用途

- 演示短码是怎么从长 URL 派生出来的
- 给你一份自建短链服务的 Nginx rewrite / Cloudflare Worker 起步代码

## 输入

| 字段   | 类型   | 约束                                              |
| ------ | ------ | ------------------------------------------------- |
| `text` | string | 长 URL（`http://` / `https://`），最大 2,000 字符 |

## 选项

| 选项 key  | 界面   | 说明                                     |
| --------- | ------ | ---------------------------------------- |
| `baseUrl` | 短域名 | 你的短链域名，如 `https://s.example.com` |

## 输出

1. 由 FNV-1a 哈希取前 8 位 base62 得到的短码
2. 完整短链示例：`<baseUrl>/<短码>`
3. Nginx `return 301` 方案
4. Cloudflare Worker（KV 存映射）方案

## 浏览器边界

- **不真起服务**：短码是确定性 hash，同一长 URL 永远得到同一短码，没有中心化发码
- hash 仅 32 位（base62 取 8 位），空间约 10 亿，**不防碰撞**；真短链服务需用 KV / 数据库去重
- 无网络请求

## 数据流向

**纯本地计算。** `meta.api = false`。

## 示例

输入：`https://example.com/very/long/article/title`

输出（节选）：

```text
# 短码（本地演示，不真起服务）
长 URL：https://example.com/very/long/article/title
短码：3f9a2b7c
完整短链示例：https://s.example.com/3f9a2b7c
…
```
