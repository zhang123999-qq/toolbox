# 音频变调

上传音频，用 Web Audio API 解码，在浏览器本地升降音调并导出为 WAV。

## 用途

给人声/乐器升调降调（±12 半音以内）：输入半音数，一键生成变调版本。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                    |
| ------- | ------ | --------------------------------------- |
| `audio` | WAV    | 变调后的音频（16 位 PCM），可试听并下载 |
| `text`  | string | 处理报告：变调量 / 频率倍率 / 时长变化  |

## 选项

| 选项        | 类型 | 默认 | 说明                               |
| ----------- | ---- | ---- | ---------------------------------- |
| `semitones` | 数字 | 0    | 半音数（-12～+12），正升调、负降调 |

## 限制

- 半音数超出 -12～+12 范围会给出中文错误提示
- 当前用重采样实现，**变调会同时改变时长**（升调变短、降调变长）
- 不支持 Web Audio API 的旧浏览器会给出中文错误提示
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（4 秒 440Hz 正弦波），升调 +3 半音：

```text
输入：示例-440Hz正弦波.wav
变调量：+3 半音（频率倍率 ×1.189）
原时长：4.00 秒 → 新时长：3.36 秒
```

## 数据流向

**纯本地处理。** 解码与变调全在浏览器内完成，`meta.api = false`，无需自备 API/Key。
