# 音频可视化（audio-visualizer）

把音频变成实时跳动的频谱 / 波形 / 圆形可视化动画，全程在浏览器本地完成。

## 功能

- 三种可视化样式：频谱柱状图、波形、圆形辐射
- WebAudio AnalyserNode 实时分析，Canvas 60fps 渲染
- 可暂停 / 继续，播放进度条可拖动跳转
- 内置示例音频（一键载入，无需准备文件）

## 使用

1. 上传音频文件（MP3 / WAV / OGG 等浏览器支持的格式），或点「载入示例音频」
2. 选择可视化样式
3. 点「暂停」/「继续」控制播放，拖动进度条跳转

## 限制

- 需要浏览器支持 WebAudio，不支持的浏览器会提示
- 示例音频为程序生成的测试音，不是音乐
