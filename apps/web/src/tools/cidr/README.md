# CIDR 计算

输入 IPv4 CIDR（如 `192.168.1.0/24`），算出网络地址、广播地址、子网掩码、
可用 IP 范围、主机总数与可用主机数，并给出二进制展开。

## 用途

划分子网、配防火墙 / 安全组、排查「这个 IP 在不在我网段里」时不用手算掩码。

## 输入

| 字段   | 类型   | 约束                                         |
| ------ | ------ | -------------------------------------------- |
| `text` | string | `A.B.C.D/前缀`，前缀 0-32，最大 200,000 字符 |

可带主机位（`192.168.1.55/24` 会自动归一到网络地址）。

## 输出

```text
CIDR：192.168.1.0/24
子网掩码：255.255.255.0
网络地址：192.168.1.0
广播地址：192.168.1.255
可用主机范围：192.168.1.1 ~ 192.168.1.254
地址总数：256
可用主机数：254
网络地址二进制：11000000.10101000.00000001.00000000
子网掩码二进制：11111111.11111111.11111111.00000000
```

## 常用前缀速查

| CIDR | 掩码            | 可用主机数 |
| ---- | --------------- | ---------- |
| /8   | 255.0.0.0       | 16,777,214 |
| /16  | 255.255.0.0     | 65,534     |
| /24  | 255.255.255.0   | 254        |
| /25  | 255.255.255.128 | 126        |
| /30  | 255.255.255.252 | 2          |
| /32  | 255.255.255.255 | 1（单机）  |

## 限制

- 仅支持 IPv4，不支持 IPv6
- 可用主机数按通用规则：前缀 ≤30 时减去网络号与广播地址；/31、/32 不扣减
- 空输入返回空串；非法格式抛中文错误

## 数据流向

**纯本地处理。** 位运算，不发送网络请求。`meta.api = false`。

## 示例

输入：

```text
192.168.1.0/24
```

输出见上方。
