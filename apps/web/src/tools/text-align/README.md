# 文本对齐

左对齐、右对齐、居中、填充。

## 用途

把每行按显示列宽对齐到统一宽度：左对齐、右对齐、居中，或把填充摊到词间做两端对齐。生成报表、排版代码块注释时常用。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

多行文本；逐行独立处理。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 对齐后的文本；超过目标宽度的行原样保留。 |

## 选项

| 选项     | 取值                                 | 默认        | 说明                        |
| -------- | ------------------------------------ | ----------- | --------------------------- |
| `mode`   | `left` / `right` / `center` / `fill` | `left`      | 左 / 右 / 居中 / 两端对齐   |
| `width`  | `20` / `40` / `60` / `80`            | `40`        | 目标显示列宽                |
| `filler` | 字符串（最多 4 字符）                | ` `（空格） | 填充字符，可填 `-` `.` 之类 |

## 限制

- **按显示列宽算**：中日韩全角字符占 2 列，emoji 也按 2 列估算——等宽字体下基本准确，比例字体下仍会有偏差
- 超过目标宽度的行**原样保留**，不会被截断（要截断请用 #63 文本截断）
- `fill` 两端对齐只按**空格**切词，中文没有空格会退化成左对齐；它也不会重排单词
- `filler` 超过 1 字符时会循环取用，且按字符数而非列宽计数，全角填充会让行超宽
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
北京
上海
广州
```

输出：

```text
北京
上海
广州
```
