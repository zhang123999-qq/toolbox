# 重量换算

输入数值并选择源单位与目标单位，即时得到重量换算结果（含斤）。

## 用途

- 毫克 / 克 / 千克 / 吨与斤 / 盎司 / 磅互转
- 烹饪、购物、物流场景的重量单位对照

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待换算的数值，最大 200,000 字符 |

## 输出

单行文本：`输入值 源单位 = 结果 目标单位`

```text
1 lb = 0.45359237 kg
```

## 选项

| 字段   | 类型   | 说明     | 可选值                   |
| ------ | ------ | -------- | ------------------------ |
| `from` | select | 源单位   | mg、g、kg、t、斤、oz、lb |
| `to`   | select | 目标单位 | 同左                     |

## 算法

- 以**千克**为基准：`结果 = 数值 × from.factor / to.factor`
- 输出用 `Number(n.toPrecision(12)).toString()` 格式化，去浮点噪声、去尾零

## 边界

- 空输入 → 输出为空（不报错）
- 非数字输入 → 中文报错「请输入有效的数字」
- 未知单位 id → 中文报错「未知单位」
- 输入 > 200,000 字符 → 报错

## 示例

输入数值：`1`，从 `斤` 到 `g`

输出：`1 斤 = 500 g`

## English

Convert between weight units, milligrams to pounds (incl. jin).

- Input: a numeric string.
- Output: one line, e.g. `1 lb = 0.45359237 kg`.
- Options: `from` / `to` selects over mg, g, kg, t, 斤 (jin), oz, lb.
