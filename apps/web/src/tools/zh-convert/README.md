# 简繁转换

简体与繁体中文互转。

## 用途

把简体稿件转成繁体（或反向），供两岸暨港澳读者阅读；s2tw 会一并处理词汇差异。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

中文文本；非中文字符原样保留。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明           |
| ------ | ------ | -------------- |
| `text` | string | 转换后的文本。 |

## 选项

| 选项   | 取值             | 默认 | 说明                            |
| ------ | ---------------- | ---- | ------------------------------- |
| `mode` | s2t / t2s / s2tw | s2t  | 方向：简→繁、繁→简、简→台湾正体 |

## 限制

- s2t 与 s2tw 在 opencc-js 当前预设下都是**字形**转换，词汇差异（如「内存」→「記憶體」）覆盖有限
- 依赖 opencc-js，字典随工具页懒加载，首次转换需加载对应字典
- 人名、地名、方言用词可能转换不准确，正式出版前需人工校对

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具库软件
```

输出：

```text
工具库软件，里面有很多实用的在线工具。
```
