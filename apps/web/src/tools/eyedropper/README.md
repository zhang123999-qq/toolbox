# 取色器

用系统取色器从屏幕任意位置取色；浏览器不支持时回退为从上传图片点击取色；也支持手动输入颜色值解析。输出 HEX / RGB / HSL。

## 用途

从设计稿、网页、图片里精确提取颜色值，用于配色与开发。

## 输入

| 字段   | 类型   | 约束 | 说明                                                                      |
| ------ | ------ | ---- | ------------------------------------------------------------------------- |
| `text` | string | —    | 手动输入颜色值（`#rgb` / `#rrggbb` / `rgb(r,g,b)`），点「解析输入框颜色」 |
| `file` | File   | 图片 | 通过「从图片取色」上传，点击图片取色，**不上传**                          |

## 输出

| 字段   | 类型 | 说明                                  |
| ------ | ---- | ------------------------------------- |
| `text` | 文本 | 三行报告：HEX / RGB / HSL，附色块预览 |

## 选项

| 选项     | 类型 | 默认 | 说明                                                                     |
| -------- | ---- | ---- | ------------------------------------------------------------------------ |
| `radius` | 数字 | `2`  | 图片取色时的采样半径（像素，0–50），0 表示只取单点，其余取方形区域平均值 |

## 限制

- 系统取色器需要浏览器支持 EyeDropper API（Chrome / Edge）；不支持时给出中文提示并引导用图片取色
- 用户按 ESC 取消取色属于正常操作，只给轻提示
- 手动输入格式非法、采样坐标越界时给出中文错误提示
- 全程本地处理，不发任何请求

## 示例

```text
HEX：#ff6b00
RGB：rgb(255, 107, 0)
HSL：hsl(24, 100%, 50%)
```

## 数据流向

**纯本地处理。** `meta.api = false`，无需自备 API/Key。
