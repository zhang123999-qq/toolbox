# 焦点顺序可视化

粘贴 HTML，按编号列出浏览器实际的 Tab 键顺序：正 `tabindex` 按数值优先，其余按 DOM 先后；`tabindex="-1"` 的元素可被脚本聚焦但跳过 Tab 顺序，单独列出。

## 用途

- 直观看到键盘用户按 Tab 时的焦点走向
- 发现正 tabindex 打乱的顺序
- 与「键盘导航分析」配合：一个看顺序，一个查问题

## 输入

| 字段   | 类型   | 约束      |
| ------ | ------ | --------- |
| `text` | string | HTML 片段 |

## 说明

- 纯浏览器内 DOMParser 解析，无网络请求。
- 非法 tabindex 值按浏览器行为视为 0。
- `disabled`、隐藏元素不计入。
