# Word 转 HTML

将 `.docx` 文档转换为 HTML 代码片段，保留标题、段落、加粗、斜体、列表、表格与超链接。

## 用途

把 Word 文档的内容搬到网页、博客、CMS 里：上传文档，一键得到可直接粘贴的 HTML。

## 输入

| 字段   | 类型 | 约束        | 说明                             |
| ------ | ---- | ----------- | -------------------------------- |
| `file` | File | 最大 50 MiB | 左下「选择文件」选取，**不上传** |

文本框不支持直接转换（点「运行」会提示改用文件入口）。

## 输出

| 字段   | 类型   | 说明                                            |
| ------ | ------ | ----------------------------------------------- |
| `text` | string | HTML 片段（不含 `<html>` 外壳），可直接嵌入页面 |

```html
<h1>Hello</h1>
<p>world</p>
```

## 选项

| 选项        | 取值           | 默认   | 说明                               |
| ----------- | -------------- | ------ | ---------------------------------- |
| `imageMode` | ignore / embed | ignore | 文档图片：去掉，或转 data URI 嵌入 |

## 限制

- **文件上限 50 MiB**：更大的文档请先拆分
- 转换由 mammoth（纯 JS，本地运行）完成，只提取内容与基础样式，不还原精确排版
- `embed` 会把图片转成 base64 data URI，输出体积会明显变大
- 加密 / 损坏的文档会直接报中文错误

## 数据流向

**纯本地处理。** 文件不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：包含标题 "Hello" 与正文 "world" 的 `.docx`

输出：

```html
<h1>Hello</h1>
<p>world</p>
```

## 元信息

| 项       | 值                       |
| -------- | ------------------------ |
| 全局编号 | #504                     |
| 域       | `media`（媒体 / 文档）   |
