# .htaccess 生成

按选项生成 Apache `.htaccess`：重定向、URL 重写、浏览器缓存、防盗链、禁止访问隐藏文件。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作触发用。

## 选项

| 选项 key    | 界面标签                     | 说明                            |
| ----------- | ---------------------------- | ------------------------------- |
| `redirects` | 重定向（每行：旧路径 新URL） | 每行生成一条 `Redirect 301`     |
| `rewrites`  | URL 重写                     | 伪静态到 index.php              |
| `cache`     | 浏览器缓存                   | ExpiresByType 静态资源          |
| `hotlink`   | 防盗链                       | 非本站 Referer 访问图片返回 403 |
| `deny`      | 禁止访问隐藏文件             | 拒绝访问 `.env` 等 dotfiles     |

## 限制

- 防盗链里的域名写死 `example.com`，上线前替换
- 什么都不输出时报错

## 数据流向

**纯本地处理。** `meta.api = false`。
