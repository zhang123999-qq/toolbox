# PDF 插入文字

选择 PDF 文件，填写要插入的文字与页码（从 1 开始），在该页面左上角插入一行 12pt 文字，
生成新 PDF 下载。纯本地处理，不经过任何服务器。

## 用途

给 PDF 加「草稿」「机密」等角标、补一行业务备注。

## 输入

| 字段   | 类型   | 约束           | 说明                       |
| ------ | ------ | -------------- | -------------------------- |
| `file` | File   | ≤ 100 MiB      | 输出区文件选择框上传的 PDF |
| `text` | string | 最大 1000 字符 | 要插入的文字               |
| `page` | string | 正整数         | 页码（从 1 开始）          |

文件与文字必填；页码必须在 PDF 实际页数范围内，超出时报错并告知总页数。
下载文件名为原文件名加 `-inserted` 后缀（如 `demo-inserted.pdf`）。

## 输出

| 字段   | 类型       | 说明                                 |
| ------ | ---------- | ------------------------------------ |
| `file` | PDF 二进制 | 插入文字后的新 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「复制/下载」按钮操作的是插入文字文本（`.txt`）。

## 选项

无。

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，插入文字含中文时会直接报错，
  不会生成乱码 PDF。
- 文字固定插在页面左上角（距左/上边缘各 72pt），12pt 黑色 Helvetica，不可调位置与样式。
- 超长文字不换行，可能超出页面右边缘；请控制在 1000 字符内并尽量简短。
- 文件全程在浏览器内存里处理，不发任何请求。

## 数据流向

**纯本地处理。** PDF 文件与生成结果都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

2 页 PDF，第 1 页插入 `DRAFT - Confidential` → 输出区显示如 `已生成 PDF：2 页，3.1 KB`，
下载 `demo-inserted.pdf`。
