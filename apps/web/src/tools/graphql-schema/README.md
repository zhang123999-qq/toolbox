# GraphQL Schema 预览

粘贴一段 GraphQL SDL（Schema Definition Language），汇总出其中定义的
**对象类型 / 输入类型 / 接口 / 枚举 / 联合 / 标量**，并列出每个类型的字段与返回类型。
纯本地解析，不依赖 `graphql` 等库。

## 用途

快速摸清一份 schema 的骨架：有哪些类型、每个类型暴露哪些字段、枚举有哪些取值、联合由谁组成；
适合阅读陌生后端、评审 schema 变更时建立全局视图。

## 输入

| 字段   | 类型   | 约束                           |
| ------ | ------ | ------------------------------ |
| `text` | string | 最大 500,000 字符；GraphQL SDL |

## 输出

一份 Markdown 结构清单：顶部给出各分类数量，随后按类型分组，逐类型列出字段（忽略参数细节，保留返回类型）、
枚举 / 联合成员，或标量名。

## 解析规则

- 顶层定义：`type` / `input` / `interface` / `enum` / `union` / `scalar` / `schema`，含 `extend` 前缀
- 对象类型字段：`name(参数): 返回类型` —— 省略参数，保留如 `[Post!]!` 的返回类型；字段上的指令（`@deprecated` 等）忽略
- `implements X & Y` 不影响名字提取；`union A = X | Y` 取成员；`enum` 取花括号内符号
- `#` 注释整行忽略

## 限制

- 面向**结构浏览**，不是完整 GraphQL 语法分析器：字段按行解析，单行内连写多个字段（`type T { a: Int b: Int }`）不会被拆开；
  建议先用 #170 GraphQL 格式化美化后再预览
- 不解析指令定义（`directive @… on …`）的参数细节、不做类型引用校验（不判断字段引用的类型是否存在）
- `union` 的多行成员写法按首个成员行处理；输入上限 500,000 字符，花括号未闭合等抛 `GraphqlSchemaError`

## 数据流向

**纯本地处理。** SDL 仅在浏览器内存中解析，不发送网络请求，不写入服务端。`meta.api = false`。
