# JSON 转 TOML

把 JSON 对象转成 TOML 配置（v1.0 语义的常用子集），纯本地序列化，不依赖第三方库。

## 用途

把现成的 JSON 配置转成 Rust（Cargo 生态）、Hugo、各类工具使用的 TOML；
嵌套对象转 `[table]`，对象数组转 `[[array-of-tables]]`，标量数组转内联数组。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 2,000,000 字符 |

顶层必须是对象（TOML 文档根是一张表），标量或数组根无法转换。

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | TOML 文本；空输入 / 空对象返回空串 |

## 选项

| 选项    | 取值            | 默认    | 说明                                                         |
| ------- | --------------- | ------- | ------------------------------------------------------------ |
| `style` | basic / literal | `basic` | basic 双引号带转义；literal 优先单引号，含特殊字符回退双引号 |

## 转换规则

- 标量：字符串加引号、布尔 `true/false`、数字原样
- 嵌套对象 → `[dotted.path]` 表头；对象数组 → 每个元素一个 `[[dotted.path]]`
- 非对象数组 → 内联 `[1, 2]` / `["a", "b"]`
- 因 TOML 规定子表头之后的裸键归子表所有，生成时把每张表的键值对统一排在其子表之前
- 非裸键（含 `.`、空格等）自动加双引号；重复的数组表之间空一行

## 限制

- TOML **没有 null 类型**：值为 `null` 的键会被跳过；内联数组里的 null 元素被过滤
- 对象与标量混排的数组无法用单一 TOML 形态表达，会报错
- 不输出日期 / 时间字面量（JSON 里它们只是字符串）、不输出多行基本字符串与字面量块
- 全部逻辑为纯 TS 自研，行为以本文档为准；输入上限 2,000,000 字符，超限抛 `JsonToTomlError`

## 数据流向

**纯本地处理。** 输入仅在浏览器内存中处理，不发送网络请求，不写入服务端。`meta.api = false`。

## 示例

输入：

```json
{
  "name": "工具库",
  "meta": { "stars": 870 },
  "servers": [{ "host": "a" }, { "host": "b" }]
}
```

输出：

```toml
name = "工具库"
[meta]
stars = 870

[[servers]]
host = "a"

[[servers]]
host = "b"
```
