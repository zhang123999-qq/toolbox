# RSA 加密

RSA-OAEP 加解密与 RSASSA-PKCS1-v1_5 签名验签，基于浏览器 WebCrypto。

## 用途

在不引入任何第三方库的前提下验证 RSA 行为：把一段文本用公钥加密、用私钥解密；
或用私钥签名、用公钥验签。适合核对接口签名、调试 JWT 的 RS256、验证别人给的公钥。

## 输入

| 字段         | 类型   | 约束              | 说明                                     |
| ------------ | ------ | ----------------- | ---------------------------------------- |
| `text`       | string | 最大 200,000 字符 | 明文（加密）、密文（解密）、原文（签名） |
| `publicKey`  | string | PEM（SPKI）       | `-----BEGIN PUBLIC KEY-----`             |
| `privateKey` | string | PEM（PKCS#8）     | `-----BEGIN PRIVATE KEY-----`            |
| `signature`  | string | Base64 / hex      | 仅验签时使用                             |

## 输出

| 字段   | 类型   | 说明                                                                  |
| ------ | ------ | --------------------------------------------------------------------- |
| `text` | string | 密文 / 明文 / 签名（按选项编码）或验签结论（`验签通过` / `验签失败`） |

## 选项

| 选项        | 取值                              | 默认    | 说明                                   |
| ----------- | --------------------------------- | ------- | -------------------------------------- |
| `direction` | sign / verify / encrypt / decrypt | sign    | 签名 / 验签 / 加密 / 解密              |
| `hash`      | SHA-256 / SHA-384 / SHA-512       | SHA-256 | 摘要算法，加解密与签名两侧必须一致     |
| `encoding`  | base64 / hex                      | base64  | 密文与签名的呈现编码，读取时按同一编码 |

## 限制

- 用 WebCrypto 的 **RSA-OAEP** 做加解密：2048 位密钥最多加密 190 字节（含中文按 UTF-8 计），
  超长内容请改用「混合加密」（AES 加密内容 + RSA 加密 AES 密钥）
- 只支持 **PKCS#8 私钥**与 **SPKI 公钥**；OpenSSL 1.x 默认产出的
  `BEGIN RSA PRIVATE KEY`（PKCS#1）需要先转换：`openssl pkcs8 -topk8 -nocrypt -in old.pem -out new.pem`
- 签名用 **RSASSA-PKCS1-v1_5**（确定性，同样输入总是同样输出）；RSA-PSS 因随机盐不可复现，未启用
- 验签失败是**结论**而不是异常，输出 `验签失败：…`，不会进入错误态
- 页面内置的演示密钥对仅供试用，**不要**用于真实数据

## 数据流向

**纯本地处理。** 密钥与明文只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（签名方向，演示私钥）：

```text
这是一段需要 RSA 签名的数据。
```

输出（SHA-256 / base64，前 32 字符）：

```text
HdUurE0L7y2qWPwayii8LbVzy0JNJype…
```
