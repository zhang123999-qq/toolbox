# 图片 Alt 检查

解析页面 HTML 中的 `img` 标签，检查每张图片的 `alt` 属性：
缺失 / 为空 / 过长（>125 字符）/ 疑似文件名 / 关键词堆砌，
统计通过率并逐项给出修改建议。全部计算在本地完成，不联网。

## 输入

| 字段   | 类型   | 约束                         |
| ------ | ------ | ---------------------------- |
| `text` | string | HTML 源码，最多 200,000 字符 |

## 输出示例

```text
图片总数：4　通过：1　通过率：25%
缺少 alt：1　alt 为空：1

问题清单：
  [2] logo.png alt=「logo.png」
      - alt 疑似文件名（如 IMG_001.jpg），请改为描述图片内容的文字
  [3] banner.jpg alt=（无 alt 属性）
      - 缺少 alt 属性：请补充描述图片内容的替代文本
  [4] deco.svg alt=「」
      - alt 为空：装饰性图片可保留空 alt，内容图片请补充描述
```

## 检查规则

- 缺少 `alt` 属性、alt 为空各计 1 项问题
- alt 超过 125 字符：过长（屏幕阅读器会在 125 字符后截断）
- alt 形如 `IMG_001.jpg` / `DSC0001` / `未命名`：疑似文件名
- 同一词在 alt 中出现 ≥4 次：疑似关键词堆砌

## 限制

- 只解析 HTML 源码中的 `img` 标签，不执行 JS 渲染；懒加载（data-src）图片以 `src` 为准
- 装饰性图片的空 alt 是合法做法，工具仅提示、不扣通过率之外的分

## 数据流向

纯本地计算，无网络请求。`meta.api = false`。
