# Gas 计算

Gas 费计算器：`Gas Price（gwei）× Gas Limit` 得出总费用（ETH / gwei / wei 三档），全部 BigInt 精确计算；也可经公共 RPC 实时查询 `eth_gasPrice`。

## 用途

发交易前估算手续费：填一个愿意出的 Gas Price，选常用操作的 Gas Limit 预设，一键算出要花多少 ETH。

## 输入

| 字段   | 类型   | 约束                                                        |
| ------ | ------ | ----------------------------------------------------------- |
| `text` | string | Gas Price（gwei，十进制，最多 9 位小数），最大 200,000 字符 |

## 选项

| 选项      | 取值                                                                                   |
| --------- | -------------------------------------------------------------------------------------- |
| 模式      | `计算器` / `实时查询`                                                                  |
| Gas Limit | 手动输入的 Gas Limit（正整数），预设选中时以预设为准                                   |
| 常用预设  | `手动输入` / `转账 21000` / `ERC20 转账 65000` / `NFT 铸造 150000` / `合约交互 200000` |
| RPC 地址  | 实时查询用的 JSON-RPC 地址，留空用默认公共节点 `https://eth.llamarpc.com`              |

## 输出（计算器）

```text
Gas Price：20 gwei
Gas Limit：21000
总费用：0.00042 ETH
      = 420000 gwei
      = 420000000000000 wei
```

## 说明

- 实时查询依赖公共 RPC 节点，可能限流或超时；失败会明确报错，可自填其他 RPC 地址重试（地址只保存在页面 state，不写入任何存储）。
- 本工具只做费用估算，不签名、不发送交易；不做 USD 等法币换算。
