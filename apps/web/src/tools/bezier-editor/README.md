# 贝塞尔曲线

调整两个控制点 (x1,y1) (x2,y2)，输出可直接粘贴的 `cubic-bezier(...)` 值，并附曲线上的采样坐标。

## 用途

CSS 动画缓动函数 `cubic-bezier(x1, y1, x2, y2)` 里 x1/x2 必须在 [0,1]，y1/y2 可超出。
填四个数字直接拿到值，并看到曲线上 t=0.25/0.5/0.75 的坐标，便于理解曲线形状。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作触发用。

## 输出

| 字段   | 类型   | 说明                             |
| ------ | ------ | -------------------------------- |
| `text` | string | `cubic-bezier(...)` + 采样点注释 |

## 选项

| 选项 key | 界面标签 | 范围    | 说明               |
| -------- | -------- | ------- | ------------------ |
| `x1`     | x1       | [0, 1]  | 第一个控制点横坐标 |
| `y1`     | y1       | [-1, 2] | 第一个控制点纵坐标 |
| `x2`     | x2       | [0, 1]  | 第二个控制点横坐标 |
| `y2`     | y2       | [-1, 2] | 第二个控制点纵坐标 |

## 数学

三次贝塞尔曲线，端点固定 P0=(0,0)、P3=(1,1)：

```
B(t) = 3(1-t)² t · P1 + 3(1-t) t² · P2 + t³ · P3
```

工具按此公式在 t=0.25/0.5/0.75 采样 (x, y)。

## 限制

- 只输出数值，不提供交互式拖拽画布
- x 越界会报错；y 允许超出 [0,1] 以做出回弹效果
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** `meta.api = false`。

## 示例

输出（默认 ease 曲线）：

```css
cubic-bezier(0.25, 0.1, 0.25, 1)

/* 曲线上的采样点（t 为参数，非时间轴） */
  t=0.25 → (0.134, 0.059)
  t=0.50 → (0.313, 0.538)
  t=0.75 → (0.61, 0.889)
```
