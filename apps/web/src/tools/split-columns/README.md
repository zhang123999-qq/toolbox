# 文本分列

按分隔符分列，提取指定列。

## 用途

按分隔符把每行拆成列，用来核对分列是否正确、有没有多出或少掉一列——导入表格前的必备自检。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

分隔文本（CSV / TSV / 分号 / 竖线 / 多空格均可）。空行丢弃，双引号内的分隔符不切分。

## 输出

| 字段   | 类型   | 说明                                                       |
| ------ | ------ | ---------------------------------------------------------- |
| `text` | string | 按所选看法的分列结果：列清单、带列号清单，或列数分布统计。 |

## 选项

| 选项        | 取值                                                                      | 默认   | 说明                              |
| ----------- | ------------------------------------------------------------------------- | ------ | --------------------------------- |
| `delimiter` | `auto` / `comma` / `tab` / `semicolon` / `pipe` / `space`                 | `auto` | 输入分隔符，auto 按每行出现次数猜 |
| `mode`      | `list`（用竖线连接各列） / `numbered`（带列号清单） / `count`（列数分布） | `list` | 输出看法                          |

## 限制

- 只做分列展示，不做类型转换，所有值按字符串处理
- 自动识别按「每行都出现且次数最多」猜，正文里逗号很多时可能猜错，请手动指定
- `space` 分隔符按「两个及以上空白」切分，单空格分隔的文本请先预处理
- 需要只取其中几列请用「列提取」（#39）
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
name,age,city
Bob,7,Beijing
Amy,9,Shanghai
```

输出：

```text
name | age | city
Bob | 7 | Beijing
Amy | 9 | Shanghai
```
