# 文件对比

上传两个文件，按文本做差异对比，高亮新增与删除的行。

## 用途

对比两个版本的配置文件、文档、导出的 CSV 等：不用把内容复制进剪贴板，直接传文件，差异行红绿高亮，一眼看出改了哪里。

## 与 text-diff 的区别

`text-diff`（#36）是粘贴两段文本对比；本工具**只走文件上传**（`file-a` / `file-b` 两个入口），适合文件本身就是对比对象的场景。

## 输入

| 字段     | 类型 | 约束                | 说明                   |
| -------- | ---- | ------------------- | ---------------------- |
| `file-a` | File | 文本文件，≤ 200 MiB | 旧版本文件，**不上传** |
| `file-b` | File | 文本文件，≤ 200 MiB | 新版本文件，**不上传** |

## 输出

| 字段   | 类型   | 说明                                                |
| ------ | ------ | --------------------------------------------------- |
| `text` | string | 差异视图：统计行 + 红（删除）绿（新增）高亮的差异行 |

「复制 / 下载」导出统一格式（`+` 新增 / `-` 删除 / 空格 相同）的 `.diff` 文本。

## 选项

| 选项               | 取值               | 默认  | 说明               |
| ------------------ | ------------------ | ----- | ------------------ |
| `mode`             | line / word / char | line  | 对比粒度           |
| `ignoreWhitespace` | boolean            | false | 忽略行首尾空白差异 |

## 限制

- **单个文件上限 200 MiB**；解码后超过 1000 万字符直接报错（渲染会卡死）
- **二进制文件拦截**：含 NUL 字节的文件报「可能是二进制文件」，不做文本 diff
- 解码按 UTF-8；非 UTF-8 文本请先转码
- 差异超过 2000 行时页面只展示前 2000 行（复制 / 下载不受影响）
- diff 走 `diff` 包（diffLines / diffWords / diffChars），全程本地

## 数据流向

**纯本地处理。** 文件只读进浏览器内存对比，`meta.api = false`，无需自备 API/Key。
