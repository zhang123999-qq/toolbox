# 视频裁剪

上传视频，按起止时间裁剪出片段，导出为 MP4 文件。支持「流拷贝」快速模式与「重编码」兼容模式。

## 用途

从录像、教程、会议回放中截取需要的片段：设好起始 / 结束时间，导出后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 500 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

时间支持三种写法：`83.5`（秒）、`1:23.5`（分:秒）、`1:02:03`（时:分:秒）。

## 输出

| 字段    | 类型 | 说明                               |
| ------- | ---- | ---------------------------------- |
| `video` | MP4  | 裁剪后的视频片段，可预览并下载     |
| `text`  | 文本 | 处理报告：原时长 / 裁剪区间 / 模式 |

## 选项

| 选项       | 类型 | 默认  | 说明                                                                       |
| ---------- | ---- | ----- | -------------------------------------------------------------------------- |
| `start`    | 文本 | `1.0` | 起始时间，不能为负                                                         |
| `end`      | 文本 | `2.0` | 结束时间，必须大于起始时间；若已探测到原时长，不得超过原时长               |
| `reencode` | 开关 | 开    | 重编码为 H.264 + AAC（兼容性最好）；关闭则流拷贝（快，但裁剪点落在关键帧） |

## 限制

- 起始时间 ≥ 结束时间、时间为负、格式非法，都会给出中文错误提示
- ffmpeg.wasm 组件按需从 CDN 加载：加载 / 初始化失败会提示检查网络后重试
- 输出固定为 MP4；文件全程留在浏览器内存里，不发任何请求

## 示例

选择视频（假设探测到 10 秒），裁剪 1.0–2.0 秒并重编码：

```text
输入：clip.mp4
原时长：10.00 秒
裁剪区间：1.00 秒 – 2.00 秒
模式：重编码（H.264 + AAC）
输出：clip-cut.mp4（1.23 MiB）
```

## 数据流向

**纯本地处理。** ffmpeg.wasm 在浏览器内转码，`meta.wasm = true`，`meta.api = false`，无需自备 API/Key。
