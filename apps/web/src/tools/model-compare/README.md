# 模型对比 Model Comparison（#594）

BYOK 模式：用同一个提示词并排调用两个模型，对比它们的输出内容与耗时，
方便挑选更适合的模型。

## 使用方法

1. 左侧输入要对比的提示词；
2. 右侧分别配置模型 A / 模型 B 的接口地址、模型名、API Key；
3. 点「开始对比」，两侧请求同时发出，结果并排展示（含各自耗时）。

## BYOK 说明

- 两侧 Key 分开保存在浏览器 localStorage；「同步 A→B」可把 A 的地址与 Key
  一键复制到 B（同一服务商的两个模型可复用同一 Key）；
- 「清除 Key」一键删除本地保存的两个 Key；
- Key 只出现在请求头中，本站不经手、不记录；
- 接口需兼容 OpenAI 的 `POST {baseURL}/chat/completions` 格式。

## 错误处理

- 一侧失败不影响另一侧：失败的一侧显示中文错误原因，成功的照常展示；
- 全局校验失败（如 Key 为空、提示词为空）显示在顶部错误条。
