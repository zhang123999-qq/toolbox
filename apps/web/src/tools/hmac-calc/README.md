# HMAC 计算

用密钥计算文本的消息认证码（HMAC-SHA-1/256/384/512）。

## 用途

HMAC 把「一段消息 + 一把密钥」压成定长认证码，用来验证消息**既未被篡改、也确实来自持有密钥的一方**。
常见于：校验 Webhook 回调签名（如 GitHub / 支付回调）、验证 API 请求签名、给下载链接做防盗链签名、构造 JWT 的 HS256 签名。
本工具输出与标准实现一致：`HMAC-SHA256(key="key", msg="The quick brown fox jumps over the lazy dog") = f7bc83f430538424b13298e6aa6fb143ef4d59a14946175997479dbc2d1a3cd8`。

## 输入

| 字段   | 类型   | 约束              | 说明                                       |
| ------ | ------ | ----------------- | ------------------------------------------ |
| `text` | string | 最大 200,000 字符 | 待认证的消息，按 UTF-8 编码参与计算        |
| `key`  | string | 最大 200,000 字符 | 密钥，独立的单行输入框；按 `type` 解析字节 |

## 输出

| 字段   | 类型   | 说明                                                           |
| ------ | ------ | -------------------------------------------------------------- |
| `text` | string | hex 或 Base64 的认证码；长度随算法为 40 / 64 / 96 / 128（hex） |

## 选项

| 选项        | 取值                                | 默认      | 说明                                         |
| ----------- | ----------------------------------- | --------- | -------------------------------------------- |
| `algorithm` | SHA-1 / SHA-256 / SHA-384 / SHA-512 | `SHA-256` | HMAC 内部使用的哈希算法                      |
| `format`    | hex / base64                        | hex       | 输出编码                                     |
| `type`      | text / hex                          | text      | 密钥是普通文本（按 UTF-8）还是十六进制字节串 |

## 限制

- **密钥不加密、不上传**：密钥仅参与当次本地计算，不落盘、不发送；但请注意不要在公共设备上粘贴生产密钥。
- **HMAC ≠ 加密**：它做的是认证（谁发的、有没有被改），不提供机密性；要加密正文请用文本加密工具。
- **SHA-1 已不推荐**：为兼容旧接口保留了 HMAC-SHA1 选项，新接口请用 SHA-256 及以上。
- 十六进制密钥会忽略空白、大小写不敏感；位数为奇数或含非十六进制字符时会明确报错，不做静默截断。
- 消息为空时返回空串（不计算）；密钥为空时提示「请先填写密钥」。
- 依赖浏览器的 WebCrypto，需要 HTTPS 或 localhost；不安全上下文会直接报错。

## 数据流向

**纯本地处理。** 密钥与消息都只在当前页面内交给浏览器 WebCrypto 计算，不写入 localStorage、不发送、不上传，无任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（消息）：

```text
The quick brown fox jumps over the lazy dog
```

密钥：

```text
key
```

输出（HMAC-SHA256 / hex）：

```text
f7bc83f430538424b13298e6aa6fb143ef4d59a14946175997479dbc2d1a3cd8
```
