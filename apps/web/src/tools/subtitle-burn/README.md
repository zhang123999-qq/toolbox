# 字幕烧录（subtitle-burn）

把 SRT / VTT 字幕文件烧录进视频画面，输出带硬字幕的新 MP4。

## 功能

- 支持 `.srt` / `.vtt` 字幕文件，VTT 会自动归一化为 SRT 后烧录
- 上传前解析并显示字幕条目数，非法字幕文件会中文报错
- 可调样式：字号、字体颜色、字幕位置（顶部 / 底部）、描边
- 使用 ffmpeg.wasm 在浏览器本地完成全部处理，视频不上传

## 使用

1. 选择视频文件（MP4 等）
2. 选择字幕文件（`.srt` / `.vtt`）
3. 调整样式后点「烧录字幕」
4. 预览结果并下载（文件名自动加 `-sub` 后缀）

## 限制

- 首次使用需下载 ffmpeg.wasm（约十几 MB），请保持网络畅通
- 输出统一为 H.264 + AAC 的 MP4，大视频处理较慢
