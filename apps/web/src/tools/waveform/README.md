# 波形显示

上传音频绘制波形图，支持放大/缩小查看细节，点击波形可移动视角。

## 用途

直观查看音频的响度包络：找静音段、爆音点、乐句分界。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

文件用浏览器 Web Audio API 本地解码（多声道自动混成单声道显示）。

## 输出

| 字段    | 类型   | 说明                                                     |
| ------- | ------ | -------------------------------------------------------- |
| `image` | canvas | 波形图（蓝色峰值柱 + 灰色中线）                          |
| `text`  | string | 当前视图摘要，如 `波形：song.wav，00:00.750 – 00:02.250` |

## 选项

| 选项   | 类型 | 默认 | 说明                  |
| ------ | ---- | ---- | --------------------- |
| `zoom` | 按钮 | ×1   | 放大/缩小，最大 ×1024 |

放大后点击波形任意位置，以该点为新的缩放中心。

## 限制

- 浏览器不支持 Web Audio API 或 Canvas 2D 时会给出中文提示
- 超大文件解码需要时间，请耐心等待
- 全程本地处理，不发任何请求

## 示例

载入示例音频（3 秒 440Hz 正弦波，带包络起伏）：

```text
显示范围：00:00.000 – 00:03.000（共 132300 个采样点，44100 Hz）
```

点「放大 ＋」后：

```text
显示范围：00:00.750 – 00:02.250（共 132300 个采样点，44100 Hz）
```

## 数据流向

**纯本地处理。** 解码、峰值抽取、绘制都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
