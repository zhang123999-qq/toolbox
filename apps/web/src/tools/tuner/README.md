# 调音器

麦克风实时音高检测：用自相关算法从麦克风声音中提取基频，换算成十二平均律音名，并显示与标准音高的偏差（音分）。

## 用途

给吉他、尤克里里、小提琴等乐器调音，或练声时检查音准。

## 输入

| 字段         | 类型   | 说明                                         |
| ------------ | ------ | -------------------------------------------- |
| `microphone` | 音频流 | 点「开始监听」后从麦克风实时采集，**不上传** |
| `text`       | string | 左侧文本区仅作备注，不参与处理               |

## 输出

| 字段   | 类型   | 说明                                              |
| ------ | ------ | ------------------------------------------------- |
| `text` | string | 调音结果摘要，如 `A4 · 440.0 Hz · 0 音分（音准）` |

界面同时大字显示音名（如 A4）、频率、音分偏差条（±5 音分内显示「音准」）。

## 选项

无。

## 限制

- 需要浏览器授予麦克风权限；拒绝后会给出中文提示
- 需要 HTTPS 或 localhost 环境（浏览器安全限制）
- 浏览器不支持麦克风采集或 Web Audio API 时会给出中文提示
- 只识别持续的单音（弹奏/哼唱），和弦与噪声无法准确检测
- 可检测范围约 40Hz～5000Hz；太安静（低于阈值）时显示等待
- 声音只在浏览器内分析，不录音、不发任何请求

## 示例

对着麦克风弹标准 A 音：

```text
A4 · 440.0 Hz · 0 音分（音准）
```

偏高 8 音分时显示 `A4 · 442.0 Hz · +8 音分（偏高）` 并提示「偏高，请调低」。

## 数据流向

**纯本地处理。** 麦克风采集与音高分析都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
