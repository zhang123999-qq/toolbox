# 节拍器

可调 BPM 与拍号的节拍器：用浏览器 Web Audio API 实时合成节拍声（重拍高音、弱拍低音），并在界面上闪烁当前拍点。

## 用途

乐器练习、录音打拍：设好速度与拍号，跟着声音和闪烁练习节奏。

## 输入

| 字段   | 类型   | 约束 | 说明                           |
| ------ | ------ | ---- | ------------------------------ |
| `text` | string | —    | 左侧文本区仅作备注，不参与处理 |

## 输出

| 字段    | 类型   | 说明                                        |
| ------- | ------ | ------------------------------------------- |
| `audio` | 合成声 | 每拍一次点击声（重拍 1600Hz，弱拍 1000Hz）  |
| `text`  | string | 当前配置摘要，如 `节拍器：120 BPM · 4/4 拍` |

## 选项

| 选项          | 类型 | 默认 | 说明                                     |
| ------------- | ---- | ---- | ---------------------------------------- |
| `bpm`         | 数字 | 120  | 每分钟拍数，20～320                      |
| `beatsPerBar` | 整数 | 4    | 每小节拍数，1～12                        |
| `beatUnit`    | 数字 | 4    | 拍号分母（以几分音符为一拍），1/2/4/8/16 |

## 限制

- 参数非法（BPM 非数字、超出范围等）会给出中文错误提示且不启动
- 修改参数后需点「停止」再「开始」才会生效
- 浏览器不支持 Web Audio API 时会提示，无法播放
- 离开页面时节拍器自动停止
- 声音全程由浏览器实时合成，不下载任何音频文件，不发任何请求

## 示例

默认 120 BPM、4/4 拍点「开始」：

```text
节拍器：120 BPM · 4/4 拍
```

每小节第 1 拍为红色高亮（重拍），其余为弱拍。

## 数据流向

**纯本地处理。** 节拍声由 Web Audio API 在浏览器内合成，`meta.api = false`，无需自备 API/Key。
