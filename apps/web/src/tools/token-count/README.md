# Token计数 Token Counter（#593）

用 OpenAI 官方分词器（gpt-tokenizer）在浏览器本地统计文本的 Token 数量，
支持按模型系列选择分词器，调用 API 前先估算用量。

## 分词器

- `o200k_base`：GPT-4o / GPT-4.1 / GPT-5 系列；
- `cl100k_base`：GPT-3.5 / GPT-4 系列。

分词器词表较大（几 MB），首次使用时才按需动态加载；之后走浏览器缓存。
全部计算在本地完成，不联网、不上传文本。

## 说明

- 不同模型的分词结果不同，务必选择与目标模型对应的分词器；
- 单次统计上限 200,000 字符；
- 统计的是纯文本 token 数，实际 API 调用还会加上 system prompt、消息结构等额外 token，
  此处结果仅供估算参考。
