# 麦克风测试（#835）

麦克风硬件检测：申请麦克风权限后实时显示输入电平，验证麦克风是否正常工作。

## 功能

- 点击"开始检测"申请麦克风权限（浏览器会弹出权限请求）。
- 通过 Web Audio AnalyserNode 实时计算输入电平（0～100%），附中文强度描述（静音 / 很弱 / 正常 / 较强 / 过载）。
- "停止检测"释放麦克风占用。

## 权限与局限

- 需要浏览器支持 `MediaDevices.getUserMedia`，且页面运行在 HTTPS 或 localhost 下；HTTP 非安全上下文会被浏览器拒绝。
- 权限被拒绝时请在浏览器地址栏的站点设置中允许麦克风后重试。
- 电平为相对值，仅用于判断"有没有声音"，不做精确声压测量。
