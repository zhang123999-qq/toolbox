# 时间线可视化

把多行「日期 | 标题」事件按日期排序，渲染成纯文本时间线，并标注相邻事件的间隔天数。

## 用途

项目里程碑、产品发布、个人大事记等一串事件，丢进来自动排成可读的时间线。

## 输入

每行一个事件，格式 `日期 | 标题`（日期支持 `YYYY-MM-DD` 或 `YYYY/MM/DD`）：

```text
2024-04-02 | 正式上线
2024-01-15 | 项目启动
2024-03-01 | 内测发布
```

- 空行、不含 `|` 的行、日期无法解析的行会被自动跳过
- 空输入返回空串；输入超过 200,000 字符报错

## 输出

按日期升序排列，首个事件后标注与上一个事件的间隔天数：

```text
2024-01-15  项目启动
2024-03-01  内测发布   (+46 天)
2024-04-02  正式上线   (+32 天)
```

## 数据流向

**纯本地处理。** 不发送网络请求，`meta.api = false`。

## 示例

输入：

```text
2024-04-02 | 正式上线
2024-01-15 | 项目启动
2024-03-01 | 内测发布
```

输出：

```text
2024-01-15  项目启动
2024-03-01  内测发布   (+46 天)
2024-04-02  正式上线   (+32 天)
```
