# 时区列表

列出运行时支持的全部 IANA 时区，可按关键词过滤，并显示每个时区此刻的墙上时间与 UTC 偏移。

## 用途

想确认一个城市的时区名到底怎么写（是 `Asia/Chongqing` 还是 `Asia/Shanghai`？）、
或者想看看某个区域都有哪些时区时，用关键词一过滤就能找到。
每行同时给出当前时间，方便和世界时钟对照。

## 输入

| 字段   | 类型   | 约束                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 时区关键词，最大 200,000 字符 |

- 留空 → 不产出内容（空输入约定）。
- 输入关键词（如 `Asia`、`Shanghai`、`New_York`）→ 大小写不敏感子串过滤。
- 无匹配 → 显示「无匹配的时区」提示（不算错误）。

## 输出

| 字段   | 类型   | 说明                                          |
| ------ | ------ | --------------------------------------------- |
| `text` | string | 每行一个时区：名称 + 当前时间 + `(UTC±HH:mm)` |

```text
Asia/Almaty      2026-09-27 13:30:45  (UTC+06:00)
Asia/Shanghai    2026-09-27 15:30:45  (UTC+08:00)
...
```

## 选项映射

本工具无选项。

## 实现规则 / 算法

1. **枚举**：直接读 `Intl.supportedValuesOf('timeZone')`，不手写时区表。
2. **过滤**：关键词 trim 后转小写，对时区名做 `includes` 子串匹配。
3. **当前时间 / 偏移**：用 `Intl.DateTimeFormat#formatToParts` 取墙上分量；
   把该分量当作 UTC 构造 `Date` 与真实时刻求差，得到此刻相对 UTC 的偏移，DST 自动体现。

## 浏览器 / 运行时边界

- 时区数量与名单取决于运行时 ICU；不同浏览器/Node 版本可能差几个已废弃的别名。
- 「当前时间」取调用瞬间，不自动刷新。
- 关键词是子串匹配，输入 `Asia` 会同时命中 `Asia/Aqtau`、`Asia/Almaty` 等全部亚洲区。
- 不做分页；匹配过多时输出区可滚动。

## 示例

输入：

```text
Asia
```

输出（随当前时刻变化）：

```text
Asia/Almaty      2026-09-27 13:30:45  (UTC+06:00)
Asia/Shanghai    2026-09-27 15:30:45  (UTC+08:00)
Asia/Tokyo       2026-09-27 16:30:45  (UTC+09:00)
...
```
