# 速度换算

输入数值并选择源/目标单位，把米/秒、千米/时、英里/时、英尺/秒、节互相转换。

## 用途

- 把车速的英里/时（mph）换成千米/时
- 航海 / 航空中换算节（knot）
- 物理习题统一速度单位

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待换算的数值，最大 200,000 字符 |

## 输出

```text
100 km/h = 27.7777777778 m/s
```

## 选项

| 选项   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `from` | select | 源单位：`m/s` `km/h` `mph` `ft/s` `knot` |
| `to`   | select | 目标单位（同上）                         |

## 算法

以**米/秒（m/s）**为基准单位：

- `结果 = 输入 × 源单位换算因子 ÷ 目标单位换算因子`
- 换算因子：`m/s`×1、`km/h`×(1/3.6)、`mph`×0.44704、`ft/s`×0.3048、`knot`×0.514444
- 数字格式化：`Number(n.toPrecision(12)).toString()`（12 位有效数字，去浮点尾巴）

## 边界

- 空输入 → 输出空串
- 非法数字 → 中文报错「请输入有效的数字」
- 非法单位 id → 中文报错「未知单位」
- 输入 > 200,000 字符 → 报错

## 示例

输入 `100`，从 `km/h` 到 `m/s`：

```text
100 km/h = 27.7777777778 m/s
```

## English

A speed converter: enter a number and pick source/target units (m/s, km/h, mph, ft/s, knots). Input: `text` (the numeric value). Output: e.g. `100 km/h = 27.7777777778 m/s`.
