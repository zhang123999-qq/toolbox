# 蓝牙测试（Bluetooth Test）

全局编号：#868｜域：教育趣味｜优先级：P3｜可行性：C（Web API）

## 功能

- **检测能力**：判断当前浏览器是否支持 Web Bluetooth
- **连接蓝牙设备**：弹出浏览器蓝牙选择器，选择后展示设备名与 ID 简写
- **列出已配对设备**：展示已授权的配对设备（未授权时如实提示空列表）

## 注意事项

- 需要 **HTTPS** 环境，并在**用户手势**（点击按钮）中调用
- 仅 Chrome / Edge 等支持 Web Bluetooth 的浏览器可用
- 仅列出已配对/已授权的设备；用户取消选择时显示浏览器返回的错误
- 本工具仅做能力检测与设备列出，不读写设备数据
