# Excel 表格预览

上传 `.xlsx` / `.xls` / `.csv` 文件，在浏览器本地渲染为可切换工作表的表格预览。

## 用途

快速查看表格内容而不打开 Excel：上传文件，直接看表，多工作表可切换。

## 输入

| 字段   | 类型 | 约束        | 说明                                      |
| ------ | ---- | ----------- | ----------------------------------------- |
| `file` | File | 最大 50 MiB | 输出区顶部「选择 Excel 文件」，**不上传** |

## 输出

| 字段    | 类型 | 说明                                |
| ------- | ---- | ----------------------------------- |
| `table` | HTML | 工作表页签 + 可滚动表格（本地渲染） |

预览限制：只显示前 1000 行 × 50 列，超出部分截断并提示。「下载」导出为 TSV 文本。

## 选项

无（工作表切换在输出区内完成）。

## 限制

- **文件上限 50 MiB**
- 渲染由 xlsx（纯 JS，本地运行）完成，取单元格的**显示文本**
- 空表显示「（空表）」
- 损坏 / 非表格文件会直接报中文错误

## 数据流向

**纯本地处理。** 文件不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：包含「人员」表（姓名 / 年龄两列）和「空表」的 `.xlsx`

输出：输出区显示「人员」「空表」两个页签，当前表渲染为带 A / B 列标头的表格。

## 元信息

| 项       | 值                     |
| -------- | ---------------------- |
| 全局编号 | #502                   |
| 域       | `media`（媒体 / 文档） |
| 大组     | `office`               |
| 优先级   | P0                     |
| 可行性   | A（纯 JS）             |
| 模板     | T3（输出区自定义渲染） |
