# 视频压缩

上传视频，用 ffmpeg.wasm 在浏览器本地降低码率 / 分辨率压缩体积，输出 MP4（H.264 + AAC）。

## 用途

视频太大发不出去、占空间：选画质档位与目标分辨率，一键压缩后下载更小的文件。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                       |
| ------- | ------ | ------------------------------------------ |
| `video` | MP4    | 压缩后的视频，可预览并下载                 |
| `text`  | string | 处理报告：画质档位 / 目标分辨率 / 输出大小 |

## 选项

| 选项         | 类型 | 默认   | 说明                                                                            |
| ------------ | ---- | ------ | ------------------------------------------------------------------------------- |
| `quality`    | 下拉 | medium | 画质档位：high（清晰，CRF 23）/ medium（均衡，CRF 28）/ low（极限压缩，CRF 33） |
| `resolution` | 下拉 | 720p   | 目标分辨率：original（保持）/ 1080p / 720p / 480p（按高度降采样）               |

## 限制

- 压缩在浏览器本地完成（ffmpeg.wasm），首次使用需从 CDN 下载 wasm 内核
- 输出固定为 MP4（H.264 视频 + AAC 128k 音频）
- 文件全程留在浏览器内存里，不发任何请求

## 示例

`movie.mp4`，均衡画质 + 720p：

```text
输入：movie.mp4
画质档位：均衡（CRF 28）
目标分辨率：高度 720px
输出大小：xxx MiB
```

## 数据流向

**纯本地处理。** 压缩在浏览器内完成，`meta.api = false`，无需自备 API/Key。

| 项       | 值                         |
