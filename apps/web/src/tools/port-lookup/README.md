# 端口查询

内置 50+ 常用网络端口。输入端口号查服务名，或输入服务名反查端口。

## 用途

看到 `ss -lntp` 里 `6379`、`9200` 不知道是啥，或要确认「MySQL 是哪个端口」时直接查。

## 输入

| 字段   | 类型   | 约束                              |
| ------ | ------ | --------------------------------- |
| `text` | string | 端口号或服务名，最大 200,000 字符 |

- 纯数字（0-65535）→ 按端口号精确查
- 其他 → 按服务名 / 中文说明模糊匹配，最多 20 条

## 输出

```text
6379/tcp  Redis  —  Redis 缓存（默认无密码，勿暴露公网）
```

## 收录范围

常见系统端口（21/22/25/53/80/443…）、邮件（110/143/993/995）、
数据库（3306/5432/1521/27017/6379/11211）、消息队列（5672/1883）、
云原生监控（9090/9200/5601/6443/8500）等。

## 安全提醒

`6379 Redis`、`9200 ES`、`27017 Mongo`、`2375 Docker` 这类**默认无认证**的服务，
绝不要直接绑公网 0.0.0.0，历史上是挖矿木马的重点目标。

## 限制

- 仅收录常用端口，未覆盖全部 1-65535
- 模糊匹配最多返回 20 条
- 空输入返回空串；未命中抛中文错误

## 数据流向

**纯本地处理。** 内置表查询，不发送网络请求。`meta.api = false`。

## 示例

输入：

```text
6379
```

输出：

```text
6379/tcp  Redis  —  Redis 缓存（默认无密码，勿暴露公网）
```
