# JSON 校验

校验 JSON 是否合法，出错时给出**行号与列号**，通过时给出结构概况。

## 用途

接口 body、配置文件、日志行、LLM 输出的「像 JSON 但不是 JSON」片段，粘进来就能定位到
第几行第几列少了一个逗号、多了一个引号、写了前导零。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                             |
| ------ | ------ | -------------------------------- |
| `text` | string | 合法时是概况报告；空输入返回空串 |

合法输出示例：

```
JSON 合法
顶层类型：object
顶层条目数：2
键总数：2
节点总数：4
最大深度：2
字符数：15
```

## 选项

| 选项     | 取值    | 默认    | 说明                                   |
| -------- | ------- | ------- | -------------------------------------- |
| `strict` | boolean | `false` | 严格模式：对象里出现重复键直接判为错误 |

## 限制

- **语法层实现为自研递归下降解析器**，不是 ajv：ajv 管的是「按 Schema 校验」（见 `json-schema-validate`），
  本工具只需要判语法合法性并给出位置
- 不支持 JSONC（注释）、单引号、尾随逗号、未转义控制字符——这些按标准 JSON 一律判非法
- 输入上限 1,000,000 字符，超过抛 `JsonValidateError`
- 嵌套超过 2,000 层会被拦下（防爆栈）
- 非严格模式下重复键只给警告，解析取最后一次出现的值

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```json
{ "name": "工具库", "tools": 870 }
```

输出：

```
JSON 合法
顶层类型：object
顶层条目数：2
键总数：2
节点总数：2
最大深度：1
字符数：40
```
