# i18n JSON 对比

对比基准语言与目标语言的 i18n JSON：嵌套键拍平后比较，检出缺失、多余、空值、未翻译（与基准相同）的键，给出翻译完成率。

## 用途

- 发版前检查新语言包漏了哪些键
- 找出基准语言新增但翻译还没跟上的文案
- 清理目标语言里多余、空值的键

## 输入

| 字段     | 类型   | 约束          |
| -------- | ------ | ------------- |
| `text`   | string | 基准语言 JSON |
| `target` | string | 目标语言 JSON |

## 说明

- 纯本地对比，无网络请求。
- 数字/布尔叶子按字符串比较；数组与 null 被视为格式错误。
- 未翻译指目标值与基准值完全相同（数字转字符串后比较）。
