# SQLite 查看器（元数据）

上传一个 SQLite 数据库文件（`.db` / `.sqlite` / `.sqlite3`），离线查看它的**文件头信息与对象清单**：
页大小、页数、编码、日志模式，以及 `sqlite_master` 中登记的全部**表 / 视图 / 索引 / 触发器**
及其 `CREATE` 语句。纯本地解析，不上传文件。

> **与规划文档的偏差说明（重要）**：规划表（03-数据格式.md #184）为 B 级、设想用 `sql.js`（SQLite 编译成
> WebAssembly）在浏览器里真正执行 SQL、浏览每张表的数据。该 wasm 依赖**未安装**，本仓库约束零新增网络
> 依赖；用纯 TS 重写一个 SQL 执行引擎不现实。因此本工具落地为**「文件头 + schema 结构查看」**：
> 手写 b-tree / record 解码读 `sqlite_master`，**不执行任何 SQL、不读取业务表的数据行**。
> 需要跑查询 / 看数据，请用 DB Browser for SQLite、`sqlite3` CLI、DuckDB 或 sql.js。

## 用途

- 不装任何工具快速了解一个 `.sqlite` 文件：多大、什么页大小 / 编码、有哪些表和视图
- 直接拿到建表 / 建视图 / 建索引 DDL，便于复制到文档或对照迁移
- 判断文件是否真的是 SQLite、是否损坏（magic、页大小、b-tree 结构校验）

## 输入

| 入口     | 接受                                        | 上限   |
| -------- | ------------------------------------------- | ------ |
| 文件上传 | `.db` / `.sqlite` / `.sqlite2` / `.sqlite3` | 30 MiB |

文本框不承载二进制内容；在文本框运行会提示改用文件上传。

## 输出

Markdown 报告：

- 文件头：文件大小、页大小、页数、保留字节、文本编码、读 / 写版本（legacy / WAL）
- 对象统计：表 / 视图 / 索引 / 触发器数量（内部 `sqlite_*` 单独标注）
- 逐对象：名字、类型、根页号、完整 `CREATE` 语句

## 实现要点

- 校验头部 magic `SQLite format 3\0` 与页大小合法性
- 从首页（`sqlite_master` 根页）遍历 table b-tree：支持叶子页（`0x0d`）与内部页（`0x05`，递归子页 / 最右指针）
- 解码 record：变长整数（varint）与 serial type（整数大端、浮点、UTF-8 文本、BLOB、NULL）
- 只取 schema 五列（type / name / tbl_name / rootpage / sql）

## 限制

- **不执行 SQL、不读业务表数据**，也不解析视图以外的查询结果
- schema 记录若走 **overflow 页**（极少见）会跳过并计数提示；不解析自由页、WAL / 回滚日志、
  虚拟表 / FTS 的内部结构
- 不展开每张表的列类型明细（如需字段级结构，可直接看输出里的 `CREATE TABLE` DDL，或用 #168 / #185）
- 仅支持 UTF-8 数据库；UTF-16 数据库能识别编码标记但 schema 文本可能乱码；加密数据库（SQLCipher）无法解析

## 数据流向

**纯本地处理。** 数据库文件只在浏览器内存中读取头部与首页，不上传、不写服务端。`meta.api = false`。
