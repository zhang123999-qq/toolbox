# 代码转 PDF

将代码源码排版为等宽字体（Courier）的 A4 PDF：行号可开关，自动换行、自动分页，纯本地生成后下载。

## 用途

代码片段、配置文件打印存档或分享评审，不经过任何服务器。

## 输入

| 字段   | 类型   | 约束              | 说明     |
| ------ | ------ | ----------------- | -------- |
| `text` | string | 最大 100,000 字符 | 代码源码 |

制表符统一展开为 4 个空格，保证等宽对齐；行号格式为 `序号 | 代码`，序号按总行数右对齐。

## 输出

| 字段   | 类型       | 说明                          |
| ------ | ---------- | ----------------------------- |
| `file` | PDF 二进制 | A4 纵向 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「下载」按钮下载的是源码文本（`.txt`）。

## 选项

| 选项          | 取值         | 默认 | 说明         |
| ------------- | ------------ | ---- | ------------ |
| `fontSize`    | 9 / 10 / 12  | 10   | 字号（pt）   |
| `lineNumbers` | boolean      | true | 是否显示行号 |
| `margin`      | 36 / 54 / 72 | 54   | 页边距（pt） |

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，代码含中文注释时会直接报错，
  不会生成乱码 PDF。
- 超长行按词换行后，续行**不重复行号**（行号只出现在逻辑行的首行）。
- 无语法高亮，只做等宽排版。
- 文件全程在浏览器内存里生成，不发任何请求。

## 数据流向

**纯本地处理。** 输入与生成的 PDF 都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
function fib(n) {
	if (n < 2) return n;
	return fib(n - 1) + fib(n - 2);
}
```

输出：A4 PDF（等宽 10pt，行号 `1 |`~`5 |`）；输出区显示如 `已生成 PDF：1 页，2.4 KB`。
