# 不可见字符

检测并高亮不可见字符。

## 用途

找出文本里看不见却真实存在的字符：不换行空格、软连字符、零宽字符、方向标记、控制字符——它们常常是复制粘贴后格式错乱、搜索不到、代码报莫名错误的元凶。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本。

## 输出

| 字段   | 类型   | 说明                                                                                                  |
| ------ | ------ | ----------------------------------------------------------------------------------------------------- |
| `text` | string | 按模式输出：mark 把不可见字符替换成 `[U+XXXX]` 标记；remove 直接删除；list 给出位置、码位与名称清单。 |

## 选项

| 选项         | 取值                                                 | 默认   | 说明                                       |
| ------------ | ---------------------------------------------------- | ------ | ------------------------------------------ |
| `mode`       | `mark`（标记） / `remove`（删除） / `list`（列清单） | `mark` | 处理方式                                   |
| `keepCommon` | 勾选 / 取消                                          | 勾选   | 常见空白（空格、制表符、换行）是否排除在外 |

## 限制

- 按**码位**判断，不做上下文推断：合法的蒙古文元音分隔符等也会被算作不可见
- 不区分「有害」与「无害」，只是列出所有不可见字符，是否删除由你决定
- 零宽字符的专项检测（含隐藏水印判断）请用「零宽字符」（#42）
- 不做 Unicode 正规化（NFC/NFD），组合字符不会被合并处理
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
a␣b␣c（两个 ␣ 分别是不换行空格 U+00A0 与零宽空格 U+200B，页面上肉眼看不出来）
```

输出：

```text
a[U+00A0]b[U+200B]c
```
