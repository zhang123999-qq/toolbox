# AI 检测 AI Content Detection（#604）

BYOK 模式：粘贴一段文本，请大模型分析它是否疑似 AI 生成，
返回结论（疑似 AI 生成 / 疑似人类撰写 / 无法确定）、置信度与理由。

## 使用方法

1. 左侧粘贴待检测文本（至少 50 字符）；
2. 右侧配置接口地址、模型名、API Key；
3. 点「开始检测」，结论徽章、置信度条与理由列表展示在下方。

## BYOK 说明

- API Key 只保存在内存中，刷新/关闭页面即清除，不写 localStorage；
- Key 只出现在请求头中，本站不经手、不记录；
- 要求模型只返回 JSON（verdict / confidence / reasons），
  解析失败时明确报错，绝不编造结论。

## 准确性说明

AI 检测本身没有 100% 准确的方法，结论仅供参考，
请勿作为学术不端等严肃判定的唯一依据。

## 错误处理

- 文本为空 / 太短 / 超长显示中文错误；
- 401 / 403 / 404 / 429 / 5xx 翻译为中文提示。
