# AI 文本摘要（ai-summarize）

调用大模型把长文本压缩成摘要。支持三种长度：简短 / 适中 / 详细。

## 功能

- 三种摘要模式：简短（1-2 句）、适中（一段）、详细（分点）
- BYOK：使用你自己的 API Key，兼容 OpenAI 接口格式
- 服务地址、模型均可修改（默认 `https://api.openai.com/v1` / `gpt-4o-mini`）
- 超时（60 秒）、401、429、网络失败都有中文提示

## 使用

1. 在「API Key」中填写你的 Key（密码框，可一键清除）
2. 粘贴要摘要的文本，选择摘要长度
3. 点「生成摘要」，结果可复制

## 隐私说明

- **Key 只保存在你浏览器的 localStorage，不会发送到除你填写的服务地址之外的任何地方**
- 摘要请求直接从浏览器发往你填写的服务地址，本工具服务器不经手
- 不记录、不硬编码任何 Key
