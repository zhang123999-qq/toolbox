# 阴影生成

配置偏移、模糊、扩散、颜色，一键生成 `box-shadow` CSS。

## 用途

不用手拼 `box-shadow: 0 4px 12px rgba(0,0,0,.15)` 这种长串，填几个数字直接拿结果。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作触发用。

## 输出

| 字段   | 类型   | 说明             |
| ------ | ------ | ---------------- |
| `text` | string | `box-shadow: …;` |

## 选项

| 选项 key  | 界面标签 | 说明                   |
| --------- | -------- | ---------------------- |
| `offsetX` | 水平偏移 | 正数向右，负数向左     |
| `offsetY` | 垂直偏移 | 正数向下               |
| `blur`    | 模糊半径 | 0 为硬边               |
| `spread`  | 扩散半径 | 正数放大阴影，负数缩小 |
| `color`   | 颜色     | HEX / rgba() / 命名色  |
| `inset`   | 内阴影   | 勾选后生成内阴影       |

## 限制

- 只输出单层阴影，不生成多阴影逗号列表
- 长度无单位时自动补 px
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** `meta.api = false`。

## 示例

输出：

```css
box-shadow: 0px 4px 12px 0px rgba(0, 0, 0, 0.15);
```
