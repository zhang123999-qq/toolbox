# AA 分账

多人 AA 平摊消费总额，支持叠加小费后算人均。

## 用途

- 聚餐结账：总额按人头平分
- 境外 AA：账单含小费时一并分摊

## 输入

| 字段    | 类型   | 约束                                      |
| ------- | ------ | ----------------------------------------- |
| `text`  | string | 消费总额（必须大于 0），最大 200,000 字符 |
| `textB` | string | 人数（必须为 ≥ 1 整数）                   |

## 输出

```text
消费总额：300.00 元
小费（0%）：0.00 元
应付总计：300.00 元
人均（3 人）：100.00 元
```

## 选项

| 选项      | 类型   | 说明                         |
| --------- | ------ | ---------------------------- |
| `tipRate` | select | 小费比例：`0` `10` `15` `20` |

## 算法

- `小费 = 总额 × 比例 / 100`，`应付总计 = 总额 + 小费`，`人均 = 应付总计 / 人数`
- 金额保留 2 位小数；比例用 12 位有效数字格式化（去浮点尾巴）

## 边界

- 空输入 → 输出空串
- 总金额非数字 / ≤ 0 → 中文报错
- 人数为空 → 中文报错「人数不能为空」
- 人数非数字 / 非整数 / < 1 → 中文报错「人数应为大于等于 1 的整数」
- 小费比例非法 → 中文报错「小费比例非法」

## 示例

总额 `300`，人数 `3`，小费比例 `0`：

```text
消费总额：300.00 元
小费（0%）：0.00 元
应付总计：300.00 元
人均（3 人）：100.00 元
```

## English

A bill splitter: split the total evenly among people, with an optional tip rate. Input: `text` (total), `textB` (headcount). Output: e.g. `应付总计：330.00 元` / `人均（3 人）：110.00 元`.
