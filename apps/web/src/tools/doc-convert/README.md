# 文档格式转换（doc-convert · #540）

多格式文档互转工具：选择源文件后，按源格式给出可达的目标格式，
全部在浏览器本地完成，不上传文件。

## 转换矩阵（共 11 种）

| 源格式           | 目标格式       | 实现                                               |
| ---------------- | -------------- | -------------------------------------------------- |
| `.docx`          | `.txt` 纯文本  | mammoth `extractRawText`                           |
| `.docx`          | `.html` 网页   | mammoth `convertToHtml`                            |
| `.docx`          | `.md` Markdown | mammoth `convertToMarkdown`                        |
| `.xlsx` / `.xls` | `.json`        | xlsx：`{ 工作表名: 行数组 }`，空表为 `[]`          |
| `.xlsx` / `.xls` | `.csv`         | xlsx：取首个工作表（CSV 为单表格式）               |
| `.xlsx` / `.xls` | `.md`          | 每工作表一节的 Markdown 表格，空表标注「（空表）」 |
| `.csv`           | `.json`        | 对象数组；空 CSV 得 `[]`（合法空结果）             |
| `.csv`           | `.md`          | Markdown 表格；空 CSV 得「（空表）」               |
| `.csv`           | `.xlsx`        | xlsx 库生成二进制工作簿                            |
| `.json`          | `.csv`         | 顶层为对象数组的 JSON                              |
| `.json`          | `.xlsx`        | xlsx 库生成二进制工作簿                            |

依赖：`mammoth`（docx 解析，动态加载）+ `xlsx`（表格解析/生成，静态导入）。

## 边界与错误

| 情况                                | 行为                                      |
| ----------------------------------- | ----------------------------------------- |
| 旧版 `.doc`                         | 提示「暂不支持旧版 .doc，请另存为 .docx」 |
| 不支持的文件类型                    | 中文错误并列出支持的扩展名                |
| 空文件 / 超 50 MiB                  | 中文错误                                  |
| 损坏的 xlsx（魔数不对 / zip 损坏）  | 中文错误「表格解析失败」                  |
| 无工作表的工作簿                    | 中文错误「工作簿中没有工作表」            |
| 无文本内容的 docx                   | 中文错误「文档中没有可转换的文本内容」    |
| 非法 JSON / 顶层非数组 / 元素非对象 | 中文错误说明期望形状                      |
| 空 CSV / 空表                       | 合法空结果（`[]` / `（空表）`），不报错   |

## 实现说明

- mammoth 走动态导入（`mammoth/mammoth.browser`），只在转换 docx 时加载；
  xlsx 静态导入（与 Excel 工具同款例外）。
- xlsx 文件先做 zip/OLE 魔数校验：`XLSX.read` 对垃圾字节不抛错，
  魔数校验保证损坏文件能给出中文错误而非静默产出空结果。
- 文本结果在页面内预览（超长截断），二进制 xlsx 显示字节数；
  下载文件名自动换为目标扩展名（如 `报告.docx` → `报告.md`）。
- 下载链接优先用 Blob URL；jsdom 等不支持 Blob URL 的环境降级为 data URL。
- CSV 输出为无 BOM 的 UTF-8；Markdown 表格中 `|` 转义、换行转 `<br/>`。
