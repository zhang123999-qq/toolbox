# 文本去重

按行去重，保留顺序。

## 用途

清掉列表里的重复行：合并多个来源的清单、去重关键词、清洗日志时，保留第一次出现的顺序，不打乱原有排列。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

多行文本。换行符统一按 LF / CRLF 识别，输出统一用 LF。

## 输出

| 字段   | 类型   | 说明                                                                                    |
| ------ | ------ | --------------------------------------------------------------------------------------- |
| `text` | string | 去重后的文本，保留每行首次出现时的原始内容（去空白 / 忽略大小写只用于比较，不改输出）。 |

## 选项

| 选项         | 取值        | 默认 | 说明                               |
| ------------ | ----------- | ---- | ---------------------------------- |
| `ignoreCase` | 勾选 / 取消 | 取消 | 比较时忽略大小写                   |
| `trimLines`  | 勾选 / 取消 | 取消 | 比较前去除行首尾空白               |
| `keepEmpty`  | 勾选 / 取消 | 取消 | 是否保留空行（保留时也只留第一个） |

## 限制

- 只按整行比较，不做子串去重、不做模糊匹配（近义或近似行不会合并）
- 去空白 / 忽略大小写只影响比较，**输出仍是首次出现的原文**
- 默认丢弃所有空行；需要保留段落结构请勾选「保留空行」
- 不排序：需要排序请用「文本排序」（#29）
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
苹果
香蕉
苹果
橙子
香蕉
```

输出：

```text
苹果
香蕉
苹果
橙子
香蕉
```
