# 对话历史 Chat History（#595）

本地对话记录管理工具：手动添加对话、导入 JSON、关键词搜索、按模型筛选、
按时间排序、导出 JSON、清空——全部数据只存在浏览器 localStorage，**不联网**。

## 使用方法

- **手动添加**：填标题、模型名，消息区按每行 `角色: 内容` 填写
  （角色为 `user` / `assistant` / `system`，冒号支持中英文）；
- **导入 JSON**：粘贴 `[{title, model, messages: [{role, content}]}]`
  或 `{sessions: [...]}`，非法条目会被跳过并计数提示；
- **搜索**：左侧输入框按标题 / 模型 / 消息内容模糊搜索；
- **筛选排序**：右上角可按模型过滤、按时间正序 / 倒序；
- **导出**：下载 `chat-history.json`；**清空**：删除全部本地记录（需二次确认）。

## 数据说明

- 存储位置：浏览器 localStorage（`toolbox:chat-history:sessions`）；
- 清除浏览器数据会一并删除，请定期导出备份；
- 导入时已存在的 id 会自动去重。
