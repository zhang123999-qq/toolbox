# 图片 Alt 生成

上传图片，填写自己的 API Key 调用多模态模型，生成简洁客观的无障碍 `alt` 替代文本，并给出可直接粘贴的 `alt="…"` 属性代码。

## 用途

- 为文章配图、产品图生成符合无障碍规范的 alt 文本
- 批量检查存量图片的替代文本质量（逐张生成后人工确认）

## 输入

| 字段   | 类型   | 约束                     |
| ------ | ------ | ------------------------ |
| `text` | string | 补充说明（可选，如"重点描述人物表情"） |

另需在页面内填写：接口地址、模型（需支持多模态）、API Key、图片类型。

## 说明

- BYOK 模式：使用你自己的 Key，费用自理；Key 只保存在组件内存中，刷新/关闭页面即清除，不写入 localStorage，不进日志。
- 浏览器直接调用第三方接口可能被 CORS 策略拦截：若报网络失败，请检查目标接口是否允许浏览器跨域调用，或改用支持 CORS 的中转地址。
- 生成的 alt 文本要求：简洁客观、不超过 125 字符、不以"图片显示"等废话开头；仍建议人工复核后再上线。
- 图片只在浏览器内转 dataURL 后发往你自己的接口，本站不存储图片。
