# 百分比计算

三种常见百分比计算：A 占 B 的百分之几、A 的 B% 是多少、从 A 到 B 的变化率（增长 / 下降）。

## 用途

- 算占比：50 是 200 的百分之几
- 算折扣 / 税费：200 的 85% 是多少
- 算涨跌幅：上月 100，本月 150，增长了百分之几

## 输入

| 字段    | 类型   | 约束                                            |
| ------- | ------ | ----------------------------------------------- |
| `text`  | string | 第一个数 A，最大 200,000 字符                   |
| `textB` | string | 第二个数 B（可空，默认按 0 处理时部分模式报错） |

## 输出

```text
50 是 200 的 25%
算式：50 ÷ 200 × 100% = 25%
小数形式：0.25
```

变化率模式示例（A=100，B=80）：

```text
从 100 到 80：下降 20%
算式：(80 − 100) ÷ 100 × 100% = -20%
变化量：-20
```

## 选项

| 选项   | 取值                      | 说明                                    |
| ------ | ------------------------- | --------------------------------------- |
| `mode` | `of` / `value` / `change` | 占比 / 求百分比的量 / 变化率，默认 `of` |

## 算法

- **占比**：`A ÷ B × 100%`，B 为 0 时报错
- **求值**：`A × B ÷ 100`
- **变化率**：`(B − A) ÷ A × 100%`，A 为 0 时报错；正数表示增长，负数表示下降
- 显示层用 `toPrecision(12)` 压平浮点噪声（如 `100/3` 显示为 `33.3333333333`）

## 边界

- 输入允许千分位逗号（`1,000`）与末尾百分号（`50%` 按 50 处理）
- 非数字输入 → 中文报错
- B=0（占比模式）/ A=0（变化率模式）→ 中文报错
- 输入 > 200,000 字符 → 报错

## 示例

输入 A=`50`，B=`200`，模式 `of`：输出 `50 是 200 的 25%`。

## 数据流向

纯前端本地计算，不调用外部接口、不上传数据。
