# JSON 压缩

去除 JSON 中的空白与换行，压成单行以减小体积。

## 用途

把为了可读性排版过的 JSON 压回单行，用于网络传输、日志埋点、配置文件瘦身。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 5,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 压缩后的 JSON；空输入返回空串 |

## 选项

| 选项       | 取值    | 默认    | 说明               |
| ---------- | ------- | ------- | ------------------ |
| `sortKeys` | boolean | `false` | 是否按键名递归排序 |

## 限制

- 输入上限 5MB，超出抛出 `JsonMinifyError`
- 压缩会丢弃原始排版（缩进、换行、键顺序仅在 `sortKeys` 关闭时保留）
- 不支持 JSONC（注释）与尾随逗号

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```json
{
  "name": "工具库",
  "tools": 870,
  "local": true
}
```

输出：

```json
{ "name": "工具库", "tools": 870, "local": true }
```

（实际输出无空格：`{"name":"工具库","tools":870,"local":true}`）
