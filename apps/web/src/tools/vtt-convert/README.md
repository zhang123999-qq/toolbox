# VTT字幕转换

解析 VTT 字幕，转换为纯文本 / JSON / SRT / VTT，并支持时间轴整体偏移（毫秒，可为负）。

## 用途

WebVTT 是网页视频字幕标准格式：解析后可转 SRT 给播放器用、提取纯文本做翻译、整体平移时间轴对齐音画。

## 输入

| 字段   | 类型   | 约束 | 说明                    |
| ------ | ------ | ---- | ----------------------- |
| `text` | string | —    | 左侧文本区粘贴 VTT 字幕 |

点「载入示例」可填入示例字幕直接试（含 NOTE 块与 cue settings）。

## 输出

| 字段   | 类型   | 说明                           |
| ------ | ------ | ------------------------------ |
| `text` | string | 转换后的字幕文本，可复制或下载 |

## 选项

| 选项       | 类型 | 默认 | 说明                                         |
| ---------- | ---- | ---- | -------------------------------------------- |
| `target`   | 下拉 | srt  | 目标格式：vtt / srt / txt（纯文本）/ json    |
| `offsetMs` | 数字 | 0    | 时间轴整体偏移（毫秒），可为负，负值钳制到 0 |

## 限制

- 文件头 `WEBVTT` 必需，缺失会给出中文错误提示
- NOTE / STYLE / REGION 功能块、cue 标识符、cue settings（如 `position:10%`）会被跳过或忽略
- 时间戳兼容 `00:00:00.000` 与 `00:00:00,000` 两种写法
- 空字幕、非法时间戳都会给出中文错误提示
- 纯本地处理，不发任何请求

## 示例

```text
WEBVTT

00:00:01.000 --> 00:00:04.000
你好，世界
```

转 SRT：

```text
1
00:00:01,000 --> 00:00:04,000
你好，世界
```

## 数据流向

**纯本地处理。** 解析与转换都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
