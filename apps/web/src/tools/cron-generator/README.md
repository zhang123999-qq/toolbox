# Cron 生成

不手写 cron 表达式：在分/时/日/月/周五个框里各填一段（留星号表示不限），
即时拼出标准 5 段 cron，并附上中文描述方便核对。

## 用途

记不住 `0 0 1 * *` 到底是每月几号几点？本工具把「填条件 → 出表达式」反过来做，
填完直接复制 crontab / Airflow / GitHub Actions 即可。

## 输入

| 字段   | 类型   | 约束                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 仅作触发用，最大 200,000 字符 |

输入框内容**不参与**生成：留空不产出，点「示例」或随手输入即按选项生成。

## 选项

| 选项     | 标签 | 取值范围 | 默认 | 说明                               |
| -------- | ---- | -------- | ---- | ---------------------------------- |
| `minute` | 分   | 0-59     | `*`  | 支持 `*`、`*/N`、`a`、`a-b`、`a,b` |
| `hour`   | 时   | 0-23     | `*`  | 同上                               |
| `dom`    | 日   | 1-31     | `*`  | 同上                               |
| `month`  | 月   | 1-12     | `*`  | 同上                               |
| `dow`    | 周   | 0-7      | `*`  | 0/7 均为周日                       |

## 输出

| 字段   | 类型   | 说明                       |
| ------ | ------ | -------------------------- |
| `text` | string | 首行 cron 表达式，随后描述 |

```text
0 2 * * 1-5

# 描述
周一到周五 02:00
```

## 例子

| 分     | 时  | 日  | 月  | 周    | 表达式         |
| ------ | --- | --- | --- | ----- | -------------- |
| `0`    | `2` | `*` | `*` | `1-5` | `0 2 * * 1-5`  |
| `*/15` | `*` | `*` | `*` | `*`   | `*/15 * * * *` |
| `0`    | `0` | `1` | `*` | `*`   | `0 0 1 * *`    |

## 限制

- 只生成标准 **5 段** cron，不含秒 / 年
- 「日」与「周」同时被限制时，表达式原样输出，不做语义合并提示
- 空输入返回空串；非法字段抛中文错误

## 数据流向

**纯本地处理。** 字符串拼接与校验，不发送网络请求。`meta.api = false`。
