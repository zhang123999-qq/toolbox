# 日出日落

按「日期 + 纬度 + 经度 + 时区偏移」计算当日的日出、正午、日落时刻与昼长。
采用 NOAA 太阳位置算法（分数年模型），纯本地计算，不依赖 suncalc 等库。

## 用途

出行、拍摄、户外运动前快速查某地当天几点天亮、几点天黑；
也用于判断某地是否处于极昼 / 极夜。

## 输入

在文本框里按行写键值（也支持紧凑位置式）：

```text
日期: 2025-06-21
纬度: 39.9
经度: 116.4
时区: +8
```

| 字段 | 类型       | 约束                                  |
| ---- | ---------- | ------------------------------------- |
| 日期 | YYYY-MM-DD | 必须是合法公历日                      |
| 纬度 | 数字       | -90 ~ 90，可带 `N`/`S` 后缀           |
| 经度 | 数字       | -180 ~ 180，可带 `E`/`W` 后缀         |
| 时区 | 数字       | -12 ~ 14，缺省按 `+8`（中国标准时间） |

紧凑写法（位置即「日期 纬度 经度 时区」）：

```text
2025-06-21 39.9 116.4 +8
```

- 纬度越界（>90 / <-90）、经度越界（>180 / <-180）、非法日期（如 2 月 30 日）都会中文报错
- 空输入返回空串；输入超过 200,000 字符报错

## 输出

```text
日期：2025-06-21
位置：39.90°N  116.40°E  时区：UTC+8
太阳赤纬：+23.45°
均时差 EoT：-1.3 分钟
日出：04:46
正午：12:16
日落：19:46
昼长：15小时01分
```

极区结果会直接标注：

```text
现象：极昼（太阳整日不落地平线）
现象：极夜（太阳整日不升起）
```

## 算法与精度

- **太阳赤纬 δ**：NOAA 傅里叶展开，分数年 γ = 2π/365·(年积日−1)
- **均时差 EoT**：229.18·(0.000075 + 0.001868·cosγ − 0.032077·sinγ − 0.014615·cos2γ − 0.040849·sin2γ)
- **日出时角 H**：cosH = [cos(90.833°) − sinφ·sinδ] / (cosφ·cosδ)，其中 90.833° 含大气折射（34′）与太阳视半径（16′）
- **正午**：UTC 分钟 = 720 − 4·经度 − EoT；日出 = 正午 − 4H，日落 = 正午 + 4H，再加时区偏移

参考：[NOAA Solar Calculator](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)。

**精度限制**：

- 中纬度地区日出 / 日落误差通常 **< 1 分钟**；与权威值（如北京 2025-06-21 日出约 04:45）对照在 ±2 分钟内
- 高纬度、极圈附近以及闰年边界，误差可能到 ±1~2 分钟
- 这是 NOAA 的**简化（一阶）模型**，未做章动、光行差、大气折射的逐项修正；若需航海级精度（秒级）请使用完整天文年历
- 时区按**固定偏移**处理，不自动应用夏令时（DST）；如纽约夏季请手动填 `-4`（EDT），冬季填 `-5`（EST）
