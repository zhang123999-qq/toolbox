# Emoji 查询

搜索、复制 Emoji。

## 用途

按中英文关键词搜 Emoji，点一下就复制。内置高频词库按分类组织，不联网、不需要接口。

## 输入

| 字段   | 类型   | 约束          |
| ------ | ------ | ------------- |
| `text` | string | 最大 100 字符 |

搜索关键词（中文名、英文名、或 Emoji 本身）；留空则列出该分类全部。

## 输出

| 字段   | 类型   | 说明                                                                 |
| ------ | ------ | -------------------------------------------------------------------- |
| `text` | string | 可点击的 Emoji 网格；复制 / 下载拿到的是「每行一个 Emoji」的纯文本。 |

## 选项

| 选项       | 取值                                                                                               | 默认  | 说明           |
| ---------- | -------------------------------------------------------------------------------------------------- | ----- | -------------- |
| `category` | `all` / `face` / `hand` / `nature` / `food` / `activity` / `travel` / `object` / `symbol` / `flag` | `all` | 只显示某一分类 |

## 限制

- **词库是手工整理的高频子集**（约 60 个），不是完整的 Unicode Emoji 全表；找不到的 Emoji 请用系统输入法的表情面板
- 关键词匹配是子串匹配，不做拼音、不做同义词扩展
- 单个「复制」按钮复制的是当前筛选结果的**全部** Emoji；单个字符请用网格里的按钮
- 剪贴板写入依赖浏览器的异步剪贴板 API，在非 HTTPS / 非安全上下文下会失败（此时只把字符显示出来，需手动选中）
- 国旗类 Emoji 在部分 Windows 字体下会显示成两个字母而非旗帜

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
笑
```

输出：

```text
😀😂🤣😊
```
