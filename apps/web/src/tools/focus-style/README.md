# 焦点样式生成

参数化生成 `:focus-visible` 焦点样式 CSS：自定义焦点颜色、描边宽度/偏移/圆角/样式，实时预览键盘聚焦效果，并用 WCAG 公式校验焦点色与背景色的对比度（非文本要求 ≥ 3:1）。

## 用途

- 为网站统一设计高可见度的键盘焦点样式
- 检查焦点颜色在背景上的对比度是否达标

## 输入

| 字段   | 类型   | 约束                 |
| ------ | ------ | -------------------- |
| `text` | string | 未使用（参数在页面表单中） |

在页面内设置：焦点颜色、背景颜色、描边宽度（1–8px）、描边偏移（0–16px）、圆角（0–32px）、描边样式。

## 说明

- 纯前端生成与预览，无网络请求，零依赖（对比度公式手写实现）。
- 生成的 CSS 包含 `prefers-reduced-motion` 下关闭过渡，避免给偏好减少动画的用户造成困扰。
- 预览区按 Tab 可聚焦示例控件查看实际效果；复制/下载得到可直接使用的 CSS。
