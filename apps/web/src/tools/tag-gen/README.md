# 标签生成

自动提取标签。

## 用途

从一段正文里提炼标签：默认走本地 n-gram 频次抽取（不联网、不虚构），需要更贴合语义的标签时切成 ai，调你自备的模型接口。

## 输入

| 字段      | 类型   | 约束                                   |
| --------- | ------ | -------------------------------------- |
| `text`    | string | 最大 20,000 字符                       |
| `apiBase` | string | 接口地址（Base URL），最大 20,000 字符 |
| `apiKey`  | string | API Key，最大 20,000 字符              |
| `model`   | string | 模型名，最大 20,000 字符               |

正文 + 接口信息（ai 模式必填：接口地址、API Key、模型名）。本地模式不需要接口信息。

## 输出

| 字段   | 类型   | 说明                                                          |
| ------ | ------ | ------------------------------------------------------------- |
| `text` | string | 每行一个标签；本地模式按「出现次数 × 长度」排序，长候选优先。 |

## 选项

| 选项    | 取值              | 默认    | 说明                                  |
| ------- | ----------------- | ------- | ------------------------------------- |
| `mode`  | `local` / `ai`    | `local` | `local` 本地频次抽取；`ai` 调自备接口 |
| `limit` | `5` / `10` / `15` | `5`     | 最多返回几个标签                      |

## 限制

- **本地模式没有中文分词**：汉字块按 2–4 字滑窗切候选，可能切出「态站点」这类不完整词，要更准的标签请用 `ai` 模式
- 出现次数只有 1 的短语不会被当成标签，因此短文本常常抽不出东西
- 被更长候选包含的片段会被剔除，避免「静态」与「静态站点」同时出现
- `ai` 模式的输出完全由你接入的模型决定，本工具不做二次过滤
- 输入上限 20,000 字符

## 数据流向

**会向外部接口发送数据。** 本工具需要你自备大模型接口（OpenAI 兼容的 `/chat/completions`）：

- 请求由**浏览器直接**发往你填写的接口地址，**不经本项目任何服务器**
- 发送内容：待处理的正文 + 一段指令（prompt），以及你填的模型名
- 凭据：API Key 放在 `Authorization` 请求头里，只存在于当前页面的输入框中，
  **不写入 localStorage**，也不会随页面分享带走
- 超时 60 秒；返回结构按 OpenAI 的 `choices[0].message.content` 解析

`meta.api = true`。没填接口信息就点运行时，工具会给出缺项提示而不会发请求。

## 示例

输入：

```text
静态站点把构建产物交给 Nginx 托管，静态站点的配置文件也要一起发布。容器镜像与宿主机共享网络，容器镜像的构建复用同一份脚本。
```

输出：

```text
静态站点
容器镜像
构建
```
