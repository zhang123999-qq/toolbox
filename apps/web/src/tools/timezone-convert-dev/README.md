# 时区转换

把某个时区下的日期时间，换算成另一个时区的墙上时间。基于浏览器原生
`Intl.DateTimeFormat`，自动处理夏令时。

## 用途

和海外同事约会议、看 UTC 日志、排跨国部署窗口时，不用心算 + 记夏令时。
输入「北京时间下午两点」，直接得到「纽约几点」。

## 输入

| 字段   | 类型   | 约束                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | `YYYY-MM-DD HH:mm:ss`，最大 200,000 字符 |

该时间按**源时区**解释。

## 选项

| 选项     | 标签     | 默认               | 说明          |
| -------- | -------- | ------------------ | ------------- |
| `fromTz` | 源时区   | `Asia/Shanghai`    | IANA 时区标识 |
| `toTz`   | 目标时区 | `America/New_York` | IANA 时区标识 |

内置 21 个常用时区：北京 / 香港 / 东京 / 首尔 / 新加坡 / 曼谷 / 迪拜 / 孟买 /
伦敦 / 巴黎 / 柏林 / 莫斯科 / 开罗 / UTC / 纽约 / 芝加哥 / 丹佛 / 洛杉矶 /
圣保罗 / 悉尼 / 奥克兰。

## 输出

| 字段   | 类型   | 说明                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 源时区 / 目标时区 / UTC 三行 |

```text
Asia/Shanghai：2026-09-26 14:00:00
America/New_York：2026-09-26 02:00:00
UTC：2026-09-26 06:00:00
```

## 限制

- 只接受 `YYYY-MM-DD[ HH:mm[:ss]]` 格式
- 时区列表为内置常用 21 个，未列出的 IANA 标识不可选
- 夏令时切换边界由浏览器 ICU 数据决定
- 空输入返回空串；非法格式抛中文错误

## 数据流向

**纯本地处理。** `Intl.DateTimeFormat`，不发送网络请求。`meta.api = false`。

## 示例

输入（源时区北京）：

```text
2026-09-26 14:00:00
```

输出（目标纽约，9 月为夏令时 EDT）：

```text
Asia/Shanghai：2026-09-26 14:00:00
America/New_York：2026-09-26 02:00:00
UTC：2026-09-26 06:00:00
```
