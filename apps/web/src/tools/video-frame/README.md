# 视频截图

从本地视频文件的指定时间点抓取一帧画面，导出为 PNG 图片。

## 用途

截取视频封面、提取关键帧、做缩略图。

## 输入

| 字段    | 类型   | 说明                                                           |
| ------- | ------ | -------------------------------------------------------------- |
| `video` | 文件   | 本地视频文件（`<input type=file accept=video/*>`），**不上传** |
| `text`  | string | 左侧文本区仅作备注，不参与处理                                 |

## 输出

| 字段    | 类型   | 说明                                                             |
| ------- | ------ | ---------------------------------------------------------------- |
| `image` | 图片   | 抓取的帧，预览 + 「下载 PNG」按钮                                |
| `text`  | string | 抓帧记录（如「已抓帧：movie_frame_01-30-500.png」），可复制/下载 |

## 选项

| 选项   | 类型 | 默认 | 说明                                                      |
| ------ | ---- | ---- | --------------------------------------------------------- |
| `time` | 数字 | 1    | 抓帧时间点（秒）：可填 `90.5` 或 `1:30.5`，也可拖滑杆定位 |

## 限制

- 视频只在本地浏览器解码，不上传到任何服务器
- 时间点不能超过视频时长
- 导出 PNG 长边超过 1920px 会等比缩放
- 文件名形如 `原名_frame_01-30-500.png`（时间戳用 `-` 连接）
- 部分浏览器对加密/DRM 视频可能抓不到画面

## 示例

加载 2 分钟视频，在时间框填 `1:30.5` 点「抓取该帧」：

```text
已抓取 01:30.500 的画面
下载 PNG（movie_frame_01-30-500.png）
```

## 数据流向

**纯本地处理。** 视频解码、seek、canvas 绘制都在浏览器本地完成，
`meta.api = false`，无需自备 API/Key，不发任何请求。
