# 缩进转换

Tab 与空格互转，增减缩进。

## 用途

统一代码缩进风格：把 Tab 展开成空格或把空格收成 Tab，也可以整体增删一级缩进，用来对齐从别处粘来的代码块。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

多行文本。只处理**行首**的 Tab / 空格，行中间的空白不动。

## 输出

| 字段   | 类型   | 说明                                   |
| ------ | ------ | -------------------------------------- |
| `text` | string | 转换后的文本，行数与行尾内容保持不变。 |

## 选项

| 选项    | 取值                                                                                          | 默认        | 说明                     |
| ------- | --------------------------------------------------------------------------------------------- | ----------- | ------------------------ |
| `mode`  | `to-spaces`（Tab→空格） / `to-tabs`（空格→Tab） / `increase`（加一级） / `decrease`（减一级） | `to-spaces` | 转换方向                 |
| `width` | `2` / `4` / `8`                                                                               | `4`         | 一个缩进单位等于几个空格 |

## 限制

- 只处理行首缩进，行中间的 Tab / 空格一律不动
- 空格转 Tab 时不足一组的余下空格会保留，不会四舍五入
- 减少缩进优先去掉一个 Tab，没有 Tab 时最多去掉 width 个空格；已经没有缩进的行不动
- 不识别语言与语法结构，不会按代码块自动缩进（需要格式化请用专门工具）
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
	if (a) {
		return
	}
```

输出：

```text
	if (a) {
		return
	}
```
