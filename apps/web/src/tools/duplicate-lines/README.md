# 重复行检测

找出重复行并统计。

## 用途

找出文本里重复出现的行并统计次数：可以直接看报告，也可以输出去重后的行、或只把重复过的行挑出来。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

每行一条的文本（日志、名单、标签列表都常用）。

## 输出

| 字段   | 类型   | 说明                                                                   |
| ------ | ------ | ---------------------------------------------------------------------- |
| `text` | string | `report` 给「次数<TAB>行」的统计表；`unique` 与 `dupes` 直接给行文本。 |

## 选项

| 选项         | 取值                          | 默认     | 说明                             |
| ------------ | ----------------------------- | -------- | -------------------------------- |
| `mode`       | `report` / `unique` / `dupes` | `report` | 统计报告 / 去重保序 / 只留重复行 |
| `trim`       | 布尔                          | `true`   | 比较前去掉每行首尾空白           |
| `ignoreCase` | 布尔                          | `false`  | 比较时忽略大小写                 |

## 限制

- 按整行比较，不做分词也不做模糊匹配：`北京` 与 `北京市` 是两行
- `trim` 只影响比较用的键，**输出保留原始行**（含首尾空白），所以 `unique` 模式留下的可能是带空格的那一行
- `report` 里的「共 N 行」包含首次出现，因此「3 次」意味着原文里有 3 行、多出 2 行冗余
- 行尾是 `\r\n` 还是 `\n` 不影响判定（换行符在切分时已被去掉），但 `\r` 在 `trim` 关闭时会留在行尾
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
北京
上海
北京
广州
上海
北京
```

输出：

```text
重复行 2 种，共 5 行（含首次出现）
3 次	北京
2 次	上海
```
