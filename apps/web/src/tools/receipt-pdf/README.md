# 收据 PDF 生成

填写商户、日期、支付方式与明细，生成简洁收据 PDF：居中标题、等宽明细表、
居中加粗总计，纯本地生成后下载。

## 用途

小店、摊主、个人收款后快速出具收据，不经过任何服务器。

## 输入

| 字段       | 类型   | 约束              | 说明                                     |
| ---------- | ------ | ----------------- | ---------------------------------------- |
| `text`     | string | 最大 100,000 字符 | 明细：每行「品名,数量,单价」（英文逗号） |
| `merchant` | string | 最大 200 字符     | 商户                                     |
| `date`     | string | 最大 100 字符     | 日期                                     |
| `payment`  | string | 最大 100 字符     | 支付方式                                 |

明细行校验：列数必须为 3；数量必须是大于 0 的数字；单价必须是不小于 0 的数字；
非法时报错并带出行号。商户、日期、支付方式均可选，留空则对应行省略。

## 输出

| 字段   | 类型       | 说明                          |
| ------ | ---------- | ----------------------------- |
| `file` | PDF 二进制 | A4 纵向 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「复制/下载」按钮操作的是收据纯文本版（`.txt`）。

## 选项

无。

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，任何字段含中文时会直接报错，
  不会生成乱码 PDF。
- 金额保留两位小数；品名超过 34 字符截断并加 `...`。
- 明细极多时会跨页，第二页不重复表头。
- 文件全程在浏览器内存里生成，不发任何请求。

## 数据流向

**纯本地处理。** 输入与生成的 PDF 都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
Coffee,2,4.5
Sandwich,1,12
```

总计 21.00；输出区显示如 `已生成 PDF：1 页，2.3 KB`。
