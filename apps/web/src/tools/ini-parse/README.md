# INI 解析

INI 与 JSON 双向互转，支持小节、注释与引号值。

## 用途

处理 Windows `.ini`、PHP `php.ini`、Git config 这类配置：转 JSON 便于程序读取，
改完再转回 INI。语法错误时给出带行列位置的中文提示。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 转换后的 JSON / INI；空输入返回空串 |

## 选项

| 选项        | 取值                    | 默认       | 说明                            |
| ----------- | ----------------------- | ---------- | ------------------------------- |
| `direction` | `ini2json` / `json2ini` | `ini2json` | 转换方向                        |
| `indent`    | `2` / `4`               | `2`        | JSON 侧缩进档位（INI 侧不使用） |

## 支持范围

- 小节 `[section]`；**带点号的小节名** `[a.b]` 解析为嵌套对象
- 小节出现之前的键 → 顶层键
- 分隔符：优先 `=`，没有 `=` 时用 `:`（兼容 php.ini 方言）
- 注释：整行 `;` / `#`，以及引号外的行尾注释
- 引号值 `"…"`（支持 `\n` `\t` `\r` `\0` `\\` 转义）与 `'…'`（字面量，`''` 表示一个 `'`）
- 值类型还原：`true` / `false`（忽略大小写）、整数、浮点、科学计数法，其余为字符串

## 限制

- **注释会丢失**：JSON 没有注释语法，INI → JSON 时注释被丢弃
- **值会被类型推断**：`1.0` 变成数字 `1`、`008` 变成 `8`；需要原样保留请用引号包起来
- **不支持跨行值**（INI 没有标准的续行语法，续行会被当成缺分隔符而报错）
- **重复键以后者为准**，不报错
- 不支持 `[section]` 之外的层级语法（如 Git 的 `[remote "origin"]` 会按字面小节名解析）
- JSON → INI 时：**顶层必须是对象**；**`null` 无法表达**（会报错，请先去掉该键）
- JSON → INI 时：标量数组按重复同名键展开；**对象数组无法表达**（会报错）
- JSON → INI 时：含 `;` `#` 或首尾空格的字符串会自动加引号

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（INI）：

```ini
name = 工具库
port = 8080

[server]
host = 127.0.0.1

[server.tls]
enabled = true
```

输出（JSON，`indent = 2`）：

```json
{
  "name": "工具库",
  "port": 8080,
  "server": {
    "host": "127.0.0.1",
    "tls": {
      "enabled": true
    }
  }
}
```
