# 接口限流模拟（#762）

A 级工具：纯前端本地计算，无网络、无第三方 API。

## 功能

- **令牌桶**：按 `capacity`（桶容量）与 `refillPerSec`（补充速率/秒）模拟，
  输出每次请求放行/拒绝与剩余令牌。
- **滑动窗口**：按 `limit`（上限）与 `windowSec`（窗口秒数）模拟，
  输出每次请求放行/拒绝与窗口内计数；被拒绝的请求不占窗口名额。

## 输入（JSON）

```json
{
  "mode": "token-bucket",
  "requests": [0, 0.2, 0.4, 0.6, 1.5, 2.5],
  "capacity": 3,
  "refillPerSec": 1,
  "limit": 5,
  "windowSec": 10
}
```

## 说明

- `requests` 为相对时间戳（秒），按给定顺序模拟。
- 仅用于算法验证与参数调优，不是真实网关限流。
- 所有计算在浏览器本地完成，不发送任何网络请求。
