# GIF 转精灵图（#798）

用浏览器 WebCodecs `ImageDecoder` 逐帧解码 GIF，按指定列数拼成雪碧图并导出 PNG。

## 功能

- **逐帧解码**：读取 GIF 每一帧的尺寸与时长（缺失时长按 100ms 计）
- **网格布局**：单元格取各帧最大宽高，每帧左上角对齐
- **导出 PNG**：一键下载雪碧图

## 浏览器支持

| 浏览器 | 最低版本 |
|--------|----------|
| Chrome / Edge | 94+ |
| Safari | 18.4+ |
| Firefox | 130+ |

不支持的浏览器会给出中文提示。
