# PBKDF2

用 PBKDF2 从口令派生密钥（HMAC-SHA 系列）。

## 用途

把人类可记的**口令**「拉伸」成固定长度的密钥材料，用于口令存储校验、派生 AES 密钥、对接只支持 PBKDF2 的系统。PBKDF2 通过大量迭代把暴力破解成本抬高。

## 输入

| 字段   | 类型   | 约束              | 说明                         |
| ------ | ------ | ----------------- | ---------------------------- |
| `text` | string | 最大 200,000 字符 | 口令                         |
| `salt` | string | 附加输入框        | 盐，按 `encoding` 解析为字节 |

盐走**独立的附加输入框**，**只在浏览器内存里使用**。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 派生密钥的十六进制（默认）或 Base64 编码 |

## 选项

| 选项         | 取值                                | 默认    | 说明                                             |
| ------------ | ----------------------------------- | ------- | ------------------------------------------------ |
| `algorithm`  | SHA-1 / SHA-256 / SHA-384 / SHA-512 | SHA-256 | 伪随机函数（HMAC 的哈希）                        |
| `iterations` | 1000 / 10000 / 100000 / 600000      | 100000  | 迭代次数，越大越安全也越慢                       |
| `length`     | 16 / 32 / 64                        | 32      | 输出字节数（对应 AES-128 / AES-256 / 更长）      |
| `encoding`   | utf8 / hex                          | utf8    | **盐输入框**的编码；hex 便于粘贴随机盐的十六进制 |
| `format`     | hex / base64                        | hex     | 输出编码                                         |

## 迭代次数怎么选（OWASP 2023 建议）

OWASP《Password Storage Cheat Sheet》在 2023 年给出的 PBKDF2 迭代次数下限：

| 哈希    | 建议迭代次数 |
| ------- | ------------ |
| SHA-1   | 1,300,000    |
| SHA-256 | 600,000      |
| SHA-512 | 210,000      |

因此**存储用户口令**时请选 600,000（SHA-256）；本工具的下拉里只有到 600,000 的档位，更高的需求请自行调用 API。

## 限制

- **必须使用随机盐**：盐要每条记录各不相同（推荐 16 字节随机值，用 hex 粘贴）。固定盐会让相同的口令派生相同结果，彩虹表就能一次命中
- **口令存储只应存「盐 + 迭代参数 + 派生结果」**，永远不要存原文
- PBKDF2 是「可并行」的慢哈希，抗 GPU 能力弱于 #99 Scrypt、Argon2；条件允许时优先 Argon2id，其次是 Scrypt
- 依赖浏览器的 WebCrypto（`crypto.subtle.deriveBits`），需要 HTTPS 或 localhost
- 本工具的迭代次数是**明文选项**，便于复现；真实系统里应把参数一起存进数据库
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 口令与盐只在浏览器内存中参与派生，**不发起任何网络请求、不写入 localStorage、不上传服务端**。
派生由浏览器 **WebCrypto** 完成，`meta.api = false`，无需自备 API/Key。

## 示例

输入（口令）：

```text
password
```

盐：

```text
salt
```

输出（SHA-256 / 1000 次 / 32 字节 / hex）：

```text
632c2812e46d4604102ba7618e9d6d7d2f8128f6266b4a03264d2a0460b7dcb3
```
