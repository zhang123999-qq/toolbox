# 注音转换

汉字转注音符号。

## 用途

把汉字转成注音符号（ㄅㄆㄇㄈ），用于华语地区教材、识字卡片与排版。

## 输入

| 字段   | 类型   | 约束             |
| ------ | ------ | ---------------- |
| `text` | string | 最大 20,000 字符 |

中文文本；逐行转换，空行保留。最大 20,000 字符。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 以空格分隔的注音串；每行对应输入的一行。 |

## 选项

| 选项   | 取值                | 默认   | 说明                                           |
| ------ | ------------------- | ------ | ---------------------------------------------- |
| `tone` | symbol / num / none | symbol | 是否标声调（num 与 symbol 效果相同，均标符号） |

## 限制

- 先由 pinyin-pro 取拼音，再按声母/韵母表映射为注音，多音字按词组判别
- 轻声统一标在音节末尾（规范写法应标在最前），仅影响显示位置
- 空韵（ㄭ）按习惯省略；生僻音节若表中无对应项则原样输出拼音

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具库
```

输出：

```text
工具库
```
