# 音频去静音

上传音频，自动检测并裁掉首尾的静音段（静音阈值 dB 与最小时长可调），导出为 16 位 PCM WAV。

## 与 #541 音频裁剪的区别

- **#541 音频裁剪**：按你手动填写的**起止时间**剪辑任意片段，静音不静音它不管。
- **本工具（#577）**：你不需要指定时间，工具自动找出开头和结尾的静音并裁掉；**只处理首尾**，中间的静音段不受影响。

## 用途

去掉录音开头结尾的空白：播客、配音、会议录音里常见的"按下录音键后的几秒沉默"和"结尾的拖尾"，一键清理。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

文件用浏览器 Web Audio API 本地解码（支持 wav / mp3 / ogg / m4a 等浏览器可解格式）。

## 输出

| 字段    | 类型   | 说明                                                   |
| ------- | ------ | ------------------------------------------------------ |
| `audio` | WAV    | 去静音后的音频，可试听并下载                           |
| `text`  | string | 处理报告：检测到的首尾静音 / 实际裁掉的时长 / 输出时长 |

## 选项

| 选项            | 类型 | 默认 | 说明                                               |
| --------------- | ---- | ---- | -------------------------------------------------- |
| `thresholdDb`   | 数字 | -40  | 静音阈值（dBFS），-90～-10；帧能量低于此值判为静音 |
| `minSilenceSec` | 数字 | 0.3  | 最小时长（秒），0.05～10；静音段短于此时予以保留   |

检测以 10ms 为一帧计算 RMS 能量；只有**连续**静音帧构成的段才会被统计，段时长达到最小时长才裁掉。

## 限制

- 只处理首尾静音，音频中间的静音段不会被裁
- 整段音频都是静音时会中文提示（没有可保留的内容）
- 输出固定为 16 位 PCM WAV
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（1 秒静音 + 2 秒 440Hz 正弦 + 1 秒静音），默认阈值 -40 dB、最小时长 0.3 秒：

```text
输入：示例-带首尾静音的正弦波.wav
原时长：4.00 秒　采样率：44100 Hz　声道：1
静音阈值：-40 dB　最小时长：0.30 秒
裁掉首部静音：1.00 秒
裁掉尾部静音：1.00 秒
输出时长：2.00 秒
```

## 数据流向

**纯本地处理。** 解码与静音检测都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
