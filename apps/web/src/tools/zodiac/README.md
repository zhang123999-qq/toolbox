# 星座查询

输入一个公历月日，查出对应的太阳星座（回归黄道坐标），给出中英文星座名、日期区间、四象元素与一句性格特质。

## 输入

| 字段   | 类型   | 约束                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 一段「月/日」文本，最大 200,000 字符 |

可接受 `3/21`、`3-21`、`3.21`、`2025-03-21`、`3月21日` 等写法；**空输入不产出任何内容**。

## 输出

```text
白羊座（Aries）
日期区间：3/21 – 4/19
四象元素：火（Fire）
性格特质：热情、冲动、行动力强
```

## 限制

- 按通行的**回归黄道**（tropical zodiac）日期划分，不同占星体系的交界日可能相差 1 天
- 只做太阳星座，不含上升/月亮星座与星盘计算
- 不校验年份是否闰年（星座与月日有关，与年无关）

## 数据流向

**纯本地处理。** 一张 12 行的静态查表，无任何网络请求。`meta.api = false`。
