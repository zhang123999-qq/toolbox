# CSS 转义

CSS 标识符与字符串转义及还原，按十六进制码点消歧。

## 用途

把任意文本转成能安全写进 CSS 选择器、`content` 或类名的形式——空格、点号、
中文、emoji 这些字符直接写会破坏语法；反向则用于把压缩过的样式表里
`\4e2d\6587` 这类转义还原成可读文字。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                                   |
| ------ | ------ | -------------------------------------- |
| `text` | string | 转义后为 `\XXXX ` 串；还原后为原始文本 |

## 选项

| 选项        | 取值              | 默认   | 说明       |
| ----------- | ----------------- | ------ | ---------- |
| `direction` | escape / unescape | escape | 转义或还原 |

## 限制

- 转义规则：`A-Z a-z 0-9 _ -` 原样保留，其余字符一律写成 `\` + 小写十六进制码点
  - **一个尾随空格**。尾随空格是规范要求的消歧分隔符，本身不是正文内容
- 非 ASCII（中文、emoji）同样按码点转义，因此输出可安全放进只认 ASCII 的环境；
  这与浏览器原生 `CSS.escape()` 不同（后者保留非 ASCII 字符）
- NUL（U+0000）不能出现在样式表里，按规范替换成 U+FFFD
- 还原时同时接受「有无尾随空格」两种写法；码点为 0 或超过 0x10FFFF 时回落为
  U+FFFD；反斜杠后紧跟换行按**续行**处理（两者都不产生字符）
- 孤立的反斜杠（输入以 `\` 结尾）无法构成转义，会明确报错

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
a b
```

输出（escape）：

```text
a\20 b
```
