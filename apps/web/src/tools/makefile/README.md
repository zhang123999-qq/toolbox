# Makefile 生成

配置目标名、依赖与配方命令，生成一个带 `.PHONY` 声明与变量区的 `Makefile`。

## 用途

手写 Makefile 时最容易踩两个坑：配方行必须以 **Tab**（不是空格）开头，以及没有声明
`.PHONY` 时若恰好存在同名文件会导致目标不执行。本工具按正确缩进与 `.PHONY` 规则生成，
复制即可用。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作触发用：留空不产出，点「示例」或任意输入即按当前选项生成。

## 选项

| 选项 key     | 界面   | 说明                                |
| ------------ | ------ | ----------------------------------- |
| `targetName` | 目标名 | phony 目标名，默认 `build`          |
| `deps`       | 依赖   | 空格分隔的依赖，可空                |
| `command`    | 命令   | 配方命令，多行时每行各起一条 recipe |

## 输出

```makefile
# 由工具生成的 Makefile
# 变量区：可按需覆盖（make build APP=foo）
APP := myapp

.PHONY: build
build:
	@echo done
```

## 限制

- 只生成单个 phony 目标；多目标需自行复制扩展
- 配方行内的 `@` 前缀（回显抑制）由你在「命令」里自行决定
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 纯字符串拼接，无网络请求。`meta.api = false`。

## 示例

输入（触发用）：`generate`

输出（默认目标 `build`，命令 `@echo done`）：

```makefile
# 由工具生成的 Makefile
# 变量区：可按需覆盖（make build APP=foo）
APP := myapp

.PHONY: build
build:
	@echo done
```
