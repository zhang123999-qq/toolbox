# 随机盐

生成密码学安全的随机盐（盐值），支持 hex / Base64 / Base64URL。

## 用途

「盐」是加在口令或数据前、参与哈希运算的一段随机字节，用来让相同输入产生不同结果，从而抵御彩虹表与批量撞库。
常见用法：给每个用户口令配一个独立盐再存入 bcrypt/PBKDF2/Argon2；给签名或令牌加盐增加随机性；给测试数据造随机 ID。

本工具产出的盐来自浏览器的 CSPRNG（`crypto.getRandomValues`），**不是** `Math.random` 那种可预测的伪随机。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作**触发**用：内容不参与计算。输入任意内容（或点「示例」填入占位文本）后点「运行」即生成一条盐。
**输入为空串时返回空串且不取随机数**——否则 SSG 预渲染会在构建期烘焙出随机内容，导致构建不可复现、水合结果不一致。

## 输出

| 字段   | 类型   | 说明                                           |
| ------ | ------ | ---------------------------------------------- |
| `text` | string | 指定字节数的盐，按所选编码输出；每次运行都不同 |

| 长度 | hex    | base64 | base64url |
| ---- | ------ | ------ | --------- |
| 16 B | 32 位  | 24 位  | 22 位     |
| 32 B | 64 位  | 44 位  | 43 位     |
| 64 B | 128 位 | 88 位  | 86 位     |

## 选项

| 选项     | 取值                     | 默认 | 说明                                                 |
| -------- | ------------------------ | ---- | ---------------------------------------------------- |
| `length` | 16 / 32 / 64             | `16` | 盐的字节数（16 / 32 / 64 字节 = 128 / 256 / 512 位） |
| `format` | hex / base64 / base64url | hex  | 输出编码；base64url 用 `-_` 替代 `+/` 并去掉 `=`     |

## 限制

- **每次运行结果都不同**，这是刻意行为；请及时复制，本工具不保存历史。
- 盐**不是密钥**：它不需要保密，但必须唯一且随机；需要保密的是密钥。
- 本工具只生成盐，不负责「加盐哈希」——拿到盐后请到对应的哈希 / KDF 工具里使用。
- `16 字节（128 位）` 是常见下限；新系统建议 16 字节起步，需要更高余量可选 32 / 64 字节。
- 依赖浏览器的 `crypto.getRandomValues`，需要 HTTPS 或 localhost；不安全上下文会直接报错，而不是退回弱随机。

## 数据流向

**纯本地处理。** 随机字节由浏览器 CSPRNG 在当前页面内生成，输出只在输入框与输出框之间流转，不写入 localStorage、不发送、不上传，无任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（仅作触发）：

```text
生成随机盐
```

输出（16 字节 / hex，每次不同）：

```text
9f2c41b7a83c0d5e6a4f8b1c2d3e4f50
```
