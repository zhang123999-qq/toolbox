# 温度换算

输入温度数值并选择源/目标单位，把摄氏度（C）、华氏度（F）、开尔文（K）互相转换；低于绝对零度的输入会被拒绝。

## 用途

- 烹饪 / 烤箱温度的中美单位对照
- 天气 / 气候数据跨单位换算
- 科学计算中换算热力学温度（开尔文）

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 待换算的温度数值，最大 200,000 字符 |

## 输出

```text
100 C = 212 F
```

## 选项

| 选项   | 类型   | 说明                |
| ------ | ------ | ------------------- |
| `from` | select | 源单位：`C` `F` `K` |
| `to`   | select | 目标单位（同上）    |

## 算法

温度是偏移量换算，不能走换算因子表，先经摄氏度中转：

- C → F：`F = C × 9/5 + 32`
- F → C：`C = (F − 32) × 5/9`
- C → K：`K = C + 273.15`
- K → C：`C = K − 273.15`
- 数字格式化：`Number(n.toPrecision(12)).toString()`（12 位有效数字，去浮点尾巴）

## 边界

- 换算**前**对输入做绝对零度校验：C < −273.15 / F < −459.67 / K < 0 → 中文报错「低于绝对零度，物理上不可能」
- 空输入 → 输出空串
- 非法数字 → 中文报错「请输入有效的数字」
- 非法单位 id → 中文报错「未知单位」
- 输入 > 200,000 字符 → 报错

## 示例

输入 `100`，从 `C` 到 `F`：

```text
100 C = 212 F
```

## English

A temperature converter between °C, °F and K, with absolute-zero validation (rejects inputs below −273.15 °C / −459.67 °F / 0 K). Input: `text` (the numeric value). Output: e.g. `100 C = 212 F`.
