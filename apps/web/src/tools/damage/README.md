# 伤害计算（#804）

攻防暴击伤害公式计算。

## 参数

```json
{"atk":100,"def":50,"critRate":0.2,"critMult":2,"variance":0.1}
```

| 参数 | 说明 |
|------|------|
| atk | 攻击力（> 0） |
| def | 防御力（≥ 0） |
| critRate | 暴击率，[0, 1] |
| critMult | 暴击倍率（≥ 1） |
| variance | 可选，伤害浮动 [0, 1)，默认 0 |

## 公式

1. 基础值 = `atk² / (atk + def)`（防御减伤）
2. 暴击时 × `critMult`
3. 浮动：最终 × `(1 ± variance)`
4. 取整，且至少为 1
