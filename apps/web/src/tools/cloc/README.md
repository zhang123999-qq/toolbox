# 代码行数统计

统计源代码的总行数 / 代码行 / 注释行 / 空行，并给出注释占比。

## 用途

写项目 README 时想写「约 xxx 行代码」，或快速估一段代码的注释密度。

## 输入

| 字段   | 类型   | 约束                      |
| ------ | ------ | ------------------------- |
| `text` | string | 源代码，最大 200,000 字符 |

## 选项

| 选项 key   | 界面 | 说明                                                                  |
| ---------- | ---- | --------------------------------------------------------------------- |
| `language` | 语言 | `c-style`（`//` 与 `/* */`）/ `python`（`#`）/ `shell`（`#` 与 `--`） |

## 输出

```text
代码行数统计：
  总行数：N
  代码行：N
  注释行：N
  空行：N
  注释占比：N.N%
```

## 限制

- 按行粗分：行内尾注释（`const a = 1 // 说明`）算代码行
- c-style 块注释跨行时整段算注释；字符串里出现的 `/*` 会被误判
- 不做词法分析，结果仅供参考

## 数据流向

**纯本地处理。** 无网络请求。`meta.api = false`。
