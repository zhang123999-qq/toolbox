# 文本 Diff

两段文本差异对比，行级/字符级。

## 用途

对比两段文本的差异：改稿前后、配置变更、代码改动都用它，行级看整段增删，字符级看一行里改了哪几个字。

## 输入

| 字段    | 类型   | 约束                        |
| ------- | ------ | --------------------------- |
| `text`  | string | 最大 100,000 字符           |
| `textB` | string | 新版文本，最大 100,000 字符 |

两个输入框：上面是原文，下面是新版。二者是平级内容，故用两个输入框而不是在正文里加分隔线。

## 输出

| 字段   | 类型   | 说明                                                     |
| ------ | ------ | -------------------------------------------------------- |
| `text` | string | 带标记的差异文本：`+` 新增、`-` 删除、行首空格表示未变。 |

## 选项

| 选项   | 取值                              | 默认   | 说明     |
| ------ | --------------------------------- | ------ | -------- |
| `mode` | `line`（行级） / `char`（字符级） | `line` | 对比粒度 |

## 限制

- 输出是带 `+` / `-` 前缀的纯文本，**不是并排双栏视图**，也不是可直接 `git apply` 的补丁
- 行级对比用 jsdiff 的 diffLines，按整行增删，不做行内高亮；需要行内细节请切字符级
- 字符级对比在长文本上较慢，建议先粗筛范围再切
- 不提供「忽略空白」「忽略大小写」「忽略行序」等选项，需要请先自行预处理两段文本
- 两边各限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
第一行
第二行
第三行
```

新版文本：

```text
第一行
第二行改了
第三行
```

输出：

```text
第一行
第二行
第三行
```
