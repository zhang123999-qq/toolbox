# Slug 生成

标题转 URL 友好 slug，支持中文拼音。

## 用途

把文章标题、产品名、文件名转成可直接放进 URL 的 slug：小写、连字符、无空格无标点，中文标题自动转拼音。

## 输入

| 字段   | 类型   | 约束            |
| ------ | ------ | --------------- |
| `text` | string | 最大 1,000 字符 |

一行标题；多个标题请逐条处理（本工具按单条标题处理）。

## 输出

| 字段   | 类型   | 说明        |
| ------ | ------ | ----------- |
| `text` | string | 一行 slug。 |

## 选项

| 选项        | 取值                                                         | 默认     | 说明         |
| ----------- | ------------------------------------------------------------ | -------- | ------------ |
| `chinese`   | `pinyin`（转拼音） / `keep`（保留汉字） / `drop`（丢弃汉字） | `pinyin` | 中文处理方式 |
| `separator` | `dash`（-） / `underscore`（_）                              | `dash`   | 分隔符       |
| `lowercase` | 勾选 / 取消                                                  | 勾选     | 是否转小写   |

## 限制

- 拼音用 pinyin-pro 的常用读音，未做多音字上下文消歧（如「重」取常用音）
- `chinese=keep` 产出的 slug 含非 ASCII 字符，浏览器会做百分号编码，放进 URL 前请确认后端能处理
- 不做停用词剔除与长度截断，需要短 slug 请自行删词
- 不做唯一性检查，同标题会得到同 slug
- 输入上限 1,000 字符（标题场景足够）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
Hello World！中文标题 2026
```

输出：

```text
Hello World！中文标题 2026
```
