# SHA-256 哈希

计算文本的 SHA-256 / SHA-384 / SHA-512 摘要。

## 用途

把任意文本压成定长摘要（SHA-256 为 256 位 / 32 字节），用于校验文件或内容是否被改动、比对两段内容是否一致、生成去重键。
支持三种 SHA-2 变体：摘要越长、抗碰撞余量越大。
`SHA-256("abc") = ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

任意文本（中英混排、emoji 均可），按 UTF-8 编码参与计算。

## 输出

| 字段   | 类型   | 说明                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 十六进制摘要；选 Base64 时为其编码值 |

## 选项

| 选项        | 取值                        | 默认      | 说明                                         |
| ----------- | --------------------------- | --------- | -------------------------------------------- |
| `algorithm` | SHA-256 / SHA-384 / SHA-512 | `SHA-256` | 摘要算法（hex 输出长度依次为 64 / 96 / 128） |
| `format`    | hex / base64                | hex       | 输出格式                                     |

## 限制

- **不是加密**：哈希不可逆，不能用来「解密」；要加解密请用文本加密工具。
- **不做加盐**：校验用可以，存口令不行——明文口令的 SHA-256 能被彩虹表反查；存口令请用带盐的 KDF。
- 依赖浏览器的 WebCrypto，需要 HTTPS 或 localhost；不安全上下文会直接报错。
- WebCrypto 只提供 SHA 家族，没有 MD5 / CRC32；要 SHA-3 请用 #120，要 BLAKE2 请用 #122。
- 输入上限 200,000 字符。

## 数据流向

**纯本地处理。** 摘要由浏览器 WebCrypto 在当前页面内计算，文本不写入 localStorage、不发送、不上传，无任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
abc
```

输出（SHA-256 / hex）：

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
