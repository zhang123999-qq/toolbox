# 功率换算

输入数值并选择源单位与目标单位，即时得到功率换算结果。

## 用途

- 瓦特 / 毫瓦 / 千瓦 / 兆瓦互转
- 英制马力 hp 与公制马力 PS 换算
- 英热单位/小时 BTU/h、千卡/小时、英尺磅/秒、尔格/秒换算

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待换算的数值，最大 200,000 字符 |

## 输出

单行文本：`输入值 源单位 = 结果 目标单位`

```text
1 hp = 0.745699872 kW
```

## 选项

| 字段   | 类型   | 说明     | 可选值                                               |
| ------ | ------ | -------- | ---------------------------------------------------- |
| `from` | select | 源单位   | W、mW、kW、MW、hp、PS、BTU/h、erg/s、kcal/h、ft·lb/s |
| `to`   | select | 目标单位 | 同左                                                 |

## 算法

- 以**瓦特（W）**为基准：`结果 = 数值 × from.factor / to.factor`
- 输出用 `Number(n.toPrecision(12)).toString()` 格式化，去浮点噪声、去尾零
- hp 为英制马力（745.699872 W），PS 为公制马力（735.49875 W）

## 边界

- 空输入 → 输出为空（不报错）
- 非数字输入 → 中文报错「请输入有效的数字」
- 未知单位 id → 中文报错「未知单位」
- 输入 > 200,000 字符 → 报错

## 示例

输入数值：`1`，从 `hp` 到 `kW`

输出：`1 hp = 0.745699872 kW`

## English

Convert between power units (W, kW, MW, hp, PS, BTU/h and more).

- Input: a numeric string.
- Output: one line, e.g. `1 hp = 0.745699872 kW`.
- Options: `from` / `to` selects over W, mW, kW, MW, hp, PS, BTU/h, erg/s, kcal/h, ft·lb/s.
