# PDF 加超链接

选择 PDF 文件，填写链接显示文字、目标网址与页码（从 1 开始），
在该页面左上角插入蓝色带下划线的可点击链接文字，生成新 PDF 下载。纯本地处理。

## 用途

给 PDF 加官网链接、参考文献跳转、目录外链。

## 输入

| 字段   | 类型   | 约束           | 说明                        |
| ------ | ------ | -------------- | --------------------------- |
| `file` | File   | ≤ 100 MiB      | 输出区文件选择框上传的 PDF  |
| `text` | string | 最大 500 字符  | 链接显示文字                |
| `url`  | string | 最大 2000 字符 | 目标网址，必须 http(s) 开头 |
| `page` | string | 正整数         | 页码（从 1 开始）           |

文件、文字、网址必填；页码必须在 PDF 实际页数范围内。
下载文件名为原文件名加 `-link` 后缀（如 `demo-link.pdf`）。

## 输出

| 字段   | 类型       | 说明                                 |
| ------ | ---------- | ------------------------------------ |
| `file` | PDF 二进制 | 插入链接后的新 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「复制/下载」按钮操作的是「文字 + 网址」文本（`.txt`）。

## 选项

无。

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，链接文字或网址含中文时会直接报错，
  不会生成乱码 PDF。
- 链接文字固定插在页面左上角（距左/上边缘各 72pt），12pt 蓝色 Helvetica 带下划线。
- 每次只加一个链接；多次添加请重复操作。
- 文件全程在浏览器内存里处理，不发任何请求。

## 数据流向

**纯本地处理。** PDF 文件与生成结果都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

2 页 PDF，第 1 页插入文字 `Visit our website` 指向 `https://example.com` →
输出区显示如 `已生成 PDF：2 页，3.4 KB`，下载 `demo-link.pdf`。
