# JSONPath

用 **JSONPath 表达式**从 JSON 里取节点，可选输出「取值」或「路径 = 取值」。

## 用途

大 JSON 里找某个深层字段：`$.store.book[*].title` 一次把所有书名捞出来；
`$..price` 不管埋了几层都能找到所有 `price`。比肉眼翻、比临时写脚本快。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                     |
| ------ | ------ | ------------------------ |
| `text` | string | 命中结果；空输入返回空串 |

- `mode = value`：JSON 数组（缩进两格），没有命中输出 `无匹配结果`
- `mode = path`：每行一条 `$.path.to.node = 取值`

## 选项

| 选项      | 取值              | 默认                    | 说明                     |
| --------- | ----------------- | ----------------------- | ------------------------ |
| `pattern` | string            | `$.store.book[*].title` | JSONPath 表达式          |
| `mode`    | `value` \| `path` | `value`                 | 输出取值 / 输出路径+取值 |

## 支持的语法子集

| 语法           | 含义             | 示例                      |
| -------------- | ---------------- | ------------------------- |
| `$`            | 根节点           | `$`                       |
| `.name`        | 子节点           | `$.store.book`            |
| `['name']`     | 子节点（引号式） | `$['store']['book']`      |
| `[0]` / `[-1]` | 下标 / 倒数第 n  | `$.book[0]`、`$.book[-1]` |
| `[0,1]`        | 下标并集         | `$.book[0,1]`             |
| `['a','b']`    | 属性名并集       | `$['title','price']`      |
| `[*]`          | 通配本级成员     | `$.book[*].title`         |
| `..name`       | 递归查找同名节点 | `$..price`                |
| `..*`          | 自身与所有后代   | `$..*`                    |

## 限制

- **规划表原定依赖 `jsonpath-plus`，本项目禁止新增 npm 依赖**，故改为自研子集实现
- **不支持筛选表达式 `[?(...)]`**（如 `$..book[?(@.price < 10)]`）——遇到会抛错说明
- **不支持切片 `[start:end:step]`**、`$..*` 之外的脚本表达式（如 `$.length()`）
- 子串读取顺序按文档顺序；`[*]` 在深层大结构上可能命中极多，超过 100,000 条会抛错
- 命中结果始终是数组形态（即使只命中一条），与 jsonpath-plus 的默认行为一致
- 输入上限 1,000,000 字符，嵌套超过 2,000 层抛错

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```json
{
  "store": {
    "book": [
      { "title": "JSON 入门", "price": 8.95 },
      { "title": "工具箱笔记", "price": 12.99 }
    ]
  }
}
```

表达式 `$.store.book[*].title`，`mode = value`：

```json
["JSON 入门", "工具箱笔记"]
```

表达式 `$..price`，`mode = path`：

```
$.store.book[0].price = 8.95
$.store.book[1].price = 12.99
```
