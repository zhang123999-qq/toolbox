# 链接检查

提取页面中的全部链接（去重、转绝对地址、站内 / 站外 / 跳过分类），
逐个发送 HEAD 请求检测存活状态（405/501 时自动回退 GET），并发 5 个，
输出正常 / 重定向 / 死链 / 超时 / 错误 / 跳过统计与明细。

## 输入

| 字段      | 类型   | 约束                                         |
| --------- | ------ | -------------------------------------------- |
| `text`    | string | 抓取模式下为页面 URL；粘贴模式下为 HTML 源码 |
| `baseUrl` | string | 粘贴HTML 模式的基准 URL（用于解析相对链接）  |

## 选项

| 选项     | 取值                    |
| -------- | ----------------------- |
| 输入模式 | `抓取页面` / `粘贴HTML` |

## 输出示例

```text
共 4 个链接：正常 2　重定向 0　死链 0　超时 0　错误 0　跳过 2

明细：
  [正常] [站内] https://example.com/about HTTP 200
  [正常] [站外] https://example.com/contact HTTP 200
  [跳过] [跳过] mailto:hi@example.com
  [跳过] [跳过] #top
```

## 浏览器边界说明

- **抓取页面模式**：用浏览器 `fetch` 直接请求目标页面。目标站点须允许跨域
  （返回 CORS 头）或与本站同源；否则浏览器会拦截，工具会如实报错并提示改用粘贴HTML
- **检测阶段**：对跨域链接的 HEAD/GET 同样受 CORS 限制，被拦截的记为「错误」并注明原因，
  不编造成「死链」
- 超时 15 秒；`mailto:` / `tel:` / `javascript:` / 页面内锚点 / 空 href 归为「跳过」不检测

## 限制

- 只检测 HTTP 层可达性，不执行 JS 跳转；需要登录态的页面可能被误判
- 相对链接按基准 URL 解析；基准 URL 必填（粘贴模式）

## 数据流向

**浏览器发起 fetch（D 类）。** 请求直连目标站点，不经过本工具后端。`meta.api = true`
（浏览器直连外部站点）。
