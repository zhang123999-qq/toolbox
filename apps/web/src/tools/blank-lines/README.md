# 空行处理

删除、压缩空行。

## 用途

处理文本里的空行：全部删掉、把连续空行压缩成一行、或只去掉开头结尾的空行。粘贴进代码或排版前最常用的一步。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

一段可能含空行的文本。

## 输出

| 字段   | 类型   | 说明                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 处理后的文本，行分隔符统一成 `\n`。 |

## 选项

| 选项   | 取值                           | 默认     | 说明                           |
| ------ | ------------------------------ | -------- | ------------------------------ |
| `mode` | `remove` / `collapse` / `trim` | `remove` | 删除全部 / 压缩连续 / 只去首尾 |

## 限制

- **只含空格或制表符的行也算空行**，会被一并处理；想保留它们请先把空白换成别的占位符
- 输出的行分隔符统一为 `\n`，原文是 `\r\n` 时换行符会被改写（需要保留请用 #44 换行符转换）
- `collapse` 只压缩**连续**空行，单个空行保持不动
- 不处理行内空白（如行尾多余空格），那是 #45 空白清理的活
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
第一段


第二段

第三段
```

输出：

```text
第一段
第二段
第三段
```
