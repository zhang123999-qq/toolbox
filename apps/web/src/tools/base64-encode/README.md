# Base64 编解码

文本与 Base64 互转，支持 URL-safe 变体。

## 用途

把文本编码成可安全放进 URL、JSON、配置文件或邮件体的 ASCII 字符串，或把收到的 Base64 还原成原文。
常用于调试 JWT / 证书 / 邮件源、构造 data URL、排查接口返回的编码内容。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

编码时是任意文本（中英混排、emoji 均可）；解码时是 Base64 字符串。

## 输出

| 字段   | 类型   | 说明                              |
| ------ | ------ | --------------------------------- |
| `text` | string | 编码后为 Base64；解码后为原始文本 |

## 选项

| 选项        | 取值               | 默认     | 说明                                            |
| ----------- | ------------------ | -------- | ----------------------------------------------- |
| `direction` | encode / decode    | encode   | 编码或解码                                      |
| `mode`      | standard / urlsafe | standard | urlsafe 用 `-_` 替代 `+/` 并省略结尾的 `=` 填充 |

## 限制

- 本工具处理**文本**。文件转 Base64 需要文件输入能力，模板尚未支持（见 `.agent/reports/` 中的说明）
- 解码要求结果必须是合法 UTF-8；二进制内容（如加密后的密文）无法还原为文本，会明确报错而不是输出乱码
- 解码忽略输入中的空白与换行，并自动补齐缺失的 `=` 填充，因此能直接粘贴证书/邮件里折行的 Base64

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具库 Toolbox
```

输出（standard / encode）：

```text
5bel5YW35bqTIFRvb2xib3g=
```
