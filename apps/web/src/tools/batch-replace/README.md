# 批量替换

多组查找替换，支持正则。

## 用途

一次性套用多组查找替换：清理术语、批量改变量名、给一批关键词加标记，改一遍规则就能复用。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

上半部分是正文，中间用**独占一行的 `---`** 分隔，下半部分是规则区：每行一条 `查找=>替换`（按第一个 `=>` 切分，替换串里可以再出现 `=>`）。

## 输出

| 字段   | 类型   | 说明                                                         |
| ------ | ------ | ------------------------------------------------------------ |
| `text` | string | 按规则区顺序依次替换后的文本。后一条规则会看到前一条的结果。 |

## 选项

| 选项         | 取值        | 默认 | 说明                              |
| ------------ | ----------- | ---- | --------------------------------- |
| `useRegex`   | 勾选 / 取消 | 取消 | 查找串按正则解析（始终带 g 标志） |
| `ignoreCase` | 勾选 / 取消 | 取消 | 比较时忽略大小写                  |

## 限制

- 规则按书写顺序依次生效，**后一条会看到前一条的结果**，可能连环替换（如需避免请拆成两次）
- 字面量模式下查找串里的 `.`、`*` 等元字符按原样处理；正则模式下则按正则解析
- 正则模式下替换串支持 `$1`、`$&`、`$<name>`，但不支持函数式替换
- 正文里若本身含独占一行的 `---`，会被当成规则区分隔线
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
苹果很好吃，香蕉也很好吃。
---
苹果=>apple
香蕉=>banana
```

输出：

```text
苹果很好吃，香蕉也很好吃。
---
苹果=>apple
香蕉=>banana
```
