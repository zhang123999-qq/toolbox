# 视频提取音频

上传视频，用 ffmpeg.wasm 在浏览器本地剥离视频流，把音轨提取为 MP3 / WAV / OGG / M4A / FLAC / AAC。

## 用途

从视频里取出音乐、讲座、播客音轨：选输出格式与比特率，一键提取后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                     |
| ------- | ------ | ---------------------------------------- |
| `audio` | 音频   | 提取的音轨（格式见选项），可试听并下载   |
| `text`  | string | 处理报告：输入视频 / 输出格式 / 输出大小 |

## 选项

| 选项          | 类型 | 默认 | 说明                                         |
| ------------- | ---- | ---- | -------------------------------------------- |
| `format`      | 下拉 | mp3  | 输出格式：mp3 / wav / ogg / m4a / flac / aac |
| `bitrateKbps` | 数字 | 192  | 比特率（kbps，32～512），仅有损格式有效      |

## 限制

- 比特率超出 32～512 范围会给出中文错误提示
- 提取参数为「去掉视频流 + 音频重编码」，不是直接拷贝封装
- ffmpeg.wasm 内核首次使用需从 CDN 下载，之后缓存复用
- 文件全程留在浏览器内存里，不发任何请求（CDN 下载 wasm 内核除外）

## 示例

载入示例音频（当前示例为 WAV 演示流程，真实使用时请上传视频）：

```text
输入：示例-440Hz正弦波.wav
输出格式：MP3（去掉视频流（-vn）+ 音频重编码）
输出大小：xx.x KB
```

## 数据流向

**纯本地处理。** 提取在浏览器内用 ffmpeg.wasm 完成，`meta.api = false`，无需自备 API/Key。
