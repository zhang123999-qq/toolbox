# SVG 优化

压缩 SVG 字符串：去注释、去默认属性、缩短数字精度、压空白，末尾给出压缩率。

## 用途

替代 SVGO 的轻量自研版：贴入导出的 SVG，输出更小的单行 SVG，直接 inline 到 HTML。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                      |
| ------ | ------ | ------------------------- |
| `text` | string | 优化后的 SVG + 压缩率注释 |

## 优化规则

- 去掉 `<?xml ?>` 声明与 `<!-- -->` 注释
- 去掉默认属性：`fill="black"`、`stroke="none"`、`stroke-width="1"`、`fill-opacity="1"`、`version="1.x"`
- 数字精度截到小数点后两位（`50.000` → `50`，`1.23456` → `1.23`）
- 标签间空白压成单空格

## 限制

- 不做 path 合并、不做渐变去重、不做 `viewBox` 推导，压缩率远不如 SVGO
- 不校验 SVG 合法性之外的语义，损坏的 path 不会修
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** `meta.api = false`。

## 示例

输入：

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="100" height="100">
  <!-- 注释 -->
  <circle cx="50.000" cy="50.000" r="40.500" fill="#ff0000" stroke="none" stroke-width="1"/>
</svg>
```

输出：

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="100" height="100"><circle cx="50" cy="50" r="40.5" fill="#ff0000"/></svg>

<!-- 原始 180 字符 → 优化后 110 字符（节省 39%） -->
```
