# 文本转语音

浏览器语音合成。

## 用途

把文本念出来：用浏览器自带的语音合成，优先挑中文语音，长文本自动分句逐段朗读，结束后给出字数、语速与估算时长。

## 输入

| 字段   | 类型   | 约束             |
| ------ | ------ | ---------------- |
| `text` | string | 最大 20,000 字符 |

要朗读的文本。

## 输出

| 字段   | 类型   | 说明                                                                     |
| ------ | ------ | ------------------------------------------------------------------------ |
| `text` | string | 朗读结束后给出一份报告：字符数、语速、分段数、估算时长、实际使用的语音。 |

## 选项

| 选项   | 取值                              | 默认 | 说明     |
| ------ | --------------------------------- | ---- | -------- |
| `rate` | `0.5` / `0.8` / `1` / `1.5` / `2` | `1`  | 语速倍率 |

## 限制

- **完全依赖浏览器与操作系统**：Chrome / Edge / Safari 支持较好，Firefox 与部分 Linux 发行版可能没有可用语音；没有语音时工具会直接报错
- 可用语音列表由系统决定，本工具只做「优先挑 zh 开头的语音」，不提供手动选择语音的界面
- 长文本按句切成不超过 200 字符的片段逐条朗读；切换期间可能有短暂停顿
- 估算时长按「中文每分钟 240 字、拉丁每分钟 150 词」折算，只是量级参考
- 朗读期间的「中断」会被当成失败处理并给出报错
- 输入上限 20,000 字符

## 数据流向

**不联网。** 全部由浏览器本地完成：数据只在当前页面的输入框与输出框之间流转，不写入 localStorage、不发送、不上传。

- 文本交给浏览器自带的语音合成引擎，**不经过任何在线服务**；音色与发音质量取决于系统已装的语音包

## 示例

输入：

```text
这是一段用来试听语音合成效果的中文文本。
```

输出：

```text
已朗读：20 字符（中文 19 字、拉丁词 0 个）
语速：1×
分 1 段朗读
估算时长：约 4.8 秒
使用语音：（系统里有中文语音时给出名称，否则省略该行）
```
