# Word 转 Markdown

将 `.docx` 文档转换为 Markdown 文本，保留标题层级、加粗、斜体、列表、表格与链接。

## 用途

把 Word 文档搬进笔记软件、Wiki、静态博客：上传文档，得到干净的 Markdown。

## 输入

| 字段   | 类型 | 约束        | 说明                             |
| ------ | ---- | ----------- | -------------------------------- |
| `file` | File | 最大 50 MiB | 左下「选择文件」选取，**不上传** |

文本框不支持直接转换（点「运行」会提示改用文件入口）。

## 输出

| 字段   | 类型   | 说明                      |
| ------ | ------ | ------------------------- |
| `text` | string | Markdown 文本，以换行结尾 |

```markdown
# 标题

正文**加粗**

- 列表项
```

## 限制

- **文件上限 50 MiB**
- 图片一律忽略（不嵌入，避免 Markdown 里出现超大 data URI）
- 转换分两步：mammoth（纯 JS，本地）先转 HTML，再由本工具的纯函数转 Markdown；
  只还原内容与基础样式，不还原精确排版
- 加密 / 损坏的文档会直接报中文错误

## 数据流向

**纯本地处理。** 文件不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：包含二级标题 "小节" 与正文的 `.docx`

输出：

```markdown
## 小节

正文内容
```
