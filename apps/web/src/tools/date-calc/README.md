# 日期加减

在一个基准日期上，按「加 / 减 + 数量 + 单位」向前或向后推算出结果日期。

## 用途

日常开发与生活中频繁需要「N 天后是几号」「3 个月前的今天」「2024-02-29 加 1 年是几月几号」这类推算。
本工具用原生 `Date` 实现，**不依赖 dayjs / date-fns**，并正确处理两类最容易出错的边界：

- **闰年 2 月 29 日**：加 / 减年份落到平年时，回退到 2 月 28 日
- **月末溢出**：如 1 月 31 日加 1 月 → 2 月最后一天（平年 28 / 闰年 29）

## 输入

| 字段   | 类型   | 约束                        |
| ------ | ------ | --------------------------- |
| `text` | string | 基准日期，最大 200,000 字符 |

支持格式：

- `YYYY-MM-DD`、`YYYY/MM/DD`（仅日期）
- `YYYY-MM-DD HH:mm:ss`、`YYYY-MM-DD HH:mm`（带时间）
- 带 `T` / `Z` 的 ISO 8601 串

**越界日期直接报错**，不做静默回绕：`2024-02-30`、`2024-13-01` 都会中文提示。

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 基准 / 操作 / 结果三行，附溢出说明 |

```text
基准日期：2024-02-29 00:00:00 星期四
操作：加 1 年
结果：2025-02-28 00:00:00 星期五
说明：基准日为闰年 2 月 29 日，目标年 2025 是平年，2 月只有 28 天，已回退到 2 月 28 日。
```

## 选项

| 选项 key | 界面标签 | 取值                                                             | 默认   |
| -------- | -------- | ---------------------------------------------------------------- | ------ |
| `op`     | 操作     | `add`（加）/ `subtract`（减）                                    | `add`  |
| `amount` | 数量     | 整数（允许负号；负数时方向自动反转）                             | `1`    |
| `unit`   | 单位     | `year` / `month` / `week` / `day` / `hour` / `minute` / `second` | `year` |

## 算法

- **年 / 月**：自研溢出处理。先按年 / 月做整数进位，再取目标月天数 `lastDay = new Date(y, m+1, 0).getDate()`，
  结果日号 `= min(原日号, lastDay)`。这正是「2-29 → 平年 2-28」「1-31 → 2 月末」的来源。
- **周 / 日**：按天进位（周 = 7 天），直接用 `new Date(y, m, d + n)`，原生自动处理月年进位。
- **时 / 分 / 秒**：按毫秒偏移，避免月 / 年维度的歧义。
- **闰年判定**：`(y % 4 === 0 && y % 100 !== 0) || y % 400 === 0`，故 2000 是闰年、1900 不是。

## 边界

- 空输入 → 空输出（不报错，与全站 T2 工具一致）
- 数量非整数 → 中文报错
- 非法单位 / 操作 → 中文报错
- 输入 > 200,000 字符 → 报错
- 越界日期（2-30、13 月）→ 报错，不回绕
- 数量为负：例如「加 -3 天」等价于「减 3 天」，输出会注明方向已反转

## 示例

输入：

```text
2024-01-31
```

选项：`op=add`，`amount=1`，`unit=month`

输出：

```text
基准日期：2024-01-31 00:00:00 星期三
操作：加 1 个月
结果：2024-02-29 00:00:00 星期四
说明：基准日 31 日在目标月不存在，已回退到该月最后一天（29 日）。
```
