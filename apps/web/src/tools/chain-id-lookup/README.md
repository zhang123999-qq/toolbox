# 链 ID 查询

输入链 ID（十进制如 `1`、十六进制如 `0x1`）、链名称（如 `Polygon`）或代币符号（如 `AVAX`），查询内置的 60 余条主流公链信息：链 ID、十六进制、代币符号、EVM / 非 EVM 类型，测试网会特别标注。

## 用途

- 接入新链前确认 chainId，避免配错网络
- 十六进制与十进制 chainId 互查
- 按代币符号反查有哪些链（如搜 `ETH` 会列出所有以 ETH 为 gas 的链）

## 输入

| 字段   | 类型   | 约束                           |
| ------ | ------ | ------------------------------ |
| `text` | string | 查询串（ID / 名称 / 代币符号） |

## 说明

- 纯本地查询，无网络请求。
- 数据表收录时已核对公开 ChainList 信息；若某新链未收录，欢迎反馈补充。
- 非 EVM 链（Solana、Bitcoin、Tron 等）使用字符串网络标识，无数字 chainId。
