# Markdown 转 HTML

生成完整 HTML 文档。

## 用途

把 Markdown 变成可以直接保存打开的 .html 文件，或只要正文片段贴进博客/CMS。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

Markdown 文本。最大 200,000 字符。

## 输出

| 字段   | 类型   | 说明                                                         |
| ------ | ------ | ------------------------------------------------------------ |
| `text` | string | 完整 HTML 文档（含 DOCTYPE / charset / title）或仅正文片段。 |

## 选项

| 选项   | 取值                | 默认     | 说明                         |
| ------ | ------------------- | -------- | ---------------------------- |
| `mode` | document / fragment | document | 输出完整文档还是只要正文片段 |

## 限制

- 同样关闭原始 HTML（html: false），Markdown 里的标签会被转义
- 完整文档只含最小骨架，没有引入任何 CSS；需要样式请自行添加
- 文档 title 取自第一个标题，标题中的 < > & 会被转义
- 依赖 markdown-it，随工具页懒加载

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
# 工具库

本地优先
```

输出：

```text
# 工具库

本地优先，**870** 个工具。
```
