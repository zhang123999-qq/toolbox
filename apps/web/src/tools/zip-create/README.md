# 打包 ZIP

多文件上传，一键打包为 ZIP 压缩包并下载，可选压缩级别（0–9）。

## 用途

临时需要把几个文件发给别人、或备份一组文档时，不用装压缩软件，直接在浏览器里打包成 `.zip` 下载。

## 输入

| 字段   | 类型   | 约束                   | 说明                                      |
| ------ | ------ | ---------------------- | ----------------------------------------- |
| `text` | string | 最多 200 字符          | 压缩包文件名（不含 `.zip`，默认 archive） |
| `file` | File[] | 多选，总大小 ≤ 200 MiB | 通过「选择文件」选取，**不上传**          |

## 输出

| 字段   | 类型   | 说明                                           |
| ------ | ------ | ---------------------------------------------- |
| `file` | binary | 生成的 `.zip` 文件，直接触发浏览器下载         |
| `text` | string | 打包报告：包名、文件数、压缩前后体积、包内清单 |

点「打包并下载」后 zip 立即下载；输出区的「重新下载」可在不重新打包的情况下再下一份。

## 选项

| 选项    | 取值       | 默认 | 说明                           |
| ------- | ---------- | ---- | ------------------------------ |
| `level` | 0–9 的整数 | 6    | 0 = 仅存储不压缩，9 = 最大压缩 |

## 限制

- **总大小上限 200 MiB**：超限直接报错，请分批打包
- 包内重名文件自动追加 ` (2)` / ` (3)`（扩展名前），保证条目名唯一
- 文件名只保留基名（去掉本地目录部分）；空文件名兜底为 `unnamed`
- 打包走 `fflate` 纯 JS 实现，全程本地，不发任何请求

## 数据流向

**纯本地处理。** 文件只读进浏览器内存做压缩，`meta.api = false`，无需自备 API/Key。

## 示例

输入：`hello.txt`（"hello zip"）、`data.json`，压缩包名 `archive`，级别 6。

输出：

```text
打包成功：archive.zip
文件数：2，原始 20 B → 压缩包 240 B，级别 6

包内文件：
1. hello.txt
2. data.json
```
