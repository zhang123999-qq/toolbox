# 文本统计图

词频、长度分布可视化。

## 用途

把文本统计画成柱状图：默认看词频 Top N，也可切换看行长分布。复制 / 下载拿到的是同一份数据的纯文本表。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

一段正文；长度分布按非空行统计。

## 输出

| 字段   | 类型   | 说明                                             |
| ------ | ------ | ------------------------------------------------ |
| `text` | string | 图表 + 纯文本表（`标签<TAB>数值`，首行是表名）。 |

## 选项

| 选项     | 取值               | 默认   | 说明                         |
| -------- | ------------------ | ------ | ---------------------------- |
| `metric` | `freq` / `length`  | `freq` | 词频 / 行长分布              |
| `limit`  | `10` / `20` / `30` | `10`   | 词频取前几个（长度分布不用） |

## 限制

- **中文没有分词**：汉字按连续块切分，一整句会被当成一个词，词频结果更适合拉丁文本
- 停用词表是内置的精简表，只覆盖最常见的一批中英文虚词
- 长度分布的桶宽按最长行自适应（最多 12 个桶），因此不同文本的横轴刻度不可直接横向比较
- 图表用 echarts（Apache-2.0）按需引入柱状图与 SVG 渲染器，不依赖 canvas；代价是本工具的分块约 490 KB（未压缩），是文本域里最大的一个——它只在打开本工具时才加载，不影响首屏
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
苹果 香蕉 苹果 橘子 香蕉 苹果
西瓜 橘子 苹果 香蕉
```

输出：

```text
词频（词：次数）
苹果	4
香蕉	3
橘子	2
西瓜	1
```
