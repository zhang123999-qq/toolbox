# 八进制转换

文本与八进制转义互转，支持按字符或按字节切分。

## 用途

把文本写成八进制转义序列（`\344\270\255` 这类），或把从日志、反汇编、串口抓包、C 源码里拿到的八进制串还原成文本。
用于核对转义是否写对、把不可见字符显式化、跨语言传递含非 ASCII 的字符串。

> 与「二进制转换」的分工：本工具是**文本 ↔ 八进制表示**的编码转换（中 → `344 270 255`）；
> 若只是把一个整数改写成二进制/八进制/十六进制，请用二进制转换。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

- 编码方向：任意文本（中英混排、emoji 均可）
- 解码方向：一个或多个八进制值，用空白（空格 / 换行 / 制表符）分隔

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 编码方向输出八进制值；解码方向输出原文本 |

## 选项

| 选项        | 取值            | 默认   | 说明                                           |
| ----------- | --------------- | ------ | ---------------------------------------------- |
| `direction` | encode / decode | encode | encode = 文本 → 八进制；decode = 八进制 → 文本 |
| `mode`      | char / byte     | byte   | char 按 UTF-16 码元；byte 按 UTF-8 字节        |

`char` 与 `byte` 的差别：`char` 一个汉字得出一个值（等同 JS 里的 `\ooo` 转义，长度短）；
`byte` 一个汉字得出三个值（UTF-8 字节，跨语言/跨工具最通用）。

## 限制

- 编码时每个值至少补齐 3 位（不足补 `0`），因此 `A` 会写作 `101` 而不是 `A`
- `byte` 模式要求每个值 ≤ `377`（255），且还原结果必须是合法 UTF-8；否则明确报错而不是输出乱码
- `char` 模式要求每个值 ≤ `177777`（65535，即一个 UTF-16 码元）
- 解码用空白切分，因此**空格本身**在编码后是值而不是分隔符，往返不会错位

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（默认选项：encode / byte）：

```text
中
```

输出：

```text
344 270 255
```

其他实算结果：

| 输入          | 选项          | 输出              |
| ------------- | ------------- | ----------------- |
| `中`          | encode / char | `47055`           |
| `😀`          | encode / byte | `360 237 230 200` |
| `AB`          | encode / byte | `101 102`         |
| `344 270 255` | decode / byte | `中`              |
| `47055`       | decode / char | `中`              |
