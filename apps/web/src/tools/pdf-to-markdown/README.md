# PDF 转 Markdown

提取 PDF 的文本层并转换为 Markdown：按字号启发式识别标题（`#`/`##`），
无序符号统一为 `-` 列表，段落与列表结构保留，页与页之间可插入 `---` 分隔线。

## 用途

把带文字层的 PDF（论文、文档、手册）转成 Markdown，方便粘贴到笔记软件、
文档站或继续用 Markdown 工具链处理。

## 输入

| 字段   | 类型 | 约束                  | 说明                                 |
| ------ | ---- | --------------------- | ------------------------------------ |
| `file` | File | PDF，≤100 MiB，≤50 页 | 通过左下「选择文件」选取，**不上传** |

## 输出

| 字段   | 类型   | 说明                   |
| ------ | ------ | ---------------------- |
| `text` | string | 转换后的 Markdown 文本 |

```markdown
# 年度报告

这是正文第一段。

- 重点一
- 重点二

---

# 第二页标题
```

## 选项

| 选项             | 类型    | 默认 | 说明                                       |
| ---------------- | ------- | ---- | ------------------------------------------ |
| `detectHeadings` | boolean | true | 字号 ≥1.5×/1.25× 正文的短行识别为 `#`/`##` |
| `pageBreaks`     | boolean | true | 页与页之间插入 `---` 分隔线                |

## 限制

- **只处理文本层**：扫描版 PDF 没有文字可提，整篇无文本时会报错并建议用
  #500「PDF 文字识别（OCR）」；个别空白页会保留占位提示
- **加密 PDF 不支持**：中文提示请先去除密码
- **页数上限 50 页**，文件上限 100 MiB
- 标题识别是启发式（字号比 + 短行），复杂排版可能误判，可关掉该选项
- 转换不保留图片、表格边框与精确排版，只保留文本结构

## 数据流向

**纯本地处理。** pdfjs-dist 在浏览器里解析 PDF 并提取文本项，全程无网络请求
（`meta.api = false`），文件不上传。
