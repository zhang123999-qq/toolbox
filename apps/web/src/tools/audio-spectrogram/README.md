# 音频频谱图

上传音频，用短时傅里叶变换（STFT，基 2 FFT 纯 JS 实现）在浏览器本地生成语谱图，导出为 PNG 图片。

## 用途

观察音频的时频能量分布：横轴为时间（左→右），纵轴为频率（低频在下），颜色越亮表示该时频点能量越强。适合检查录音中的噪声、音乐的频谱特征。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

文件用浏览器 Web Audio API 本地解码（支持 wav / mp3 / ogg / m4a 等浏览器可解格式）；多声道会先混成单声道再分析。

## 输出

| 字段    | 类型   | 说明                                              |
| ------- | ------ | ------------------------------------------------- |
| `image` | PNG    | 语谱图，可预览并下载                              |
| `text`  | string | 分析报告：窗长 / 重叠率 / 帧数 / 频率与时间分辨率 |

## 选项

| 选项         | 类型 | 默认 | 说明                                             |
| ------------ | ---- | ---- | ------------------------------------------------ |
| `windowSize` | 数字 | 1024 | 分析窗长（采样点），可选 256 / 512 / 1024 / 2048 |
| `overlapPct` | 数字 | 50   | 相邻窗口的重叠率（%），可选 0 / 25 / 50 / 75     |

窗长越大频率分辨率越高、时间分辨率越低；重叠率越大时间轴越平滑、计算量越大。

## 限制

- 音频时长必须 ≥ 一个窗长，否则会中文提示「音频太短」
- 帧数超过 1600 列时画布按列抽稀显示（不影响分析精度）
- dB 刻度以全信号最大幅度为 0 dB，-90 dB 以下按底噪显示为深蓝色
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（4 秒 440Hz 正弦波），默认窗长 1024、重叠率 50%：

```text
输入：示例-440Hz正弦波.wav
原时长：4.00 秒　采样率：44100 Hz
窗长：1024 采样点　重叠率：50%　帧数：343
频率分辨率：43.07 Hz / 频点　时间分辨率：11.6 ms / 帧
颜色越亮表示该时频点能量越强（0 dB 为最亮，-90 dB 以下为底噪）。
```

## 数据流向

**纯本地处理。** 解码、STFT、Canvas 绘制都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
