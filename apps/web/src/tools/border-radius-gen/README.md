# 圆角生成

分别配置四个角的圆角半径，输出 `border-radius` 简写与分别写法。

## 用途

做卡片、按钮时手拼四个角的半径容易记错顺序，填四个数字直接拿结果。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作触发用。

## 输出

| 字段   | 类型   | 说明                            |
| ------ | ------ | ------------------------------- |
| `text` | string | `border-radius` 简写 + 分别写法 |

## 选项

| 选项 key | 界面标签 | 说明                          |
| -------- | -------- | ----------------------------- |
| `tl`     | 左上角   | 数字（无单位补 px），如 `8px` |
| `tr`     | 右上角   |                               |
| `br`     | 右下角   |                               |
| `bl`     | 左下角   |                               |

## 限制

- 只输出正圆半径，不做椭圆 `/` 斜杠写法
- 不生成 `border-*-radius` 的斜杠双值
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** `meta.api = false`。

## 示例

输出：

```css
border-radius: 8px 8px 8px 8px;

/* 分别写法 */
border-top-left-radius: 8px;
border-top-right-radius: 8px;
border-bottom-right-radius: 8px;
border-bottom-left-radius: 8px;
```
