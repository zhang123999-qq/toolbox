# 特殊符号

数学、箭头、货币等符号。

## 用途

按中英文关键词找特殊符号，点一下就复制。覆盖数学、箭头、货币、单位、制表、星标、勾叉、圈号、希腊与罗马数字。

## 输入

| 字段   | 类型   | 约束          |
| ------ | ------ | ------------- |
| `text` | string | 最大 100 字符 |

搜索关键词（中文名、英文名、或符号本身）；留空则列出该分类全部。

## 输出

| 字段   | 类型   | 说明                                                                |
| ------ | ------ | ------------------------------------------------------------------- |
| `text` | string | 可点击的符号网格；复制 / 下载拿到的是「所有命中符号连成的字符串」。 |

## 选项

| 选项       | 取值                                                                                                               | 默认  | 说明           |
| ---------- | ------------------------------------------------------------------------------------------------------------------ | ----- | -------------- |
| `category` | `all` / `math` / `arrow` / `currency` / `unit` / `punct` / `box` / `star` / `check` / `number` / `greek` / `roman` | `all` | 只显示某一分类 |

## 限制

- 符号表是手工整理的常用子集（约 110 个），不是 Unicode 全表
- 「度」符号 `°` 同时出现在 math 与 unit 两个分类里，按分类筛选时会各出现一次
- 关键词匹配是子串匹配，不做拼音、不做同义词扩展
- 单个「复制」按钮复制的是当前筛选结果的**全部**符号连成的字符串；单个符号请用网格里的按钮
- 剪贴板写入依赖浏览器的异步剪贴板 API，在非 HTTPS / 非安全上下文下会失败

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
箭头
```

输出：

```text
←→↑↓↔↕⇐⇒↩
```
