# Data URL 解析

解析 Data URL 的媒体类型、Base64 标志与解码内容，并统计字节数。

## 用途

线上 `<img src="data:image/png;base64,...">`、内联 SVG、邮件里塞的小附件，
贴进来就能看清「它声明了什么类型、有没有用 Base64、实际多少字节、内容是不是文本」，
以及把载荷还原成原文。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 2,000,000 字符 |

即以 `data:` 开头的完整 URL（大小写不敏感）。粘贴时被折行的 Base64 也能解。

## 输出

| 字段   | 类型   | 说明                     |
| ------ | ------ | ------------------------ |
| `text` | string | 解析结果；空输入返回空串 |

## 选项

| 选项     | 取值                      | 默认     | 说明                                    |
| -------- | ------------------------- | -------- | --------------------------------------- |
| `format` | `report` / `json` / `raw` | `report` | 逐项报告 / 机器可读 JSON / 只要还原正文 |

### 输出形态

- `report`：
  `媒体类型` `主类型` `参数` `编码方式` `字节数` `声明字符集` `内容形态` 各占一行，
  随后空一行给出内容（二进制时是十六进制转储）。
- `json`：`mediaType` / `essence` / `charset` / `base64` / `byteLength` / `binary`
  / `parameters`，文本载荷给 `text`、二进制载荷给 `hex`。
- `raw`：只要还原出的正文；二进制载荷退化为十六进制转储。

## 限制

- **只做解析**：生成 Data URL 请用 `data-url` 工具；本工具与其各自独立实现、互不依赖。
- 字符集只用 UTF-8 做「能不能解成文本」的判定，不会按 `charset` 参数去重新解码内容
  （例如 `charset=gbk` 的载荷仍按 UTF-8 判 Abinary，后续一律走十六进制转储）。
- 十六进制转储上限 4,096 字节，超出部分截断并标注总字节数。
- 逗号之后的内容全部视为载荷，不识别 URL 片段（`#`）；`data:` 之后没有逗号时报错。
- Base64 容忍换行、URL 安全变体（`-_`）、缺失填充，但不容忍其它非法字符。

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
data:text/plain;charset=utf-8;base64,5bel5YW35bqTCg==
```

输出（report）：

```text
媒体类型: text/plain;charset=utf-8
主类型: text/plain
参数: charset=utf-8
编码方式: Base64
字节数: 10 字节
声明字符集: utf-8
内容形态: 文本（合法 UTF-8）

内容:
工具库
```
