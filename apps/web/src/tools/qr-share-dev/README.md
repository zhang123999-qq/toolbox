# 二维码分享

把一段文本或链接在本地生成二维码（SVG 源码），手机扫码即可在另一台设备上打开。

## 用途

在电脑上调试时，想让手机访问本地的临时地址、或分享一段链接给身边人，
不必截图发微信——生成二维码直接扫。

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 要编码的文本 / URL，最大 2,000 字符 |

## 选项

| 选项 key | 界面     | 取值          |
| -------- | -------- | ------------- |
| `level`  | 容错等级 | L / M / Q / H |

容错等级越高，二维码被遮挡时仍可识别，但模块更密。日常分享用 `M` 即可。

## 输出

输出区直接给出 **SVG 源码**（含一行版本 / 模块数 / 容错等级注释）。
你可以：

- 把 SVG 源码存成 `.svg` 文件直接在浏览器打开扫码
- 粘到 HTML 里 `<div dangerouslySetInnerHTML>` 渲染成图

> 与 `text-to-qr`（T3 多面板，直接渲染成图）不同，本工具走 T2 双栏，
> 输出的是文本区里的 SVG 源码，便于复制 / 下载 / 嵌入。

## 浏览器边界

- 完全本地：用 `qrcode` 包的同步 `create()` 在浏览器内编码，不发送任何网络请求
- 输入过长（> 2,000 字符）时 QR 版本会很高，扫码可能变慢，请控制长度

## 数据流向

**纯本地处理。** `meta.api = false`，无需 Key。

## 示例

输入：`https://example.com/分享链接`，容错 `M`，输出：

```xml
<!-- 版本 4 · 33×33 模块 · 容错 M · 扫码分享 -->
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 41 41" style="...">
  <rect width="41" height="41" fill="#fff"/>
  <g fill="#000"><rect .../></g>
</svg>
```
