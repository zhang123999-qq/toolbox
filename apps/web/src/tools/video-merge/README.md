# 视频合并

把多个视频按选择顺序拼接成一个 MP4 文件。编码不一致导致拼接失败时，可一键开启「重编码统一」。

## 用途

把分段录制的视频、多个短片按顺序拼成一个完整视频。

## 输入

| 字段   | 类型   | 约束                   | 说明                                 |
| ------ | ------ | ---------------------- | ------------------------------------ |
| `file` | File[] | 至少 2 个，各 ≤500 MiB | 通过「选择多个视频」多选，**不上传** |
| `text` | string | —                      | 左侧文本区仅作备注，不参与处理       |

列表顺序即拼接顺序。

## 输出

| 字段    | 类型 | 说明                             |
| ------- | ---- | -------------------------------- |
| `video` | MP4  | 拼接后的视频（merged.mp4）       |
| `text`  | 文本 | 处理报告：片段清单 / 模式 / 大小 |

## 选项

| 选项       | 类型 | 默认 | 说明                                                                                                          |
| ---------- | ---- | ---- | ------------------------------------------------------------------------------------------------------------- |
| `reencode` | 开关 | 开   | 重编码统一为 H.264 + AAC：解决多视频编码 / 分辨率不一致导致的拼接失败；关闭则流拷贝拼接（快，但要求编码一致） |

## 编码一致性说明

流拷贝拼接要求所有输入视频的视频编码、音频编码、分辨率等参数一致，否则 ffmpeg 会报错退出，本工具会明确提示开启「重编码统一」后重试。默认开启重编码，兼容性最好。

## 限制

- 少于 2 个视频、单个文件为空或超 500 MiB，都会给出中文错误提示
- ffmpeg.wasm 组件按需从 CDN 加载：加载 / 初始化失败会提示检查网络后重试
- 文件全程留在浏览器内存里，不发任何请求

## 示例

选择 a.mp4、b.mp4 并合并（重编码模式）：

```text
已按顺序合并 2 个视频：
1. a.mp4
2. b.mp4
模式：重编码（H.264 + AAC，编码已统一）
输出：merged.mp4（8.42 MiB）
```

## 数据流向

**纯本地处理。** ffmpeg.wasm 在浏览器内拼接，`meta.wasm = true`，`meta.api = false`，无需自备 API/Key。
