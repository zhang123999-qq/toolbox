# Git 命令速查

按分类列出 40+ 条常用 Git 命令、说明与示例，按分类过滤后可直接复制。

## 用途

背不下 `git restore --staged` 和 `git reset --soft` 的区别时，在这里按分类查一下，
每条命令附带一句人话说明和一个可直接照抄的示例。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

**输入框只作触发用**，内容不参与输出：留空不产出，点「示例」或随手输入即按当前分类输出速查表。

## 选项

| 选项 key   | 界面标签 | 取值                                                                    |
| ---------- | -------- | ----------------------------------------------------------------------- |
| `category` | 分类     | `all` / `base` / `branch` / `remote` / `undo` / `stash` / `log` / `tag` |

## 输出

Markdown 表格：`命令 | 说明 | 示例`，每个分类一个二级标题。

## 限制

- 只覆盖日常高频命令，不含子模块、二分查找、filter-branch 等进阶场景
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 纯字符串拼接，不发送任何网络请求。`meta.api = false`。
