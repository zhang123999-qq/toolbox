# 在线录音机

调用浏览器的 MediaRecorder 录制麦克风，实时计时，停止后试听并下载。

## 用途

快速录一段语音、会议记录、灵感备忘：开始 → 暂停/继续 → 停止，录完直接下载。

## 输入

| 字段   | 类型   | 约束         | 说明                           |
| ------ | ------ | ------------ | ------------------------------ |
| `file` | File   | 最大 200 MiB | 录音工具**不使用**文件上传     |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理 |

## 输出

| 字段    | 类型   | 说明                                                   |
| ------- | ------ | ------------------------------------------------------ |
| `audio` | 音频   | 录制的音频（webm/opus 或浏览器默认格式），可试听并下载 |
| `text`  | string | 处理报告：录音时长 / 格式 / 文件大小                   |

## 选项

无（可直接开始录音）。

## 限制

- 首次使用会弹窗请求**麦克风权限**，拒绝后会给出中文错误提示
- 不支持 MediaRecorder 或 getUserMedia 的旧浏览器会给出中文错误提示
- 录音数据全程留在浏览器内存里，不发任何请求
- 暂停时计时器也暂停；重置可清除录音回到待机状态

## 示例

点「开始录音」→ 说话 → 点「停止录音」：

```text
录音时长：00:07　格式：audio/webm;codecs=opus
文件大小：xx.x KB
```

## 数据流向

**纯本地处理。** 麦克风采集与编码全在浏览器内完成，`meta.api = false`，无需自备 API/Key。
