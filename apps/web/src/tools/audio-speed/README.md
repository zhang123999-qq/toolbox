# 音频变速

上传音频，用 Web Audio API 解码，在浏览器本地改变播放速度并导出为 WAV。

## 用途

给语音、播客提速（省时间）或慢放（听清细节）：输入 0.25～4 倍变速倍率，一键生成。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                     |
| ------- | ------ | ---------------------------------------- |
| `audio` | WAV    | 变速后的音频（16 位 PCM），可试听并下载  |
| `text`  | string | 处理报告：变速倍率 / 时长变化 / 新采样率 |

## 选项

| 选项    | 类型 | 默认 | 说明                              |
| ------- | ---- | ---- | --------------------------------- |
| `speed` | 数字 | 1    | 变速倍率（0.25～4），1 为保持不变 |

## 限制

- 变速倍率超出 0.25～4 范围会给出中文错误提示
- 当前用线性插值重采样实现，**变速会同时改变音调**（加速变高、减速变低）
- 不支持 Web Audio API 的旧浏览器会给出中文错误提示
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（4 秒 440Hz 正弦波），变速 1.5×：

```text
输入：示例-440Hz正弦波.wav
变速倍率：1.5×（新采样率：29400 Hz）
原时长：4.00 秒 → 新时长：2.67 秒
```

## 数据流向

**纯本地处理。** 解码与变速全在浏览器内完成，`meta.api = false`，无需自备 API/Key。
