# 音频格式识别

读取文件头魔数，识别音频文件真实格式（扩展名可伪造，魔数不会）。

## 用途

下载的文件扩展名不对、打不开时，先看看到底是什么格式，再决定用什么软件打开或转码。

## 输入

| 字段   | 类型   | 约束 | 说明                                 |
| ------ | ------ | ---- | ------------------------------------ |
| `file` | File   | 任意 | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —    | 左侧文本区仅作备注，不参与处理       |

只读取文件前 64 字节头做识别，不解码整文件，速度极快。

## 输出

| 字段   | 类型   | 说明                                  |
| ------ | ------ | ------------------------------------- |
| `text` | string | 识别报告：文件名 / 大小 / 格式 / 依据 |

## 支持的格式

| 格式         | 魔数依据                        |
| ------------ | ------------------------------- |
| WAV 音频     | `RIFF....WAVE`                  |
| MP3 音频     | `ID3` 标签头 / MPEG 帧同步      |
| FLAC 音频    | `fLaC`                          |
| Ogg 音频     | `OggS`（Vorbis / Opus 等）      |
| M4A 音频     | `ftyp` 主品牌 `M4A `            |
| M4A/MP4 音频 | `ftyp` 其他品牌（ISO 媒体格式） |
| AAC 音频     | ADTS 帧同步字                   |
| WMA 音频     | ASF 容器 GUID                   |
| AIFF 音频    | `FORM....AIFF`                  |

识别不出、文件头截断、空文件都会给出中文说明，不会静默失败。

## 限制

- 只看魔数不校验文件完整性：头对但内容损坏的文件仍会显示"识别成功"
- 输出为识别报告文本，不做转码

## 示例

载入示例音频（最小 WAV 头）：

```text
文件：示例.wav
大小：44 B
识别结果：WAV 音频
依据：RIFF/WAVE 容器（通常为 PCM）
```

## 数据流向

**纯本地处理。** 只读文件头 64 字节，`meta.api = false`，无需自备 API/Key。
