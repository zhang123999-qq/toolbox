# 网站速度测试

在浏览器内对目标 URL 多次 `fetch` 计时：总耗时、TTFB 近似、传输体积，
取平均 / 最快 / 最慢并按耗时分档打分。

## 用途

快速摸一下某个页面（或 API 接口）从你的网络访问有多快，不用开 DevTools。

## 输入

| 字段   | 类型   | 约束         |
| ------ | ------ | ------------ |
| `text` | string | 待测页面 URL |

## 选项

| 选项     | 取值            |
| -------- | --------------- |
| 测量次数 | `1` / `3` / `5` |

## 输出

```text
目标：https://example.com/
评级：优等（95 分）
平均耗时：320 ms（1 次成功，最快 320 ms / 最慢 320 ms）
平均 TTFB：120 ms
传输体积：2.0 KiB

各次测量：
  #1 320 ms（TTFB 120ms / 2.0 KiB）
```

## 评分规则

平均耗时 <1s 优等、<2s 良好、<3s 一般、<5s 较慢、≥5s 慢。

## 浏览器边界说明

- **同源测量为精确值**：可读状态码、响应体流，TTFB 取首 chunk 到达时间，体积为实际字节数
- **跨域走 `no-cors`**：浏览器返回 opaque 响应，读不到状态码与响应体，
  只能测总耗时，TTFB/体积记为「不可测」，报告明确标注「跨域测量为近似值」——不编造数据
- 测的是**你的浏览器到目标站点的网络耗时**（含 DNS / TLS / 传输），不是服务器端渲染耗时
- 浏览器缓存已用 `cache: 'no-store'` 禁用；结果受你当前网络波动影响，多次测量取平均更稳

## 限制

- 单次超时 30 秒；目标站点挂掉 / 拦截机器人时如实报错
- 不执行 JS、不渲染页面，与 Lighthouse 的 lab 数据不是一回事

## 数据流向

**浏览器发起 fetch（D 类）。** 请求直连目标站点，不经过本工具后端。`meta.api = true`
（浏览器直连外部站点）。
