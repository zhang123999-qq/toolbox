# Webhook 测试

向一个 Webhook 地址发送一条 POST JSON，查看响应或错误，用来验证回调是否真的通。

## 用途

接第三方平台回调、或自己写 webhook 接收端时，想先打一发看看服务端收没收到、回了什么。
本工具把载荷 POST 到你给的地址，把状态码和响应体回显出来。

## 输入

| 字段             | 类型   | 说明                         |
| ---------------- | ------ | ---------------------------- |
| `text`（主输入） | string | Webhook URL，需 `http(s)://` |
| 请求体（JSON）   | string | POST 载荷，留空则发 `{}`     |

## 输出

```text
POST https://hooks.example.com/xxx
状态：200 OK
响应体：
{"received":true}
```

## 浏览器边界说明

- 请求从你的浏览器发出，受 CORS 限制：目标若不返回 CORS 头，会报跨域错误；
  但**请求本身通常已经送达**（webhook 服务端可能已收到），只是浏览器不让你读响应
- 适合「打一发看通不通」，不适合需要读完整响应的场景（那种请用 HTTP 请求测试）
- 别往真实生产 webhook 乱发测试数据，会污染下游事件

## 数据流向

**浏览器发起 fetch（C 类）。** 不经过本工具后端。`meta.api = false`。
