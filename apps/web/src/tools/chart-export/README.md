# 图表导出

粘贴 ECharts option JSON，在浏览器本地预览渲染，按指定尺寸与背景色导出 PNG / SVG 图片。

## 用途

- 把代码里的 echarts option 快速渲染成图并导出
- 为文档、演示生成指定尺寸的图表图片
- 需要透明背景或矢量 SVG 的场景

## 输入

| 字段   | 类型   | 约束                                   |
| ------ | ------ | -------------------------------------- |
| `text` | string | echarts option JSON 对象（留空用示例） |

输入格式示例：

```json
{
  "title": { "text": "示例柱状图", "left": "center" },
  "xAxis": { "type": "category", "data": ["A", "B", "C"] },
  "yAxis": { "type": "value" },
  "series": [{ "type": "bar", "data": [120, 200, 150] }]
}
```

- 须为 JSON 对象（不能是数组或原始值），`series` 可选
- 非法 JSON 会中文报错

## 选项

| 选项     | 默认值    | 范围 / 约束                        | 说明                                |
| -------- | --------- | ---------------------------------- | ----------------------------------- |
| 宽度     | `800`     | 100–4000                           | 导出宽（px）                        |
| 高度     | `600`     | 100–4000                           | 导出高（px）                        |
| 背景色   | `#ffffff` | `#rrggbb` / `#rgb` / `transparent` | PNG 背景；`transparent` 为透明背景  |
| 导出格式 | `png`     | `png` / `svg`                      | PNG 为位图（2x 像素比），SVG 为矢量 |

## 说明

- 预览与导出都在浏览器本地完成，option JSON 不上传
- SVG 导出通过 ECharts 的 svg 渲染器在临时容器中绘制后序列化得到
