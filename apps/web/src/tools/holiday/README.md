# 假期推算

按**历法规则**推算某一年中国主要节日的公历日期，并给出周末天数统计。

## ⚠️ 重要边界说明（请务必阅读）

- **本工具不是权威法定节假日表。** 中国每年的放假安排、调休、补班由国务院办公厅另行通知，
  逐年变动，且无法用固定规则推出。本工具只做「历法层面的日期推算」。
- **不含调休 / 补班**：不会把某个周末标成上班日，也不会把某个工作日标成放假。
- **清明为节气近似**：清明是太阳黄经节气，精确日期需天文计算；这里按 `4/4` 近似标注。
- 浏览器环境下直连免费公共假期 API（如 date.nager.at）普遍存在 **CORS 跨域限制**，
  浏览器端调用会被拦截、且各源不稳定。因此本工具**默认完全走本地规则**，不发起网络请求，
  以免页面卡死或给出不可靠数据；如需权威数据，请查询当年国务院公告或官方日历。

## 输入

| 字段   | 类型   | 约束                   |
| ------ | ------ | ---------------------- |
| `text` | string | 四位整数年份 1900–2100 |

## 输出示例（2025）

```text
2025 年主要节日（规则推算）：
2025-01-01  元旦（公历）
2025-01-29  春节（农历）
2025-02-12  元宵节（农历）
2025-04-04  清明（近似）（节气近似）
2025-05-01  劳动节（公历）
2025-05-31  端午节（农历）
2025-10-01  国庆节（公历）
2025-10-06  中秋节（农历）

全年周末（周六+周日）约 104 天
注意：以上为按历法规则的推算，不含国务院法定调休/补班安排，非权威。
```

## 覆盖的节日

| 节日   | 类型 | 规则                       |
| ------ | ---- | -------------------------- |
| 元旦   | 公历 | 1/1                        |
| 劳动节 | 公历 | 5/1                        |
| 国庆节 | 公历 | 10/1                       |
| 清明   | 节气 | 近似 4/4                   |
| 春节   | 农历 | 正月初一（内置农历表换算） |
| 元宵节 | 农历 | 正月十五                   |
| 端午节 | 农历 | 五月初五                   |
| 中秋节 | 农历 | 八月十五                   |

农历换算的核心数据表与「公历农历互转」工具一致，但**本工具内联了一份最小副本**，
不跨工具 import。

## 数据流向

**纯本地处理。** 不发起任何网络请求，无第三方依赖。`meta.api = false`。
