# 桑基图（#672）

## 用途

输入「源 → 目标 → 数值」三列数据，用 ECharts 渲染桑基图（流量流向图），
适用于展示用户转化漏斗、资金流向、能源分配等流量关系，并可一键导出 PNG。

## 输入格式

每行一条连线，格式为 `源, 目标, 数值`（全角逗号会自动归一为半角）：

```
访问, 注册, 100
注册, 付费, 30
访问, 流失, 70
```

规则：

- 节点自动去重：同一节点名只出现一次，按首次出现顺序排列
- 数值必须是**大于 0** 的数字（0、负数、非数字都会报错）
- **不支持自环**：源与目标不能相同
- 空输入会自动填入上面的示例数据

## 选项

- **标题**：图表标题，留空则不显示
- **宽度 / 高度**：图表尺寸（像素），100–2000，留空默认 600×400

## 输出

- 图表区实时渲染桑基图（悬停查看流量明细）
- 「下载 PNG」按钮导出 2x 高清 PNG（白底，文件名为 `sankey.png`）
- 文本下载（download 按钮）导出原始行文本（.txt）

## 边界

- 空输入 → 使用示例数据
- 行不是恰好 3 列 → 报错「数据格式非法」
- 节点名为空 → 报错「节点名不能为空」
- 自环（源 = 目标）→ 报错「源与目标不能相同（不支持自环）」
- 数值非有限数字或 ≤ 0 → 报错「数值非法」
- 尺寸超出 100–2000 → 报错
- 图表尚未渲染时点「下载 PNG」→ 提示「图表尚未渲染，无法导出 PNG」
