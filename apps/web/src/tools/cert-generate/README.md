# 证书生成

在浏览器本地生成一张自签名 X.509 证书和配套私钥（RSA 2048 / 4096），适合本地 HTTPS 开发。

## 用途

前端调本地接口要用 `https://`、或要在局域网里给个内网服务加 TLS 时，
不必装 OpenSSL，直接在这里填好域名生成一对 `.pem`。私钥不离开你的浏览器。

## 输入

| 字段   | 类型   | 约束                      |
| ------ | ------ | ------------------------- |
| `text` | string | 触发用，最大 200,000 字符 |

## 选项

| 选项                  | 说明                                     |
| --------------------- | ---------------------------------------- |
| 通用名（CN）          | 必填，主域名，如 `example.localhost`     |
| 组织（O）/ 部门（OU） | 选填                                     |
| 国家（C）             | 选填，两位字母，如 `CN`                  |
| 有效期（天）          | 365 / 3650 / 36500                       |
| 密钥长度              | RSA 2048 / 4096                          |
| 备用域名（SAN）       | 逗号分隔，现代浏览器要求 SAN 而非只靠 CN |

## 输出

```text
# 证书（cert.pem）
-----BEGIN CERTIFICATE-----
...
-----END CERTIFICATE-----

# 私钥（key.pem）—— 妥善保管，切勿泄露
-----BEGIN RSA PRIVATE KEY-----
...
-----END RSA PRIVATE KEY-----
```

## 提醒

- **自签名证书浏览器默认不信任**，仅用于本地/内网开发；公网请用 Let's Encrypt 等受信 CA
- 私钥（`PRIVATE KEY` 段）不会上传，但本工具也不会帮你安全存储，请自行保管
- SAN 一定要把要访问的域名/IP 都写上，否则浏览器报 `ERR_CERT_COMMON_NAME_INVALID`
- RSA 4096 生成略慢，属正常现象

## 数据流向

**纯本地处理。** node-forge 在浏览器内生成密钥对，不出网。`meta.api = false`。
