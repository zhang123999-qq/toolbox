# Chmod 计算

数字权限（`755`）与符号权限（`rwxr-xr-x`）双向转换，并给出等价的 chmod 命令。

## 输入

| 字段   | 类型   | 约束                                    |
| ------ | ------ | --------------------------------------- |
| `text` | string | `755` 或 `rwxr-xr-x`，最大 200,000 字符 |

## 输出

```text
数字权限：755
符号权限：rwxr-xr-x

对象 | 读 | 写 | 执行
--- | --- | --- | ---
所有者 | r | w | x
所属组 | r | - | x
其他人 | r | - | x

# 等价命令
chmod 755 <文件>
chmod u=rwx,g=r-x,o=r-x <文件>
```

## 规则

- `r=4`、`w=2`、`x=1`，三位相加得数字
- 输入 4 位数字时只取后三位（SUID/SGID/sticky 位暂不展开）
- 其他格式抛「无法识别的权限格式」
