# YAML 格式化

YAML 缩进重排与语法校验，保留注释与常见块结构。

## 用途

把缩进不统一、手改过的 YAML 配置排回规范缩进（2 / 4 空格可选），或只做一次语法体检。
解析失败时给出带行列位置的中文提示，直接跳到出错行。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                                        |
| ------ | ------ | ------------------------------------------- |
| `text` | string | 格式化后的 YAML，或校验报告；空输入返回空串 |

## 选项

| 选项       | 取值                  | 默认     | 说明                       |
| ---------- | --------------------- | -------- | -------------------------- |
| `mode`     | `format` / `validate` | `format` | 重新排版，或只输出体检报告 |
| `indent`   | `2` / `4`             | `2`      | 缩进档位                   |
| `sortKeys` | boolean               | `false`  | 是否按键名字典序递归重排   |

## 支持范围

- 块映射（`key: value`）、任意深度嵌套、块序列（`- item`）、`- k: v` 形式的序列项
- 流式集合：`[1, 2]`、`{a: 1, b: 2}`（**必须写在同一行内**）
- 标量：裸标量、单引号、双引号（含 `\n` `\t` `\uXXXX` 转义）、`~` / `null`、`true` / `false`
- 数字：十进制、十六进制 `0x`、八进制 `0o`、二进制 `0b`、浮点、科学计数法、下划线分隔
- 块标量 `|` / `>`（含 `-` / `+` 两种 chomping；折叠标量按简化规则处理）
- 行尾注释、整行注释、文件头注释块；格式化后注释会跟随各自的键
- 纯标量跨行续写（缩进更深的行按空格折叠）

## 限制

- **不支持多文档**：出现第二个 `---` 或在内容之后出现 `---` 会报错
- **不支持锚点 / 别名 / 合并键**（`&a`、`*a`、`<<`），遇到即报错
- **不支持显式标签**（`!!str` 之外的自定义 `!tag` 同样不支持）
- **不支持复杂键**（`? key`）、不支持跨行的流式集合、不支持跨行的引号标量
- **不支持 Tab 缩进**，会明确报错提示改用空格
- 数字超 `Number.MAX_SAFE_INTEGER` 时按双精度处理，可能丢失末位精度
- 日期时间（`2024-01-01`）按字符串处理，不做类型转换
- 重复键以最后一个为准，不报错
- 开启 `sortKeys` 后注释仍跟随原键，可能出现注释与相邻键错位
- 格式化是「规范化」而非「只改缩进」：**流式集合会展开成块结构**，块标量（`|` / `>`）改写成带 `\n` 的双引号字符串

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```yaml
# 应用配置
name: 工具库
server:
  port: 8080
```

输出（`indent = 2`）：

```yaml
# 应用配置
name: 工具库
server:
  port: 8080
```
