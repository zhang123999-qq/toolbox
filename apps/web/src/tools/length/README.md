# 长度换算

输入数值并选择源单位与目标单位，即时得到长度换算结果。

## 用途

- 毫米 / 厘米 / 米 / 千米与英寸 / 英尺 / 码 / 英里 / 海里互转
- 快速查英制—公制对照（如英寸→厘米）

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待换算的数值，最大 200,000 字符 |

## 输出

单行文本：`输入值 源单位 = 结果 目标单位`

```text
1 mi = 1.609344 km
```

## 选项

| 字段   | 类型   | 说明     | 可选值                                 |
| ------ | ------ | -------- | -------------------------------------- |
| `from` | select | 源单位   | μm、mm、cm、m、km、in、ft、yd、mi、nmi |
| `to`   | select | 目标单位 | 同左                                   |

## 算法

- 以**米**为基准：`结果 = 数值 × from.factor / to.factor`
- 输出用 `Number(n.toPrecision(12)).toString()` 格式化，去浮点噪声、去尾零

## 边界

- 空输入 → 输出为空（不报错）
- 非数字输入 → 中文报错「请输入有效的数字」
- 未知单位 id → 中文报错「未知单位」
- 输入 > 200,000 字符 → 报错

## 示例

输入数值：`1`，从 `in` 到 `cm`

输出：`1 in = 2.54 cm`（精确值）

## English

Convert between length units (mm to miles).

- Input: a numeric string.
- Output: one line, e.g. `1 mi = 1.609344 km`.
- Options: `from` / `to` selects over μm, mm, cm, m, km, in, ft, yd, mi, nmi.
