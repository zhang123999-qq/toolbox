# 简历 PDF 生成

填写姓名、求职意向、联系方式、个人简介、工作经历、教育背景与技能，
生成一页式简历 PDF：姓名居中大标题、章节加粗标题加分割线，纯本地生成后下载。

## 用途

快速生成投递用的英文简历 PDF，不经过任何服务器。

## 输入

| 字段         | 类型   | 约束            | 说明                                                                   |
| ------------ | ------ | --------------- | ---------------------------------------------------------------------- |
| `name`       | string | 最大 100 字符   | 姓名（必填）                                                           |
| `title`      | string | 最大 200 字符   | 求职意向                                                               |
| `email`      | string | 最大 200 字符   | 邮箱                                                                   |
| `phone`      | string | 最大 100 字符   | 电话                                                                   |
| `location`   | string | 最大 200 字符   | 城市                                                                   |
| `summary`    | string | 最大 2000 字符  | 个人简介（多行）                                                       |
| `experience` | string | 最大 10000 字符 | 工作经历：每行「公司 \| 职位 \| 时间段 \| 描述」（英文竖线，描述可空） |
| `education`  | string | 最大 5000 字符  | 教育背景（多行）                                                       |
| `skills`     | string | 最大 2000 字符  | 技能（多行）                                                           |

姓名必填，为空报错「请填写姓名」。经历行校验：列数必须为 3–4；公司、职位、时间段均不能为空；
非法时报错并带出行号。简介、教育、技能中的空行会被跳过。

## 输出

| 字段   | 类型       | 说明                          |
| ------ | ---------- | ----------------------------- |
| `file` | PDF 二进制 | A4 纵向 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「复制/下载」按钮操作的是简历纯文本版（`.txt`）。

## 选项

无。

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，任何字段含中文时会直接报错，
  不会生成乱码 PDF（本工具目前只适合英文简历）。
- 内容较多时会跨页（目标是一页，请精简内容）。
- 文件全程在浏览器内存里生成，不发任何请求。

## 数据流向

**纯本地处理。** 输入与生成的 PDF 都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

姓名 Jane Doe、求职意向 Frontend Engineer、两段经历 → 输出 A4 PDF（姓名 24pt 居中、
Experience 章节两条经历）；输出区显示如 `已生成 PDF：1 页，2.5 KB`。
