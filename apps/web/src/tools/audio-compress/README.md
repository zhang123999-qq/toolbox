# 音频压缩

上传音频，用 ffmpeg.wasm 在浏览器本地压缩为 MP3：降低比特率，减小文件体积。

## 用途

把体积大的录音、音乐压小，方便分享或上传：选预设或自定义比特率，一键压缩后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                          |
| ------- | ------ | --------------------------------------------- |
| `audio` | MP3    | 压缩后的音频，可试听并下载                    |
| `text`  | string | 处理报告：输入 / 压缩配置 / 输出大小 / 压缩比 |

## 选项

| 选项          | 类型 | 默认   | 说明                                               |
| ------------- | ---- | ------ | -------------------------------------------------- |
| `preset`      | 下拉 | medium | 压缩预设：low（64k）/ medium（128k）/ high（192k） |
| `bitrateKbps` | 数字 | 留空   | 自定义比特率（kbps，16～320），留空则用预设值      |

## 限制

- 自定义比特率超出 16～320 范围会给出中文错误提示
- 输出固定为 MP3；如需其他格式请用「音频格式转换」
- ffmpeg.wasm 内核首次使用需从 CDN 下载，之后缓存复用
- 文件全程留在浏览器内存里，不发任何请求（CDN 下载 wasm 内核除外）

## 示例

载入示例音频（4 秒 440Hz 正弦波），默认 medium 预设（128k）：

```text
输入：示例-440Hz正弦波.wav
压缩配置：中（128 kbps，通用）
输出大小：xx.x KB　压缩比：xx.x%
```

## 数据流向

**纯本地处理。** 压缩在浏览器内用 ffmpeg.wasm 完成，`meta.api = false`，无需自备 API/Key。
