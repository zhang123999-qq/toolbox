# 签名验签

以太坊 `personal_sign` 签名与验签：RFC6979 确定性随机数签名、ecrecover 恢复签名地址。

## 用途

- **签名**：输入私钥 + 消息，输出消息哈希、r / s / v 与 65 字节签名。
- **验签**：输入签名 + 消息 + 地址，恢复签名地址并比对。

签名流程：`keccak("\x19Ethereum Signed Message:\n" + len + message)` → RFC6979 确定性 k → ECDSA（低 S 值规范化，EIP-2）。

## 输入

| 字段      | 类型   | 约束                                      |
| --------- | ------ | ----------------------------------------- |
| `text`    | string | 私钥 hex（签名）/ 65 字节签名 hex（验签） |
| `message` | string | 待签消息                                  |
| `address` | string | 待比对地址（验签模式）                    |

## 安全

- 仅供学习测试使用；生产环境请使用硬件钱包签名。
- 私钥只保存在页面内存中，不写入任何存储、不上传网络。
- RFC6979 / secp256k1 / Keccak 均为本工具内手写实现，无第三方依赖；签名向量经 Python ecdsa 库独立验证。

## 说明

- v 只支持 27 / 28（以太坊 personal_sign 惯例）。
- 确定性签名：同一私钥 + 同一消息永远得到同一签名。
