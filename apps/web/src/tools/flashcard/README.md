# 单词卡（#830）

抽认卡学习工具，基于 SM-2 简化版间隔重复算法安排复习，全部本地运行。

## 功能

- **学习（study）**：逐张展示卡片正面，点击"显示答案"后按 0–5 评分；答对拉长间隔（1 天 → 6 天 → 按简易度放大），答错重置为 1 天。
- **到期（due）**：列出当前到期的卡片。
- **统计（stats）**：牌组总数、到期数、新卡数。
- 输入框为 CSV 牌组（每行 `正面,背面`），背面可含逗号。

## 局限

- 学习进度仅保存在页面内存中，刷新页面会重置；如需长期保存可用 JSON 导出（utils 的 `exportDeckJson`）。
