# 秒表

一个带计次（lap）功能的秒表：开始 / 暂停 / 复位 / 记录分段用时。

## 用途

跑步、煮面、限时任务……需要「从 0 开始往上数、并记下中间每一段用时」的场合。
全部在浏览器本地运行。

## 操作方式

| 按钮      | data-testid | 作用                                   |
| --------- | ----------- | -------------------------------------- |
| 开始/继续 | `sw-start`  | 从 0 或暂停处继续走动                  |
| 暂停      | `sw-pause`  | 冻结当前读数                           |
| 计次      | `sw-lap`    | 记录一个分段（显示该段用时与累计时间） |
| 复位      | `sw-reset`  | 清零并清空所有计次                     |

## 状态机

```
未开始(idle) ──开始──▶ 计时中(running) ──暂停──▶ 已暂停(paused)
                            │                        │
                            ├──计次──▶ 往计次列表追加一条
                            │
                            └────── 复位(任意状态) ──▶ 未开始(idle)
```

- 走动中每 10ms 刷新一次读数，显示到百分之一秒（`mm:ss.cs`）。
- 计次列表按时间倒序展示（最新一次在最上面）；「分段」= 本次累计 − 上次累计。
- 组件卸载（切选项、离开页面）时清除定时器，不会后台继续累加。

## 输出

右侧面板直接渲染秒表表盘与计次列表。本工具的「复制 / 下载」不产出内容（读数是实时的，文本快照意义不大）。

## 限制

- 基于浏览器 `setInterval(10ms)`，不是高精度计时；后台标签页会被浏览器节流。
- 不持久化刷新页面后的计时。
- 输入框仅为模板占位，不参与功能。

## 数据流向

**纯本地处理。** 毫秒格式化、分段计算都是纯函数（`utils.ts`），计时循环在组件内持有并随卸载清理。`meta.api = false`。
