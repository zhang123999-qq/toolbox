# 体积换算

输入数值并选择源/目标单位，把毫升、升、立方米、立方英寸、加仑、液盎司等体积/容积单位互相转换。

## 用途

- 烹饪 / 烘焙时换算美制与公制体积单位
- 把加仑、立方英尺等英制体积换成升或立方米
- 工程计算中统一体积单位

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待换算的数值，最大 200,000 字符 |

## 输出

```text
1 gal = 3.785411784 l
```

## 选项

| 选项   | 类型   | 说明                                                  |
| ------ | ------ | ----------------------------------------------------- |
| `from` | select | 源单位：`ml` `cm3` `l` `m3` `in3` `ft3` `gal` `fl-oz` |
| `to`   | select | 目标单位（同上）                                      |

## 算法

以**升（L）**为基准单位：

- `结果 = 输入 × 源单位换算因子 ÷ 目标单位换算因子`
- 换算因子：`ml`×0.001、`cm3`×0.001、`l`×1、`m3`×1000、`in3`×0.016387064、`ft3`×28.316846592、`gal`×3.785411784（美制加仑）、`fl-oz`×0.0295735295625（美制液盎司）
- 数字格式化：`Number(n.toPrecision(12)).toString()`（12 位有效数字，去浮点尾巴）

## 边界

- 空输入 → 输出空串
- 非法数字 → 中文报错「请输入有效的数字」
- 非法单位 id → 中文报错「未知单位」
- 输入 > 200,000 字符 → 报错

## 示例

输入 `1`，从 `gal` 到 `l`：

```text
1 gal = 3.785411784 l
```

## English

A volume/unit converter: enter a number and pick source/target units (ml, cm³, L, m³, in³, ft³, US gallons, US fluid ounces). Input: `text` (the numeric value). Output: e.g. `1 gal = 3.785411784 l`.
