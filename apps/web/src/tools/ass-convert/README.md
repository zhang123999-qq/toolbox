# ASS字幕转换

解析 ASS / SSA 字幕，转换为纯文本 / JSON / SRT / VTT / ASS，并支持时间轴整体偏移（毫秒，可为负）。

## 用途

ASS 是动漫、影视常用的高级字幕格式（含样式）：解析后可转 SRT 给播放器用、提取纯文本做翻译、整体平移时间轴对齐音画；ASS → ASS 可选择保留或丢弃样式段。

## 输入

| 字段   | 类型   | 约束 | 说明                     |
| ------ | ------ | ---- | ------------------------ |
| `text` | string | —    | 左侧文本区粘贴 ASS / SSA |

点「载入示例」可填入示例字幕直接试（含样式段）。

## 输出

| 字段   | 类型   | 说明                           |
| ------ | ------ | ------------------------------ |
| `text` | string | 转换后的字幕文本，可复制或下载 |

## 选项

| 选项         | 类型 | 默认 | 说明                                                         |
| ------------ | ---- | ---- | ------------------------------------------------------------ |
| `target`     | 下拉 | srt  | 目标格式：srt / vtt / txt（纯文本）/ json / ass              |
| `offsetMs`   | 数字 | 0    | 时间轴整体偏移（毫秒），可为负，负值钳制到 0                 |
| `keepStyles` | 开关 | 开   | ASS 输出时是否保留样式段（[V4+ Styles] 等），仅 ASS 目标有效 |

## 限制

- 通过 `[Events]` 的 `Format` 行定位 Start / End / Text 列，兼容列顺序变化与 SSA 的 `Marked=` 前缀
- Comment 等非 Dialogue 行会被跳过
- 空字幕、缺少 `[Events]` 段、非法时间戳都会给出中文错误提示
- 纯本地处理，不发任何请求

## 示例

```text
[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
Dialogue: 0,0:00:01.00,0:00:04.00,Default,,0,0,0,,你好，世界
```

转 SRT：

```text
1
00:00:01,000 --> 00:00:04,000
你好，世界
```

## 数据流向

**纯本地处理。** 解析与转换都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
