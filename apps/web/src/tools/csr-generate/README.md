# CSR 生成

在**浏览器本地**生成一对 RSA 密钥和一份 PKCS#10 证书签名请求（CSR / X.509 CSR），
用于向 CA（Let's Encrypt、DigiCert、内部 PKI 等）申请 TLS 证书。基于 `node-forge`，私钥不出本机。

## 用途

申请 HTTPS / 内网服务证书时，免装 OpenSSL：填好域名与组织信息，一键拿到可直接提交给 CA 的 CSR PEM；
需要时一并产出对应的 RSA 私钥。

## 输入 / 选项

主题信息都在选项里（左侧大文本框仅作触发）：

| 选项                               | 说明                                               |
| ---------------------------------- | -------------------------------------------------- |
| 通用名（CN）                       | 必填，主域名，如 `example.com`                     |
| 组织（O） / 部门（OU） / 国家（C） | 可选主题字段；国家必须为 2 位字母（自动转大写）    |
| 备用域名（SAN）                    | 逗号 / 换行分隔；域名走 DNS 项，IPv4/IPv6 走 IP 项 |
| 密钥长度                           | 2048 / 3072 / 4096（RSA，SHA-256 签名）            |
| 同时输出私钥                       | 勾选后在 CSR 后追加 `BEGIN RSA PRIVATE KEY`        |

## 输出

| 字段   | 类型   | 说明                                                |
| ------ | ------ | --------------------------------------------------- |
| `text` | string | `-----BEGIN CERTIFICATE REQUEST-----` PEM，可选私钥 |

## 安全说明

- 密钥对在浏览器内通过 `node-forge` 现场生成，**全程不发网络请求、不写入任何服务端**
- 「同时输出私钥」时请妥善保管输出内容：私钥一旦泄露，对应证书的安全性即失效；生产环境更推荐在受控主机上用 HSM / KMS 管理私钥
- 本工具只生成 CSR 与自有用私钥，**不签发证书**（CA 才会签发）

## 限制

- 仅 RSA + SHA-256；不支持 ECDSA / Ed25519、自定义扩展（除 SAN）、 challenge 密码、属性证书等高级项
- 私钥输出为 PKCS#1 `RSA PRIVATE KEY`（未加密 PEM）；不提供 PKCS#8 转换或口令加密
- 4096 位在低性能设备上生成可能需要数秒

## 数据流向

**纯本地处理。** 主题信息与私钥仅存在于浏览器内存，不发送网络请求。`meta.api = false`。
