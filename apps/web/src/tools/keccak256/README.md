# Keccak-256 哈希（#694）

计算 Keccak-256 摘要：以太坊使用的哈希函数（FIPS 202、Keccak padding `0x01`），纯 JS 实现，无外部依赖。

## 输入

- **文本模式**：按 UTF-8 编码后哈希。
- **hex 模式**：偶数位十六进制（可带 `0x` 前缀），直接按字节哈希。

## 输出

- **hex**：64 位小写十六进制。
- **Base64**：44 字符（含 `=` 填充）。

## 说明

- 注意 Keccak-256 ≠ NIST SHA3-256：二者仅 padding 不同（`0x01` vs `0x06`），摘要完全不同；以太坊地址、交易哈希用的都是 Keccak-256。
- 已用空串 / `abc` / `hello` / `hello world` 四组独立向量验证。
- 纯前端计算，输入不离开浏览器。
