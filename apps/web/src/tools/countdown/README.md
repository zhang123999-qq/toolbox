# 倒数日

输入一个目标日期时间（可选标题、可选开始日期），算出还剩多久到目标；如果目标已过，则显示已经过去多久。给了开始日期还能算进度百分比。

## 用途

- 等发版、等考试、等假期、等交房
- 把「还有 X 天 X 小时」换算成天 + HH:mm:ss
- 给一段周期（开始 → 目标）算当前进度百分比

## 输入

| 字段    | 类型   | 约束                            |
| ------- | ------ | ------------------------------- |
| `text`  | string | 目标日期时间，最大 200,000 字符 |
| `textB` | string | 开始日期时间（可选，算进度用）  |

格式：`YYYY-MM-DD HH:mm:ss`、`YYYY/MM/DD HH:mm`，或带 T/Z 的 ISO 串。

## 选项

| 选项 key | 界面标签 | 类型 | 默认     |
| -------- | -------- | ---- | -------- |
| `title`  | 标题     | 文本 | `倒数日` |

## 输出

未开始：

```text
标题：发版上线
目标：2027-01-01 00:00:00
状态：未开始
剩余：95 天 03:12:44
开始：2026-09-01 00:00:00
进度：26.31%
```

已过期：

```text
标题：deadline
目标：2020-01-01 00:00:00
状态：已过期
已过去：2472 天 05:12:33
```

## 算法

- 剩余 / 已过去 = `|目标 - 现在|` 毫秒差，拆成天 + HH:mm:ss。
- 进度百分比 = `(现在 - 开始) / (目标 - 开始) × 100%`，夹到 [0, 100]。
- 目标 == 现在 → 显示「就是现在」。

## 边界

- 目标在未来 → 状态「未开始」+ 剩余
- 目标在过去 → 状态「已过期」+ 已过去
- 不给开始日期 → 不输出进度行
- 开始日期不早于目标日期 → 提示「无法计算百分比」
- 越界日期 / 时间（2-30、25:00）→ 中文报错
- 倒计时为静态快照（打开页面算一次），不每秒跳动

## 示例

目标：`2027-01-01 00:00:00`，开始：`2020-01-01 00:00:00`

输出会显示从 2020 到 2027 这七年周期里当前走到了百分之多少。
