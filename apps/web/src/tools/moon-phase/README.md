# 月相查询

输入一个日期，输出该日的月龄、照明比例、月相名，以及下一次满月 / 新月的日期。
基于朔望月的线性外推，纯本地计算。

## 用途

查某天晚上月亮是新月还是满月、亮了几成，便于观月、拍摄夜景或安排户外行程。

## 输入

| 字段   | 类型   | 约束                                                      |
| ------ | ------ | --------------------------------------------------------- |
| `text` | string | 一个日期 `YYYY-MM-DD`（支持 `/` 分隔），最大 200,000 字符 |

空输入返回空串；非法日期（如 2 月 30 日）中文报错。

## 输出

```text
日期：2025-10-06
月龄：13.51 天（0–29.53）
照明比例：98.2%
月相：满月
下一次满月：2025-10-07
下一次新月：2025-10-22
```

| 字段     | 说明                                                                  |
| -------- | --------------------------------------------------------------------- |
| 月龄     | 距上一次新月的天数，范围 0 ~ 29.53                                    |
| 照明比例 | 月亮被太阳照亮的视面积百分比，0% = 新月，100% = 满月                  |
| 月相     | 八相：新月 / 蛾眉月 / 上弦月 / 盈凸月 / 满月 / 亏凸月 / 下弦月 / 残月 |

## 算法与精度

- **基准新月**：2000-01-06 18:14 UTC
- **朔望月**：29.530588853 天（平均会合周期）
- 月龄 `age = (目标日 − 基准新月) mod 朔望月`
- 照明比例 `= (1 − cos(2π·age/朔望月)) / 2`

**精度限制**：

- 按需求**精度到天即可**；线性外推在数百年尺度内月龄误差约 0.1~0.5 天，照明比例误差 < 5%
- 不做月球轨道扰动（出差方程、中心差高阶项）修正，因此与天文台时刻可能有半天级偏差
- 日期按 **UTC** 折算；下一次满月 / 新月只给出日期，不带时刻

## 数据流向

**纯本地处理。** 不发送任何网络请求，`meta.api = false`。

## 示例

输入：

```text
2025-10-06
```

输出：

```text
日期：2025-10-06
月龄：13.51 天（0–29.53）
照明比例：98.2%
月相：满月
下一次满月：2025-10-07
下一次新月：2025-10-22
```
