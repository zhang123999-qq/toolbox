# YAML 转 JSON

YAML 与 JSON 双向互转，保留类型与嵌套结构。

## 用途

把 Kubernetes / CI / 各类配置里的 YAML 转成 JSON 交给程序消费，或反过来把 JSON 转成更易读写的 YAML。
YAML 解析失败时给出带行列位置的中文提示，直接跳到出错行。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 转换后的 JSON / YAML；空输入返回空串 |

## 选项

| 选项        | 取值                      | 默认        | 说明                           |
| ----------- | ------------------------- | ----------- | ------------------------------ |
| `direction` | `yaml2json` / `json2yaml` | `yaml2json` | 转换方向                       |
| `indent`    | `2` / `4`                 | `2`         | 输出缩进档位（两个方向都生效） |

## 支持范围

- 块映射、任意深度嵌套、块序列、`- k: v` 形式的序列项
- 流式集合 `[1, 2]`、`{a: 1}`（**必须写在同一行内**）
- 标量：裸标量、单 / 双引号（含 `\n` `\t` `\uXXXX` 转义）、`~` / `null`、`true` / `false`
- 数字：十进制、`0x` / `0o` / `0b`、浮点、科学计数法、下划线分隔
- 块标量 `|` / `>`（含 `-` / `+` chomping，折叠标量按简化规则处理）
- 纯标量跨行续写

## 限制

- **注释会丢失**：JSON 没有注释语法，YAML → JSON 时行尾 / 整行注释被丢弃
- **不支持多文档**：出现第二个 `---` 或在内容之后出现 `---` 会报错
- **不支持锚点 / 别名 / 合并键**（`&a`、`*a`、`<<`）
- **不支持显式标签**（`!!str` 之外的自定义 `!tag` 同样不支持）
- **不支持复杂键**（`? key`）、跨行流式集合、跨行引号标量
- **不支持 Tab 缩进**，会明确报错提示改用空格
- 日期时间（`2024-01-01`）按字符串输出，不转时间戳
- 数字超 `Number.MAX_SAFE_INTEGER` 时按双精度处理，可能丢失末位精度
- JSON → YAML 时，空数组 / 空对象输出为 `[]` / `{}`；键名含特殊字符时自动加引号
- JSON → YAML 时不生成流式集合与块标量：含换行的字符串一律写成带 `\n` 的双引号标量

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（YAML）：

```yaml
name: 工具库
port: 8080
debug: false
tags:
  - yaml
  - json
```

输出（JSON，`indent = 2`）：

```json
{
  "name": "工具库",
  "port": 8080,
  "debug": false,
  "tags": ["yaml", "json"]
}
```

（实际输出中数组逐行展开，与 `JSON.stringify(_, null, 2)` 一致）
