# 数据过滤（#689）

按多条件过滤 CSV 数据：12 种运算符，条件之间支持 AND / OR，输出过滤后的表格并可导出 CSV。

## 输入

- **CSV**（主输入框）：首行为表头。留空用内置示例。
- **过滤条件**（附加输入框）：每行一条，格式 `列名 运算符 值`，如：

```
年龄 > 30
城市 包含 海
备注 不为空
```

## 运算符

`=`, `!=`, `>`, `>=`, `<`, `<=`, `包含`, `不包含`, `开头`, `结尾`, `为空`, `不为空`

- 数值比较是数字感知的：`9 < 10` 按数值成立（而非字符串比较）。
- `为空` / `不为空` 不需要写值。
- 列名与值内部可以含空格（按空白分词后取第一段为列名、运算符后全部为值）。

## 条件关系

选项 `条件关系` 填 `AND`（默认）或 `OR`：AND 要求全部条件命中，OR 任一命中即可。

## 说明

- 纯前端实现，数据不离开浏览器。
- 条件引用不存在的列会明确报错。
