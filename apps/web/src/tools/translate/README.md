# 翻译

多语言翻译。

## 用途

把一段文本翻成另一种语言：中英日韩法德西俄互翻，源语言可自动识别——适合翻文档、翻邮件、翻评论。

## 输入

| 字段      | 类型   | 约束                                   |
| --------- | ------ | -------------------------------------- |
| `text`    | string | 最大 20,000 字符                       |
| `apiBase` | string | 接口地址（Base URL），最大 20,000 字符 |
| `apiKey`  | string | API Key，最大 20,000 字符              |
| `model`   | string | 模型名，最大 20,000 字符               |

待翻译文本 + 接口信息（接口地址、API Key、模型名）。

## 输出

| 字段   | 类型   | 说明             |
| ------ | ------ | ---------------- |
| `text` | string | 模型返回的译文。 |

## 选项

| 选项     | 取值                                                           | 默认   | 说明                      |
| -------- | -------------------------------------------------------------- | ------ | ------------------------- |
| `source` | `auto` / `zh` / `en` / `ja` / `ko` / `fr` / `de` / `es` / `ru` | `auto` | 源语言，auto 交给模型识别 |
| `target` | `en` / `zh` / `ja` / `ko` / `fr` / `de` / `es` / `ru`          | `en`   | 目标语言                  |

## 限制

- **需要自备 OpenAI 兼容接口**，本工具不内置任何模型与额度
- 译文质量取决于你接入的模型，专有名词、术语、代码建议人工复核
- 不是术语表驱动的翻译：同一段文本多次翻译可能不一致，也不保证术语统一
- 长文本可能被模型截断，超长内容请分段翻译
- 输入上限 20,000 字符

## 数据流向

**会向外部接口发送数据。** 本工具需要你自备大模型接口（OpenAI 兼容的 `/chat/completions`）：

- 请求由**浏览器直接**发往你填写的接口地址，**不经本项目任何服务器**
- 发送内容：待处理的正文 + 一段指令（prompt），以及你填的模型名
- 凭据：API Key 放在 `Authorization` 请求头里，只存在于当前页面的输入框中，
  **不写入 localStorage**，也不会随页面分享带走
- 超时 60 秒；返回结构按 OpenAI 的 `choices[0].message.content` 解析

`meta.api = true`。没填接口信息就点运行时，工具会给出缺项提示而不会发请求。

## 示例

输入：

```text
这是一段需要翻译的中文文本，用来验证翻译工具的效果。
```

输出：

```text
（由你接入的模型返回，此处不预设内容）
```
