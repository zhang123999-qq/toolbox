# 中英文字数

区分中文字符与英文单词分别计数。

## 用途

中英混排稿件的字数核算：中文按字符、英文按单词，避免用一种口径套两种语言。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本，中英混排均可。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                                             |
| ------ | ------ | ---------------------------------------------------------------- |
| `text` | string | 分类计数：中文字符、英文单词、数字、标点、空白、其他、合计字符。 |

## 选项

该工具无选项。

## 限制

- 「中文字符」含 CJK 表意文字与日文假名，不含中文标点
- 英文按连续字母串计为一个单词，带撇号或连字符的（如 don’t）仍算一个
- 数字按单个数字字符计数，「870」记为 3
- 未被前几类归中的字符（如 emoji、拉丁字母以外的符号）计入「其他」

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具库 toolbox 870
```

输出：

```text
Toolbox 是一个工具库，共有 870 个工具。
```
