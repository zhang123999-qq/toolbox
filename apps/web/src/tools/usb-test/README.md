# USB 测试（USB Test）

全局编号：#869｜域：教育趣味｜优先级：P3｜可行性：C（Web API）

## 功能

- **检测能力**：判断当前浏览器是否支持 WebUSB
- **请求 USB 设备**：弹出浏览器设备选择器，选择后展示设备名与厂商/产品 ID（十六进制，如 0x2341:0x0043）
- **列出已授权设备**：展示已授权的 USB 设备（未授权时如实提示空列表）

## 注意事项

- 需要 **HTTPS** 环境，并在**用户手势**（点击按钮）中调用
- 仅 Chrome / Edge 等支持 WebUSB 的浏览器可用
- 仅列出已授权的设备；用户取消选择时显示浏览器返回的错误
- 本工具仅做能力检测与设备列出，不读写设备数据
