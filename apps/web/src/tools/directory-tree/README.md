# 目录树生成

选择本地文件夹，生成树形目录结构文本。

## 用途

写 README 要贴项目结构、给别人描述代码布局时，一键生成标准的 `tree` 风格文本。

## 输入

| 字段   | 类型   | 约束       | 说明                                       |
| ------ | ------ | ---------- | ------------------------------------------ |
| `file` | File[] | 文件夹多选 | 通过文件夹选择入口选取，**只读路径不上传** |

浏览器出于安全只暴露相对路径（`webkitRelativePath`），文件内容不会被读取。

## 输出

| 字段   | 类型   | 说明                       |
| ------ | ------ | -------------------------- |
| `text` | string | 树形目录文本，可复制或下载 |

## 选项

| 选项         | 取值               | 默认       | 说明                     |
| ------------ | ------------------ | ---------- | ------------------------ |
| `maxDepth`   | 1–20               | 8          | 最大展示深度，超深打 `…` |
| `showHidden` | boolean            | false      | 显示 `.git` 等隐藏文件   |
| `sortMode`   | dirs-first / alpha | dirs-first | 目录优先 / 纯字母排序    |

## 限制

- 单次最多 50000 个文件；空文件夹中文提示
- 隐藏文件默认过滤，全是隐藏文件时提示打开开关
- 全程本地处理

## 数据流向

**纯本地处理。** 只读文件名路径，不读文件内容，`meta.api = false`，无需自备 API/Key。

## 示例

输入：示例文件夹 `demo`。

输出：

```text
目录树：2 个目录，4 个文件

demo/
├── README.md
├── docs/
│   └── guide.md
└── src/
    ├── index.ts
    └── util.ts
```
