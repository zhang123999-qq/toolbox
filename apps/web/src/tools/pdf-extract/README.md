# PDF 文本提取

上传 PDF 文件，按页提取全部文本：行按 y 坐标重组、页之间加「第 N 页」分隔，
纯本地解析后可直接复制。

## 用途

论文、合同、电子书的文本摘取；提取结果可再粘贴到翻译、摘要工具。

## 输入

| 字段   | 类型 | 约束               | 说明                       |
| ------ | ---- | ------------------ | -------------------------- |
| `file` | File | ≤ 100 MiB，≤ 50 页 | 左下「选择文件」上传的 PDF |

非 PDF、空文件、超 100 MiB、超 50 页都会给出中文错误并拒绝处理；
加密 PDF 提示先去除密码；损坏文件提示检查后重试。

## 输出

| 字段   | 类型   | 说明                       |
| ------ | ------ | -------------------------- |
| `text` | string | 提取的文本，多页时加页分隔 |

单页直接返回文本；多页格式为：

```text
--- 第 1 页 ---
第一页的文本……

--- 第 2 页 ---
第二页的文本……
```

## 选项

无。

## 限制

- **本工具是 14 个工具中唯一不使用 pdf-lib 的**：文本提取用 `pdfjs-dist`（见 meta `deps`），
  worker 通过 `pdfjs-dist/build/pdf.worker.min.mjs?url` 加载。
- 扫描件（图片型 PDF）没有可提取的文本层，会提示「可能是扫描件」；
  如需识别图片文字请用 OCR 类工具。
- 复杂排版（多栏、表格）的行顺序按坐标启发式重组，可能与视觉顺序有出入。
- 提取结果不保留字体、颜色、图片。
- 文件全程在浏览器内存里解析，不发任何请求。

## 数据流向

**纯本地处理。** PDF 文件与提取文本都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

上传一份 2 页 PDF → 输出区显示：

```text
--- 第 1 页 ---
Hello World

--- 第 2 页 ---
Second
```
