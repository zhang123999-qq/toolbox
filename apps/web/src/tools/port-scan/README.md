# 端口扫描

按目标主机、端口范围与扫描类型，生成可复制到终端执行的 **nmap / nc / PowerShell / bash** 端口扫描命令，并解释端口状态。

## 用途

排查「某台服务器的某个端口通不通」「服务有没有对外暴露」时，最直接的办法就是端口扫描。
但**浏览器沙箱不允许网页发起任意 TCP / SYN / UDP 连接**——这是刻意的安全限制，
所以本工具**不做任何真实扫描**，只替你把命令拼好，你贴到自己的终端里跑。

## 输入

| 字段   | 类型   | 约束                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 目标主机名或 IPv4，最大 200,000 字符 |

填入目标，如 `192.168.1.1`、`example.com`。留空不产出任何内容。

## 输出

| 字段   | 类型   | 说明                                                 |
| ------ | ------ | ---------------------------------------------------- |
| `text` | string | 四种环境的命令块 + 端口状态说明 + 常见端口服务速查表 |

```text
# 浏览器无法发起真实 TCP/UDP 扫描 —— 以下为可复制到本机终端执行的命令
## nmap
nmap -sT -p 1-1000 -sV example.com
## nc
for p in $(seq 1 1000); do nc -zv -w 2 example.com $p; done
…
```

## 选项

| 选项 key   | 界面标签 | 取值 / 说明                                                          |
| ---------- | -------- | -------------------------------------------------------------------- |
| `ports`    | 端口范围 | nmap `-p` 实参，如 `1-1000` 或 `22,80,443`；端口须在 1-65535         |
| `scanType` | 扫描类型 | `connect`=TCP 全连接(`-sT`)、`syn`=SYN 半开(`-sS`)、`udp`=UDP(`-sU`) |
| `speed`    | 速度     | `slow`=`-T2`、`normal`=`-T3`（默认）、`fast`=`-T4`                   |

## 各命令说明

- **nmap**：功能最全。`-sV` 顺带探测端口上跑的是什么服务；`-sS`/`-sU` 需要 root/sudo；
  对大批量端口建议加 `--open` 只看开放的
- **nc / netcat**：系统里往往没有 nmap 但有 nc；`-z` 只探测不发数据、`-w 2` 超时 2 秒
- **PowerShell**：Windows 自带 `Test-NetConnection`，不用装任何东西
- **bash /dev/tcp**：连 nc 都没有时，bash 内置的 `/dev/tcp` 伪设备也能做 TCP connect 探测

## 端口状态含义

- **open**：有应用正在监听并接受连接
- **closed**：主机可达但该端口无应用监听（收到 RST），常用来判断主机是否存活
- **filtered**：防火墙 / ACL 丢弃了探测包，无法判断；换 `-sS` 或加 `--reason` 复核

## 限制（浏览器边界，必须诚实说明）

- **本工具不发起任何网络请求、不做真实扫描**。浏览器没有任意 TCP 套接字能力，
  `fetch` / `WebSocket` 都受同源与协议限制，无法等价 nmap
- 生成的命令需要你在**自己有权限的机器**上运行；`-sS`/`-sU` 多数系统要求 root
- 扫描别人的主机前请确保已获得授权；未经许可的端口扫描在很多司法辖区可能违法
- 不解析 nmap 输出，也不做端口服务指纹识别
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 纯字符串拼接，不发送任何网络请求。`meta.api = false`，无需 API/Key。

## 示例

输入：

```text
example.com
```

选项：端口范围 `22,80,443`，扫描类型 `connect`，速度 `normal`。

输出（节选）：

```text
## nmap（功能最全，推荐）
nmap -sT -p 22,80,443 -sV example.com

## nc / netcat
for p in 22 80 443; do nc -zv -w 2 example.com $p; done
```
