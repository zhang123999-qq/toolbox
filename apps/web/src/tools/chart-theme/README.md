# 图表主题（#687）

定制 ECharts 主题：背景色、主色板、字体、标题字号，实时预览并导出可注册的主题 JSON。

## 输入

- **预览标题**（主输入框）：预览图表的标题，留空则无标题。
- **背景色**：`#RGB` 或 `#RRGGBB`，如 `#ffffff`。
- **主色板**：逗号分隔的 hex 颜色，1–12 个，如 `#5470c6,#91cc75,#fac858`。
- **字体**：CSS 字体族，如 `sans-serif`、`PingFang SC`。
- **标题字号**：10–48 的整数。

留空的选项使用默认值（白底 / 默认 5 色板 / sans-serif / 18px）。

## 输出

- 主题预览图（柱状 + 折线示例，颜色取自你的色板）。
- 主题 JSON：可直接 `echarts.init(dom, theme)` 使用，或 `echarts.registerTheme('myTheme', theme)` 注册后复用。

## 示例

背景色 `#1a1a2e`、色板 `#e94560,#0f3460,#16213e` 即得到暗色主题。
