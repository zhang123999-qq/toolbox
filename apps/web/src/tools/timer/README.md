# 计时器

输入一段时长（时 / 分 / 秒），做倒计时；支持开始、暂停、复位，时间到给出提示。

## 用途

做菜、冥想、限时刷题、煮蛋……需要一个「从某个时长往下数到 0」的小工具。
全部在浏览器本地运行，不写服务端、不发请求。

## 操作方式

1. 在左侧输入框填写时长（写法见下）。
2. 点「开始」从该时长往下数；运行中可「暂停」继续，或「复位」回到设定时长。
3. 数到 0 后状态变为「时间到」。

| 按钮      | data-testid   | 作用                        |
| --------- | ------------- | --------------------------- |
| 开始/继续 | `timer-start` | 从剩余时间开始 / 继续倒计时 |
| 暂停      | `timer-pause` | 冻结当前剩余时间            |
| 复位      | `timer-reset` | 回到设定时长，状态为就绪    |

## 状态机

```
就绪(idle) ──开始──▶ 计时中(running) ──暂停──▶ 已暂停(paused)
   ▲                    │  │                       │
   │                    │  └───── 剩余=0 ─────▶ 时间到(done)
   │                    │                       │
   └──────────────── 复位(任意状态) ◀────────────┘
```

- 运行中每秒减 1；减到 0 自动进入「时间到」。
- 运行中修改左侧时长不会打断当前倒计时；只有在「就绪 / 时间到」状态才跟随新时长复位。
- 组件卸载（切选项、离开页面）时会清除定时器，不会后台继续跑。

## 输入时长格式

| 写法       | 含义       | 示例      |
| ---------- | ---------- | --------- |
| `秒`       | 纯秒数     | `90`      |
| `分:秒`    | 分和秒     | `1:30`    |
| `时:分:秒` | 时、分、秒 | `1:30:00` |

约束：必须为非负整数；时长大于 0；不超过 24 小时。

## 输出

右侧面板直接渲染倒计时表盘（大字号 `MM:SS` 或 `H:MM:SS`）。
「复制 / 下载」拿到的是当前设定时长的文本摘要，例如：

```text
倒计时：1 小时 30 分钟（共 5400 秒）
```

## 限制

- 精度为 1 秒（浏览器 `setInterval(1000)`），不做毫秒级。
- 不播放提示音，只在界面上把状态切到「时间到」。
- 输入上限 200,000 字符；非法格式中文报错。

## 数据流向

**纯本地处理。** 时长解析、格式化、状态转移都是纯函数（`utils.ts`），定时器在组件内持有并随卸载清理。`meta.api = false`。
