# CORS 检测

把一段 HTTP **响应头**（`curl -I`、浏览器 DevTools Network 里复制）粘进来，离线分析
CORS（跨源资源共享）配置是否正确、是否存在安全风险，输出逐项结论与总评级。纯本地规则判断，不发网络请求。

## 用途

接口跨域调不通时，快速定位是缺了哪个 `Access-Control-*` 头；或在上线前检查 CORS 配置是否放得太宽
（通配符 + 凭据、回显 `null`、缺 `Vary: Origin` 等典型问题）。

## 输入

| 字段   | 类型   | 约束                                                  |
| ------ | ------ | ----------------------------------------------------- |
| `text` | string | 最大 200,000 字符；每行一个 `Name: value`，可含状态行 |

## 输出

一份 Markdown 报告：总评级（问题 / 风险 / 通过）+ 各等级计数 + 逐项明细。

## 检测项与规则

| 响应头                             | 主要判定                                                                                  |
| ---------------------------------- | ----------------------------------------------------------------------------------------- |
| `Access-Control-Allow-Origin`      | 无 → 提示（默认同源）；`*`+凭据 → **问题**；仅 `*` → 风险；`null` → 风险；具体来源 → 通过 |
| `Vary`                             | 按来源回显 ACAO 却不含 `Origin` → 提示（缓存串味风险）                                    |
| `Access-Control-Allow-Credentials` | 与 `*` 同现的非法组合在 ACAO 项判为问题                                                   |
| `Access-Control-Allow-Methods`     | 有跨域头但缺该头 → 提示（预检可能失败）                                                   |
| `Access-Control-Allow-Headers`     | 缺失 → 提示；`*` 且带凭据 → 风险（不匹配 Authorization）                                  |
| `Access-Control-Expose-Headers`    | 缺失 → 提示（跨源 JS 读不到自定义响应头）                                                 |
| `Access-Control-Max-Age`           | 非非负整数 → 问题；否则给出缓存秒数                                                       |

## 与「实时 fetch 检测」的区别（重要）

规划中本工具为 D 级（浏览器 `fetch` 实测任意 URL）。实际落地改为**离线规则分析**，原因：

- 浏览器同源策略决定了页面脚本**无法稳定读取任意第三方站点的响应头**；预检是否通过、错误细节也受浏览器实现限制
- 直接 `fetch` 还会受目标站 CORS、混合内容、网络环境影响，结果不可复现、不可单测

因此本工具只分析你**粘贴进来的真实响应头**，结论确定可复现；它不替目标站发请求。

## 限制

- 静态规则判断，不模拟浏览器的完整预检（preflight）协商，也不判断请求方 Origin 是否在白名单内
- 不解析 `Cross-Origin-Resource-Policy`、`Cross-Origin-Opener-Policy` 等非 CORS 头
- 输入上限 200,000 字符；解析不到任何头时抛 `CorsCheckError`

## 数据流向

**纯本地处理。** 响应头仅在浏览器内存中分析，不发送网络请求，不写入服务端。`meta.api = false`。
