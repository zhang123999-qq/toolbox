# 元素周期表（#821）

A 级工具：纯前端本地数据查询，无网络、无第三方 API。

## 功能

- **查询模式（search）**：左侧输入元素符号（如 Fe，不区分大小写）、中文名（如 铁）、英文名（如 gold）或原子序数（如 26），输出该元素的符号、中英文名、原子序数、原子量、族、周期与分类；未知查询中文报错。
- **分类模式（category）**：右侧选择非金属 / 碱金属 / 碱土金属 / 过渡金属 / 贫金属 / 类金属 / 卤素 / 稀有气体 / 镧系 / 锕系，列出该分类全部元素。
- **复制 / 下载**：查询结果可复制或下载为 `.txt`。

## 说明

- 内置 118 种元素数据；人工合成元素原子量以方括号标注最稳定同位素质量数（如 `[294]`）。
- 镧系 / 锕系元素族显示为"镧系/锕系"（不适用主族编号）。
