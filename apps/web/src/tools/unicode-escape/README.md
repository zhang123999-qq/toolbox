# Unicode 转义

文本与 `\uXXXX` 转义序列互转，兼容 `\u{XXXXX}` 写法。

## 用途

把中文、emoji 等非 ASCII 字符写成纯 ASCII 的转义序列，便于塞进只认 ASCII 的
配置文件、日志格式或老式系统；反向则用于把源码、JSON dump、抓包结果里成片的
`\u4E2D` 还原成人能读的文字。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

转义时是任意文本（中英混排、emoji 均可）；还原时是含 `\u` 转义的字符串。

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 转义后为 `\uXXXX` 串；还原后为原文 |

## 选项

| 选项        | 取值              | 默认   | 说明       |
| ----------- | ----------------- | ------ | ---------- |
| `direction` | escape / unescape | escape | 转义或还原 |

## 限制

- 转义只动**非 ASCII**（码点 > 0x7F）字符，ASCII 一律原样保留；
  因此反斜杠 `\` 本身不会被转义——若原文里恰好写着 `\u4E2D` 这样的字面量，
  转义结果与「中」的转义结果无法区分，还原时会被当成转义序列
- 码点在 BMP 内输出四位 `\uXXXX`，超出 0xFFFF 的（如 emoji）输出 `\u{XXXXX}`；
  还原时两种写法都接受，也接受 `\uD83D\uDE80` 这种手工拼接的代理对
- 十六进制统一大写输出，还原时大小写均可识别
- 还原遇到形如 `\u` 但后面不是合法转义的片段会**报错**，不会静默保留半截原文

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
Toolbox 工具库
```

输出（escape）：

```text
Toolbox \u5DE5\u5177\u5E93
```
