# 音频格式转换

上传音频，用 ffmpeg.wasm 在浏览器本地转换为 MP3 / WAV / OGG / M4A / FLAC / AAC 格式。

## 用途

把录音、视频配乐等转成需要的格式：选好输出格式与比特率，试听确认后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                          |
| ------- | ------ | --------------------------------------------- |
| `audio` | 音频   | 转换后的音频（格式见选项），可试听并下载      |
| `text`  | string | 处理报告：输入 / 输出格式 / 比特率 / 输出大小 |

## 选项

| 选项          | 类型 | 默认 | 说明                                         |
| ------------- | ---- | ---- | -------------------------------------------- |
| `format`      | 下拉 | mp3  | 输出格式：mp3 / wav / ogg / m4a / flac / aac |
| `bitrateKbps` | 数字 | 192  | 比特率（kbps，32～512），仅有损格式有效      |

## 限制

- 比特率超出 32～512 范围会给出中文错误提示
- wav 用 16 位 PCM 编码，flac 为无损，两者忽略比特率选项
- ffmpeg.wasm 内核首次使用需从 CDN 下载（约几十 MB），之后缓存复用
- 文件全程留在浏览器内存里，不发任何请求（CDN 下载 wasm 内核除外）

## 示例

载入示例音频（4 秒 440Hz 正弦波），默认转 MP3 / 192 kbps：

```text
输入：示例-440Hz正弦波.wav
输出格式：MP3　比特率：192 kbps
输出大小：xx.x KB
```

## 数据流向

**纯本地处理。** 转码在浏览器内用 ffmpeg.wasm 完成，`meta.api = false`，无需自备 API/Key。
