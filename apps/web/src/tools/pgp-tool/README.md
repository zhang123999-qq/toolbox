# PGP 报文检查

粘贴一段 **OpenPGP ASCII Armor**（`-----BEGIN PGP ... -----`），离线解析它的结构：
报文类型、Armor 头字段、Radix64 体大小、**CRC24 完整性校验**，并逐个列出 OpenPGP packet
（签名包 / 公私钥包 / 用户 ID / 加密数据 …）及密钥包的版本、创建时间、算法。纯本地、零依赖。

> **与规划文档的偏差说明（重要）**：规划表（02-编码加密安全.md #112）设想依赖 `openpgp` 做
> 加解密、签名 / 验签、密钥生成。该库**未安装**，本仓库约束零新增网络依赖；而用纯 TS 自行实现
> 完整 OpenPGP 密码体系（CFB 流加密、S2K 密钥派生、签名验证等）既不安全也不现实。因此本工具
> **只做「结构 / 完整性检查」，不执行任何加解密、签名、验签或密钥生成**。真正的加解密请使用
> GnuPG（`gpg`）、Sequoia-PGP 或 openpgp.js 等成熟实现。

## 用途

- 辨认一段 PGP 内容到底是什么（公钥 / 私钥 / 签名 / 加密报文 / 分离签名）
- 检查 armor 在复制粘贴后是否损坏（CRC24）
- 概览一把公钥里有哪些 packet、用什么算法（RSA / ECDSA / EdDSA）、何时创建、绑定了哪个 UID

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 最大 200,000 字符；一段或多段 Armor |

## 输出

中文文本：段数总览 → 每段的类型 / 头字段 / 体大小 / CRC24 → packet 列表（tag、名称、新老格式、长度；
密钥包附版本 / 算法 / 创建时间；UID 包附用户标识）。

## 支持的解析

- Radix64（base64）解码 + RFC 4880 §6.1 CRC24 校验
- 新旧两种 packet 头格式、多字节长度（含 partial 长度的收尾处理）
- 常见 packet tag 名称与密钥算法 OID（RSA / DSA / ElGamal / ECDH / ECDSA / EdDSA）

## 限制

- **不做加解密 / 签名 / 验签 / 密钥生成**（见上方偏差说明），不校验签名正确性、不推导指纹 / Key ID
- 只解析 packet「头部」与少量明文元数据（密钥版本、时间、算法、UID 文本）；不深入 MPI 密钥材料、
  用户属性图片、子钥绑定签名细节
- 不支持二进制（非 armor）`.gpg`、不处理对称加密体的内容；CRC 行缺失时标注「未提供」而非判错
- 解析到无法识别的 packet 结构时在该段给出错误说明并继续后续段

## 数据流向

**纯本地处理。** Armor 内容仅在浏览器内存中解析，不发送网络请求、不接触任何私钥口令。`meta.api = false`。
