# 中位数

求一组数字排序后的中位数（中间值），附个数与排序结果。

## 用途

- 看收入 / 房价等偏态数据的"中间水平"（不受极端值影响）
- 与平均数对照，判断数据是否偏斜

## 输入

| 字段   | 类型   | 约束                        |
| ------ | ------ | --------------------------- |
| `text` | string | 一组数字，最大 200,000 字符 |

分隔符：空白（空格 / 换行 / 制表符）、逗号 `,` `，`、分号 `;` `；`、顿号 `、`，可混用。

## 输出

```text
个数：8
排序后：1, 1, 2, 3, 4, 5, 6, 9
中位数：3.5
```

## 选项

| 选项       | 取值                               | 说明                       |
| ---------- | ---------------------------------- | -------------------------- |
| `decimals` | `0` / `1` / `2` / `4` / `6` / `10` | 结果保留小数位数，默认 `4` |

## 算法

- 排序后：奇数个取正中间，偶数个取中间两数之均值
- 排序展示超过 100 个时只显示首尾各 50 个并注明总数，避免输出爆炸

## 边界

- 非数字项 → 中文报错并指出该项
- 无有效数字 → 中文报错
- 输入 > 200,000 字符 → 报错

## 示例

输入 `3 1 4 1 5 9 2 6`：排序后 `1, 1, 2, 3, 4, 5, 6, 9`，中位数 `3.5`。

## 数据流向

纯前端本地计算，不调用外部接口、不上传数据。
