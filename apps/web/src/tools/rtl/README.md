# RTL 预览

输入文本，分析双向（bidi）方向：统计 LTR / RTL / 中性字符数，判定主导方向，标出方向混合的可疑位置；下方三栏按 `dir="rtl"` / `dir="ltr"` / `dir="auto"` 渲染同一文本，直观对照显示差异。

## 用途

- 检查阿拉伯语、希伯来语混排时的显示错乱
- 出海产品验证 RTL 地区文案的渲染效果
- 发现双向文本中的方向"污染"字符位置

## 输入

| 字段   | 类型   | 约束 |
| ------ | ------ | ---- |
| `text` | string | 文本 |

## 说明

- 纯本地分析，无网络请求。
- 强方向判定：RTL 取希伯来/阿拉伯及相关区段，LTR 取拉丁/希腊/西里尔/中日韩；数字、标点、空格、Emoji 视为中性。
- Unicode 双向算法的完整实现由浏览器负责，本工具做字符级统计与混合预警，不替代真实渲染测试。
