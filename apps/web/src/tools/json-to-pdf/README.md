# JSON 转 PDF

将 JSON 文本格式化打印（2 空格缩进）为等宽字体（Courier）的 A4 PDF，自动换行、自动分页，纯本地生成后下载。

## 用途

接口返回、配置文件的内容存档或打印，不经过任何服务器。

## 输入

| 字段   | 类型   | 约束              | 说明      |
| ------ | ------ | ----------------- | --------- |
| `text` | string | 最大 100,000 字符 | JSON 文本 |

输入必须是合法 JSON（对象、数组、字符串、数字、布尔、null 均可）；非法 JSON 会报错
「JSON 解析失败：请检查括号、引号、逗号是否配对完整」。

## 输出

| 字段   | 类型       | 说明                          |
| ------ | ---------- | ----------------------------- |
| `file` | PDF 二进制 | A4 纵向 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「下载」按钮下载的是 JSON 源文本（`.json`）。

## 选项

| 选项       | 取值         | 默认 | 说明         |
| ---------- | ------------ | ---- | ------------ |
| `fontSize` | 9 / 10 / 12  | 10   | 字号（pt）   |
| `margin`   | 36 / 54 / 72 | 54   | 页边距（pt） |

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，JSON 字符串值含中文时会直接报错，
  不会生成乱码 PDF。
- 超长行按词换行（不断词），续行不特殊缩进。
- 文件全程在浏览器内存里生成，不发任何请求。

## 数据流向

**纯本地处理。** 输入与生成的 PDF 都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```json
{ "name": "toolbox", "tools": 382 }
```

输出：A4 PDF（等宽 10pt，2 空格缩进）；输出区显示如 `已生成 PDF：1 页，2.2 KB`。
