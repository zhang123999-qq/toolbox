# CSV 格式化

CSV 对齐列宽、规范化引号，并校验每行列数是否一致。

## 用途

把挤在一起的 CSV 排成肉眼可读的表格；或反过来去掉多余引号、统一换行为 LF；
也可以只做体检，找出列数不一致的行（脏数据最常见的来源）。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 5,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                                             |
| ------ | ------ | ------------------------------------------------ |
| `text` | string | 对齐 / 规范化后的 CSV 或校验报告；空输入返回空串 |

## 选项

| 选项        | 取值                                   | 默认    | 说明                                 |
| ----------- | -------------------------------------- | ------- | ------------------------------------ |
| `mode`      | `align` / `minify` / `validate`        | `align` | 对齐列宽 / 规范化 / 只出校验报告     |
| `delimiter` | `comma` / `tab` / `semicolon` / `pipe` | `comma` | 分隔符                               |
| `strict`    | boolean                                | `false` | 列数不一致时直接抛错，而不是给出报告 |

## 三种模式

- `align`：每列补齐到该列最宽的显示宽度（中日韩全角字符按两格计算），便于阅读。
  注意补齐是在单元格后面加空格，**这种结果只适合看，不适合再当 CSV 解析**。
- `minify`：交给 papaparse 重新序列化，去掉不必要的引号，换行统一成 LF，并丢掉空行。
- `validate`：不输出表格，只输出校验报告：总行数、首行列数，以及每一处列数不一致的行号与实际列数。

## 限制

- 输入上限 5,000,000 字符，超出抛出 `CsvFormatterError`
- 列数一致性以**首行**为准
- 引号不配对的行无法解析，会直接抛错（papaparse 报 `Quotes` 错误）
- `minify` 只去掉「不必要的」引号，单元格内的前导 / 尾随空格属于数据，不会被改动

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```csv
name,tools,local
工具库,870,true
"含,逗号",1,false
```

输出（`mode=align`）：

```csv
name   ,tools,local
工具库 ,870  ,true
含,逗号,1    ,false
```

输出（`mode=validate`）：

```text
共 3 行，首行 3 列，列数全部一致 ✓
```
