# 音频降噪

上传音频，用 Web Audio API 解码，在浏览器本地做频谱减法降噪并导出为 WAV。

## 用途

给有底噪的录音（风扇声、电流声）降噪：按开头静音段估计噪声谱，谱减法去除后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                          |
| ------- | ------ | --------------------------------------------- |
| `audio` | WAV    | 降噪后的音频（16 位 PCM），可试听并下载       |
| `text`  | string | 处理报告：降噪方法 / 噪声段 / 参数 / 输出时长 |

## 选项

| 选项              | 类型 | 默认 | 说明                                                 |
| ----------------- | ---- | ---- | ---------------------------------------------------- |
| `noiseSeconds`    | 数字 | 0.5  | 噪声估计时长（秒，0.1～5），取开头静音段             |
| `oversubtraction` | 数字 | 2    | 过减因子（0.5～5），越大降噪越狠但越容易产生音乐噪声 |

## 限制

- 噪声估计时长超出 0.1～5 秒、过减因子超出 0.5～5 会给出中文错误提示
- 需要音频**开头有一段纯噪声**（建议 0.5 秒以上静音）作为噪声估计依据
- 降噪是折中：过减因子太大可能产生「音乐噪声」失真
- 不支持 Web Audio API 的旧浏览器会给出中文错误提示
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（4 秒：0.8 秒噪声 + 3.2 秒 440Hz 音）：

```text
输入：示例-噪声+440Hz.wav
降噪方法：频谱减法（STFT/WOLA）
噪声段：开头 0.5 秒　过减因子：2
输出时长：4.00 秒
```

## 数据流向

**纯本地处理。** 解码与降噪全在浏览器内完成，`meta.api = false`，无需自备 API/Key。
