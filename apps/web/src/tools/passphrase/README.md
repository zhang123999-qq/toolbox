# 密码短语

用内置词表生成易记的多词口令（passphrase / Diceware 风格）。

## 用途

「正确-马-电池-订书钉」这类由随机单词拼出来的口令，比 `aB3!x9` 好记得多，
但长度带来的熵反而更高，适合做主密码、密码管理器主口令、磁盘加密口令。
所有随机数来自浏览器的 `crypto.getRandomValues`（加密安全伪随机数发生器），生成过程完全在本地。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

**输入框只作触发用**，内容本身不参与生成：留空时不产出任何内容，
点「示例」或随手输入任意字符即生成一条短语；之后点「运行」可以再摇一条。

## 输出

| 字段   | 类型   | 说明                             |
| ------ | ------ | -------------------------------- |
| `text` | string | 一条密码短语，**每次结果都不同** |

## 选项

| 选项          | 取值                              | 默认   | 说明                                           |
| ------------- | --------------------------------- | ------ | ---------------------------------------------- |
| `words`       | 3 / 4 / 5 / 6                     | 4      | 单词个数                                       |
| `separator`   | hyphen / underscore / space / dot | hyphen | 依次产出 `-` `_` 空格 `.`                      |
| `noAmbiguous` | 勾选 / 取消                       | 取消   | 剔除含 `l` / `o` 的词（与 `1` / `0` 肉眼难分） |
| `uppercase`   | 勾选 / 取消                       | 取消   | 每个词首字母大写                               |

## 词表与熵估算

词表**内置**在 `utils.ts` 里，共 **256 个**常用英文短词（全小写、3~8 字母），
不依赖任何外部文件或网络请求，按数组下标等概率抽取：

| 词数 | 词池 256（每词 8 bit） | 勾选排除易混后词池 102（每词 ≈6.67 bit） |
| ---- | ---------------------- | ---------------------------------------- |
| 3    | 24 bit                 | 约 20 bit                                |
| 4    | 32 bit                 | 约 26.7 bit                              |
| 5    | 40 bit                 | 约 33.4 bit                              |
| 6    | 48 bit                 | 约 40 bit                                |

也就是说：**勾选「排除易混字符」会明显削弱强度**（词池从 256 掉到 102），
如果在意熵，请把词数提到 6，或不要勾选这一项。

## 限制

- 词表是英文单词，中文用户念起来不直观；也**不做**词典过滤，理论上可能抽出连续两个同形词
- 输入框内容**不参与**生成，只是为了适配 T2 双栏模板的交互（留空即不产出）
- 分隔符选 `space` 时得到的是一句带空格的短语，粘到只认无空格口令的地方要自行替换
- 短语不会自动复制：点「复制」按钮才写入剪贴板
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 随机数取自 `crypto.getRandomValues`，输入与结果都只在内存里，
不发送任何网络请求，不写入服务端。`meta.api = false`，无需自备 API/Key。

## 示例

输入（触发用）：

```text
generate
```

输出（4 词、`-` 分隔，**每次点「运行」都不一样**）：

```text
apple-apple-apple-apple
```

上面是把随机源换成「恒为 0」的确定性测试源时的结果（单测里的已知向量），
真实随机源下形态固定为 `^[a-z]{3,8}(-[a-z]{3,8}){3}$`。
