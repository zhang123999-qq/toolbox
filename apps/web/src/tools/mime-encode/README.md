# MIME 编码

RFC 2047 邮件头编码（Encoded-Word），支持 B / Q 两种模式。

## 用途

把含中文的主题、发件人、附件名编码成邮件头允许的 ASCII 形式（`=?UTF-8?B?...?=`），
或把收到的 `=?UTF-8?Q?...?=` 还原成可读文字。
用于排查邮件主题乱码、核对邮件网关是否正确处理 encoded-word、构造符合 RFC 的测试头。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

- 编码方向：任意的头部文本（如`工具库`、`会议纪要 2024`）
- 解码方向：含 encoded-word 的头部文本（可含折行）

## 输出

| 字段   | 类型   | 说明                                        |
| ------ | ------ | ------------------------------------------- |
| `text` | string | 编码方向输出 encoded-word；解码方向输出原文 |

## 选项

| 选项        | 取值                        | 默认   | 说明                                                |
| ----------- | --------------------------- | ------ | --------------------------------------------------- |
| `direction` | encode / decode             | encode | 编码或解码                                          |
| `charset`   | UTF-8 / GB2312 / ISO-8859-1 | UTF-8  | 写进 encoded-word 的字符集标签                      |
| `mode`      | B / Q                       | B      | B = base64；Q = quoted-printable 变体（空格写 `_`） |

## 限制

- **只有输入含非 ASCII 字符时才编码**；纯 ASCII 头按 RFC 原样输出（超过 76 字符时在空白处折行）
- 字节一律按 **UTF-8** 产出，`charset` 选项只决定写进 `=?…?` 的标签：
  浏览器只有 `TextEncoder`（仅支持 UTF-8），没有 GB2312 的编码表；
  若你确实需要 GB2312 的真实字节，属于「需要码表」的场景，本工具不做（不产出错误字节）
- 解码时先按 UTF-8 试解，失败再按声明的字符集试解（所以能还原 latin1 之类的外部邮件头）
- 单个 encoded-word 严格不超过 75 字符（RFC 2047 §2），过长内容自动拆成多个；
  超长时用 CRLF + 空格折行
- 按 RFC 2047 §6.2，两个相邻 encoded-word 之间的空白在还原时会被丢弃
- 解码方向对「没有 encoded-word 的输入」原样返回（这不是错误）；但 encoded-word 内部数据非法会明确报错

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（默认选项：encode / UTF-8 / B）：

```text
工具库
```

输出：

```text
=?UTF-8?B?5bel5YW35bqT?=
```

其他实算结果：

| 输入                       | 选项               | 输出                                      |
| -------------------------- | ------------------ | ----------------------------------------- |
| `工具库`                   | encode / UTF-8 / Q | `=?UTF-8?Q?=E5=B7=A5=E5=85=B7=E5=BA=93?=` |
| `a 中`                     | encode / UTF-8 / Q | `=?UTF-8?Q?a_=E4=B8=AD?=`                 |
| `Hello World`              | encode / UTF-8 / B | `Hello World`（纯 ASCII 原样输出）        |
| `中_?`                     | encode / UTF-8 / Q | `=?UTF-8?Q?=E4=B8=AD=5F=3F?=`             |
| `=?UTF-8?B?5bel5YW35bqT?=` | decode             | `工具库`                                  |
