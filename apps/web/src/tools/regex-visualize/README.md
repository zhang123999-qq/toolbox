# 正则可视化

把一段正则表达式画成 **SVG 铁路图（railroad diagram）** 源码。自研解析 + 布局，
不依赖 regexper 等第三方包。

## 用途

正则写长了很难一眼看清「到底哪些分支、哪些是可选、哪里回环」。
铁路图用流水线的方式把语法结构摊开：盒子是一个元素，上下并排是选择，
上方蓝色回环是重复量词。本工具输出 SVG 标记文本，可直接保存为 `.svg` 打开查看。

## 输入

| 字段   | 类型   | 约束              | 说明                         |
| ------ | ------ | ----------------- | ---------------------------- |
| `text` | string | 最大 200,000 字符 | 正则表达式主体（不含 flags） |

## 输出

| 字段   | 类型   | 说明                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 合法的 SVG 文档源码（文本形式） |

```svg
<svg xmlns="http://www.w3.org/2000/svg" …>
  …绿色 start 胶囊 → 字面量盒 → 蓝色量词回环 → 红色 end 胶囊…
</svg>
```

## 支持的语法子集

| 结构   | 示例                             | 图中表现                    |
| ------ | -------------------------------- | --------------------------- |
| 字面量 | `a`                              | 白色圆角盒                  |
| 字符类 | `[0-9]`、`\d`                    | 黄色圆角盒                  |
| 锚点   | `^`、`$`                         | 紫色圆角盒                  |
| 连接   | `ab`                             | 盒子横向串联                |
| 选择   | `a\|b`                           | 上下两条分支 + 左右垂直母线 |
| 分组   | `(ab)`、`(?:…)`、`(?<n>…)`       | 内嵌子图                    |
| 量词   | `?` `*` `+` `{n}` `{n,}` `{n,m}` | 上方蓝色回环 + 量词标签     |

## 实现规则 / 算法

1. **递归下降解析**：`parseAlt → parseSeq → parseBase → parseQuant`，产出 AST
2. **自底向上布局**：每个节点返回 `{svg, w, h}`，轨道固定在垂直中线；
   串联横向排列、选择竖向堆叠用量线汇接、量词在上方画回环路径
3. **XML 转义**：盒内文本经 `& < >` 转义后写入 `<text>`
4. 不支持反向引用 `\1`、前瞻后顾 `(?=)` `(?<=)`、具名回溯等高级特性，遇到即报错

## 浏览器边界与限制

- 输出是 **SVG 源码文本**（在 `<pre>` 中展示），不是渲染后的图片；可复制存成 `.svg`
- 布局为固定宽度启发式（按字符数估算盒宽），超长正则可能溢出画布
- 不做灾难性回溯防护（本工具只解析不执行）
- 空输入不产出内容；非法正则抛中文错误

## 数据流向

**纯本地处理。** 自研解析与 SVG 拼接，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
(https?://)?[\w.-]+(:\d+)?
```

输出（节选）：以绿色 `start` 起，依次为可选 `https?://` 分组回环、
`[\w.-]+` 字符类回环、可选端口分组回环，最后接到红色 `end`。
