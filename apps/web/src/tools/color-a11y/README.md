# 颜色无障碍

颜色无障碍检查：用 Machado 风格矩阵模拟红/绿/蓝/全四种色盲下的颜色，在每种视觉模型下分别计算前景与背景的对比度；四种模型全部达到 WCAG AA（4.5:1）才判定色盲安全，并输出模拟色板。

## 用途

- 检查按钮/文字配色对色盲用户是否可读
- 找出哪种色盲类型下对比度会跌破 AA
- 对比普通人群与色盲人群的感知差异

## 输入

| 字段   | 类型   | 约束                        |
| ------ | ------ | --------------------------- |
| `text` | string | 前景色（#rrggbb / 颜色名）  |
| `bg`   | string | 背景色（#rrggbb / 颜色名）  |

## 说明

- 纯本地计算，无网络请求。
- 本工具做的是**色盲模拟 + 判定**，与 #716「WCAG 对比度」只算普通对比度不同。
- 使用仓库已有的 `culori` 解析颜色，未新增依赖。
