# GraphQL 格式化

把压缩在一行的 GraphQL 查询 / 变更 / 订阅，或 SDL（Schema Definition Language）美化成
统一缩进、换行的可读形式。纯本地词法 + 排版，不依赖 `graphql` / `prettier` 等库。

## 用途

阅读或提交压缩的 GraphQL 文档、调试请求、整理 schema：选择集与类型体换行缩进，
变量定义与参数保持单行，指令（`@skip` 等）紧贴字段名。

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 最大 500,000 字符；GraphQL 文本 |

## 输出

| 字段   | 类型   | 说明                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 美化后的文本；空输入返回空串 |

## 选项

| 选项     | 取值 | 默认 | 说明         |
| -------- | ---- | ---- | ------------ |
| `indent` | 2/4  | `2`  | 每层缩进空格 |

## 排版规则

- 选择集 `{ ... }`、类型体换行并缩进；闭合括号回到上一层
- 参数 `(...)`、列表 `[Post!]!`、变量定义 `($id: ID!, $x: Boolean = false)` 保持单行
- 非空 `!` 紧贴类型；变量 `$name`、指令 `@include(if: $x)` 紧贴对应字段
- 内联片段 `... on Type { }` 与片段展开 `...Fragment` 正确处理；枚举值 / 字段逐行排列
- 保留 `#` 注释（各自成行）与三引号块字符串、转义字符串
- 忽略逗号与多余空白（GraphQL 中逗号仅作分隔，无语义）

## 限制

- 这是**词法级美化器**，不做完整语法校验：括号是否配平、字符串是否闭合会检查，但不验证字段是否存在、
  类型是否合法、变量是否被使用；可接受大多数格式良好的查询与 SDL
- 不会对参数 / 指令列表做超长折行，也不会自动排序字段或补全 schema
- 输入上限 500,000 字符；括号不匹配、字符串未闭合时抛 `GraphqlFormatError`

## 数据流向

**纯本地处理。** 输入仅在浏览器内存中排版，不发送网络请求，不写入服务端。`meta.api = false`。

## 示例

输入：

```graphql
query GetUser($id: ID!) {
  user(id: $id) {
    id
    name
    ... on Admin {
      role
    }
  }
}
```

输出：

```graphql
query GetUser($id: ID!) {
  user(id: $id) {
    id
    name
    ... on Admin {
      role
    }
  }
}
```
