# 大小写转换

大写、小写、首字母大写、标题化。

## 用途

统一文案或代码里的大小写：常量转小写、标题转 Title Case、句首大写等。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本，中英混排均可。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                           |
| ------ | ------ | ------------------------------ |
| `text` | string | 转换后的文本，长度与行数不变。 |

## 选项

| 选项   | 取值                               | 默认  | 说明     |
| ------ | ---------------------------------- | ----- | -------- |
| `mode` | upper / lower / capitalize / title | upper | 转换模式 |

## 限制

- title 模式先整体小写再逐词首字母大写，已有大写缩写（如 HTTP）会被改写为 Http
- capitalize 只改第一个字符，其余保持原样
- 大小写映射按 Unicode 规则，土耳其语等特有映射未做特殊处理

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
hello toolbox world
```

输出：

```text
hello toolbox world
```
