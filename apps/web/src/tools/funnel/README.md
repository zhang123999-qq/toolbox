# 漏斗图

输入各阶段数据，用 ECharts 在浏览器本地渲染漏斗图，自动标注相对首阶段的转化率，支持标题、画布尺寸与 PNG 导出。

## 用途

- 销售 / 运营转化漏斗分析（访问 → 注册 → 下单 → 支付）
- 用户行为路径的阶段流失可视化
- 导出 PNG 图片用于汇报、文档

## 输入

| 字段   | 类型   | 约束                                           |
| ------ | ------ | ---------------------------------------------- |
| `text` | string | 数据行：每行一个阶段，格式 `阶段名:数值`（留空用示例） |

数据行格式示例：

```
访问:10000
注册:3000
下单:800
支付:500
```

- 全角冒号（`：`）会自动归一为半角
- 数值须为 ≥0 的数字；阶段名不可重复
- 至少需要 2 个阶段

## 选项

| 选项 | 默认值 | 范围 / 约束 | 说明         |
| ---- | ------ | ----------- | ------------ |
| 标题 | （空） | 任意文本    | 留空则无标题 |
| 宽度 | `600`  | 100–2000    | 画布宽（px） |
| 高度 | `400`  | 100–2000    | 画布高（px） |

## 转化率

各阶段标签显示 `阶段名 / 数值 / 转化率`，转化率 = 该阶段数值 ÷ 首阶段数值 × 100%，保留 1 位小数。首阶段为 0 时转化率记为 0。
