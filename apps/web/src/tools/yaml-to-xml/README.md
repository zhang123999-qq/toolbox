# YAML 转 XML

把 YAML 数据转成 XML 文档，键名即元素名。

## 用途

给只吃 XML 的老系统 / 配置生成器喂数据：先写易维护的 YAML，再转成 XML 粘贴过去。
YAML 解析失败时给出带行列位置的中文提示，直接跳到出错行。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 转换后的 XML；空输入返回空串 |

## 选项

| 选项     | 取值      | 默认 | 说明     |
| -------- | --------- | ---- | -------- |
| `indent` | `2` / `4` | `2`  | 缩进档位 |

## 转换规则

- 映射键 → 元素名；嵌套映射 → 嵌套元素
- 序列 → **重复的同名元素**（`<tags>a</tags><tags>b</tags>`），不使用包装元素
- 标量 → 元素文本；`null` → 自闭合空元素 `<a />`
- 根元素固定为 `<root>`；顶层是序列时用 `<root><item>…</item></root>` 包裹
- 文本节点转义 `&` `<` `>` `"` `'`
- 非法 XML 名（含空格、中文等）中的非法字符替换为 `_`，首字符非法时补 `k_` 前缀
- 输出带 `<?xml version="1.0" encoding="UTF-8"?>` 声明

## 限制

- YAML 侧的限制与 yaml-to-json 一致：不支持多文档、锚点 / 别名 / 合并键、显式标签、复杂键、跨行流式集合、Tab 缩进
- **注释不会进入 XML**（YAML 注释在转换中丢弃）
- **根元素名固定为 `root`**，不可自定义
- 序列与「只有一个元素的序列」在 XML 中无法区分，反向回不到 YAML
- 本工具只做 YAML → XML，**不提供 XML → YAML**
- 键名中的中文会被替换成 `_`，如需保留请改用 ASCII 键名

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```yaml
app:
  name: 工具库
  port: 8080
tags:
  - yaml
  - xml
```

输出（`indent = 2`）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root>
  <app>
    <name>工具库</name>
    <port>8080</port>
  </app>
  <tags>yaml</tags>
  <tags>xml</tags>
</root>
```
