# 标题结构检查

粘贴 HTML，检查标题层级结构：生成 h1–h6 大纲，输出 0–100 结构评分，并发现多 h1、缺少 h1、层级跳跃、空标题、标题过长等问题，给出修复建议。

## 用途

- 检查页面标题层级是否逐级递进
- 发现重复主标题、跳级标题等 SEO 与无障碍问题

## 输入

| 字段   | 类型   | 约束       |
| ------ | ------ | ---------- |
| `text` | string | HTML 片段  |

## 说明

- 纯浏览器内 DOMParser 解析，无网络请求。
- 与「屏幕阅读器预览」的区别：本工具专注标题结构评分与修复建议，不做朗读模拟。
- 评分规则：缺少 h1 扣 25、多 h1 扣 15、空标题每个扣 20、层级跳跃每个扣 10、标题过长每个扣 5，最低 0 分。
