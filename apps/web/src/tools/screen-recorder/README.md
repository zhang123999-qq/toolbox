# 屏幕录制

用浏览器原生能力录制屏幕 / 窗口 / 标签页，录完可预览并导出 webm（或 mp4，取决于浏览器支持）视频。

## 用途

录制操作演示、Bug 复现、会议分享：点开始录制，在浏览器弹出的共享面板里选择目标，停止后下载。

## 输入

本工具无文本输入，纯浏览器能力工具。

## 输出

| 字段    | 类型       | 说明                        |
| ------- | ---------- | --------------------------- |
| `video` | webm / mp4 | 录制结果，可预览并下载      |
| `text`  | 文本       | 录制完成报告：文件名 / 大小 |

## 选项

| 选项        | 类型 | 默认 | 说明                                     |
| ----------- | ---- | ---- | ---------------------------------------- |
| `withAudio` | 开关 | 关   | 同时录制音频（浏览器支持该能力时才生效） |

## 限制

- 需要浏览器支持 `getDisplayMedia` 与 `MediaRecorder`（Chrome / Edge / Firefox 最新版）；不支持时会给出中文提示
- 用户在共享面板里点「取消」会提示「已取消屏幕共享」
- 编码按 `vp9 → vp8 → webm → mp4` 优先级自动选择浏览器支持的第一个
- 全程本地录制，不上传任何数据

## 示例

```text
录制完成：屏幕录制-20260928-111905.webm（3.42 MiB）
```

## 数据流向

**纯本地处理。** `meta.api = false`，无需自备 API/Key。
