# 数据表格（#688）

把粘贴的 CSV 变成可交互的数据表格：点击表头排序、关键词搜索、分页浏览、导出 CSV。

## 输入

CSV 文本，首行为表头，支持双引号字段与 `""` 转义：

```csv
姓名,年龄,城市,销售额
张三,28,北京,12000
李四,35,上海,9800
```

留空时使用内置示例。

## 功能

- **排序**：点击表头在升序 / 降序 / 原序之间切换；数字按数值比，其余按中文拼音序；空值永远置后。
- **搜索**：关键词匹配任意单元格，不区分大小写。
- **分页**：每页条数可在选项中设置（1–500，默认 10）。
- **导出 CSV**：导出当前排序 + 搜索过滤后的视图。

## 说明

- 纯前端实现，数据不离开浏览器。
- 行数较多时建议先用「数据过滤」「数据排序」做预处理。
