# 重定向检测

跟踪 URL 的重定向链：每跳状态码、跳转目标、跳数、成环检测；也支持粘贴原始 HTTP
响应做离线分析。

## 用途

换域名、做 SEO 或排查「这个短链到底跳到哪」时，看清完整的跳转链，
发现循环跳转、过长跳转链等问题。

## 输入

| 字段   | 类型   | 约束                                         |
| ------ | ------ | -------------------------------------------- |
| `text` | string | 实时检测模式下为 URL；粘贴分析模式下为原始 HTTP 响应文本 |

## 选项

| 选项     | 取值                   |
| -------- | ---------------------- |
| 检测模式 | `实时检测` / `粘贴分析` |

## 输出

```text
起始 URL：https://x.test/
跳转次数：1
最终 URL：https://x.test/b
结论：跟踪结束：最终状态 200

跳转链：
  [0] 301 https://x.test/ → /b
  [1] 200 https://x.test/b → （无）
```

## 浏览器边界说明

- 实时检测用 `fetch(url, { method: 'HEAD', redirect: 'manual' })` 手动跟随 `Location`，
  最多 10 跳，超时 15 秒；部分服务器不支持 HEAD 时会自动回退 GET 重试一次
- **跨域限制（浏览器安全策略，非工具 bug）**：目标与本站不同源时，浏览器只返回
  `opaque-redirect`，读不到状态码与 Location，只能报告「检测到重定向但无法读取目标」；
  同源 URL 可完整跟踪
- 粘贴分析模式纯离线：把 `curl -sI <url>` 的输出粘进来即可分析

## 限制

- 只跟踪 HTTP 层跳转（301/302/303/307/308），不执行 JS 跳转与 meta refresh
- 相对 Location 按请求 URL 解析；Location 为空或非法时如实报错

## 数据流向

**浏览器发起 fetch（D 类）。** 请求直连目标站点，不经过本工具后端。`meta.api = true`
（浏览器直连外部站点）。
