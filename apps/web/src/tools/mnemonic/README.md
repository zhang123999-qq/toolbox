# 助记词

BIP39 助记词：生成 12/15/18/21/24 词、英文词库校验 checksum、一键派生 64 字节种子。

## 用途

离线生成符合 BIP39 标准的助记词、验证一组助记词是否合法、派生 HD 钱包种子（配合 #703 HD 钱包使用）。

## 模式

| 模式     | 输入     | 输出                             |
| -------- | -------- | -------------------------------- |
| `生成`   | （忽略） | 随机助记词，可选词数，可重新生成 |
| `校验`   | 助记词   | 校验结果 + 熵（hex）             |
| `转种子` | 助记词   | 64 字节种子（hex），口令参与派生 |

种子派生：PBKDF2-HMAC-SHA512，2048 轮，salt 为 `mnemonic` + 口令（BIP39 标准）。

## 安全

- 仅供学习测试使用；生产环境请使用硬件钱包生成和保管助记词。
- 助记词只保存在页面内存中，不写入任何存储、不上传网络。
- SHA-256 / SHA-512 / PBKDF2 均为本工具内手写实现，无第三方依赖。

## 说明

- 词库为 BIP39 官方英文词库（2048 词）。
- 非法助记词（词不在词库 / 词数不对 / checksum 错误）会明确报错。
