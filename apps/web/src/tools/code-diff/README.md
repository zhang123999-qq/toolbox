# 代码 Diff

两段代码差异对比，输出 **unified diff** 文本（`---`/`+++`/`@@` 格式），支持行级与字符级。

## 用途

code review 时快速看清「这两版代码到底改了哪几行、哪几个字符」。
基于已装的 `diff` 包计算差异，输出接近 `git diff` 的可读文本。

## 输入

| 字段    | 类型   | 约束              | 说明         |
| ------- | ------ | ----------------- | ------------ |
| `text`  | string | 最大 200,000 字符 | 旧版代码 (a) |
| `textB` | string | 最大 200,000 字符 | 新版代码 (b) |

`textB` 通过附加输入框输入。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | unified diff：`---`/`+++` 头 + `@@` hunk |

```diff
--- 旧版 (a)
+++ 新版 (b)
@@ -1,3 +1,4 @@
 function add(a, b) {
-  return a - b
+  // 修正：应为加法
+  return a + b
 }
```

## 选项

| 选项 key | 界面标签 | 取值                             |
| -------- | -------- | -------------------------------- |
| `mode`   | 模式     | `line`（行级）/ `char`（字符级） |

## 实现规则 / 算法

- **行级**：`diffLines` 计算逐行差异，合并成 hunk，每个 hunk 上下文保留 3 行，
  带 `@@ -起始行,行数 +起始行,行数 @@` 头
- **字符级**：`diffChars` 直接输出带符号的字符片段流（不做 hunk 压缩）
- 行前缀：`+` 新增、`-` 删除、空格为未变上下文
- 两段完全相同时输出 `(两段代码完全相同)`

## 浏览器边界与限制

- 输出是**带标记的纯文本**，不是可直接 `git apply` 的补丁（文件头写的是 `旧版/新版`，非 `a/ b/` 路径）
- 行级 hunk 上下文固定 3 行，不可调
- 不支持语法高亮、侧边并排视图
- 两段都空返回空串；单段超长报错

## 数据流向

**纯本地处理。** 浏览器内用 `diff` 包计算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（旧版）：

```text
function add(a, b) {
  return a - b
}
```

输入（新版）：

```text
function add(a, b) {
  // 修正：应为加法
  return a + b
}
```

输出（`mode=line`，见上）。
