# Cron 解析

把标准 5 段 cron 表达式（分 时 日 月 周）翻译成中文自然语言描述，
例如 `0 2 * * 1-5` → `周一到周五 02:00`。纯前端自研解析，不依赖 cronstrue。

## 用途

写定时任务（crontab / Airflow / Jenkins / GitHub Actions schedule）时，
光看 `*/15 9-18 * * 1-5` 不容易一眼确认含义。本工具把它读成人话，
避免「以为每天凌晨跑，结果是工作日才跑」这类线上事故。

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 5 段 cron 表达式，最大 200,000 字符 |

格式：`分 时 日 月 周`，空格分隔。各段取值范围：

| 字段 | 范围 | 说明              |
| ---- | ---- | ----------------- |
| 分   | 0-59 |                   |
| 时   | 0-23 |                   |
| 日   | 1-31 |                   |
| 月   | 1-12 |                   |
| 周   | 0-7  | 0 与 7 都代表周日 |

支持语法：`*`（每）、`*/N`（每 N）、`a`、`a-b`（区间）、`a,b,c`（列表）、`a-b/N`（区间步长）、`?`（等同 `*`）。

## 输出

| 字段   | 类型   | 说明             |
| ------ | ------ | ---------------- |
| `text` | string | 中文自然语言描述 |

```text
周一到周五 02:00
```

## 常见写法对照

| 表达式         | 描述             |
| -------------- | ---------------- |
| `* * * * *`    | 每分钟           |
| `*/15 * * * *` | 每 15 分钟       |
| `0 * * * *`    | 每小时整点       |
| `30 8 * * *`   | 每天 08:30       |
| `0 2 * * 1-5`  | 周一到周五 02:00 |
| `0 0 1 * *`    | 每月 1 号 00:00  |
| `0 0 * * 0`    | 每周日 00:00     |

## 限制

- 只支持标准 **5 段** cron，不支持 6 段（带秒 / 带年）Quartz 扩展
- `L`（月末）、`#`（第几个周几）这类 Quartz 专有写法未做特殊语义，按非法处理
- 「日」与「周」同时被限定且互相矛盾时，本工具不做并集语义合并（与主流 cron 实现一致：二者取并集触发）
- 空输入返回空串；非法格式抛中文错误

## 数据流向

**纯本地处理。** 字符串解析，不发送任何网络请求。`meta.api = false`。

## 示例

输入：

```text
0 2 * * 1-5
```

输出：

```text
周一到周五 02:00
```
