# CSV 转 JSON

把 CSV 转成 JSON 数组，首行为表头，自动推断数字与布尔。

## 用途

把导出的报表、数据库 dump、埋点日志等 CSV 直接转成 JSON，粘进代码或喂给下游脚本。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 5,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                      |
| ------ | ------ | ------------------------- |
| `text` | string | JSON 文本；空输入返回空串 |

## 选项

| 选项        | 取值                                   | 默认    | 说明                                     |
| ----------- | -------------------------------------- | ------- | ---------------------------------------- |
| `header`    | boolean                                | `true`  | 首行为表头：开 → 对象数组，关 → 二维数组 |
| `delimiter` | `comma` / `tab` / `semicolon` / `pipe` | `comma` | 分隔符                                   |
| `indent`    | `0` / `2` / `4`                        | `2`     | JSON 缩进，`0` 为单行压缩                |

## 转换规则

1. 空单元格与 `null` → `null`
2. `true` / `false`（小写）→ 布尔
3. 数字串 → 数字，但两种情况保持字符串：
   - 有前导零（`007`），转数字会丢掉格式信息
   - 整数超出 `Number.MAX_SAFE_INTEGER`
4. 重名表头依次加后缀（`a`、`a_2`…），空表头补 `column_N`（N 从 1 开始）
5. 数据行列数少于表头时，缺失的键补 `null`；多出的列会被忽略
6. 空行跳过（`skipEmptyLines: greedy`），CRLF 统一成 LF

## 限制

- 输入上限 5,000,000 字符，超出抛出 `CsvToJsonError`
- 引号不配对的行无法解析，直接抛错
- 类型推断只有上述三类，不识别日期、`NaN`、`Infinity` 等
- 默认分隔符为逗号，TSV 需要手动切到 `tab`

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```csv
name,tools,local
工具库,870,true
"含,逗号",1,false
```

输出（`header=true`、`indent=2`）：

```json
[
  { "name": "工具库", "tools": 870, "local": true },
  { "name": "含,逗号", "tools": 1, "local": false }
]
```
