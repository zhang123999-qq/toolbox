# 文件类型鉴定

读取文件头魔数，鉴定文件真实类型并判断扩展名是否疑似篡改。

## 用途

收到一个改了扩展名的可疑文件（如把 `exe` 改成 `jpg` 发过来）时，上传鉴定真实类型；下载的文件打不开时，看看到底是什么格式。

## 输入

| 字段   | 类型 | 约束           | 说明                                   |
| ------ | ---- | -------------- | -------------------------------------- |
| `file` | File | 单个 ≤ 200 MiB | 待鉴定文件，**不上传**，只读前 64 字节 |

## 输出

| 字段   | 类型   | 说明                                                       |
| ------ | ------ | ---------------------------------------------------------- |
| `text` | string | 文件头十六进制、鉴定出的真实类型、建议扩展名、篡改判断结论 |

## 选项

无可调选项。

## 限制

- 签名表收录约 28 种常见类型（图片 / 文档 / 压缩包 / 音视频 / 可执行文件）；未收录的如实提示「未知类型」，不猜
- 空文件直接报错
- 全程本地处理

## 与 file-mime 的区别

`file-magic` 只做**魔数鉴定与篡改判断**，不维护扩展名→MIME 对照表；`file-mime` 侧重**扩展名 ↔ MIME 的正查/反查**。

## 数据流向

**纯本地处理。** 只读文件头 64 字节，`meta.api = false`，无需自备 API/Key。

## 示例

输入：示例文件 `mystery.bin`（内容为 PNG 文件头）。

输出：

```text
文件：mystery.bin（16 字节）
文件头：89 50 4E 47 0D 0A 1A 0A 00 00 00 0D 49 48 44 52
鉴定结果：PNG 图片
建议扩展名：.png

疑似篡改：扩展名是 .bin，但文件头指向 .png 类型
```
