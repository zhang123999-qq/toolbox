# 密钥生成

生成对称与非对称密钥，导出 hex / base64 / JWK / PEM。

## 用途

在浏览器里快速生成一把随机密钥或密钥对，用于本地测试、临时签名、填充 `.env`、调试 JWT / TLS 流程。所有生成都由浏览器 WebCrypto 的密码学安全随机数完成。

> ⚠️ **页面生成的私钥仅用于测试，刷新即失**：密钥只存在于当前页面的输出框里，**不会保存、不会下载到磁盘、也不会写入 localStorage**。请立刻复制到你的密码管理器或密钥库；如果刷新页面就找不回来了（需要重新生成）。
> **生产环境请使用 `openssl` / `ssh-keygen` / KMS 等经过审计的工具生成长期密钥。**

## 输入

| 字段   | 类型   | 约束              | 说明                                             |
| ------ | ------ | ----------------- | ------------------------------------------------ |
| `text` | string | 最大 200,000 字符 | **只作触发用**：空串不生成，填任意内容即生成一次 |

本工具不需要真实输入内容。输入框沿用模板的 `text` 字段，行为与 password-generator 一致：**空串返回空串**（避免静态预渲染时烘焙出一把随机密钥），填任意内容即触发。

## 输出

| 字段   | 类型   | 说明                                                                                                               |
| ------ | ------ | ------------------------------------------------------------------------------------------------------------------ |
| `text` | string | 对称：hex / base64 / JWK；非对称：**私钥**的 hex / base64 / PEM（PKCS#8），或 `{ privateKey, publicKey }` 两个 JWK |

## 选项

| 选项     | 取值                                 | 默认     | 说明                                                                     |
| -------- | ------------------------------------ | -------- | ------------------------------------------------------------------------ |
| `type`   | aes-hmac / rsa / ec / ed25519        | aes-hmac | 密钥类型                                                                 |
| `bits`   | 128 / 192 / 256 / 2048 / 3072 / 4096 | 128      | **对称**用 128/192/256；**RSA** 用 2048/3072/4096；ec / ed25519 忽略此项 |
| `curve`  | P-256 / P-384 / P-521 / Ed25519      | P-256    | **仅 ec 使用**（可选三条 NIST 曲线）；ed25519 类型忽略此项               |
| `format` | hex / base64 / jwk / pem             | hex      | 输出格式；对称密钥没有 PEM 形式，选 pem 会报错                           |

类型与参数必须匹配：

- `aes-hmac` + 128/192/256 → 生成 HMAC-SHA-256 密钥（长度即 AES 的密钥长度），导出原始字节或 `oct` JWK
- `rsa` + 2048/3072/4096 → RSASSA-PKCS1-v1_5（SHA-256）密钥对，导出 PKCS#8 私钥或 JWK 对
- `ec` + P-256/P-384/P-521 → ECDSA 密钥对
- `ed25519` → Ed25519 密钥对（现代签名算法，密钥短、速度快）

## PEM 是怎么来的

WebCrypto 的 `exportKey('pkcs8', privateKey)` 给出的是 **DER** 二进制。PEM 只是把 DER 做 base64 后每 64 字符换行，再包上 `-----BEGIN PRIVATE KEY-----` / `-----END PRIVATE KEY-----` 头尾——本工具就地完成这一步，**不依赖任何第三方库**。

## 限制

- 生成的密钥**不做持久化**，刷新页面即失（见上方警告）
- 只导出**私钥**（`jwk` 格式除外，它会同时给出私钥与公钥 JWK）；需要公钥 PEM 可用私钥推导
- 对称密钥没有 PEM 形式（PEM 是给非对称密钥用的容器格式）
- RSA 4096 位生成可能耗时数秒，请稍候
- 需要 HTTPS 或 localhost（WebCrypto 的要求）
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 密钥在浏览器内用 `crypto.subtle.generateKey` 生成，**生成的密钥与随机数不离开当前页面**：
**不发起任何网络请求、不写入 localStorage、不上传服务端**。
`meta.api = false`，无需自备 API/Key。

## 示例

默认（aes-hmac / 128 位 / hex）输出：

```text
（32 位十六进制，例如 a3f1…，每次不同）
```

EC / P-256 / pem 输出：

```text
-----BEGIN PRIVATE KEY-----
MIGHAgEAMBMGByqGSM49AgEGCCqGSM49AwEHBG0wawIBAQQg…
-----END PRIVATE KEY-----
```
