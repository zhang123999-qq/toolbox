# Cron 下次运行

输入一条标准的 5 段 Cron 表达式，本工具用浏览器本地时间逐分钟扫描，算出接下来 N 次会在什么时候触发。

## 用途

写定时任务（Linux crontab、Jenkins、GitLab CI、K8s CronJob……）时，最容易猜错的就是「这条表达式到底几点跑」。本工具不装任何依赖、不发网络请求，直接把未来 N 次触发时间列出来，方便上线前核对。

## 支持的语法

表达式共 **5 段**，用空白分隔，顺序固定：

```
分  时  日  月  周
*   *   *   *   *
```

| 段          | 含义     | 取值范围                 |
| ----------- | -------- | ------------------------ |
| 分（min）   | 第几分钟 | 0–59                     |
| 时（hour）  | 第几小时 | 0–23                     |
| 日（dom）   | 每月几号 | 1–31                     |
| 月（month） | 第几月   | 1–12                     |
| 周（dow）   | 星期几   | 0–7（0 和 7 都表示周日） |

每段支持以下写法，可以用逗号并列：

| 写法      | 示例      | 含义                             |
| --------- | --------- | -------------------------------- |
| `*` / `?` | `*`       | 任意值（每一分 / 每一小时……）    |
| 单值      | `30`      | 只在 30 分                       |
| 区间      | `9-18`    | 9 点到 18 点（含两端）           |
| 步长      | `*/15`    | 每 15 分钟                       |
| 区间步长  | `0-30/10` | 前半小时内每 10 分钟：0/10/20/30 |
| 起点步长  | `5/20`    | 从 5 开始到段末尾：5/25/45       |
| 列表      | `1,15,30` | 命中其中任意一个                 |

> `?` 与 `*` 等价（兼容习惯了 Quartz 的写法）。星期字段里 `0` 与 `7` 都表示周日。

### 日 / 周的 OR 语义（Vixie cron）

当「日」和「周」**都写死了具体值**（都不是 `*` / `?`）时，两者取**并集**：
只要当天是指定日期，**或** 是指定星期，就触发。

例如 `0 0 13 * 5`（凌晨 0 点，每月 13 号 **或** 每周五）会在「所有周五」和「每月 13 号」都触发，而不是只在「既是 13 号又是周五」那天触发。
只有其中一边写死时，才要求被写死的那一边命中。

## 输入

| 字段   | 类型   | 约束                           |
| ------ | ------ | ------------------------------ |
| `text` | string | Cron 表达式，最大 200,000 字符 |

## 选项

| 字段    | 类型   | 默认 | 说明                       |
| ------- | ------ | ---- | -------------------------- |
| `count` | string | `5`  | 列出接下来几次运行（1–50） |

## 输出

列出接下来 N 次触发时间（本地时区，精确到分钟）：

```text
下次 5 次运行（从 2026-09-27 12:00:00 起）：
1. 2026-09-28 09:00:00
2. 2026-09-29 09:00:00
3. 2026-09-30 09:00:00
4. 2026-10-01 09:00:00
5. 2026-10-02 09:00:00
```

## 错误处理

- 空输入：不产出任何内容。
- 段数不是 5、字段越界、含非数字、步长 ≤ 0：中文报错。
- 未来 5 年内没有任何命中（例如 `0 0 30 2 *` 2 月 30 号）：中文报错。
- 输入超过 200,000 字符：中文报错。

## 限制

- 只支持 5 段（分 时 日 月 周），不支持 6 段带秒、不支持年份字段。
- 不支持月份 / 星期的英文别名（`JAN`、`MON`），只认数字。
- 不做夏令时换算，按浏览器本地时区逐分钟扫描。
- 扫描上限约 5 年，超出即报错（正常表达式不会接近这个上限）。

## 数据流向

**纯本地处理。** 仅做字符串解析与日期计算，不发送任何网络请求。`meta.api = false`。
