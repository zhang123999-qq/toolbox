# 二进制查看

以十六进制 + ASCII 双栏方式查看文件字节，统计字节分布，也支持把 hex 文本还原。

## 用途

不写十六进制主导镐上手也能用：看一段文件的开头是什么、头部有没有对、数据是不是明文、
有没有一堆无意义的零填充；或者把 xxd / hexdump 的输出原样贴回来还原成字节再重新查看。

两个入口并存：

- **左下「选择文件」**：选中即算，报告里带文件名、体积与 MIME 类型。
- **左上文本区**：粘贴内容后由「方向」决定怎么看。

## 输入

| 字段   | 类型   | 约束                  |
| ------ | ------ | --------------------- |
| `text` | string | 最大 1,000,000 字符   |
| `file` | File   | 文件入口，最大 16 MiB |

## 输出

| 字段   | 类型   | 说明                     |
| ------ | ------ | ------------------------ |
| `text` | string | 字节报告；空输入返回空串 |

## 选项

| 选项        | 取值               | 默认      | 说明                                          |
| ----------- | ------------------ | --------- | --------------------------------------------- |
| `direction` | `view` / `fromHex` | `fromHex` | 查看文本自身的 UTF-8 字节，还是按十六进制还原 |
| `columns`   | `8` / `16` / `32`  | `16`      | 每行显示几个字节                              |

### 报告结构

```
文件：xxx.bin
类型：application/octet-stream
大小：N 字节（人类可读体积）

== 字节统计 ==
总字节数 / 不同字节值 / 可打印 ASCII / 零字节 / 高位字节 / 香农熵 / 最高频字节

== 文件类型线索 ==
按文件头猜一种可能格式

== 十六进制视图 ==
00000000  89 50 4e 47 0d 0a 1a 0a  |.PNG....|
```

## 还原（fromHex）接受的写法

会先去掉 `|......|` 形式的 ASCII 栏，再去掉行首的偏移地址（`00000000`、`0000:0010` 等），
其余部分只收十六进制字符。因此以下写法都能直接贴：

- 纯十六进制：`89504e47`
- xxd / hexdump 输出：`00000000  89 50 4e 47  |.PNG|`
- 带分隔符：`89:50 4e-47`

## 限制

- **文件上限 16 MiB**，超出报错并建议改用命令行 `xxd`；文件会被整份读进内存。
- **转储上限 65,536 字节**（16 列时约 4000 行），超出的部分截断并标注总字节数；
  统计与文件头识别始终基于完整数据。
- 不可打印字节在 ASCII 栏一律显示为 `.`，包括 `\t`、`\r`、`\n` 这类可见控制符。
- 偏移量按行首字节位置计算并补零到 8 位以上，不做段式分割（`:` 前缀）。
- 文件类型只按**魔数前缀**判断且只罗列了十余种常见格式，命中不了不代表文件无效。
- 文本模式查看的是 **UTF-8** 字节；要看其它字符集下的字节，请先用 `encoding-convert` 生成。
- 熵基于单字节频率（`log2`），不用做加密强度判定的依据。

## 数据流向

**纯本地处理。** 文件内容只在本机浏览器内存中读取与计算，不上传任何服务器。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（fromHex）：

```text
00000000  89 50 4e 47 0d 0a 1a 0a  |.PNG....|
00000008  00 00 00 0d 49 48 44 52  |....IHDR|
```

输出（节选）：

```text
来源：粘贴的十六进制文本（还原出 16 字节）

== 字节统计 ==
总字节数: 16
不同字节值: 12 / 256
香农熵: 3.45 bit/字节

== 文件类型线索 ==
PNG 图片

== 十六进制视图 ==
00000000  89 50 4e 47 0d 0a 1a 0a 00 00 00 0d 49 48 44 52  |.PNG........IHDR|
```
