# 语言标签

解析、构建与校验 BCP 47 语言标签（如 `zh-Hant-TW`）：拆解语言 / 文字 / 地区 / 变体 / 扩展 / 私用子标签，输出规范化标签与中文含义。

## 用途

- 写 `lang` 属性、Accept-Language 前先校验标签合法性
- 看懂 `zh-Hant-TW`、`en-US-u-ca-buddhist` 这类标签的含义
- 统一标签大小写规范（语言小写、文字首字母大写、地区大写）

## 输入

| 字段   | 类型   | 约束            |
| ------ | ------ | --------------- |
| `text` | string | BCP 47 语言标签 |

## 说明

- 纯本地解析，无网络请求。
- 覆盖 50+ 常用语言、16 种文字、24 个地区的中文名；未知代码回退显示原文。
- 构建器暂不支持扩展（`u-…` 等）部件，解析支持。
