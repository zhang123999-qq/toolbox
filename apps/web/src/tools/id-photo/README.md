# 证件照制作 id-photo（#459）

## 用途 | Purpose

- 上传人像照片 → 按证件照规格裁剪 → 更换底色 → 输出 JPG；可选拼版打印（多张拼到一张纸上）。
- Upload a portrait → crop to ID photo spec → change background color → export JPG; optional multi-photo print layout.

## 规格表 | Specs（毫米对照）

| 规格   | 宽 × 高（mm） | 说明            |
| ------ | ------------- | --------------- |
| 一寸   | 25 × 35       | 1inch           |
| 二寸   | 35 × 49       | 2inch           |
| 小二寸 | 35 × 45       | small2inch      |
| 大一寸 | 33 × 48       | large1inch      |
| 自定义 | 用户填写      | custom，0–500mm |

像素尺寸 = 毫米 / 25.4 × DPI（四舍五入）。例如一寸 @300DPI = 295 × 413px。

## 选项 | Options

| 选项        | 说明                                                          |
| ----------- | ------------------------------------------------------------- |
| 规格 spec   | 一寸 / 二寸 / 小二寸 / 大一寸 / 自定义（自定义时另填宽高 mm） |
| 分辨率 dpi  | 150 / 300 / 600，默认 300                                     |
| 底色 bg     | 红 `#ff0000` / 蓝 `#3584e4` / 白 `#ffffff` / 自定义颜色       |
| 缩放 scale  | 50–200%，默认 100%；>100% 时人像在裁剪框内放大                |
| 排版 layout | 单张 / 5寸相纸（127×89mm）/ A4（210×297mm）                   |

## 排版说明 | Layout

- 选择 5寸相纸或 A4 后，同一张证件照按 2mm 间距自动铺满纸张，输出一张拼版 JPG。
- 结果区显示可排张数（列 × 行）。
- 若照片单张尺寸大于纸张（一张也排不下），会明确报错，请改用 A4 或减小规格 / DPI。

## 边界 | Limits

- 全程本地 Canvas 处理，不上传。
- 输出统一为 JPG（质量 0.92）；原图透明区域会被底色填充。
- 缩放滑杆只改变人像在裁剪框内的大小，不改变输出尺寸。
- 单文件上限 50MB；自定义规格上限 500mm。
- 浏览器不支持 Canvas 2D 时报错。

## 数据流向 | Data flow

文件 → 内存 Canvas（底色填充 + 裁剪绘制 [+ 拼版]）→ JPG Blob → 下载；不经过网络。
