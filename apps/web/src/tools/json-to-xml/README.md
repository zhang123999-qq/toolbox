# JSON 转 XML

把 JSON 对象转成结构清晰、缩进整齐的 XML，纯本地转换。

## 用途

需要 XML 报文（旧接口、SOAP、配置）时，把现成 JSON 贴进来即可；
数组转重复同名元素，嵌套对象转嵌套标签，`null` 与空容器转自闭合标签。

## 输入

| 字段   | 类型   | 约束                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 最大 2,000,000 字符，任意合法 JSON |

## 输出

| 字段   | 类型   | 说明                     |
| ------ | ------ | ------------------------ |
| `text` | string | XML 文本；空输入返回空串 |

## 选项

| 选项          | 取值    | 默认   | 说明                                 |
| ------------- | ------- | ------ | ------------------------------------ |
| `rootName`    | 文本    | `root` | 根元素名（非 XML Name 字符会被归一） |
| `declaration` | boolean | `true` | 是否输出 `<?xml ...?>` 声明          |
| `indent`      | 2/4/tab | `2`    | 一级缩进                             |

## 转换规则

- 对象 → 嵌套元素；数组 → 重复同名元素（顶层数组包成根下重复 `<item>`）
- `null`、空对象、空数组、空字符串 → 自闭合 `<x/>`
- 文本里的 `& < >` 分别转义为 `&amp; &lt; &gt;`
- 键名含非 XML Name 字符时归一（替换为 `_`，数字 / `.` / `-` 开头补 `_`）
- 标量根（字符串 / 数字等）直接成为根元素的文本内容

## 限制

- 全部逻辑为纯 TS 自研，不依赖 npm XML 库，行为以本文档为准
- 不输出属性（attribute）、命名空间、CDATA 与注释；所有数据都用「子元素」表达
- 不做 JSON `$schema` 风格的属性映射；同名键在对象内若重复会各自成标签
- 不保证可逆（XML 无法区分「数字文本」与「数字」），反向请用 #139 XML 转 JSON
- 输入上限 2,000,000 字符，超限抛 `JsonToXmlError`

## 数据流向

**纯本地处理。** 输入仅在浏览器内存中处理，不发送网络请求，不写入服务端。`meta.api = false`。

## 示例

输入：

```json
{ "id": 1, "tags": ["json", "xml"], "meta": { "stars": 870 }, "note": null }
```

输出（节选）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root>
  <id>1</id>
  <tags>json</tags>
  <tags>xml</tags>
  <meta>
    <stars>870</stars>
  </meta>
  <note/>
</root>
```
