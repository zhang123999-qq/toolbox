# HTML 实体编解码

HTML 实体转义与还原，支持命名与数字两种写法。

## 用途

把 `<`、`&`、引号等字符转义成实体，避免它们破坏 HTML 结构或造成 XSS；
反向则用于把网页源码、邮件正文里的一堆 `&amp;`、`&#x27;` 还原成人能读的文字。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 编码后为实体串；解码后为原文 |

## 选项

| 选项        | 取值            | 默认   | 说明                                                      |
| ----------- | --------------- | ------ | --------------------------------------------------------- |
| `direction` | encode / decode | encode | 编码或解码                                                |
| `mode`      | named / numeric | named  | named 优先用 `&copy;` 这类命名实体；numeric 全用 `&#169;` |

## 限制

- 命名实体表收录约 70 个常用符号（含拉丁符号、标点、箭头、希腊字母）；
  表外字符编码时回落为数字实体，解码时数字实体一律支持
- 编码只转义「必须转义的 5 个字符 + 非 ASCII 字符」，普通 ASCII 保持原样，
  因此不会把一段普通英文变成满屏 `&#xx;`
- 解码遇到无法识别的实体（如模板自有的 `&foo;`）**原样保留**，不会被吃掉

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
<a href="x">工具库</a> & ©
```

输出（named / encode）：

```text
&lt;a href=&quot;x&quot;&gt;&#24037;&#20855;&#24211;&lt;/a&gt; &amp; &copy;
```
