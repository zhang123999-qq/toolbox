# 正则速查

内置 16 条最常用的正则表达式，按分类过滤，可直接复制到代码里用。

## 用途

写表单校验、日志解析时，「邮箱/手机号/URL/IP 到底怎么写」是高频问题。
本工具把这些久经考验的正则收在一处，按分类筛选，省得每次现搜。

## 输入

| 字段   | 类型   | 约束              | 说明                   |
| ------ | ------ | ----------------- | ---------------------- |
| `text` | string | 最大 200,000 字符 | 仅作触发用，内容不参与 |

留空不产出；点「示例」或任意输入即按当前分类输出速查表。

## 输出

| 字段   | 类型   | 说明                                       |
| ------ | ------ | ------------------------------------------ |
| `text` | string | 当前分类下的正则列表（名称 + 正则 + 说明） |

```text
分类：网络与地址（4 条）

【电子邮箱】
  正则: /^[\w.+-]+@[\w-]+\.[\w.]+$/
  说明: 通用邮箱格式校验
…
```

## 选项

| 选项 key   | 界面标签 | 取值                                                    |
| ---------- | -------- | ------------------------------------------------------- |
| `category` | 分类     | `all` / `web` / `identity` / `number` / `date` / `text` |

## 内置条目

| 分类       | 条目                                    |
| ---------- | --------------------------------------- |
| 网络与地址 | 电子邮箱、URL、IPv4、十六进制颜色       |
| 证件与账号 | 手机号、身份证号、邮政编码、QQ 号、UUID |
| 数值       | 整数、浮点数、十六进制数                |
| 日期时间   | 日期 YYYY-MM-DD、时间 HH:MM:SS          |
| 文本用户名 | 纯中文、用户名                          |

## 实现规则 / 注意事项

- 所有正则均以 `^…$` 锚定，用于**整串校验**；做「包含」匹配时去掉首尾锚点
- IPv4 / 日期等只做**格式**校验，不判断每段是否落在合法范围（如 999.999.999.999 也会通过）
- 手机号只覆盖大陆 11 号段；邮箱正则是工程上的折中，不是 RFC 5322 完整文法

## 浏览器边界与限制

- 静态数据查表，不执行正则匹配
- 不提供「一键导出」之外的在线测试（测试请用「正则测试」工具）
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 纯静态数据 + 字符串拼接，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（触发用）：

```text
show
```

输出（`category=web` 时）：

```text
分类：网络与地址（4 条）

【电子邮箱】
  正则: /^[\w.+-]+@[\w-]+\.[\w.]+$/
  说明: 通用邮箱格式校验
【URL】
  正则: /^https?:\/\/[\w.-]+(?::\d+)?(?:\/\S*)?$/
  说明: http/https 链接
…
```
