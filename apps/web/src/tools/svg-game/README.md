# SVG 游戏资源（#795）

游戏精灵 SVG 模板库：8 种预设精灵（角色/道具/地形/特效），主/副配色可参数化替换，一键复制或下载 SVG 文件。

## 功能

- **8 种精灵模板**：史莱姆、幽灵（角色）；金币、剑、宝箱、药水（道具）；红心（特效）；树（地形）
- **参数化配色**：主色/副色任意替换，切换模板时自动重置为该模板默认值
- **复制/下载**：复制 SVG 代码到剪贴板，或下载为 `.svg` 文件
- **批量渲染**：`renderAllSprites` 可一次性渲染全部模板（供二次开发）

## 说明

- 本工具定位是"游戏精灵模板库"，与通用图案生成器 `svg-gen`（点阵/条纹/棋盘/波浪/网格）互补不重复
- 输出为标准 SVG（viewBox 0 0 64×64），可直接用于网页游戏或导入矢量编辑器
- 纯前端本地处理，不发送任何网络请求
