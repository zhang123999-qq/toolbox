# SHA-1 哈希

计算文本的 SHA-1 摘要，支持 hex 与 Base64 输出。

## 用途

把任意文本压成 160 位（20 字节）的定长摘要，用于校验文件/内容在传输或复制后是否被改动、比对两段内容是否相同、或生成旧系统的兼容校验值。
`SHA-1("abc") = a9993e364706816aba3e25717850c26c9cd0d89d`，可直接与标准向量对照。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

任意文本（中英混排、emoji 均可），按 UTF-8 编码参与计算。

## 输出

| 字段   | 类型   | 说明                                      |
| ------ | ------ | ----------------------------------------- |
| `text` | string | 40 位十六进制摘要；选 Base64 时为其编码值 |

## 选项

| 选项        | 取值         | 默认  | 说明                                 |
| ----------- | ------------ | ----- | ------------------------------------ |
| `uppercase` | 布尔         | false | 十六进制是否用大写（对 Base64 无效） |
| `format`    | hex / base64 | hex   | 输出格式                             |

## 限制

- **SHA-1 已不安全**：2017 年 SHAttered 攻击已构造出同一摘要的两份不同文件，密码学上不应再用于数字签名、证书或口令存储。本工具保留它**仅用于内容校验（如校验下载文件）与兼容旧系统**。
- 需要抗碰撞保证时请改用 SHA-256（见 #119）或 SHA-3（见 #120）。
- **不是加密**：哈希不可逆，不能用来「解密」。
- 依赖浏览器的 WebCrypto，需要 HTTPS 或 localhost；不安全上下文会直接报错。
- 输入上限 200,000 字符。

## 数据流向

**纯本地处理。** 摘要由浏览器 WebCrypto 在当前页面内计算，文本不写入 localStorage、不发送、不上传，无任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
abc
```

输出（hex / 小写）：

```text
a9993e364706816aba3e25717850c26c9cd0d89d
```
