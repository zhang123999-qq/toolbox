# README 生成

填项目名、一句话描述、功能列表与许可证，生成一份结构化的 `README.md` 骨架。

## 用途

开新仓时不用每次从零写 README。本工具给出标题 / 功能 / 安装 / 使用 / 许可证 五段骨架，
复制后再按需补充。

## 输入

输入框每行写一个功能点：

```text
零依赖
TypeScript 编写
支持 Tree Shaking
```

| 字段   | 类型   | 约束             |
| ------ | ------ | ---------------- |
| `text` | string | 最大 20,000 字符 |

## 选项

| 选项 key      | 界面       | 说明                                   |
| ------------- | ---------- | -------------------------------------- |
| `projectName` | 项目名     | 包名 / 仓名                            |
| `description` | 一句话描述 | 放在标题下                             |
| `license`     | 许可证     | MIT / Apache-2.0 / GPL-3.0 / Unlicense |

## 输出结构

- `# 项目名` + 描述
- `## 功能特性`：每行一个 bullet
- `## 安装`：`npm install <项目名>`
- `## 使用`：一段 import 示例
- `## 许可证`

## 数据流向

**纯本地处理。** 无网络请求。`meta.api = false`。
