# 解压 ZIP

上传 ZIP 压缩包，列出包内文件清单，可逐个或全部解压下载。

## 用途

收到别人发来的 zip，想先看里面有什么、只拿其中一两个文件时，不用整包解压：上传后看清单，按需下载。

## 输入

| 字段   | 类型 | 约束           | 说明                                          |
| ------ | ---- | -------------- | --------------------------------------------- |
| `file` | File | 单个 ≤ 200 MiB | 通过左下的「选择文件」选取 `.zip`，**不上传** |

## 输出

| 字段   | 类型   | 说明                                              |
| ------ | ------ | ------------------------------------------------- |
| `text` | string | 包内清单：文件数 / 目录数 / 解压后体积 + 逐条列表 |
| `file` | binary | 下方下载面板：逐个下载，或「全部打包下载」为 zip  |

```text
压缩包：pack.zip
共 2 个文件，1 个目录；解压后 11 B

包内清单：
1. ［文件］ a.txt（5 B）
2. ［文件］ dir/b.txt（6 B）
3. ［目录］ dir/
```

## 选项

无。

## 限制

- **单个文件上限 200 MiB**：超限直接报错，请用桌面解压软件
- **损坏 / 非 zip 文件**：报「不是有效的 ZIP 文件，或文件已损坏」
- **空 zip**：提示「压缩包为空」，下载面板不出现
- 加密 zip（需要密码）暂不支持：fflate 无法解密，会报解析失败
- 解压走 `fflate` 纯 JS 实现，全程本地，不发任何请求

## 数据流向

**纯本地处理。** 压缩包只在浏览器内存里解析，`meta.api = false`，无需自备 API/Key。

## 元信息

| 项       | 值                       |
| -------- | ------------------------ |
| 全局编号 | #516                     |
| 域       | `media`（音视频 / 媒体） |
| 大组     | `office`                 |
| 优先级   | P0                       |
| 可行性   | A（纯 JS）               |
| 模板     | T2（双栏，扩展文件入口） |
