# 富文本转纯文本

去除 HTML 标签保留文本。

## 用途

把富文本编辑器或网页里拷出来的内容清成纯文本，去掉标签、样式与脚本残留。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

HTML 片段。最大 200,000 字符。

## 输出

| 字段   | 类型   | 说明                                           |
| ------ | ------ | ---------------------------------------------- |
| `text` | string | 纯文本：默认按块级标签换行，可关闭以压成一段。 |

## 选项

| 选项             | 取值    | 默认 | 说明                                 |
| ---------------- | ------- | ---- | ------------------------------------ |
| `keepLineBreaks` | boolean | true | 块级标签是否转成换行；关闭则压成一行 |

## 限制

- 用正则处理标签，**不是完整的 HTML 解析器**：属性里含 > 的畸形片段可能误判
- script / style 与 HTML 注释会被整段丢弃
- 只解码常见具名实体与数字实体，罕见实体原样保留
- 不保留任何结构信息（层级、表格列、链接地址都会丢失）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
<div><h2>工具库</h2><p>本地<strong>优先</strong>。</p></div>
```

输出：

```text
<div><h2>工具库</h2><p>本地<strong>优先</strong>。</p><p>共 870 个。</p></div>
```
