# 物理公式（#822）

A 级工具：纯前端本地速查与计算，无网络、无第三方 API。

## 功能

- **速查模式（lookup）**：列出 15 条中学物理公式目录（力学 / 电学 / 热学），含公式表达式。
- **计算模式（calc）**：右侧选择公式，左侧按 `symbol=value` 逐行填写变量值（如 `m=2`），实时代入计算并输出结果；缺变量、非数字、格式非法时中文报错。
- **复制 / 下载**：结果可复制或下载为 `.txt`。

## 说明

- 本工具为公式速查与代入计算，非游戏物理模拟（游戏物理参数请用 #791 physics 工具）。
- 重力相关公式中 g 取 9.8 m/s²。
