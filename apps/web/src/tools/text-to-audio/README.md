# 文字转语音

用浏览器 SpeechSynthesis 把文字朗读出来：音色、语速、音调可调，长文本自动按句子分段逐段朗读。

## 用途

听文章、校对文案、给视频配旁白初稿。

## 输入

| 字段   | 类型   | 说明                     |
| ------ | ------ | ------------------------ |
| `text` | string | 左侧文本区：要朗读的文字 |

## 输出

| 字段    | 类型   | 说明                        |
| ------- | ------ | --------------------------- |
| `audio` | 语音   | 浏览器实时合成的朗读音频    |
| `text`  | string | 输入原文，可复制/下载为 txt |

## 选项

| 选项    | 类型 | 默认         | 说明                      |
| ------- | ---- | ------------ | ------------------------- |
| `voice` | 选择 | 中文音色优先 | 浏览器提供的可用音色      |
| `rate`  | 数字 | 1            | 语速，0.1～10（1 为正常） |
| `pitch` | 数字 | 1            | 音调，0～2（1 为正常）    |

## 限制

- 需要 Chrome / Edge 浏览器（SpeechSynthesis），其他浏览器会给出中文提示
- 长文本按句子边界切成 ≤200 字的段逐段朗读，单句超长会被硬切
- 朗读过程中点「停止」可中断
- 浏览器语音合成**不支持直接导出音频文件**；导出提示：点下方「复制 / 下载」可把文字导出为 txt

## 示例

输入 `床前明月光，疑是地上霜。` 点「朗读」：

```text
共 1 段，语速 1×，音调 1
朗读中（1/1）
```

## 数据流向

**纯本地处理。** 语音由浏览器 SpeechSynthesis 在本地合成，`meta.api = false`，无需自备 API/Key，不发任何请求。
