# Excel 转 Markdown

将 `.xlsx` / `.xls` / `.csv` 表格转换为 Markdown 表格，可选单个工作表。

## 用途

把 Excel 数据搬进 Markdown 文档、Wiki、笔记：上传表格，一键得到可粘贴的 Markdown 表格。

## 输入

| 字段   | 类型 | 约束        | 说明                             |
| ------ | ---- | ----------- | -------------------------------- |
| `file` | File | 最大 50 MiB | 左下「选择文件」选取，**不上传** |

文本框不支持直接转换（点「运行」会提示改用文件入口）。

## 输出

| 字段   | 类型   | 说明                      |
| ------ | ------ | ------------------------- |
| `text` | string | Markdown 文本，以换行结尾 |

工作表留空时每表一段（`## 表名` + 表格）；空表标注为「（空表）」。

```markdown
## 人员

| 姓名 | 年龄 |
| ---- | ---- |
| 张三 | 30   |
```

## 选项

| 选项    | 取值   | 默认 | 说明                        |
| ------- | ------ | ---- | --------------------------- |
| `sheet` | string | 留空 | 工作表名；留空 = 全部工作表 |

## 限制

- **文件上限 50 MiB**
- 转换由 xlsx（纯 JS，本地运行）完成，取单元格的**显示文本**
- 单元格里的 `|` 会转义为 `\|`，换行转为 `<br/>`，避免破坏表格结构
- 损坏 / 非表格文件会直接报中文错误

## 数据流向

**纯本地处理。** 文件不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：包含「人员」表（姓名 / 年龄两列）的 `.xlsx`

输出：

```markdown
## 人员

| 姓名 | 年龄 |
| ---- | ---- |
| 张三 | 30   |
```

## 元信息

| 项       | 值                       |
| -------- | ------------------------ |
| 全局编号 | #539                     |
| 域       | `media`（媒体 / 文档）   |
| 大组     | `office`                 |
| 优先级   | P1                       |
| 可行性   | A（纯 JS）               |
| 模板     | T2（双栏，扩展文件入口） |
