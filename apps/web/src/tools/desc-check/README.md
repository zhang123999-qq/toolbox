# 页面描述检查

分析 `meta description` 的 SEO 质量：长度、关键词前置、重复词、行动号召词，
给出 0–100 评分与改写建议。全部计算在本地完成，不联网。

## 输入

| 字段      | 类型   | 约束                                |
| --------- | ------ | ----------------------------------- |
| `text`    | string | description 文本，最多 200,000 字符 |
| `keyword` | string | 目标关键词（可选），最多 200 字符   |

## 输出示例

```text
字符数：78　显示宽度：156　长度评级：合适
目标关键词「在线工具箱」：已找到（前置）
重复词：无
行动号召词：免费、立即、了解更多
综合评分：100 / 100

改写建议：
  1. 描述长度与结构良好，关键词位置恰当
```

## 评分规则

- 显示宽度：ASCII 计 1，中文/全角计 2；100–320 为「合适」（对应 Google 约 155–160 字符展示位）
- 过短 −30、过长 −20；关键词缺失 −15、位置靠后 −5；重复词每个 −10（最多 −20）
- 命中行动号召词（免费/立即/了解更多/free/download 等）+5

## 限制

- 只做文本层面的启发式分析，不抓取页面、不保证搜索排名效果
- 中文重复词按「双字词出现 ≥3 次」判定，介词类高频双字词可能误报，仅供参考

## 数据流向

纯本地计算，无网络请求。`meta.api = false`。
