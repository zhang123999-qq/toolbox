# 文本截断

按字数截断并加省略号。

## 用途

按字符数、词数或行数截断文本，超出部分用省略号收尾：列表摘要、卡片文案、日志预览都靠它。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

一段文本。

## 输出

| 字段   | 类型   | 说明                                               |
| ------ | ------ | -------------------------------------------------- |
| `text` | string | 截断后的文本；未超限时原样返回（不会多出省略号）。 |

## 选项

| 选项       | 取值                        | 默认    | 说明                   |
| ---------- | --------------------------- | ------- | ---------------------- |
| `mode`     | `chars` / `words` / `lines` | `chars` | 按字符 / 按词 / 按行   |
| `limit`    | `20` / `50` / `100` / `200` | `20`    | 上限                   |
| `ellipsis` | 字符串（最多 8 字符）       | `…`     | 省略符号，可写成 `...` |

## 限制

- **按码点计数**：emoji、部分生僻字占 1 个「字符」，但显示宽度可能是 2 列，与 #61 / #62 的「列宽」不是同一把尺子
- `words` 模式复用全站的切词口径：**中文没有分词**，一整段连续汉字算一个词，因此中文请优先用 `chars`
- `words` 模式输出时把词直接连起来会丢掉原文空格（`one two` 截 2 词得 `onetwo`），这是按词拼接的固有代价
- 正好等于上限时**不加**省略号，只有超出才加
- 不处理 HTML：截断会把标签切坏，请先转成纯文本（#20 富文本转纯文本）
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
这是一段比较长的示例文本，用来演示按字数截断之后会自动补上省略号的效果。
```

输出：

```text
这是一段比较长的示例文本，用来演示按字数…
```
