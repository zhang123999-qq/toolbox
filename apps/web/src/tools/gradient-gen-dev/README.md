# 渐变生成

生成 `linear` / `radial` / `conic` 三种 CSS 渐变背景，支持多个色标定位。

## 用途

随手拼一个好看的渐变背景，直接拿到 `background: ...` 这一行。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

输入框只作触发用。

## 输出

| 字段   | 类型   | 说明                  |
| ------ | ------ | --------------------- |
| `text` | string | `background: <渐变>;` |

## 选项

| 选项 key | 界面标签    | 说明                              |
| -------- | ----------- | --------------------------------- |
| `type`   | 类型        | linear / radial / conic           |
| `angle`  | 角度(deg)   | 线性/锥形渐变的角度，空则回退默认 |
| `color1` | 颜色1       | HEX / rgb() / 命名色              |
| `pos1`   | 位置1       | 如 `0%`                           |
| `color2` | 颜色2       | 第二色                            |
| `pos2`   | 位置2       | 如 `100%`                         |
| `color3` | 颜色3(可选) | 留空则不输出第三个色标            |
| `pos3`   | 位置3       | 如 `50%`                          |

## 限制

- 不输出 `-webkit-` 前缀（现代浏览器均已标准）
- radial 固定 `circle`，不做 `ellipse at ...` 定位
- 颜色仅做格式校验
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** `meta.api = false`。

## 示例

输出：

```css
background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%);
```
