# 拼音转换

汉字转拼音，支持声调、多音字。

## 用途

给汉字标注读音：做识字卡片、排版注音、生成拼音索引或文件名。

## 输入

| 字段   | 类型   | 约束             |
| ------ | ------ | ---------------- |
| `text` | string | 最大 20,000 字符 |

中文文本；逐行转换，空行保留。最大 20,000 字符（拼音库按词组解析，长文本较慢）。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 以空格分隔的拼音串；每行对应输入的一行。 |

## 选项

| 选项   | 取值                | 默认   | 说明                               |
| ------ | ------------------- | ------ | ---------------------------------- |
| `tone` | symbol / num / none | symbol | 声调形式：声调符号 / 数字 / 无声调 |

## 限制

- 依赖 pinyin-pro，字典随工具页懒加载（首次使用需加载字典）
- 多音字按词组自动判别，生僻组合可能判错；单字场景下取常用读音
- 非中文字符会被逐字符分隔输出（如 `A1` → `A 1`），不做转写

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具库
```

输出：

```text
工具库
```
