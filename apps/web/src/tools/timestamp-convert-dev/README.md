# 时间戳转换

Unix 时间戳与人类可读日期互相转换。输入纯数字按时间戳解释，输入日期串按日期解析；
秒 / 毫秒可自动识别，也可强制指定。纯原生 `Date` 实现，不依赖 dayjs。

## 用途

后端日志 / JWT / 缓存键里到处是 `1600000000` 这种数字，本工具一键还原成可读时间，
或把一个日期算成 Unix 秒 / 毫秒。

## 输入

| 字段   | 类型   | 约束                                  |
| ------ | ------ | ------------------------------------- |
| `text` | string | 时间戳数字或日期串，最大 200,000 字符 |

- **纯数字** → 当作时间戳：默认按绝对值 ≥ 1e12 判为毫秒，否则按秒
- **日期串** → 支持 `YYYY-MM-DD HH:mm:ss`、`YYYY/MM/DD`、ISO 8601（带 T / Z）

## 选项

| 选项   | 标签 | 值                  | 说明                       |
| ------ | ---- | ------------------- | -------------------------- |
| `unit` | 单位 | `auto` / `s` / `ms` | 强制按秒或毫秒解释数字输入 |

## 输出

| 方向          | 输出内容                     |
| ------------- | ---------------------------- |
| 时间戳 → 日期 | 秒、毫秒、本地时间、UTC 时间 |
| 日期 → 时间戳 | 秒、毫秒、ISO 8601、本地时间 |

```text
Unix 时间戳（秒）：1600000000
Unix 时间戳（毫秒）：1600000000000
本地时间：2020-09-13 20:26:40
UTC 时间：2020-09-13 12:26:40
```

## 限制

- 日期串按**浏览器本地时区**解析（ISO 带 Z 除外，按 UTC）
- 自动识别阈值为 1e12：更早的合法毫秒时间戳（1970 年代）需手动选 `ms`
- 空输入返回空串；无法解析的输入抛中文错误

## 数据流向

**纯本地处理。** 原生 Date 运算，不发送网络请求。`meta.api = false`。

## 示例

输入：

```text
1600000000
```

输出（东八区）：

```text
Unix 时间戳（秒）：1600000000
Unix 时间戳（毫秒）：1600000000000
本地时间：2020-09-13 20:26:40
UTC 时间：2020-09-13 12:26:40
```
