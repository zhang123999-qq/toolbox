# 方差（Variance）

输入一组数字，计算总体方差或样本方差，附均值与数据个数。

## 用途

- 衡量一组数据的离散程度
- 总体方差（分母 n）与样本方差（分母 n−1）一键切换

## 输入

| 字段   | 类型   | 约束                        |
| ------ | ------ | --------------------------- |
| `text` | string | 数值列表，最大 200,000 字符 |

分隔符支持逗号（中英文）、空格、换行、分号、顿号、竖线，可混用；支持小数与负数。

## 输出

```text
数据个数：8
均值：5
总体方差：4
（分母 n）
```

## 选项

| 选项     | 类型    | 说明                                       |
| -------- | ------- | ------------------------------------------ |
| `sample` | boolean | 样本模式：勾选后按样本方差（分母 n−1）计算 |

## 算法

- 均值 μ = Σx / n
- 总体方差 = Σ(x − μ)² / n
- 样本方差 = Σ(x − μ)² / (n − 1)

## 边界

- 空输入 → 输出空
- 非数字 → 中文报错并指出具体 token
- 样本模式下只有 1 个数据 → 中文报错（需要至少 2 个）
- 输入 > 200,000 字符 → 报错

## 示例

输入：`2, 4, 4, 4, 5, 5, 7, 9`

输出总体方差：`4`；样本方差：`4.571429`。

## 数据流向

纯本地计算，不上传任何数据。

## English

Enter a list of numbers to compute the population variance (÷ n) or sample variance (÷ n−1, toggle the "sample" option), with the mean and count. All computation is done locally in the browser; no data is uploaded.
