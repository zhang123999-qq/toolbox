# 换行符转换

LF、CRLF、CR 互转。

## 用途

统一换行符：Windows 的 CRLF 与 Unix 的 LF 混在一起会让 diff 满屏、脚本报错、Git 反复提示改动——用它一键归一。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

任意文本。CRLF、LF、CR 混排也能处理，先归一成 LF 再转成目标。

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 换行符统一后的文本，其余内容不变。 |

## 选项

| 选项     | 取值                                     | 默认 | 说明       |
| -------- | ---------------------------------------- | ---- | ---------- |
| `target` | `lf`（\n） / `crlf`（\r\n） / `cr`（\r） | `lf` | 目标换行符 |

## 限制

- 只改换行符，不动行内容、不去首尾空行、不处理文件末尾是否有换行
- 古老的 CR（Mac Classic）换行会一并归一，不会单独保留
- 按字符处理而非字节：本工具面对的是浏览器里已解码的字符串，不读写文件
- 不提供「按文件批量转换」（纯静态站点不访问本地文件系统）
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
第一行
第二行
第三行
```

输出：

```text
第一行
第二行
第三行
```
