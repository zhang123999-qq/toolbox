# 频谱分析

上传音频或使用麦克风，用 FFT（快速傅里叶变换）分析频率成分，在 canvas 上绘制实时频谱图。

## 用途

查看音频的频率分布：找共振峰、检查低频噪声、观察乐器谐波结构。

## 输入

| 字段         | 类型   | 约束         | 说明                                         |
| ------------ | ------ | ------------ | -------------------------------------------- |
| `file`       | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传**         |
| `microphone` | 音频流 | —            | 「麦克风实时」模式，浏览器内分析，**不上传** |
| `text`       | string | —            | 左侧文本区仅作备注，不参与处理               |

文件用浏览器 Web Audio API 本地解码；示例音频为 440/880/1320Hz 混合正弦波。

## 输出

| 字段    | 类型   | 说明                                  |
| ------- | ------ | ------------------------------------- |
| `image` | canvas | 频谱柱状图（颜色随能量从蓝变红）      |
| `text`  | string | 峰值频率报告，如 `峰值频率：440.0 Hz` |

## 选项

| 选项      | 类型 | 默认 | 说明                                      |
| --------- | ---- | ---- | ----------------------------------------- |
| `fftSize` | 数字 | 4096 | FFT 点数，512 / 1024 / 2048 / 4096 / 8192 |

FFT 点数越大频率分辨率越高（4096 点 @44.1kHz ≈ 10.8Hz/格）。

## 限制

- 文件模式取音频中段做分析（长度按 FFT 点数截取/补齐）
- 浏览器不支持 Web Audio API 或 Canvas 2D 时会给出中文提示
- 麦克风模式需要授予麦克风权限（HTTPS 或 localhost）
- 全程本地处理，不发任何请求

## 示例

载入示例音频（440/880/1320Hz 混合正弦）：

```text
峰值频率：440.0 Hz（-12.0 dB）
```

频谱图上 440Hz 处柱最高，880Hz、1320Hz 次之。

## 数据流向

**纯本地处理。** 解码、FFT、绘制都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
