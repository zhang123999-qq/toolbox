# 数据转换工作台

按步骤串依次为数据套用多步转换（大小写、去空白、JSON 与 YAML 互转、编码等）。

## 用途

一次粘贴，连着做几步处理，而不是在多个工具之间来回复制粘贴：
「先把每行去空白 → 删空行 → 排序 → 去重」，
「JSON 压成单行 → Base64」，
「YAML 转 JSON → 美化缩进」。每一步的中间结果都能看到，方便定位是哪一步改坏了。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 每步结果（或仅最终结果）；空输入返回空串 |

## 选项

| 选项    | 类型            | 默认    | 说明                               |
| ------- | --------------- | ------- | ---------------------------------- |
| `steps` | 多行文本        | 见下文  | 每行一个步骤，按顺序执行           |
| `mode`  | `steps`/`final` | `steps` | 输出每步中间结果，还是只给最终结果 |

### 步骤写法

每行一个步骤，形如 `名称` 或 `名称(参数1,参数2)`；名称不区分大小写；
`#` 之后的内容视为注释、空行跳过：

```text
trimlines        # 去掉每行首尾空白
removeempty
sort
dedupe
```

## 步骤一览

| 步骤                              | 说明                                          |
| --------------------------------- | --------------------------------------------- |
| `upper` / `lower`                 | 大小写转换                                    |
| `trim`                            | 去掉整段首尾空白                              |
| `trimlines`                       | 去掉每行首尾空白                              |
| `collapse`                        | 折叠连续空白为一个空格                        |
| `removeempty`                     | 删除空行                                      |
| `dedupe`                          | 删除重复行（保留首次出现）                    |
| `sort` / `sortdesc`               | 按行升 / 降序（中文用 `zh-Hans-CN` 排序规则） |
| `reverse`                         | 反转行顺序                                    |
| `jsonformat(n)`                   | JSON 美化，`n` 为缩进空格数（默认 2）         |
| `jsonminify`                      | JSON 压成单行                                 |
| `json2yaml(n)`                    | JSON 转 YAML                                  |
| `yaml2json(n)`                    | YAML 转 JSON                                  |
| `csv2json` / `csv2json(noheader)` | CSV 转 JSON；默认首行是表头                   |
| `json2csv`                        | JSON 对象数组转 CSV                           |
| `base64` / `base64decode`         | Base64 编解码                                 |
| `urlencode` / `urldecode`         | URL 百分号编解码                              |
| `hex` / `hexdecode`               | 十六进制编解码                                |
| `replace(from,to)`                | 字面替换                                      |
| `replaceRegex(p,to,flags)`        | 正则替换，`flags` 缺省为 `g`                  |
| `prefix(x)` / `suffix(x)`         | 每行加前缀 / 后缀                             |
| `linecount`                       | 输出行数、字符数与 UTF-8 字节数               |

## 限制

- **YAML 是自实现的子集解析器**：支持块映射、块序列、`- key: value` 起头的内嵌映射、
  单双引号标量、`true/false/null/数字`；**不支持**流集合（`[a, b]`、`{a: 1}`）、
  锚点与别名、合并键、多文档（`---`）、块标量（`|` / `>`）、复杂键与标签。
  `json2yaml` 的输出能被 `yaml2json` 读回，但反过来处理外部复杂 YAML 时可能报错或不完整。
- CSV 支持引号内的逗号与换行、`""` 转义；不支持自定义分隔符（固定逗号）。
- `base64` 默认按 UTF-8 编码 / 解码，不处理字符集转换（用 `encoding-convert` 工具）。
- 中间结果的展示上限为 4,000 字符，超出部分截断并标注总量；`final` 模式不做截断。
- 步骤失败时整个流水线中止并报错（不会跳过），单步最多 3 个参数。
- 换行统一按 `\n` 输出，不会保留原始的 CRLF。

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
  香蕉

苹果
橙子
苹果
```

步骤：

```text
trimlines
removeempty
sort
dedupe
```

输出（steps 模式节选）：

```text
== 步骤 4 · dedupe ==
3 行 / 8 字符
橙子
苹果
香蕉

== 最终结果 ==
橙子
苹果
香蕉
```
