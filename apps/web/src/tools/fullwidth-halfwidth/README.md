# 全角半角

全角与半角字符互相转换。

## 用途

清理从表格、PDF、日文系统里粘出来的全角字符，或反向生成全角排版。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                                |
| ------ | ------ | --------------------------------------------------- |
| `text` | string | 转换后的文本，非 ASCII / 非全角区间的字符原样保留。 |

## 选项

| 选项   | 取值            | 默认   | 说明                         |
| ------ | --------------- | ------ | ---------------------------- |
| `mode` | toHalf / toFull | toHalf | 方向：全角→半角 或 半角→全角 |

## 限制

- 只处理 U+FF01–U+FF5E 与全角空格 U+3000；日文假名的全半角（ぁ/あ）不在范围内
- 中文标点（，。！）不属于全角 ASCII 区间，不会被转换
- 往返转换对 ASCII 可见字符可逆，其它字符原样保留

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
Ｔｏｏｌｂｏｘ　８７０
```

输出：

```text
Ｔｏｏｌｂｏｘ　８７０
```
