# Markdown 预览

实时渲染 Markdown，支持 GFM。

## 用途

粘贴 Markdown 立刻看到排版效果，用于写 README、文档、评论前的预览。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

Markdown 文本（GFM：表格、删除线、任务列表）。最大 200,000 字符。

## 输出

| 字段   | 类型   | 说明                                                                         |
| ------ | ------ | ---------------------------------------------------------------------------- |
| `text` | string | 右侧渲染区显示排版结果；「复制 / 下载」拿到的是渲染后的 HTML 源码（.html）。 |

## 选项

| 选项     | 取值    | 默认  | 说明                                         |
| -------- | ------- | ----- | -------------------------------------------- |
| `breaks` | boolean | false | 开启后单个换行渲染为 <br>（GitHub 评论风格） |

## 限制

- **关闭了原始 HTML**（markdown-it 的 html: false）：输入里的 <script> 等标签会被转义而非执行
- 只做 Markdown 渲染，不做 XSS 之外的安全过滤；把渲染结果发布到别处请自行复核链接
- 依赖 markdown-it，随工具页懒加载；GFM 的表格与删除线由 markdown-it 默认规则支持
- 本工具用 T3 多面板模板（输出是渲染结果而非纯文本），与「Markdown 转 HTML」的区别是前者给你看、后者给你源码

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
# 工具库

- 本地优先
```

输出：

```text
# 工具库

- 本地优先
- **870** 个工具

| 域 | 数量 |
| -- | -- |
| text | 70 |
```
