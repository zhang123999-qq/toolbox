# WCAG 对比度

输入前景色与背景色（支持 `#rrggbb`、`#rgb`、颜色名、`rgb()` 等 CSS 颜色写法），按 WCAG 2.x 公式计算对比度，并判定正文 AA / AAA、大文本 AA / AAA、UI 组件图形四个级别是否通过；不通过时给出明度调整后的修复建议色。

## 用途

- 检查网站文字配色是否满足无障碍要求
- 设计稿走查：快速验证按钮、标题配色
- 生成修复建议：一键得到达标的替换色

## 输入

| 字段   | 类型   | 约束   |
| ------ | ------ | ------ |
| `text` | string | 前景色 |
| `bg`   | string | 背景色 |

## 说明

- 纯本地计算，无网络请求。
- 阈值：正文 AA ≥ 4.5、AAA ≥ 7；大文本 AA ≥ 3、AAA ≥ 4.5；UI 组件 / 图形 ≥ 3。
- 修复建议沿 Oklch 明度轴搜索首个达标色；若两方向都找不到（如背景为中灰），会提示更换配色方案。
