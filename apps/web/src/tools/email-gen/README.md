# 邮件生成 Email Generator（#611）

BYOK 模式：填写收件人与写信目的，选择语气（正式 / 亲切 / 简洁 / 恳切）
与语言（中文 / 英文），请大模型生成邮件主题与正文。

## 使用方法

1. 左侧上方填收件人，下方写清写信目的；
2. 右上角选择语气与语言；
3. 右侧配置接口地址、模型名、API Key；
4. 点「生成邮件」，主题与正文展示在下方，可复制/下载。

## 结构化解析

提示词要求模型第一行以「主题：」开头写主题，空一行后写正文；
本站用 `parseEmailOutput` 严格解析，缺主题或正文为空会报中文错。

## BYOK 说明

- API Key 只保存在内存中，刷新/关闭页面即清除，不写 localStorage；
- Key 只出现在请求头中，本站不经手、不记录；
- 接口需兼容 OpenAI 的 `POST {baseURL}/chat/completions` 格式。

## 错误处理

- 收件人 / 目的为空或超长显示中文错误；
- 401 / 403 / 404 / 429 / 5xx 翻译为中文提示。
