# 音频合并

选择多个音频文件，用 Web Audio API 解码，在浏览器本地拼接或混音并导出为 WAV。

## 用途

把多段录音拼成一段（拼接），或把人声与配乐叠在一起（混音）：选好模式一键生成。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」**多选**，不上传 |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                    |
| ------- | ------ | --------------------------------------- |
| `audio` | WAV    | 合并后的音频（16 位 PCM），可试听并下载 |
| `text`  | string | 处理报告：合并模式 / 轨道数 / 输出时长  |

## 选项

| 选项   | 类型 | 默认   | 说明                                          |
| ------ | ---- | ------ | --------------------------------------------- |
| `mode` | 下拉 | concat | 合并模式：concat（首尾拼接）/ mix（混音叠加） |

## 限制

- 至少需要 2 个音频文件，少于 2 个会给出中文错误提示
- 所有轨道的采样率、声道数必须一致，不一致会给出中文错误提示
- 混音叠加后按峰值归一化，避免削波
- 不支持 Web Audio API 的旧浏览器会给出中文错误提示
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（2 轨：3 秒 440Hz + 2 秒 330Hz），拼接模式：

```text
共 2 轨　合并模式：首尾拼接
输出时长：5.00 秒
```

## 数据流向

**纯本地处理。** 解码与合并全在浏览器内完成，`meta.api = false`，无需自备 API/Key。
