# 摄像头拍照

打开摄像头预览，一键拍照并导出 PNG 图片。

## 用途

快速拍一张证件照式的快照、记录白板内容、采集测试图片。

## 输入

本工具无文本输入，纯浏览器能力工具。

## 输出

| 字段    | 类型 | 说明                        |
| ------- | ---- | --------------------------- |
| `image` | PNG  | 拍摄的照片，可预览并下载    |
| `text`  | 文本 | 拍照报告：文件名 / 导出尺寸 |

## 选项

| 选项      | 类型 | 默认   | 说明                                                 |
| --------- | ---- | ------ | ---------------------------------------------------- |
| `maxSide` | 数字 | `1920` | 导出图片的最长边（像素，160–4096），过大自动等比缩小 |

## 限制

- 需要浏览器支持 `getUserMedia` 且用户授予摄像头权限；权限拒绝 / 无摄像头时给出中文提示
- 摄像头画面尚未就绪时拍照会提示稍候再试
- 照片只在本地生成，不上传

## 示例

```text
拍照成功：拍照-20260928-111905.png（1280×720）
```

## 数据流向

**纯本地处理。** `meta.api = false`，无需自备 API/Key。
