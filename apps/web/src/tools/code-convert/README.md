# 代码转换

在 JavaScript 与 Python 之间做**基础语法映射**。不是完整 transpiler，只覆盖常见语法点。

## 用途

把一段 JS 片段快速「翻」成 Python 骨架（或反向），方便对照阅读 / 起步。

## 输入

| 字段   | 类型   | 约束                     |
| ------ | ------ | ------------------------ |
| `text` | string | 源代码，最大 50,000 字符 |

## 选项

| 选项 key | 界面           | 取值                |
| -------- | -------------- | ------------------- |
| `from`   | 来源（Origin） | javascript / python |
| `to`     | 目标语言       | javascript / python |

## 映射表

| JS                             | Python                    |
| ------------------------------ | ------------------------- |
| `function f(a) {`              | `def f(a):`               |
| `console.log(x)`               | `print(x)`                |
| `let/const/var x =`            | `x =`                     |
| `if (c) {` / `else {`          | `if c:` / `else:`         |
| `for (let i=0;i<n;i++) {`      | `for i in range(n):`      |
| `true` / `false` / `undefined` | `True` / `False` / `None` |

## 限制

- **逐行正则替换**，不做词法 / 语法分析：缩进、字符串内关键字、嵌套块、数组方法（`map`/`filter`）都不会处理
- 花括号是粗略删除，转换结果**不能直接运行**，需人工补全缩进与细节
- `from === to` 时原样返回

## 数据流向

**纯本地处理。** 无网络请求。`meta.api = false`。
