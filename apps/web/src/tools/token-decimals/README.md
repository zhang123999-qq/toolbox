# Token 精度

Token 单位换算：`wei` / `gwei` / `ether` / 自定义 decimals 互转，纯前端 BigInt 精确计算，无浮点误差。

## 用途

查余额、算 Gas、填表单时在最小单位整数和人类可读金额之间换算，例如把 `1000000000000000000` 换成 `1 ether`。

## 输入

| 字段   | 类型   | 约束                                                    |
| ------ | ------ | ------------------------------------------------------- |
| `text` | string | 待换算数值（十进制，可带千分位逗号），最大 200,000 字符 |

## 选项

| 选项                | 取值                                |
| ------------------- | ----------------------------------- |
| 源单位              | `wei` / `gwei` / `ether` / `自定义` |
| 目标单位            | `wei` / `gwei` / `ether` / `自定义` |
| 源自定义 decimals   | 自定义时的 decimals（0–255 的整数） |
| 目标自定义 decimals | 自定义时的 decimals（0–255 的整数） |

## 输出

```text
输入：1（ether）
结果：1000000000000000000（wei）
最小单位整数：1000000000000000000
```

## 说明

- 小数位数超出源单位精度时报错，不做静默截断（例如源为 `gwei` 时输入 `1.0000000001` 会报错）。
- 负数不被接受；如需处理负数请先自行取绝对值。
