# 公历农历互转

内置 **1900–2100** 农历数据表，在公历（Gregorian）与中国农历之间做**双向**转换，
输出农历年月日（含闰月标记）、干支纪年与生肖。

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 一段日期文本，最大 200,000 字符 |

配合「方向」选项：

- **公历→农历**：输入公历日期，如 `2025-01-29`
- **农历→公历**：输入农历日期，闰月在月份前加「闰」，如 `2023-闰2-1`（2023 闰二月初一）

空输入不产出内容；越界或非法日期给出中文错误。

## 输出示例

公历→农历：

```text
公历 2025-01-29
农历：2025 年 正月初一
干支：乙巳年（生肖属蛇）
```

农历→公历：

```text
农历 2023 年 闰二月初一
公历：2023-03-22
```

## 数据表与编码（数据来源）

农历每月长短与闰月无法用简单公式算出，必须查**历书**。本工具把 1900–2100 共 201 年的历书
压缩成一张静态表 `LUNAR_INFO`，每年一个十六进制整数，采用业界标准的紧凑位编码：

| 位段           | 含义                                                   |
| -------------- | ------------------------------------------------------ |
| `bit16`        | 当年有闰月时，闰月大小：`1`=大月 30 天，`0`=小月 29 天 |
| `bit15 … bit4` | 正月…十二月每月大小：`1`=大月 30 天，`0`=小月 29 天    |
| `bit3 … bit0`  | 闰月月份：`0`=当年无闰月，非 `0`=闰该月                |

基准日 **1900-01-31 = 农历 1900 年正月初一**（庚子鼠年）。转换即从该基准日算起的天数差。

> 数据为公开历书整理（香港天文台 / 通行农历表口径），在 1900–2100 范围内与
> 春节、闰月、朔望月大小一一对应；本表不做天文实时计算。

## 闰月策略

- 每年最多一个闰月，插在对应的正常月之后（如 2023 闰二月 = 正常二月之后再跟一个「闰二月」）。
- 闰月天数由 `bit16` 决定（29 或 30），与正常月长度位分开存储。
- 农历→公历输入带「闰」才落到闰月槽；若该年该月无闰，会报中文错误。
- 已验证的闰月：**2020 闰四月、2023 闰二月、2025 闰六月**。

## 干支与生肖

按**农历年**（正月初一为界）计算：`(year-4) mod 10` 取天干，`(year-4) mod 12` 取地支/生肖。
公历 1 月 1 日到春节之间，农历年仍属上一年，本工具会自动按农历年落位。

## 覆盖范围与边界

- 覆盖公历约 **1900-01-31（农历 1900 正月初一）至 2100 农历年末**。
- 早于 1900-01-31、或公历年份超出 1900–2100 的输入，直接抛中文错误，不做近似外推。
- 不处理节气（二十四节气需要太阳黄经计算，不在本工具范围）。

## 数据流向

**纯本地处理。** 一张 201 项静态表 + 纯整数运算，无任何网络请求、无第三方依赖。
`meta.api = false`。
