# 视频缩略图

上传视频，在多个时间点截取视频帧，生成缩略图网格预览，每张可单独下载为 PNG。

## 用途

快速浏览视频关键帧：填入多个时间点（秒），一次截取出所有帧，适合做视频封面挑选、内容审查、 storyboard 拼图。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 500 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

文件用浏览器 `<video>` 元素本地解码（支持 mp4 / webm 等浏览器可播格式），截取经 `<canvas>` 完成。

## 输出

| 字段    | 类型   | 说明                               |
| ------- | ------ | ---------------------------------- |
| `image` | PNG    | 每张缩略图，可单独下载             |
| `text`  | string | 截取报告：视频时长 / 时间点 / 张数 |

## 选项

| 选项         | 类型 | 默认        | 说明                                                    |
| ------------ | ---- | ----------- | ------------------------------------------------------- |
| `timestamps` | 文本 | `0.5, 2, 5` | 时间点（秒），逗号 / 顿号 / 空格 / 换行分隔，最多 12 个 |
| `columns`    | 数字 | 3           | 网格每行列数，1～6 的整数                               |

## 限制

- 时间点必须在 `[0, 视频时长]` 内，超出会中文提示并指出是第几个
- 单次跳转超过 8 秒无响应会中文提示超时（视频解码卡住时）
- 读不到视频时长（如文件损坏）会中文提示
- 文件全程留在浏览器内存里，不发任何请求

## 示例

```text
输入：movie.mp4
视频时长：10.00 秒
截取时间点：0.50 秒、2.00 秒、5.00 秒
共 3 张缩略图，每张可单独下载 PNG。
```

## 数据流向

**纯本地处理。** 解码与截取都在浏览器内完成，`meta.api = false`，无需自备 API/Key。

## 元信息

| 项       | 值                         |
| -------- | -------------------------- |
| 全局编号 | #576                       |
| 域       | `media`（音视频媒体）      |
| 大组     | `design`                   |
| 优先级   | P0                         |
| 可行性   | C（video + canvas）        |
| 模板     | T3（多面板，带缩略图网格） |
