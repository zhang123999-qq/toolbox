# SSL 证书体检

粘贴一张 **PEM 编码的 X.509 证书**（`-----BEGIN CERTIFICATE-----`），离线做一次安全体检：
有效期、信任链（自签名）、签名算法强度、公钥长度、SAN 覆盖。解析用已安装的 `node-forge`，
证书文本不出本机。

> **与规划文档的偏差说明**：规划表（02-编码加密安全.md #130）设想为 D 级在线工具——输入域名 / URL，
> 由服务端抓取并校验实时 TLS 证书。浏览器端无法稳定、可复现地对任意站点完成 TLS 握手并读取证书链
> （受跨域与证书 API 限制），结果也无法单测。因此本工具落地为**「粘贴证书 → 离线规则体检」**：
> `feasibility=A`、`api=false`、零网络请求。需要实时联网巡检请用 `openssl s_client` 或专业监控服务。

## 用途

拿到一张证书（运维导出、`openssl` 输出、CDN 控制台下载）后快速判断：是否快过期、是不是自签名、
有没有还在用 SHA-1、RSA 密钥是否太短、是否缺 SAN。

## 输入

| 字段   | 类型   | 约束                                   |
| ------ | ------ | -------------------------------------- |
| `text` | string | 最大 100,000 字符；单张 PEM X.509 证书 |

## 输出

中文文本报告：总体结论（通过 / 警告数 / 问题数）+ 主题、签发者 + 逐项检查结果。

## 检查规则

| 检查项   | 通过                             | 警告         | 问题（不通过）    |
| -------- | -------------------------------- | ------------ | ----------------- |
| 有效期   | 剩余 > 30 天                     | 剩余 ≤ 30 天 | 已过期 / 尚未生效 |
| 信任链   | 由 CA 签发（subject ≠ issuer）   | 自签名       | —                 |
| 签名算法 | SHA-256 及更强                   | —            | MD2 / MD5 / SHA-1 |
| 密钥强度 | RSA ≥ 2048 位（EC 等不判定位数） | —            | RSA < 2048 位     |
| SAN      | 含 subjectAltName                | 缺少 SAN     | —                 |

## 限制

- **纯离线、不联网**：不校验证书是否被吊销（CRL / OCSP）、不验证完整信任链 / 中间证书是否齐全、
  不检查域名与证书是否匹配（不发起连接）
- 一次只解析**一张**证书；PKCS#7 证书链、DER 二进制、PFX/P12 不支持（可先用 openssl 转 PEM）
- 密钥强度对 EC / Ed25519 只标注算法、不比较位数；有效期阈值（30 天）内置不可调
- 无法解析时抛 `SslCheckError`

## 数据流向

**纯本地处理。** 证书仅在浏览器内存中解析（node-forge），不上传、不发起任何网络请求。`meta.api = false`。
