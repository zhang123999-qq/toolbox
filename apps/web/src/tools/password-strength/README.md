# 密码强度

用 zxcvbn 估算一段口令的强度与破解耗时。

## 用途

判断一个口令到底有多抗猜：它不数「有没有大写字母」，而是按真实攻击手法
（字典、键盘图案、日期、常见替换）估算猜测次数，再换算成不同场景下的破解耗时。
适合评审口令策略、给用户看实时反馈时参考。

## 输入

| 字段   | 类型   | 约束              | 说明         |
| ------ | ------ | ----------------- | ------------ |
| `text` | string | 最大 200,000 字符 | 待评估的口令 |

## 输出

| 字段   | 类型   | 说明                                               |
| ------ | ------ | -------------------------------------------------- |
| `text` | string | 强度档位（0–4）+ 三种破解场景耗时 + 风险提示与建议 |

## 选项

本工具没有选项：评估口径固定为 zxcvbn 的默认模型（也是 Dropbox 线上用的那一套）。

## 限制

- **不要把真实口令粘到任何在线工具里**，包括这一个。要评估真实口令，
  请把它改到「结构相似但内容不同」再粘进来（`MyDog2024!` → `Xq7#kL2!vZz9$w`）
- 评估是**估算**：zxcvbn 的字典有限，遇到特定语种、特定行业的口令可能偏高
- 只看单条口令，不知道你的站点有没有限速、有没有加盐——那属于服务端策略
- 评分是确定性的：同样的口令永远得到同样的结论

## 数据流向

**纯本地处理。** 口令只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
P@ssw0rd
```

输出：

```text
强度 0 / 4（极弱）

在线破解（无限速，10 次/秒）：2 秒
离线破解（慢哈希，1e4 次/秒）：6 分钟
离线破解（快哈希，1e10 次/秒）：不到 1 秒

风险：它与某个常用密码很接近

建议：
- 用几个不相关的词拼起来，避免常见短语
…
```
