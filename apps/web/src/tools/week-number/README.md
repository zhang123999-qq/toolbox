# ISO 周数

输入一个日期，输出它在 ISO 8601 里是第几周（Wxx）、星期几、该周周一和周日分别是几号、以及所在 ISO 年共有多少周。

## 用途

- 周报 / 迭代排期里说「W42」具体指哪几天
- 跨年周边界：1 月 1 日可能属于上一年第 52/53 周，12 月 31 日可能属于下一年第 1 周
- 查某周的周一 / 周日日期范围

## 输入

| 字段   | 类型   | 约束                    |
| ------ | ------ | ----------------------- |
| `text` | string | 日期，最大 200,000 字符 |

格式同其它 datetime 工具：`YYYY-MM-DD`、`YYYY/MM/DD`，可带时间。

## 输出

```text
日期：2026-09-27
星期：日（ISO 周 7）
ISO 周数：2026-W39
该周周一：2026-09-21
该周周日：2026-09-27
2026 年共 53 个 ISO 周
```

## 选项

本工具无选项。

## 算法（ISO 8601，自研）

- **周一为一周开始**，周日为一周结束。
- **第 1 周**是包含当年第一个周四的那一周（等价于包含 1 月 4 日的那一周）。
- 步骤：
  1. 算出输入日期所在周的周四；
  2. 这个周四所在的公历年就是 **ISO 年**；
  3. 以 ISO 年第 1 周的周一为零点，`(周四 - 零点) / 7 + 1` 即周号。
- **当年总周数**：1 月 1 日是周四 → 53 周；闰年且 1 月 1 日是周三 → 53 周；否则 52 周。

## 边界

- **1 月 1 日可能属于上一年**：如 2023-01-01（周日）= 2022-W52；2012-01-01（周日）= 2011-W52
- **12 月 31 日可能属于下一年**：如 2025-12-31（周三）= 2026-W01
- 闰年 53 周边界：2020-12-31（周四）= 2020-W53
- 越界日期（2-30）→ 中文报错
- 输入 > 200,000 字符 → 报错

## 示例

输入：`2025-12-31`

输出：`ISO 周数：2026-W01`（虽然日历上还是 2025 年，但按 ISO 规则已算入 2026 年第 1 周）。
