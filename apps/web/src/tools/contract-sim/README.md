# 合约只读模拟

给定合约地址 + ABI + 方法名 + 参数，用 `eth_call` 在本地节点模拟执行，只看返回值，不签名、不发交易、不上链。

## 用途

调合约的 view 方法（如查 `balanceOf`、查某个配置值）时，先在本地模拟跑一遍看返回，不用钱包、不用发交易。

## 输入

| 字段   | 类型   | 约束                                                          |
| ------ | ------ | ------------------------------------------------------------- |
| `text` | string | 调用参数 JSON 数组，如 `["0xabc...", 100]`，最大 200,000 字符 |

## 选项

| 选项     | 取值                                                         |
| -------- | ------------------------------------------------------------ |
| 合约地址 | 0x 开头的 40 位十六进制地址                                  |
| ABI JSON | 合约 ABI（JSON 数组，只解析其中的 `function` 条目）          |
| 方法名   | 要调用的方法名（如 `balanceOf`）；重载方法暂不支持           |
| RPC 地址 | JSON-RPC 地址，留空用默认公共节点 `https://eth.llamarpc.com` |

支持的参数类型：`uintN` / `intN` / `address` / `bool` / `bytesN` / `string` / `bytes`；tuple 与数组暂不支持。

## 输出

```text
方法：balanceOf(address)
调用数据：0x70a082310000000000000000000000007e5f4552091a69125d5dfcb7b8c2659029395bdf
返回：
#0 = 100
```

## 说明

- `eth_call` 是节点在本地对最新状态做的只读执行；非 view/pure 方法也会明确标注"仅模拟，不上链"。
- 依赖公共 RPC 节点，可能限流、超时或被浏览器 CORS 限制；失败会明确报错，可自填其他 RPC 地址重试（地址只保存在页面 state，不写入任何存储）。
