# 正则测试

输入一段正则表达式与待测文本，列出**全部命中**、**每个捕获组**与**起止索引**，
并用 `⟦ ⟧` 在原文上做文本级高亮。

## 用途

写正则时最痛的两件事：到底命中了哪几段、每个分组抓到了什么。本工具把
`RegExp.exec` 的遍历结果摊平成可读清单，配合 5 个常用标志开关即时复算，
无需打开浏览器 DevTools 的 Console。

## 输入

| 字段      | 类型   | 约束              | 说明                         |
| --------- | ------ | ----------------- | ---------------------------- |
| `text`    | string | 最大 200,000 字符 | 待测文本                     |
| `pattern` | string | —                 | 正则表达式主体（不含 flags） |

**正则表达式**通过附加输入框输入；flags 不写在斜杠字面量里，改由右侧选项开关控制。

## 输出

| 字段   | 类型   | 说明                                           |
| ------ | ------ | ---------------------------------------------- |
| `text` | string | 命中清单（索引 / 命中文 / 各捕获组）+ 标注视图 |

```text
正则: /#([A-Z])(\d+)/g
共 2 个匹配

#1  [3, 9)  "#A1001"
      组1: "A"
      组2: "1001"
...
--- 标注视图（⟦ ⟧ 包裹命中）---
订单 ⟦#A1001⟧ 共 3 件，订单 ⟦#B2050⟧ 共 7 件
```

## 选项与标志映射

| 选项 key     | 界面标签       | 对应 JS 标志 | 语义                                  |
| ------------ | -------------- | ------------ | ------------------------------------- |
| `global`     | 全局匹配 (g)   | `g`          | 遍历全部命中；关闭时只取第一个        |
| `ignoreCase` | 忽略大小写     | `i`          | 不区分大小写                          |
| `multiline`  | 多行模式       | `m`          | `^`/`$` 匹配每行首尾而非整个文本首尾  |
| `dotAll`     | 点匹配换行 (s) | `s`          | `.` 也能匹配换行符                    |
| `unicode`    | Unicode (u)    | `u`          | 启用 Unicode 模式（按码点处理代理对） |

## 实现规则 / 算法

- 用 `new RegExp(pattern, flags)` 编译；非法模式直接抛中文错误
- `global` 开启时 `exec` 循环收集全部命中，空命中（如 `/x*/`）自动 `lastIndex+1` 防死循环
- `global` 关闭时只 `exec` 一次，符合 JS 非全局正则的语义
- 分组来自 `RegExpExecArray.slice(1)`；未参与匹配的可选组显示 `undefined`

## 浏览器边界与限制

- 只覆盖 JS（ES2018+）正则语法；`y`（sticky）、命名反向引用 `\k<name>` 等未单列开关
- 不做替换（replace）演示，只做匹配观察
- 超长回溯型正则（灾难性回溯）仍可能卡住主线程；输入上限 200,000 字符
- 空文本或空正则不产出内容（不进入错误态）

## 数据流向

**纯本地处理。** 直接调用浏览器内置 `RegExp`，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
text    = 订单 #A1001 共 3 件，订单 #B2050 共 7 件
pattern = #([A-Z])(\d+)
flags   = g
```

输出（节选自上）：

```text
正则: /#([A-Z])(\d+)/g
共 2 个匹配

#1  [3, 9)  "#A1001"
      组1: "A"
      组2: "1001"
#2  [19, 25)  "#B2050"
      组1: "B"
      组2: "2050"

--- 标注视图（⟦ ⟧ 包裹命中）---
订单 ⟦#A1001⟧ 共 3 件，订单 ⟦#B2050⟧ 共 7 件
```
