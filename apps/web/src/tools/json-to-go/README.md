# JSON 转 Go

由一段 JSON 样本推断并生成 Go 结构体：字段名导出为 PascalCase、自带 `json` tag，
嵌套对象可拆成独立命名结构体或内联匿名结构体。纯本地生成，不依赖第三方库。

## 用途

对接返回 JSON 的接口时，快速得到可直接 `encoding/json` 反序列化的类型定义；
数组样本会合并所有元素的形状，跨元素缺失的键自动判为可空（指针类型）。

## 输入

| 字段   | 类型   | 约束                                            |
| ------ | ------ | ----------------------------------------------- |
| `text` | string | 最大 2,000,000 字符；根节点必须是对象或对象数组 |

## 输出

| 字段   | 类型   | 说明                        |
| ------ | ------ | --------------------------- |
| `text` | string | Go 源码文本；空输入返回空串 |

## 选项

| 选项     | 取值              | 默认        | 说明                                               |
| -------- | ----------------- | ----------- | -------------------------------------------------- |
| `mode`   | nested / inline   | `nested`    | nested 拆成独立命名结构体；inline 用匿名内联结构体 |
| `style`  | omitempty / plain | `omitempty` | tag 是否追加 `,omitempty`                          |
| `indent` | 2 / 4 / tab       | `tab`       | 结构体字段缩进                                     |

## 类型推断规则

| JSON                  | Go                           |
| --------------------- | ---------------------------- |
| string                | `string`                     |
| boolean               | `bool`                       |
| 整数                  | `int`                        |
| 小数                  | `float64`                    |
| 数组                  | `[]T`（元素合并推断）        |
| 对象                  | 命名结构体 / 内联结构体      |
| null / 跨元素缺键     | 指针 `*T`（区分 nil 与零值） |
| 类型冲突 / 空数组元素 | `interface{}`                |

- 根结构体统一命名为 `Root`；嵌套结构体按字段名 PascalCase 命名，数组元素取单数（`users → User`），重名追加数字去重
- 字段名按小写单词 / 大小写边界切分后转 PascalCase；非字母数字键用 `FieldN` 兜底
- nested 模式下被引用的结构体先声明，避免「未定义类型」

## 限制

- 由**样本推断**，不是 JSON Schema：未出现在样本里的字段 / 取值不会生成；同名字段类型随样本变化
- 对象与标量混排的数组、纯 `null` 等无法确定类型时退化为 `interface{}`
- 不生成 `time.Time`（JSON 里的时间只是字符串），也不生成校验方法 / 反序列化接口
- 输入上限 2,000,000 字符，超长或非法输入抛 `JsonToGoError`

## 数据流向

**纯本地处理。** 输入仅在浏览器内存中处理，不发送网络请求，不写入服务端。`meta.api = false`。

## 示例

输入：

```json
{ "id": 1, "name": "工具库", "tags": ["go"], "meta": { "stars": 870 } }
```

输出（nested + omitempty，tab 缩进）：

```go
type Meta struct {
	Stars int `json:"stars"`
}

type Root struct {
	Id   int      `json:"id"`
	Name string   `json:"name"`
	Tags []string `json:"tags"`
	Meta Meta     `json:"meta,omitempty"`
}
```

> 说明：样本中实际出现的对象字段生成**值类型** `Meta`；只有跨数组元素缺键或值为 `null` 时才生成指针 `*Meta`，以便区分零值与缺失。
