# 二进制转换

二进制、八进制、十进制、十六进制互转，支持任意长度整数。

## 用途

把一个整数在 2 / 8 / 10 / 16 进制之间改写，用于读寄存器位掩码、看内存/协议里的十六进制、核对权限位或哈希前的数值。
输入哪怕有几百位也能精确换算——内部用 `BigInt` 而不是 `Number`，不会在 2^53 附近静默丢精度。

> 与「八进制转换」的分工：本工具做的是**数值的进制改写**（255 ↔ 11111111）；
> 若要把文本按 UTF-8 字节写成八进制转义，请用八进制转换。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

一行一个数值，多值用换行分隔；行内的空白会被忽略，因此可直接粘贴 `1010 1010` 这类分组写法。
每行允许带前导 `+` / `-`。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 逐行转换后的目标进制数值（十六进制小写） |

## 选项

| 选项        | 取值            | 默认 | 说明                     |
| ----------- | --------------- | ---- | ------------------------ |
| `source`    | 2 / 8 / 10 / 16 | 10   | 输入按哪个进制解析       |
| `target`    | 2 / 8 / 10 / 16 | 2    | 输出用哪个进制           |
| `separator` | none / 4 / 8    | 4    | 输出按几位一组加空格分隔 |

## 限制

- 只接受**整数**。小数、科学计数法（`1e3`）都会因为含非法字符而报错
- 输入中用错进制的字符会**明确报错并指出行号**，不会退化成 `parseInt` 的「截断到第一个非法字符」
- 十六进制输出统一用小写字母（输入大小写均可）
- 分组只影响显示：`separator` 不改变数值，转换回去时行内空白会被重新忽略

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（默认选项：10 进制 → 2 进制，每 4 位分组）：

```text
255
```

输出：

```text
1111 1111
```

其他实算结果：

| 输入（source）                         | 选项         | 输出                        |
| -------------------------------------- | ------------ | --------------------------- |
| `1111 1111`（2）                       | → 10，不分组 | `255`                       |
| `777`（8）                             | → 10，不分组 | `511`                       |
| `FF`（16）                             | → 10，不分组 | `255`                       |
| `255`（10）                            | → 16，不分组 | `ff`                        |
| `123456789012345678901234567890`（10） | → 16，不分组 | `18ee90ff6c373e0ee4e3f0ad2` |
