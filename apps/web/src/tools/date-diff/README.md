# 日期间隔

计算两个日期之间相差多久，同时给出「X 年 Y 个月 Z 天」的复合口径和「总天 / 总时 / 总分 / 总秒」的总量口径。

## 用途

- 算工龄、还款期限、合同到期还差多久
- 把「两个日期差多少天」换算成周 / 小时 / 秒
- 处理闰年、跨月、跨年的借位

## 输入

| 字段    | 类型   | 约束                      |
| ------- | ------ | ------------------------- |
| `text`  | string | 日期 A，最大 200,000 字符 |
| `textB` | string | 日期 B，最大 200,000 字符 |

两框格式同 date-calc：`YYYY-MM-DD`、`YYYY/MM/DD`、带时间的 `YYYY-MM-DD HH:mm:ss`。
任一为空即不产出；越界日期（2-30 等）中文报错。

## 输出

```text
日期 A：2024-01-01
日期 B：2025-03-15
方向：B 晚于 A
复合间隔：1 年 2 个月 14 天（00:00:00）
总天数：439 天（约 62 周）
总小时：10536 小时
总分钟：632160 分钟
总秒数：37929600 秒
```

## 选项

本工具无选项——所有维度同时输出。

## 算法

1. 两个日期都按本地时区解析。
2. **复合间隔**：先按日历日借位——
   - `年 = B.y - A.y`，`月 = B.m - A.m`，`日 = B.d - A.d`
   - 若 `日 < 0`，从 `月` 借 1（加上 B 上一个月的天数）
   - 若 `月 < 0`，从 `年` 借 1（月 += 12）
3. **总量**：直接用毫秒差 `|B - A|`，再除以 86400000 / 3600000 / 60000 / 1000。
4. 闰年影响体现在总天数里：2024-01-01 → 2025-01-01 = 366 天（2 月多 1 天）。

## 边界

- 任一日期为空 → 空输出
- B 早于 A：方向标「B 早于 A」，复合间隔绝对值不变
- 反向日期的复合分量与正向对称（仅 sign 不同）
- 越界日期 / 非法格式 → 中文报错
- 输入 > 200,000 字符 → 报错

## 示例

输入 A：`2024-02-28`，输入 B：`2024-03-01`

输出复合间隔：`0 年 0 个月 2 天`（闰年 2 月有 29 天）。
换成 2023 年则为 `1 天`（平年 2 月只有 28 天）。
