# 视频剪辑（video-editor）

多片段裁剪 + 排序 + 拼接：给视频"划重点"，输出一个新的 MP4。

## 功能

- 片段起止时间支持三种写法：秒数（`90`）、`mm:ss`（`1:30`）、`hh:mm:ss`（`01:02:03`）
- 片段可增删、上移 / 下移排序，自动校验起止合法性
- 导出采用流拷贝（`-c copy`），速度快、不重新编码
- ffmpeg.wasm 本地处理，视频不上传

## 使用

1. 选择视频文件（MP4 等）
2. 填写起止时间，点「添加片段」，可添加多个
3. 用上移 / 下移调整片段顺序
4. 点「导出视频」，预览后下载（文件名自动加 `-edit` 后缀）

## 限制（重要）

- **流拷贝裁剪只能切到关键帧**：片段边界会吸附到最近的关键帧，实际起止点可能与填写值有零点几秒偏差
- 如需帧精确裁剪，需要重新编码（本工具为保速度未采用）
- 首次使用需下载 ffmpeg.wasm（约十几 MB）
