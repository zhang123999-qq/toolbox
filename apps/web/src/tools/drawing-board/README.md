# 在线画图（#798）

在线工具大组的首个工具：自由画布，纯前端绘制，无需登录、无需上传。

## 功能

- **画笔**：拖动连续绘制，圆头笔触
- **直线 / 矩形 / 圆形**：拖拽预览、松开落笔
- **橡皮**：擦除为白色底
- **填充**：油漆桶，洪水填充连通区域
- **颜色**：8 色预设 + 自定义取色器
- **粗细**：1–50px 滑杆
- **撤销 / 重做**：保留最近 40 步
- **清空**：一键白底（可撤销）
- **导出 PNG**：960×600 原尺寸下载

## 说明

- 触屏可用（Pointer Events）。
- 所有绘制都在本地 canvas 完成，不经过网络。
