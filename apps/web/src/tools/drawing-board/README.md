# 在线画图（#798）

在线工具大组的首个工具：自由画布，纯前端绘制，无需登录、无需上传。

## 功能

- **13 种工具**：画笔、喷雾、荧光笔（半透明）、直线、箭头、矩形、圆形、三角形、菱形、星形、文本、橡皮、油漆桶填充
  - 直线 / 箭头 / 图形：拖拽预览、松开落笔
  - 图形支持**描边 / 填充 / 描边+填充**三种模式
  - 文本：点击画布弹出输入框，回车确认，可选字号
- **颜色**：8 色预设 + 自定义取色器
- **粗细**：1–50px 滑杆（荧光笔为 3 倍笔触、35% 透明度）
- **画布**：4 种尺寸（960×600 / 1280×720 / 800×800 / 620×877 A4竖版），切换后清空重来
- **背景色**：一键重填整个画布（可撤销）；橡皮按当前背景色擦除
- **图片底图**：上传本地图片，按比例完整放入居中作底图（可撤销）
- **撤销 / 重做**：保留最近 40 步，记录每次操作完成后的状态
- **清空**：按当前背景色清空（可撤销）
- **导出**：PNG 原尺寸 / JPG（0.92 质量）
- **全屏**：整个画板全屏，画布按比例自适应，Esc 退出
- **快捷键**：B 画笔 · S 喷雾 · M 荧光笔 · E 橡皮 · T 文本 · L 直线 · R 矩形 · A 箭头 · F 填充 · Ctrl+Z 撤销 · Ctrl+Y / Ctrl+Shift+Z 重做

## 说明

- 触屏可用（Pointer Events）。
- 所有绘制都在本地 canvas 完成，不经过网络。
