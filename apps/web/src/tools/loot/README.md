# 随机掉落（#803）

按权重抽取随机掉落，可模拟 N 次统计掉落分布。

## 掉落表格式

```json
[
  { "id": "gold", "weight": 70, "min": 10, "max": 20 },
  { "id": "sword", "weight": 20 },
  { "id": "gem", "weight": 10 }
]
```

- `id`：掉落项标识
- `weight`：权重（≥ 0；全表权重和必须 > 0）
- `min` / `max`：可选，掉落数量区间（默认 1）

## 功能

- **单次抽取**：按权重随机抽取一项，并按数量区间随机数量
- **模拟统计**：用 mulberry32（可复现种子）模拟 N 次，统计各掉落项次数与概率

## 说明

纯前端本地计算，不发送任何网络请求。模拟结果可复现（相同种子结果相同）。
