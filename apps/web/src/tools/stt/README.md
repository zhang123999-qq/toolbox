# 语音转文本

浏览器语音识别。

## 用途

把说的话转成文字：点「运行」后浏览器会申请麦克风权限，说完后自动结束并把结果连同置信度一起给出。

## 输入

| 字段   | 类型   | 约束            |
| ------ | ------ | --------------- |
| `text` | string | 最大 5,000 字符 |

本工具不需要输入文本，输入框留空即可；识别语言在选项里选。

## 输出

| 字段   | 类型   | 说明                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 识别语言、识别结果、置信度。 |

## 选项

| 选项       | 取值                        | 默认    | 说明     |
| ---------- | --------------------------- | ------- | -------- |
| `language` | `zh-CN` / `en-US` / `ja-JP` | `zh-CN` | 识别语言 |

## 限制

- **浏览器支持面比语音合成窄得多**：Chrome / Edge 能用（且走的是厂商的在线识别服务），Safari 需要在系统设置里开启，Firefox 默认没有该接口
- Chrome / Edge 的语音识别**会把音频送到厂商服务器**，不是纯本地；涉及敏感内容请改用其他方式（本工具 meta.api = false 是因为它不经过本项目服务器）
- 需要麦克风权限；被拒绝或设备被占用时会直接报「识别失败」
- 设为单次识别（说完后自动结束），不支持长时间连续听写
- 只取置信度最高的那一个候选，不提供备选结果
- 输入框上限 5,000 字符，实际上本工具不用输入

## 数据流向

**本项目不接收任何音频。** 识别直接由浏览器发起：

- 麦克风音频经浏览器交给**操作系统或浏览器厂商自带的识别服务**（Chrome / Edge 走在线服务），不经本项目任何服务器
- 识别结果只出现在当前页面的输出框里
- 需要麦克风授权；可以随时在浏览器地址栏的权限设置里收回

## 示例

输入：

```text
（无需输入，点运行后对着麦克风说话）
```

输出：

```text
识别语言：zh-CN
识别结果：（你说的话）
置信度：（由引擎给出）
```
