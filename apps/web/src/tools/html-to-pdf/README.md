# HTML 转 PDF

从 HTML 源码中提取文本结构（标题、段落、列表、引用、代码块、分割线），简化排版为 A4 PDF，纯本地生成后下载。

## 用途

把网页正文、导出的 HTML 文档快速转成可打印的 PDF；不需要保留原网页样式时比「打印为 PDF」更干净。

## 输入

| 字段   | 类型   | 约束              | 说明      |
| ------ | ------ | ----------------- | --------- |
| `text` | string | 最大 100,000 字符 | HTML 源码 |

提取规则（两遍处理）：

1. 整块丢弃 `<script>` / `<style>`；`<br>`、`<hr>`、`</p>` 等转成换行/分割线
2. `<h1>`~`<h6>` → `#`~`######` 标题；`<li>` → 列表项；`<pre>` → 代码围栏；`<blockquote>` → 引用
3. 其余标签全部剥除，HTML 实体解码（`&amp;`、`&#65;`、`&#x41;` 等）

**不保留**：行内样式（加粗/斜体/颜色）、超链接、图片、表格（表格内容会按文本流输出，无边框）。

## 输出

| 字段   | 类型       | 说明                          |
| ------ | ---------- | ----------------------------- |
| `file` | PDF 二进制 | A4 纵向 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「下载」按钮下载的是 HTML 源文本（`.html`）。

## 选项

| 选项       | 取值         | 默认 | 说明           |
| ---------- | ------------ | ---- | -------------- |
| `fontSize` | 10 / 12 / 14 | 12   | 基准字号（pt） |
| `margin`   | 36 / 54 / 72 | 54   | 页边距（pt）   |

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，输入含中文（或 emoji
  等非 Latin-1 字符）时会直接报错，不会生成乱码 PDF。
- 只提取到标签、没有文本内容时（如 `<div><br></div>`）会报错「HTML 中未提取到任何文本内容」。
- 文件全程在浏览器内存里生成，不发任何请求。

## 数据流向

**纯本地处理。** 输入与生成的 PDF 都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```html
<h1>Weekly Digest</h1>
<p>Highlights:</p>
<ul>
  <li>Ship v2.0</li>
</ul>
```

输出：A4 PDF；输出区显示如 `已生成 PDF：1 页，2.8 KB`。
