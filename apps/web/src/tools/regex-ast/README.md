# 正则转 AST

把一段正则表达式解析成**语法树（AST）文本**，看清它由哪些连接、选择、量词、分组组成。

## 用途

调试正则时，除了看「铁路图」，有时更想看一个贴近文法的树形结构：
哪个 `*` 修饰的是哪一段、`|` 的优先级如何、分组有没有捕获。本工具输出缩进树。

## 输入

| 字段   | 类型   | 约束              | 说明                         |
| ------ | ------ | ----------------- | ---------------------------- |
| `text` | string | 最大 200,000 字符 | 正则表达式主体（不含 flags） |

## 输出

| 字段   | 类型   | 说明              |
| ------ | ------ | ----------------- |
| `text` | string | 缩进的 AST 树文本 |

```text
Regex
Concatenation
  Group
    Group (non-capturing)
      Literal "a"
  Quantifier {1,∞}
    CharClass [0-9]
```

## 节点类型

| 节点                    | 含义                            |
| ----------------------- | ------------------------------- |
| `Concatenation`         | 顺序连接的一串子节点            |
| `Alternation`           | `a\|b` 选择分支                 |
| `Literal "x"`           | 字面量字符                      |
| `CharClass [...]`       | 字符类，含 `\d`/`\w` 等元字符类 |
| `Anchor ^`/`$`          | 锚点                            |
| `Group`                 | 捕获分组（含 `(?<name>…)`）     |
| `Group (non-capturing)` | `(?:…)` 非捕获分组              |
| `Quantifier {n,m}`      | 量词（`∞` 表示无上限）          |
| `Epsilon`               | 空分支（如 `a                   | `） |

## 实现规则 / 算法

- 递归下降：`parseAlt → parseSeq → parseBase → parseQuant`
- 连接多节点时包一层 `Concatenation`；选择多分支时包一层 `Alternation`
- 量词挂在被修饰节点外层，范围用 `{min,max}` 标注，`∞` 表示 `*`/`{n,}`
- 不支持反向引用、前瞻后顾等高级特性，遇到即报错

## 浏览器边界与限制

- 输出是**文本树**，不是图形；想看图形请用「正则可视化」
- 与「正则可视化」共用同一套语法子集，但各自独立实现（工具间不互相 import）
- 空输入不产出；非法正则抛中文错误

## 数据流向

**纯本地处理。** 自研解析，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
(https?://)?[\w.-]+(:\d+)?
```

输出（节选）：

```text
Regex
Concatenation
  Group
    Quantifier {0,1}
      Literal "("
      ...
```
