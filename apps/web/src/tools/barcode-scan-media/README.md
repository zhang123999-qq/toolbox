# 条码扫描

用摄像头实时扫描或上传图片，用 ZXing 在本地解码一维条码与二维码。

> **与「条码生成」器的区别**：仓库已有的 barcode 工具是把文本「生成」成条码图片；
> 本工具反过来，是从摄像头 / 图片里把条码「扫描识别」出来解码成文本。两者不重复。

## 用途

快速读取商品条码、物流面单、票据上的条码内容，无需掏出手机。

## 输入

| 字段   | 类型   | 约束 | 说明                                           |
| ------ | ------ | ---- | ---------------------------------------------- |
| `file` | File   | 图片 | 图片模式下通过「选择条码图片」选取，**不上传** |
| `text` | string | —    | 左侧文本区仅作备注，不参与处理                 |

## 输出

| 字段   | 类型 | 说明                                     |
| ------ | ---- | ---------------------------------------- |
| `text` | 文本 | 解码结果：条码格式中文名 / 内容 / 字符数 |

## 选项

| 选项   | 类型 | 默认     | 说明                        |
| ------ | ---- | -------- | --------------------------- |
| `mode` | 下拉 | `camera` | 扫描来源：摄像头 / 上传图片 |

## 限制

- 支持 QR Code、EAN-13/8、UPC-A/E、Code 128/39/93、Codabar、ITF、Data Matrix、Aztec、PDF417 等常见格式
- 摄像头模式把条码对准画面后自动停止并出结果；单帧未扫到会自动尝试下一帧
- @zxing/browser 按需动态加载：加载失败会提示检查网络后重试
- 全程本地解码，不上传

## 示例

```text
解码成功：一维条码（EAN-13，商品条码）（13 个字符）
6921234567890
```

## 数据流向

**纯本地处理。** ZXing 在浏览器内解码，`meta.api = false`，无需自备 API/Key。
