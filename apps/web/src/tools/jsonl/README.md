# JSON Lines

JSONL / NDJSON 的**解析、生成、逐行校验**三合一。

## 用途

日志、埋点、LLM 的流式输出常常是一行一个 JSON。要把它变成能喂给工具的数组、
要看哪一行是坏的、或者反过来把数组导成一行一条的 JSONL——都在这里。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 依 mode 而定；空输入返回空串 |

- `jsonl2json`：JSON 数组（缩进两格）
- `json2jsonl`：一行一个 JSON，行内不换行
- `validate`：逐行清单，首行是统计

```
校验结果：合法 2 行，不合法 1 行，空行 0 行
行 1：合法，顶层类型 object
行 2：不合法 —— broken
行 3：合法，顶层类型 number
```

## 选项

| 选项        | 取值                                       | 默认         | 说明                     |
| ----------- | ------------------------------------------ | ------------ | ------------------------ |
| `mode`      | `jsonl2json` \| `json2jsonl` \| `validate` | `jsonl2json` | 转换方向 / 只校验        |
| `skipEmpty` | boolean                                    | `false`      | 跳过空行而不报错／不计入 |

## 限制

- **解析模式不做容错**：任何一行不合法就整体报错并给出行号，
  不给「缺了几行」的半成品数组（静默丢数据比报错危险）
- 非勾选 `skipEmpty` 时空行也算错误（JSONL 规范允许空行，故做成开关）
- `json2jsonl` 要求输入是 **JSON 数组**，其他形态一律报错
- 行数上限 200,000，字符上限 1,000,000
- 兼容 `\n`、`\r\n`、`\r` 三种换行；**只忽略结尾的那一个换行**，多余的空行按 `skipEmpty` 决定是否报错

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（`mode = jsonl2json`）：

```
{"id":1,"name":"工具库"}
{"id":2,"name":"收纳盒"}
```

输出：

```json
[
  {
    "id": 1,
    "name": "工具库"
  },
  {
    "id": 2,
    "name": "收纳盒"
  }
]
```

反向（`mode = json2jsonl`）：

```json
[
  { "id": 1, "name": "工具库" },
  { "id": 2, "name": "收纳盒" }
]
```

输出：

```
{"id":1,"name":"工具库"}
{"id":2,"name":"收纳盒"}
```
