# MIME 类型查询

上传文件或输入扩展名，查询对应的 MIME 类型并校对扩展名与文件头。

## 用途

写 HTML/HTTP 头时查某个扩展名的 MIME；怀疑文件被改名（如把 exe 改成 jpg）时，上传后校对文件头。

## 输入

| 字段   | 类型   | 约束           | 说明                              |
| ------ | ------ | -------------- | --------------------------------- |
| `text` | string | 最多 100 字符  | 扩展名，如 `png` / `.png` / `PNG` |
| `file` | File   | 单个 ≤ 200 MiB | 待校对的文件，**不上传**          |

## 输出

| 字段   | 类型   | 说明                                                                               |
| ------ | ------ | ---------------------------------------------------------------------------------- |
| `text` | string | 文本查询：扩展名 → MIME + 同 MIME 别名；文件查询：扩展名对照、文件头嗅探、校对结论 |

## 选项

无可调选项。

## 限制

- 收录约 50 种常见扩展名，未收录的中文提示
- 文件头嗅探只看前 16 字节的常见签名，识别不出时如实提示「无法识别」，不猜
- 空文件直接报错
- 全程本地处理

## 与 file-magic 的区别

`file-mime` 侧重**扩展名 → MIME 的正查/反查与校对**；`file-magic` 侧重**魔数鉴定文件真实类型**，不做扩展名对照表。

## 数据流向

**纯本地处理。** 只读文件头 16 字节，`meta.api = false`，无需自备 API/Key。

## 示例

输入：`png`。

输出：

```text
.png → image/png
没有常用别名扩展名。
```

## 元信息

| 项       | 值                         |
| -------- | -------------------------- |
| 全局编号 | #524                       |
| 域       | `media`（音视频 / 媒体）   |
| 大组     | `office`                   |
