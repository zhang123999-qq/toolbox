# xxHash 哈希

极快的非加密哈希 xxHash32 / xxHash64（WASM 按需加载）。

## 用途

需要「快速判断两块内容是否一致」而不是「防篡改」的场合：缓存键、分桶、
内容去重、快速校验和。速度比 SHA-256 快一个数量级以上。

## 输入

| 字段   | 类型   | 约束              | 说明         |
| ------ | ------ | ----------------- | ------------ |
| `text` | string | 最大 200,000 字符 | 待哈希的文本 |

## 输出

| 字段   | 类型   | 说明                                  |
| ------ | ------ | ------------------------------------- |
| `text` | string | 十六进制哈希（32 位 8 位 / 64 位 16 位） |

## 选项

| 选项        | 取值    | 默认 | 说明                     |
| ----------- | ------- | ---- | ------------------------ |
| `bits`      | 32 / 64 | 32   | 位宽；碰撞概率与体积权衡 |
| `uppercase` | 开 / 关 | 关   | 十六进制是否大写         |

## 限制

- **非加密哈希**：不能防篡改、不能用于口令或签名。需要安全性请用 SHA-256 / BLAKE3
- WASM 首次点「运行」才加载，未触发前不占首屏体积
- 只处理文本；文件哈希请用专门工具
- 32 位碰撞概率不低（约 2^16 条就可能出现碰撞），做唯一键请用 64 位

## 数据流向

**纯本地处理。** 内容只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
hello
```

输出（32 位 / 64 位）：

```text
fb0077f9
26c7827d889f6da3
```
