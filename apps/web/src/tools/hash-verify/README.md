# 哈希校验（#714）

计算数据的哈希并与期望值比对，验证文件 / 文本在传输、下载后是否完整。全部在浏览器本地计算（WebCrypto），数据不离开本机。

## 输入

- 数据：文本（UTF-8）或 hex 二选一
- 期望哈希：hex（可带 `0x`、可含空白、大小写不限）
- 算法：SHA-256 / SHA-384 / SHA-512 / SHA-1

## 输出

实际哈希、期望哈希与「匹配 / 不匹配」结论。

## 规则

- 期望哈希长度与所选算法不符时直接判不匹配，并提示应有长度。
- SHA-1 仅用于兼容老系统校验，新场景请用 SHA-256 及以上。

## 限制

- 本工具做完整性比对，不做密码学安全评估；不要用它「验证」口令强度。
