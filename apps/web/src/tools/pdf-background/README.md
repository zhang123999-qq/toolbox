# PDF 加背景色

选择 PDF 文件与背景色，给每一页垫一层浅色背景，生成新 PDF 下载。
背景通过 content stream 前插实现，画在原有内容之下，不遮挡正文。纯本地处理。

## 用途

打印省墨的浅色底、阅读护眼、文档美化。

## 输入

| 字段   | 类型 | 约束      | 说明                       |
| ------ | ---- | --------- | -------------------------- |
| `file` | File | ≤ 100 MiB | 输出区文件选择框上传的 PDF |

下载文件名为原文件名加 `-background` 后缀（如 `demo-background.pdf`）。

## 输出

| 字段   | 类型       | 说明                               |
| ------ | ---------- | ---------------------------------- |
| `file` | PDF 二进制 | 加背景后的新 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积。

## 选项

| 选项    | 取值                                | 默认 | 说明               |
| ------- | ----------------------------------- | ---- | ------------------ |
| `color` | gray / blue / yellow / green / pink | gray | 背景色（均为浅色） |

## 限制

- 背景是整页填充的纯色矩形，不支持图片背景与渐变。
- 已有背景色的页面会再叠一层（颜色加深），不可撤销单步。
- 文件全程在浏览器内存里处理，不发任何请求。

## 数据流向

**纯本地处理。** PDF 文件与生成结果都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

1 页 PDF 选 blue → 输出区显示如 `已生成 PDF：1 页，1.2 KB`，下载 `demo-background.pdf`。
