# 文件转 Base64

把文件编码为 Base64 文本，可选输出 DataURL 格式。

## 用途

把小图片转成 DataURL 直接嵌进 HTML / CSS；把二进制文件转成文本塞进 JSON 接口；快速算一段文本的 Base64。

## 输入

| 字段   | 类型   | 约束            | 说明                                     |
| ------ | ------ | --------------- | ---------------------------------------- |
| `text` | string | 最多 500 万字符 | 待编码的文本（按 UTF-8），点「运行」转换 |
| `file` | File   | 单个 ≤ 200 MiB  | 通过左下的「选择文件」选取，**不上传**   |

两条路径互斥：选了文件就以文件为准；点「运行」则以文本区为准。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 说明行（来源与体积）+ 空行 + Base64 正文 |

## 选项

| 选项      | 取值    | 默认  | 说明                             |
| --------- | ------- | ----- | -------------------------------- |
| `dataUrl` | boolean | false | 输出 `data:<mime>;base64,…` 格式 |

## 限制

- **单个文件上限 200 MiB**；文本超过 500 万字符直接报错
- 大文件转出的 Base64 很长（约为原体积的 4/3），复制时注意
- 文件的 MIME 取自浏览器识别的类型，识别不出回退 `application/octet-stream`
- 全程本地编码，不发任何请求

## 数据流向

**纯本地处理。** 文件与文本都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 元信息

| 项       | 值                       |
| -------- | ------------------------ |
| 全局编号 | #523                     |
| 域       | `media`（音视频 / 媒体） |
| 大组     | `office`                 |
| 优先级   | P1                       |
| 可行性   | A（纯 JS）               |
| 模板     | T2（双栏，扩展文件入口） |
