# 日期格式化

按自定义格式串把日期时间格式化成任意样子，自研 token 解析，不引入 dayjs。

## 用途

后端给的是 `2026-09-27T08:05:09`，页面上要显示成 `2026年9月27日 星期日`；
或者要拼一个 `26-09-27` 这种紧凑 ID。本工具接收一个日期串 + 一个格式串，输出格式化结果。

## 输入

| 字段   | 类型   | 约束                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 日期时间串，最大 200,000 字符 |

支持 `YYYY-MM-DD`、`YYYY/MM/DD`，可附 `HH:mm[:ss]`。非法日期（如 2 月 29 日落在非闰年）会报错。

## 输出

| 字段   | 类型   | 说明                 |
| ------ | ------ | -------------------- |
| `text` | string | 格式化后的单行字符串 |

## 选项映射

| 选项 key  | 界面标签 | 语义                        |
| --------- | -------- | --------------------------- |
| `pattern` | 格式串   | 由下方 token 拼成的格式模板 |

## 支持的 token

| token  | 含义          | 示例（2026-09-27 08:05:09） |
| ------ | ------------- | --------------------------- |
| `YYYY` | 四位年        | `2026`                      |
| `YY`   | 两位年        | `26`                        |
| `MMMM` | 中文月全称    | `九月`                      |
| `MMM`  | 中文月缩写    | `9月`                       |
| `MM`   | 两位月        | `09`                        |
| `M`    | 不补零月      | `9`                         |
| `DD`   | 两位日        | `27`                        |
| `D`    | 不补零日      | `27`                        |
| `dddd` | 星期全称      | `星期日`                    |
| `ddd`  | 星期缩写      | `周日`                      |
| `HH`   | 两位时（24h） | `08`                        |
| `H`    | 不补零时      | `8`                         |
| `mm`   | 两位分        | `05`                        |
| `m`    | 不补零分      | `5`                         |
| `ss`   | 两位秒        | `09`                        |
| `s`    | 不补零秒      | `9`                         |
| `A`    | 上午 / 下午   | `上午`                      |
| `a`    | 上午 / 下午   | `上午`                      |

不在表里的字符（斜杠、冒号、汉字、空格）一律按字面量原样输出。

## 实现规则 / 算法

1. 从左到右扫描格式串，按 token 长度从长到短尝试匹配，命中即替换；否则把当前字符当字面量。
   这样 `DD` 不会被 `D` 抢先匹配，`MMM` 也不会被 `M` 截断。
2. 日期串用正则抽取后构造本地 `Date`，再回读年月日校验，避免 `new Date` 把 `2026-02-29` 静默进位成 3 月 1 日。
3. 全程原生 `Date`，零第三方依赖。

## 浏览器 / 运行时边界

- 日期按浏览器**本地时区**解释；本工具不做时区换算。
- token 区分大小写：`MM` 是月、`mm` 是分，写错不会自动纠正。
- 没有 `Do`（日期序数）这类 token；`o` 会按字面量输出。
- 格式串不能为空。

## 示例

输入：

```text
2026-09-27 08:05:09
```

格式串：

```text
YYYY年M月D日 dddd
```

输出：

```text
2026年9月27日 星期日
```
