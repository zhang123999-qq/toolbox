# 地址校验（#691）

校验以太坊钱包地址：`0x` 格式检查 + EIP-55 checksum 校验，支持每行一个的批量校验。

## 输入

每行一个地址，可带或不带 `0x` 前缀：

```
0x5aAeb6053F3E94C9b9A09f33669435E7Ef1BeAed
0x5aaeb6053f3e94c9b9a09f33669435e7ef1beaed
```

## 校验规则

1. **格式**：40 位十六进制字符（可带 `0x` 前缀）；长度不对或含非法字符直接报错。
2. **全小写 / 全大写**：视为有效，但提示"未使用 EIP-55 checksum 编码"，并给出正确的 checksum 地址。
3. **混合大小写**：必须与 EIP-55 checksum 一致，否则判无效（可能输错地址）。

## 输出

每个地址：有效/无效、规范形式（小写）、EIP-55 checksum 地址、问题提示。

## 说明

- Keccak-256 为纯 JS 实现（FIPS 202，与 SHA3-256 的区别在于 padding），无外部依赖。
- 仅支持以太坊风格地址（EVM 链通用），不支持 ENS 域名。
- 纯前端实现，地址不离开浏览器。
