# ISO8601

ISO 8601 日期时间的双向工具：把时间戳 / 日期串转成带时区偏移（或 Z）的 ISO 串，
或把一条 ISO 串拆开看各字段。纯原生 `Date`。

## 用途

接口里到处是 `2026-09-26T06:00:00Z`。本工具既能「生成」标准格式，也能把它
拆成年/月/日/时/分/秒/周几/Unix 秒，方便核对时区与夏令时。

## 输入

| 字段   | 类型   | 约束                                            |
| ------ | ------ | ----------------------------------------------- |
| `text` | string | 时间戳数字 / 日期串 / ISO 串，最大 200,000 字符 |

支持：纯数字时间戳（秒/毫秒自动）、`YYYY-MM-DD HH:mm:ss`、带 `T` 的 ISO、带 `Z` 或 `±HH:mm` 偏移。

## 输出

| 字段   | 类型   | 说明                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 两种 ISO 形式 + 逐字段 + Unix 时间戳 |

```text
ISO 8601（UTC，带 Z）：2026-09-26T06:00:00.000Z
ISO 8601（本地偏移）：2026-09-26T14:00:00+08:00

年：2026
月：9
日：26
时：14
分：0
秒：0
周：周六
Unix 秒：1790402400
Unix 毫秒：1790402400000
```

## 限制

- 不带时区的日期串按**浏览器本地时区**解释
- 毫秒精度截断到 3 位
- 空输入返回空串；无法解析抛中文错误

## 数据流向

**纯本地处理。** 原生 Date，不发送网络请求。`meta.api = false`。

## 示例

输入：

```text
2026-09-26T14:00:00+08:00
```

输出（东八区浏览器）：

```text
ISO 8601（UTC，带 Z）：2026-09-26T06:00:00.000Z
ISO 8601（本地偏移）：2026-09-26T14:00:00+08:00
…
```
