# 标题标签检查

解析页面 HTML 中的 `h1–h6`，输出层级大纲并检查 SEO 常见问题：
h1 唯一性、层级跳跃、空标题、过长标题、重复标题，给出 0–100 评分。
全部计算在本地完成，不联网。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | HTML 源码，最多 200,000 字符 |

## 输出示例

```text
标题总数：6　h1 数量：1　综合评分：90 / 100

大纲：
h1 免费在线工具箱
  h2 文本工具
    h3 字数统计
    h3 大小写转换
  h2 图片工具
      h4 跳过了 h3（演示告警）

发现 1 个问题：
  1. [警告] 第 6 个标题从 h2 直接跳到 h4，层级跳跃（建议逐级使用）
```

## 检查规则

- 未找到任何标题：0 分（错误）
- 缺少 h1：−30；多个 h1：−15
- 层级跳跃（如 h1 后直接 h3）：每个 −10（最多 −30）
- 空标题：每个 −10（最多 −20）；标题超过 70 字符：每个 −5（最多 −15）
- 重复标题：每组 −10（最多 −20）

## 限制

- 用正则提取标题标签，极端不规范的 HTML 可能漏提；`<script>` / `<style>` / HTML
  注释中的 `<h1>`…`<h6>` 文本可能被误提取（正则不做脚本剥离），结果中出现明显不属于
  正文大纲的标题时请忽略
- 只做结构检查，不评价标题文案质量

## 数据流向

纯本地计算，无网络请求。`meta.api = false`。
