# 图片拼接批量 merge-batch（#474）

## 用途 | Purpose

- 多张图片按「每组 N 张」自动分组，每组按统一设置拼成一张图：多组输入 → 多张拼图输出，逐项缩略图 + 逐项下载。
- Batch-merge images: auto-group every N images, merge each group into one collage with shared settings — multiple groups in, multiple collages out, each with thumbnail and individual download.

## 分组规则 | Grouping

- 每组张数可设 2–10，默认 3；按选择顺序依次分组。
- 整除：如 6 张、每组 3 张 → 2 组；余多：如 8 张 → [3, 3, 2]。
- 余 1：最后一组只有 1 张时，该组**不拼接、直接输出原图**（文件名不变），结果卡片会注明。
- 单文件上限 50MB；总张数上限 30 张（解码后位图常驻内存，30 张高清图已是浏览器内存安全边界）。

## 布局说明 | Layout

- 图片按原尺寸拼接，不拉伸、不缩放。
- 横向：总宽 = 各图宽度之和 + 间距×(n−1)，总高 = 最高图；对齐控制垂直方向：起点=顶部对齐，居中=垂直居中。
- 纵向：总高 = 各图高度之和 + 间距×(n−1)，总宽 = 最宽图；对齐控制水平方向：起点=左对齐，居中=水平居中。
- 间距 0–100px；空白处填充背景色（#rrggbb）。
- 输出格式 jpeg / png / webp，质量 1–100（默认 80，PNG 无损不生效）。
- 输出文件名：组内第一张图基名 + `-merged-<组号>` 后缀，按格式换扩展名（如 `a-merged-1.jpg`）。

## 与相近工具的差异 | Differences

- vs #439 image-merge（图片拼接）：单次任务，多张图 → 一张图，支持横向/纵向/网格；本工具是**批量版**——多组 → 多张，按每组 N 张自动分组，逐项输出下载。
- vs #440 long-image（长图拼接）：多图纵向拼一张长图，单任务；本工具是**多组批量**，每组独立输出一张拼图。

## 边界 | Limits

- 全程本地 Canvas 处理，不上传；组内图片串行解码，对象 URL 及时释放。
- 某组拼接失败（如图片损坏）只影响该组，其他组正常输出，失败组展示错误信息。
- 浏览器不支持的导出格式会报错（如旧浏览器导出 WebP）。

## 数据流向 | Data flow

文件 → 按组串行解码 → 内存 Canvas 拼接 → Blob → 逐项下载；不经过网络。
