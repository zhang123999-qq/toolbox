# PEM 解析

读出 PEM 证书 / 私钥 / 公钥 / CSR 里的关键字段，不用敲 `openssl`。

## 用途

手上有一段 PEM，想知道它是谁的、什么时候过期、多少位、有没有 SAN——粘进来就完事。
也常用于确认「线上证书是不是该换了」「SAN 里到底有没有这个域名」。

## 输入

| 字段   | 类型   | 约束              | 说明                                 |
| ------ | ------ | ----------------- | ------------------------------------ |
| `text` | string | 最大 200,000 字符 | 一段 PEM（证书 / 私钥 / 公钥 / CSR） |

## 输出

| 字段   | 类型   | 说明                                                                 |
| ------ | ------ | -------------------------------------------------------------------- |
| `text` | string | 按类型给出字段清单：证书含主题、签发者、有效期、公钥、签名算法、扩展 |

## 选项

本工具没有选项：解析什么完全由 PEM 自己的标签决定。

## 限制

- **不校验证书链**：它只解析内容，不做信任链验证，也不查吊销（OCSP / CRL）
- 加密私钥（`ENCRYPTED PRIVATE KEY`）只能识别标签，读不出内容——需要先解密
- 非 RSA 密钥（EC / Ed25519）读不出位数：node-forge 对它们的支持有限，会如实写明
- 过期判断用**你本机的时钟**；页面内置的演示证书 2034-01-01 到期
- 解析库（node-forge）体积较大，**首次点「运行」才加载**

## 数据流向

**纯本地处理。** PEM 内容只在浏览器内存里解析，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。**不要把生产私钥粘贴到任何在线工具里。**

## 示例

输入（内置演示证书）：

```text
-----BEGIN CERTIFICATE-----
MIIDkDCCAnigAwIBAgIBATANBgkqhkiG9w0BAQsFADBu…
-----END CERTIFICATE-----
```

输出：

```text
类型：X.509 证书（CERTIFICATE）
主题（subject）：CN=demo.toolbox.local, C=CN, ST=Beijing, L=Beijing, O=Toolbox, OU=Dev
签发者（issuer）：同上（自签发）
序列号：01
版本：v3
有效期：2024-01-01T00:00:00.000Z → 2034-01-01T00:00:00.000Z
状态：有效期内（还剩 … 天）
公钥：RSA 2048 位
签名算法：sha256WithRSAEncryption（1.2.840.113549.1.1.11）
扩展：basicConstraints, keyUsage, subjectAltName
SAN：DNS:demo.toolbox.local
```

## 元信息

| 项       | 值                               |
| -------- | -------------------------------- |

| 域       | `encoding`（编码 / 加密 / 安全） |
| 大组     | `dev`                            |
| 优先级   | P2                               |
| 可行性   | A（纯 JS，解析库按需加载）       |
| 模板     | T2（双栏）                       |
