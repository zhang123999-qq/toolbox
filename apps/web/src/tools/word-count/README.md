# 字数统计

统计字符、字、词、句、段、行、字节与阅读时间。

## 用途

写作、编辑、投稿前确认篇幅；也用于核对接口或数据库字段的长度限制（字符数 / 字节数）。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本，中英混排均可。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                                                       |
| ------ | ------ | -------------------------------------------------------------------------- |
| `text` | string | 一份多行统计报告：字符数、词数、句数、段数、行数、UTF-8 字节数、阅读时间。 |

## 选项

| 选项          | 取值    | 默认 | 说明                                       |
| ------------- | ------- | ---- | ------------------------------------------ |
| `countSpaces` | boolean | true | 「字符数」是否计入空格；关闭时按不含空格计 |

## 限制

- 字符数按 Unicode 码点统计，emoji 与组合字符按码点数计，可能与「可见字形数」不同
- 「词数」= 中日韩字符数 + 拉丁单词数，中文未做分词（分词见「词频统计」）
- 句数按中英文句末标点切分；整段无标点但有内容时记为 1 句
- 阅读时间按中文 300 字/分钟、英文 200 词/分钟估算，仅供参考

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具库 toolbox
```

输出：

```text
工具库 toolbox
共 870 个工具，全部在浏览器本地计算。
```
