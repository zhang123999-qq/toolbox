# 随机地图（#792）

用可复现随机种子生成游戏地形图：随机初始化水域/陆地，经 2 轮细胞自动机平滑形成岛屿，再按概率在陆地上生成山地。

## 输入

```json
{
  "w": 40,
  "h": 24,
  "seed": 20260928,
  "waterLevel": 0.45,
  "mountainRate": 0.08
}
```

- `w`/`h`：地图宽高（格数，上限 256）
- `seed`：整数种子，相同种子必生成相同地图
- `waterLevel`：初始水域比例 [0,1]，默认 0.45
- `mountainRate`：陆地转山地概率 [0,1]，默认 0.08

## 功能

- **生成地图**：按当前参数生成，输出地形统计 + ASCII 图
- **随机种子**：换一个随机种子重新生成
- **画布预览**：蓝色=水域，绿色=陆地，棕色=山地

## 说明

- 纯前端本地计算，不发送任何网络请求
- 地形图例：≈ 水域 · 陆地 ▲ 山地
