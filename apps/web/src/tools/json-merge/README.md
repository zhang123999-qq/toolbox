# JSON Merge

合并**两份 JSON**，支持深层 / 浅层合并，冲突时可指定听谁的。

## 用途

基础配置 + 环境配置、默认参数 + 用户参数、多段分片响应拼成一整块——
把「基准」放左、「补丁」放右，一键得到合并后的完整文档。

## 输入

| 字段    | 类型   | 约束                            |
| ------- | ------ | ------------------------------- |
| `text`  | string | 基础 JSON，≤ 1,000,000 字符     |
| `textB` | string | 待并入的 JSON，≤ 1,000,000 字符 |

`textB` 由模板的 `extraInputs` 渲染成第二个输入框（界面标签「另一份文本」）。

## 输出

| 字段   | 类型   | 说明                                        |
| ------ | ------ | ------------------------------------------- |
| `text` | string | 合并后的 JSON（缩进两格）；两侧都空返回空串 |

## 选项

| 选项     | 取值                 | 默认       | 说明                              |
| -------- | -------------------- | ---------- | --------------------------------- |
| `mode`   | `deep` \| `shallow`  | `deep`     | 深层递归合并 / 只合并顶层对象     |
| `prefer` | `override` \| `base` | `override` | 类型合不上时取合并方 / 保留基础方 |

## 合并规则

1. 两边都是对象 → 同名键递归处理，独有键直接并入
2. 深层模式下递归到任意层；浅层模式只合并顶层，同名子树整体替换
3. 类型合不上（标量对对象、对象对数组、数组对标量…）→ 按 `prefer` 整体取舍
4. **数组不做拼接**：数组是有序容器，「合并」没有唯一正确答案，默认按 `prefer` 整体替换

## 限制

- 一次只能合并两份（`text` + `textB`）；更多份请两两迭代
- 只填了一侧会抛 `JsonMergeError`——合并需要基准与补丁都在
- 单侧上限 1,000,000 字符，嵌套超过 2,000 层抛错
- 合并结果会按 `JSON.stringify` 重排缩进与键序（键序：先基础侧顺序，新键追加在后）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

左（基础）：

```json
{ "name": "工具库", "tools": 870, "flags": { "static": true } }
```

右（待并入）：

```json
{ "tools": 871, "flags": { "dark": true } }
```

输出（`deep` + `override`）：

```json
{
  "name": "工具库",
  "tools": 871,
  "flags": {
    "static": true,
    "dark": true
  }
}
```
