# PDF 加书签

选择 PDF 文件，按每行「标题,页码」（英文逗号）填写书签列表，
给 PDF 添加扁平一级书签目录（Outlines），生成新 PDF 下载。纯本地处理。

## 用途

给无目录的 PDF（扫描书、导出文档）补书签，方便阅读器侧栏跳转。

## 输入

| 字段   | 类型   | 约束            | 说明                        |
| ------ | ------ | --------------- | --------------------------- |
| `file` | File   | ≤ 100 MiB       | 输出区文件选择框上传的 PDF  |
| `text` | string | 最大 10000 字符 | 书签列表：每行「标题,页码」 |

文件与书签列表必填；页码必须在 PDF 实际页数范围内，超出时报错并带书签名。
标题含英文逗号时以最后一个逗号为分隔。
下载文件名为原文件名加 `-bookmark` 后缀（如 `demo-bookmark.pdf`）。

## 输出

| 字段   | 类型       | 说明                                 |
| ------ | ---------- | ------------------------------------ |
| `file` | PDF 二进制 | 添加书签后的新 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「复制/下载」按钮操作的是书签列表文本（`.txt`）。

## 选项

无。

## 限制

- **暂不支持中文字符**：书签 Title 写不进 CJK，含中文时会直接报错，不会生成乱码 PDF。
- 书签为扁平一级，不支持嵌套子书签；点击跳转为整页 Fit 模式。
- 原文件若已有书签，将被本次的列表整体替换（不可合并）。
- 文件全程在浏览器内存里处理，不发任何请求。

## 数据流向

**纯本地处理。** PDF 文件与生成结果都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

3 页 PDF，书签 `Chapter 1,1` / `Chapter 2,2` / `Appendix,3` →
输出区显示如 `已生成 PDF：3 页，2.8 KB`，下载 `demo-bookmark.pdf`。
