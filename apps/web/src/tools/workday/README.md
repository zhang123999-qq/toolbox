# 工作日计算

从一个开始日期，向前或向后数 N 个**工作日**（周一到周五），自动跳过周末；
可额外提供一份「自定义排除日」列表跳过指定日期。

## 输入

多行文本，按行解析：

| 行        | 含义                                        |
| --------- | ------------------------------------------- |
| 第 1 行   | 开始日期 `YYYY-MM-DD`                       |
| 第 2 行   | 工作日天数（整数，方向由选项决定）          |
| 第 3 行起 | 自定义排除日，每行一个 `YYYY-MM-DD`（可空） |

```text
2025-01-27
1
2025-01-28
```

## 方向选项

| 值         | 含义                      |
| ---------- | ------------------------- |
| `add`      | 开始日期之后数 N 个工作日 |
| `subtract` | 开始日期之前数 N 个工作日 |

**不计开始日当天**：`add 1` 表示开始日之后的第一个工作日。

## 输出

```text
开始日期：2025-01-27
加工作日：1 天（排除周末与 1 个自定义排除日）
结果日期：2025-01-29
```

## 规则

- 工作日 = 周一至周五；周六、周日一律跳过。
- 自定义排除日即使落在周一到周五也跳过；落在周末不影响结果。
- 自动处理跨年、跨月。
- **不内置中国法定节假日与调休**：法定放假日与补班日每年都由国务院另行通知、变动频繁，
  本工具不做权威内置；需要排除某些日期时，请在第 3 行起自行列出。

## 限制

- 天数范围 -100000 ~ 100000，输入上限 200,000 字符。
- 仅做「跳过」，不支持按国家/地区节假日表自动补班。

## 数据流向

**纯本地处理。** 纯日期推算，无网络请求。`meta.api = false`。
