# 时间戳转换

Unix 时间戳与日期互转，秒 / 毫秒按阈值自动识别，支持公元 1970 之前的负数时间戳。

## 用途

后端日志、接口返回、数据库里常见的 `1790494200`（秒）或 `1790494200000`（毫秒）需要人肉看时间；
反过来排接口时又要把一个日期换算成时间戳。本工具两个方向都做，单位自动识别，不用自己数位数。

## 输入

| 字段   | 类型   | 约束                                  |
| ------ | ------ | ------------------------------------- |
| `text` | string | 时间戳整数或日期串，最大 200,000 字符 |

- 输入是纯整数（允许负号）→ 按「时间戳 → 日期」处理；
- 否则按「日期 → 时间戳」处理。

## 输出

| 字段   | 类型   | 说明                                          |
| ------ | ------ | --------------------------------------------- |
| `text` | string | 方向、Unix 秒 / 毫秒、UTC 时间、本地时间 四行 |

```text
识别方向：时间戳 → 日期（按秒识别，阈值 1e12）
Unix 秒：1790494200
Unix 毫秒：1790494200000
UTC：2026-09-27 07:30:00
本地：2026-09-27 15:30:00（UTC+08:00）
```

## 选项映射

本工具无选项：方向与单位全部自动识别。

## 实现规则 / 算法

1. **方向判定**：输入 trim 后匹配 `/^-?\d+$/` 即为时间戳，否则当日期串。
2. **秒 / 毫秒阈值**：`Math.abs(n) >= 1e12` 判定为毫秒，否则为秒。
   - 依据：秒级时间戳要到 `33658` 年才会达到 1e12，而毫秒级在 `2001-09-09`（1e12 毫秒）就跨过该阈值；
   - 因此阈值两侧分别落在「未来的秒」与「2001 年之后的毫秒」，几乎不会误判。
3. **负数时间戳**：直接 `new Date(ms)`，原生支持 1970 年之前的时刻。
4. **日期串解析**：支持 `YYYY-MM-DD`、`YYYY/MM/DD`，可附 `HH:mm[:ss]`；
   带 `Z` 或 `±HH:mm` 后缀按 UTC / 指定偏移解析，不带后缀按浏览器本地时区解析。

## 浏览器 / 运行时边界

- 本地时间列依赖运行时所在时区；同样的时间戳在不同时区打开，「本地」一行会不同（UTC 行恒定）。
- `Date` 可表示范围为 `−8,640,000,000,000,000` ~ `+8,640,000,000,000,000` 毫秒（约公元前 271821 年 ~ 公元 275760 年），越界会报错。
- 不接受带逗号、带空格分组的数字（如 `1,790,536,200`），请输入纯数字。
- 解析不了的日期串直接报错，不会静默返回 `Invalid Date`。

## 示例

输入：

```text
1790494200
```

输出：

```text
识别方向：时间戳 → 日期（按秒识别，阈值 1e12）
Unix 秒：1790494200
Unix 毫秒：1790494200000
UTC：2026-09-27 07:30:00
本地：2026-09-27 15:30:00（UTC+08:00）
```

反向输入：

```text
2026-09-27T07:30:00Z
```

输出：

```text
识别方向：日期 → 时间戳
Unix 秒：1790494200
Unix 毫秒：1790494200000
UTC：2026-09-27 07:30:00
本地：2026-09-27 15:30:00（UTC+08:00）
```
