# PDF 转 HTML

提取 PDF 的文本层并转换为结构化 HTML：按字号启发式识别 `<h1>`/`<h2>` 标题，
列表转为 `<ul>`/`<ol>`，段落为 `<p>`。右侧可在「预览 / 源码」间切换，
「复制 / 下载」导出为可独立打开的网页文件（含最小样式）。

## 用途

把带文字层的 PDF（论文、文档、手册）转成网页片段，粘贴到 CMS、文档站，
或下载为独立 HTML 存档。

## 输入

| 字段   | 类型 | 约束                  | 说明                                 |
| ------ | ---- | --------------------- | ------------------------------------ |
| `file` | File | PDF，≤100 MiB，≤50 页 | 通过右侧「选择文件」选取，**不上传** |

## 输出

| 字段   | 类型   | 说明                                      |
| ------ | ------ | ----------------------------------------- |
| `text` | string | 预览区渲染的 HTML 片段                    |
| `html` | string | 下载时为包好 `<!DOCTYPE html>` 的独立文档 |

```html
<section class="pdf-page" data-page="1">
  <h1>年度报告</h1>
  <p>这是正文第一段。</p>
  <ul>
    <li>重点一</li>
    <li>重点二</li>
  </ul>
</section>
```

## 选项

| 选项             | 类型    | 默认 | 说明                                  |
| ---------------- | ------- | ---- | ------------------------------------- |
| `detectHeadings` | boolean | true | 字号 ≥1.5×/1.25× 正文的短行识别为标题 |
| `pageBreaks`     | boolean | true | 页与页之间插入 `<hr>` 分隔线          |

## 限制

- **只处理文本层**：扫描版 PDF 没有文字可提，整篇无文本时会报错并建议用
  #500「PDF 文字识别（OCR）」；个别空白页会保留占位提示
- **加密 PDF 不支持**：中文提示请先去除密码
- **页数上限 50 页**，文件上限 100 MiB
- 转换不保留图片、表格边框与精确排版，只保留文本语义结构
- 所有文本内容均做 HTML 转义后再渲染，无 XSS 风险

## 数据流向

**纯本地处理。** pdfjs-dist 在浏览器里解析 PDF 并提取文本项，全程无网络请求
（`meta.api = false`），文件不上传。
