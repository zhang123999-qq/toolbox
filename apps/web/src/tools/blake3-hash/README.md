# BLAKE3 哈希

BLAKE3 摘要计算，支持 32 / 64 字节输出，WASM 按需加载。

## 用途

算 BLAKE3 —— 比 SHA-256 快一个量级、且天然支持「延长输出」（XOF）的现代哈希。
适合做大文件校验、内容寻址、去重键。

## 输入

| 字段   | 类型   | 约束              | 说明         |
| ------ | ------ | ----------------- | ------------ |
| `text` | string | 最大 200,000 字符 | 待摘要的文本 |

## 输出

| 字段   | 类型   | 说明                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 十六进制摘要（32 或 64 字节） |

## 选项

| 选项        | 取值    | 默认 | 说明                                    |
| ----------- | ------- | ---- | --------------------------------------- |
| `length`    | 32 / 64 | 32   | 输出长度（字节）；BLAKE3 是 XOF，可延长 |
| `uppercase` | 开 / 关 | 关   | 十六进制是否大写                        |

## 限制

- 底层是 WASM，**首次点「运行」才会加载**；未触发前不占首屏体积
- 只处理文本：文件/大块二进制的哈希请用「文件哈希」（需文件输入，模板待扩展）
  或命令行工具
- 64 字节输出不是「再算一次」，而是同一摘要的延长：它的前 32 字节就是 32 字节模式的输出
- BLAKE3 不是口令哈希（没有抗 ASIC 的内存开销），口令请用 Bcrypt / Argon2

## 数据流向

**纯本地处理。** 内容只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
hello
```

输出（32 字节，与官方测试向量一致）：

```text
ea8f163db38682925e4491c5e58d4bb3506ef8c14eb78a86e908c5624a67200f
```
