# Unicode 查询

查询字符 Unicode 编码、名称、分类。

## 用途

查一个字符的码位、UTF-8/UTF-16 编码与所属区段，用于排查乱码、写转义、确认字符来源。

## 输入

| 字段   | 类型   | 约束            |
| ------ | ------ | --------------- |
| `text` | string | 最大 1,000 字符 |

一个或多个字符；最多取前 1,000 个字符，逐个字符列出。

## 输出

| 字段   | 类型   | 说明                                                                                                 |
| ------ | ------ | ---------------------------------------------------------------------------------------------------- |
| `text` | string | 每个字符一段：字符、码位（十六进制与十进制）、UTF-8 字节、UTF-16 码元、分类、区段、JS 与 HTML 转义。 |

## 选项

该工具无选项。

## 限制

- 「区段」是常用区段表的粗匹配，不是完整的 Unicode Blocks（未收录时显示「未收录区段」）
- 「分类」是语义粗分类（汉字 / 假名 / 数字 / 标点…），**不是**官方 General_Category
- 不提供逐字符的 Unicode 官方名称（那需要上 MB 的名称表，与本地优先的取向冲突）
- emoji 与组合字符按码点逐个处理，组合序列不会被合并成一个字形

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
A工😀
```

输出：

```text
A工😀
```
