# 化学方程式（#823）

化学方程式配平、化学式解析与摩尔质量计算，全部在浏览器本地完成，无需联网。

## 功能

- **配平（balance）**：输入如 `H2+O2=H2O` 或 `CH4 + O2 -> CO2 + H2O`，输出最小正整数系数与配平式。算法为高斯消元求零空间，支持括号（如 `Ca(OH)2+H2SO4=CaSO4+H2O`）。
- **摩尔质量（molar）**：输入化学式，输出 g/mol（内置 48 种常见元素原子量）。
- **解析（parse）**：输入化学式，输出各元素原子个数。

## 局限

- 仅支持无机常见写法；不支持离子电荷（如 `SO4^2-`）、水合物点号写法。
- 解不唯一或无解的方程式会明确报错，不会编造系数。
