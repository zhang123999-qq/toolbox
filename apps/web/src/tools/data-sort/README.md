# 数据排序（#690）

CSV 多列排序：每行一条「列名:asc|desc」规则，按规则先后依次比较，输出排序后的表格并可导出 CSV。

## 输入

- **CSV**（主输入框）：首行为表头。留空用内置示例。
- **排序规则**（附加输入框）：每行一条，格式 `列名:asc|desc`，如：

```
年龄:desc
销售额:asc
```

方向缺省为 `asc`；列名可含冒号（按最后一个冒号切分）。

## 排序语义

- **稳定排序**：全部规则相等时保持原相对顺序。
- **数字感知**：`9 < 10` 按数值成立。
- **空值置后**：空单元格无论升降序都排在最后。
- 数字与文本混排时数字在前；文本按中文拼音序。

## 说明

- 纯前端实现，数据不离开浏览器。
- 规则引用不存在的列、同一列重复出现都会明确报错。
- 交互式"点表头排序 / 分页浏览"请用「数据表格」。
