# 自然语言日期解析

把「今天 / 明天 / 3 天后 / 下周一 / 2026年9月27日」这类中文说法解析成标准日期，并给出相对偏移、年积日与时间戳。

## 用途

手写脚本、排日程时经常要用人话表达日期。本工具不引入任何日期库，
用正则 + 相对日期计算，把常见中文说法换算成 `YYYY-MM-DD`，并告诉你它距今天几天、是当年第几天。

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 一句中文日期，最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                                          |
| ------ | ------ | --------------------------------------------- |
| `text` | string | 解析结果（含星期）、相对今天、年积日、Unix 秒 |

```text
解析结果：2026-09-30（星期三）
相对今天：+3 天
当年第 273 天
Unix 秒：1790668800
```

## 支持的写法

| 类别     | 示例                                             |
| -------- | ------------------------------------------------ |
| 绝对日期 | `2026-09-27`、`2026/9/27`、`2026年9月27日`       |
| 固定相对 | `今天`、`明天`、`后天`、`大后天`、`昨天`、`前天` |
| 数量相对 | `3天后`、`5天前`、`3日以后`                      |
| 星期     | `周一`、`星期五`、`周日`、`星期天`               |
| 带限定   | `本周三`、`这周五`、`下周一`、`下周三`           |
| 下周整周 | `下周`（视为下周一）                             |

## 实现规则 / 算法

1. **绝对日期**：正则抽取 年/月/日，构造本地 `Date` 后回读校验，避免 `2026-02-29` 被静默进位。
2. **相对计算**：以「今天 0 点」为基准，按天加减。
3. **星期定位**：把周一记为 0、周日记为 6；
   - 裸「周X」取从今天起的下一次出现（今天正好是该星期就算今天）；
   - 「本周X」取本周（周一起）内的那一天；
   - 「下周X」取下一周的那一天；
   - 「下周」单独出现视为下周一。
4. 解析不了直接抛中文错误，绝不把 `Invalid Date` 输出。

## 浏览器 / 运行时边界

- 以浏览器本地时区的「今天」为准；不同时区打开，相对基准会差一天。
- 只精确到「日」，不带时分秒。
- 星期归属按**周一为一周开始**计算。
- 口语里「下周一」在周日常有歧义（到底是明天还是下下周的周一），本工具按「下一次出现」的确定规则处理，见上表。

## 示例

输入：

```text
3天后
```

输出（以 2026-09-27 为今天）：

```text
解析结果：2026-09-30（星期三）
相对今天：+3 天
当年第 273 天
Unix 秒：1790668800
```
