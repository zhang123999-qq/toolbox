# 翻译文件转换

i18n 翻译文件格式互转：JSON、PO、YAML、CSV 四种格式任意互转。嵌套 JSON 键拍平为点路径（如 `app.title`）；PO 复数取第一条译文；YAML 仅支持缩进映射；CSV 只有键值两列。

## 用途

- 把前端 JSON 语言包导出为 PO 交给翻译平台
- 把翻译公司回传的 PO/CSV 转回项目用的 JSON/YAML
- 快速查看不同格式的翻译文件内容

## 输入

| 字段   | 类型   | 约束                    |
| ------ | ------ | ----------------------- |
| `text` | string | 源格式的 i18n 文本      |

## 选项

| 选项   | 类型   | 约束                    |
| ------ | ------ | ----------------------- |
| `from` | string | 源格式：json/po/yaml/csv |
| `to`   | string | 目标格式：json/po/yaml/csv |

## 说明

- 纯本地转换，无网络请求。
- 空键、重复键、路径冲突、数组值、非法引号等都会给出中文错误。
- PO 导出按多行格式保留换行；转出 CSV 会对含逗号/引号的值自动加引号。
