# 文本工作台

多工具组合流水线。

## 用途

把多个文本处理步骤串成一条流水线一次跑完：在「流水线步骤」里每行写一条，页面会逐个阶段显示中间结果，复制 / 下载拿到的是最终结果。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

要处理的文本；步骤写在「流水线步骤」选项里，每行一条。

## 输出

| 字段   | 类型   | 说明                                                                     |
| ------ | ------ | ------------------------------------------------------------------------ |
| `text` | string | 页面上按阶段列出「步骤 → 结果预览（前 3 行）」；复制与下载给出最终文本。 |

## 选项

| 选项    | 取值                                      | 默认                                      | 说明                                                                                                                                                                                       |
| ------- | ----------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `steps` | 多行文本，每行一条 `name` 或 `name=value` | `trim` / `drop-empty` / `dedupe` / `sort` | 可用步骤：`trim`、`drop-empty`、`squeeze-empty`、`dedupe`、`sort`、`sort-desc`、`reverse`、`upper`、`lower`、`strip-zero-width`、`prefix=X`、`suffix=X`、`replace=A>B`、`take=N`、`drop=N` |

## 限制

- **步骤不认识就直接跳过**，并在结果末尾列出未识别的步骤名；不会中断整条流水线
- `replace=A>B` 是朴素的子串替换（不支持正则），`>` 本身不能出现在被替换的文本里
- `prefix` / `suffix` 的值里不能含换行；`take` / `drop` 的 N 必须是非负整数
- 排序用**码点序**而非 localeCompare，中文不会按拼音排
- 行级原语实现在 `lib/pipeline.ts`，#59 重复行检测与 #60 空行处理已改为复用同一份；其余单功能工具（#28 / #29 / #32 / #33…）参数口径不同，仍各自实现——需要它们的全部选项时请直接用对应工具
- 页面只预览每个阶段的前 3 行，完整结果用「复制」或「下载」取
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
  北京
上海

北京
  广州
```

输出：

```text
上海
北京
广州
```
