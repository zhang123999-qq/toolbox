# 精灵图预览（#799）

预览精灵帧动画：输入帧的 spriteId 列表（逗号或换行分隔）与 fps，播放/暂停/单步查看，canvas 实时渲染当前帧。

## 功能

- **帧序列**：逗号或换行分隔的 spriteId 列表
- **fps**：1~120
- **循环/不循环**：循环按总时长取模，不循环钳制到末帧
- **播放控制**：播放/暂停、单步（前进一帧）
- **占位渲染**：每帧按 spriteId 哈希配色绘制占位块，便于快速验证动画节奏

## 说明

- 播放器为纯逻辑实现（时间由渲染循环传入），`advance` 仅在播放中推进游标
- 纯前端本地处理，不发送任何网络请求
