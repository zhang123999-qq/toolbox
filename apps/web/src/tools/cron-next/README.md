# Cron 下次运行

给定一条标准 5 段 cron 表达式，用原生 `Date` 从当前时间往后推算，
列出接下来 N 次会在什么时候触发（纯前端自研，不依赖 cron-parser 包）。

## 用途

写好定时任务后想知道「它下次到底几点跑、一周后是周几」，
本工具直接把未来的触发时刻列出来，避免排期误判。

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 5 段 cron 表达式，最大 200,000 字符 |

格式：`分 时 日 月 周`。支持 `*`、`*/N`、`a`、`a-b`、`a,b`、`a-b/N`，周字段 0/7 均为周日。

## 选项

| 选项    | 标签 | 默认 | 说明                  |
| ------- | ---- | ---- | --------------------- |
| `count` | 数量 | `5`  | 列出接下来几次，1-100 |

## 输出

| 字段   | 类型   | 说明                 |
| ------ | ------ | -------------------- |
| `text` | string | 带序号的本地时间列表 |

```text
1. 2026-09-28 02:00
2. 2026-09-29 02:00
3. 2026-09-30 02:00
```

## 语义说明

- 按**浏览器本地时区**计算并展示时间
- 「日」与「周」同时被限制时取**并集**（OR）：任意一个命中即触发，与 Vixie cron 一致
- 从当前分钟的下一分钟开始扫描，最多向后扫描 5 年

## 限制

- 只支持标准 5 段 cron，不含秒 / 年
- `L`、`#` 等 Quartz 专有写法不支持
- 空输入返回空串；非法格式抛中文错误

## 数据流向

**纯本地处理。** 原生 Date 逐分钟扫描，不发送网络请求。`meta.api = false`。

## 示例

输入：

```text
0 2 * * 1-5
```

输出（以当前时间推算，示意）：

```text
1. 2026-09-28 02:00
2. 2026-09-29 02:00
3. 2026-09-30 02:00
4. 2026-10-01 02:00
5. 2026-10-02 02:00
```
