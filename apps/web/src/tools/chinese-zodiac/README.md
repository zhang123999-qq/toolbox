# 生肖干支查询

输入一个公历年份，按中国传统干支纪年输出：生肖（中英名）、地支、天干五行、干支名与生肖排序。

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 四位整数年份，最大 200,000 字符 |

仅支持 **1900–2100**；空输入不产出内容，越界年份给出中文错误。

## 输出

```text
2025 年：蛇（Snake）
干支：乙巳（乙巳）
天干五行：木（Wood）
生肖排序：第 6 位（巳蛇）
```

## 算法

- 生肖 / 地支：`(year - 4) mod 12`，下标 0 = 子鼠，1900 为庚子鼠年
- 天干：`(year - 4) mod 10`，下标 0 = 甲
- 五行随天干：甲乙木、丙丁火、戊己土、庚辛金、壬癸水

## 说明与限制

- 这里按**年份整年**取生肖。严格说生肖在**正月初一**切换，公历 1 月 1 日到春节之间仍属上一年生肖；需要精确到日请使用「公历农历互转」工具。
- 覆盖 1900–2100，与内置农历表范围一致；更早/更晚的年份不做推算。
- 不区分公元前（无公元前输入）。

## 数据流向

**纯本地处理。** 纯模运算 + 静态查表，无网络请求。`meta.api = false`。
