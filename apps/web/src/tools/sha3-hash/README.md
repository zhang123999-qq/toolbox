# SHA-3 哈希

计算文本的 SHA3-256 / SHA3-384 / SHA3-512 摘要。

## 用途

SHA-3（FIPS 202）是与 SHA-2 结构完全不同的新一代标准哈希，基于 Keccak 海绵结构，可避免 SHA-2 一旦被攻破时的连带风险。
用于校验内容完整性、比对两段内容是否一致、生成去重键。
`SHA3-256("abc") = 3a985da74fe225b2045c172d6bd390bd855f086e3e9d525b46bfe24511431532`。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

任意文本（中英混排、emoji 均可），按 UTF-8 编码参与计算。

## 输出

| 字段   | 类型   | 说明                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 十六进制摘要；选 Base64 时为其编码值 |

## 选项

| 选项        | 取值                           | 默认       | 说明                                         |
| ----------- | ------------------------------ | ---------- | -------------------------------------------- |
| `algorithm` | SHA3-256 / SHA3-384 / SHA3-512 | `SHA3-256` | 摘要算法（hex 输出长度依次为 64 / 96 / 128） |
| `format`    | hex / base64                   | hex        | 输出格式                                     |

## 限制

- **不是加密**：哈希不可逆，不能用来「解密」。
- **不做加盐**：存口令请用带盐的 KDF，不要直接存摘要。
- **浏览器原生支持不完整**：`subtle.digest` 的规范里已包含 `SHA3-*`，但并非所有浏览器都实现。本工具**优先调用浏览器原生实现，若不被支持则自动回落到内置的纯 JS Keccak 实现**，两条路径对同一输入产生相同结果。
- 输入上限 200,000 字符；超大输入走内置实现时耗时随输入线性增长。

## 数据流向

**纯本地处理。** 摘要在当前页面内计算（原生 WebCrypto 或内置实现），文本不写入 localStorage、不发送、不上传，无任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
abc
```

输出（SHA3-256 / hex）：

```text
3a985da74fe225b2045c172d6bd390bd855f086e3e9d525b46bfe24511431532
```
