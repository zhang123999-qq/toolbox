# JSON 排序

按键名**递归排序**，支持升序 / 降序，可选缩进或单行输出。

## 用途

同一个接口两次返回的键顺序不一样，diff 就全是噪音。先把两边都排一遍，
再交给 diff / Git 对比，差异才真的是字段内容的差异。

## 输入

| 字段   | 类型   | 约束                |
| ------ | ------ | ------------------- |
| `text` | string | 最大 1,000,000 字符 |

## 输出

| 字段   | 类型   | 说明                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 排序后的 JSON；空输入返回空串 |

## 选项

| 选项         | 取值                  | 默认     | 说明                    |
| ------------ | --------------------- | -------- | ----------------------- |
| `descending` | boolean               | `false`  | 改为降序（Z→A）         |
| `format`     | `pretty` \| `compact` | `pretty` | 缩进两格输出 / 压成单行 |

## 限制

- 只排**对象键**；数组是有序容器，元素顺序一律保持原样（元素内部的键仍会递归排序）
- 排序口径是 Unicode 码点序（`"A" < "a"`、`"z" < "中"`），不随浏览器 locale 变化
- 输入上限 1,000,000 字符，超过抛 `JsonSortError`
- 非法 JSON 抛 `JsonSortError`

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```json
{ "tools": 870, "name": "工具库", "tags": ["json", "static"] }
```

输出（`pretty`）：

```json
{
  "name": "工具库",
  "tags": ["json", "static"],
  "tools": 870
}
```
