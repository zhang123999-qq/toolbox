# 数值精度 | Numeric Precision

浮点误差演示与修正：输入两个数与运算符，用 **decimal.js** 给出精确结果，并与 **JS 原生浮点**结果对照展示，定位 `0.1 + 0.2 ≠ 0.3` 类陷阱。

Demonstrates floating-point error and its fix: computes the exact result with decimal.js side-by-side with the native JS float result.

## 用途 | Purpose

- 直观理解二进制浮点的表示误差（`0.1 + 0.2`、`1 − 0.9`…）
- 验证金额 / 科学计算是否需要高精度库
- 极大 / 极小数运算的精度对照

## 输入 | Inputs

| 字段    | 类型   | 约束                        |
| ------- | ------ | --------------------------- |
| `text`  | string | 第一个数，最大 200,000 字符 |
| `textB` | string | 第二个数                    |

## 输出 | Output

```text
表达式：0.1 + 0.2
精确结果（decimal.js）：0.3
JS 原生浮点结果：0.30000000000000004
误差（JS − 精确）：4e-17
结论：存在浮点误差，金额与科学计算请采用 decimal.js 精确结果
```

两者一致时输出 `结论：两者一致，无浮点误差`。

## 算法 | Algorithm

- **精确侧**：`decimal.js`（本工具将其有效数字设为 50 位，避免默认 20 位在极大 / 极小数上同样丢精度）十进制运算 —— 即「修正」本身。
- **浮点侧**：JS `number`（IEEE 754 双精度）原生运算，不做任何修正。
- **误差**：`JS结果 − 精确结果`，同样用 decimal.js 计算，避免二次误差；
  一致性判定用 `Decimal.equals`，`NaN` / `Infinity` 等极端值也能正确判定。

## 边界 | Edge cases

- 任一输入留空 → 空态，不报错
- 非数字 / `NaN` / `Infinity` → 中英双语报错
- 除零 → 中英双语报错（与 #330 decimal 工具一致）
- 极大数（`1e21 + 1`：JS 丢精度）/ 极小数（`1e-325`：JS 下溢为 0）→ 检出误差

## 限制 | Limits

- decimal.js 有效数字设为 50 位（`Decimal.clone`，不污染全局配置），超出部分按默认舍入策略（ROUND_HALF_UP）处理
- 纯前端本地计算，数据不上传

## 数据流向 | Data flow

全部在浏览器本地完成，无网络请求。

## 示例 | Example

`0.1 + 0.2` → 精确结果 `0.3`，JS 浮点 `0.30000000000000004`，误差 `4e-17`。
