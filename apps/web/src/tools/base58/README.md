# Base58 编解码

比特币常用 Base58，提供 Bitcoin 与 Flickr 两套字母表。

## 用途

Base58 在 Base64 的基础上**去掉了 `0OIl` 与 `+/`**：既没有容易看混的字符，
也不含需要在 URL、文件名里转义的符号。比特币地址、IPFS CID、短链 ID 都用它。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                              |
| ------ | ------ | --------------------------------- |
| `text` | string | 编码后为 Base58；解码后为原始文本 |

## 选项

| 选项        | 取值             | 默认    | 说明                             |
| ----------- | ---------------- | ------- | -------------------------------- |
| `direction` | encode / decode  | encode  | 编码或解码                       |
| `mode`      | bitcoin / flickr | bitcoin | 字母表变体（两者大小写位置相反） |

## 限制

- 实现的是**裸 Base58**，不含 Base58Check 的版本号与校验和；比特币地址的校验需另行处理
- 编码结果能否还原依赖「输入是文本」：解码要求结果必须是合法 UTF-8，二进制内容会报错
- 同一串文本在两套字母表下结果不同，解码时用错字母表会报错或得到错误结果，注意成对使用

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
hello world
```

输出（bitcoin / encode）：

```text
StV1DL6CwTryKyV
```
