# 文本比较

相似度、编辑距离。

## 用途

给两份文本打分：相似度百分比、编辑距离、长度差、公共前后缀，也可以直接看逐字符差异。查重、校对、判断「改了多少」时常用。

## 输入

| 字段    | 类型   | 约束                         |
| ------- | ------ | ---------------------------- |
| `text`  | string | 最大 50,000 字符             |
| `textB` | string | 另一份文本，最大 50,000 字符 |

两份平级文本。

## 输出

| 字段   | 类型   | 说明                                                    |
| ------ | ------ | ------------------------------------------------------- |
| `text` | string | `report` 给统计报告；`diff` 给带 +/- 标记的逐字符差异。 |

## 选项

| 选项   | 取值              | 默认     | 说明                  |
| ------ | ----------------- | -------- | --------------------- |
| `mode` | `report` / `diff` | `report` | 统计报告 / 逐字符差异 |

## 限制

- **相似度是「1 − 编辑距离 / 较长者长度」**，不是语义相似度：`意思一样但措辞完全不同` 会得到很低的分
- 编辑距离按**码点**计算，Levenshtein 的时间复杂度是 O(len₁ × len₂)，长文本（几千字以上）会比较慢
- 中文没有分词，公共前后缀是字符级的，可能切出半个词
- `diff` 模式把换行渲染成 `⏎`，否则差异会挤成一行看不清
- 输入上限 50,000 字符（每个框）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
这是第一句示例文本。
```

另一份文本：

```text
这是第二句示例文本。
```

输出：

```text
相似度：90.0%
编辑距离：1 次单字符编辑
长度：10 / 10（差 0）
公共前缀：这是第（3 字符）
公共后缀：句示例文本。（6 字符）
```
