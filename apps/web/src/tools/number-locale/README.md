# 数字本地化

输入一个数字，并排对比它在多个语言区域（locale）下的本地化写法：十进制、百分比、紧凑表示三档，直观看到千分位符号、小数点、数字系统的差异。

## 用途

- 出海产品检查数字在各地区的展示（德语 `1.234,5`、阿拉伯语 `١٢٣`、印度 `1,23,45,678`）
- 与 `number-format` 的区别：`number-format` 是按千分位/小数位/百分比等**样式**格式化单个数字，本工具是**多 locale 并排本地化对比**

## 输入

| 字段      | 类型   | 约束                   |
| --------- | ------ | ---------------------- |
| `text`    | string | 数字                   |
| `locales` | string | 逗号分隔的 locale 列表 |

## 说明

- 使用浏览器/Node 内置 `Intl.NumberFormat`，无网络请求。
- 内置 22 个常用语言区域，含阿拉伯-印度数字、天城文数字、波斯语数字等特殊数字系统示例。
