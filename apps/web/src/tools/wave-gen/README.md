# 波浪生成

用多层正弦波叠加生成波浪 SVG，每层振幅 / 频率略有差异，颜色从起始色渐变到结束色，半透明填充，可复制 / 下载（`.svg`）。

## 用途

- 生成网页头图、banner 背景的波浪纹理
- 调整振幅 / 频率 / 层数 / 渐变色得到不同视觉效果
- 导出 SVG 源码，粘贴到设计稿 / 页面里复用

## 输入

| 字段   | 类型   | 约束                                          |
| ------ | ------ | --------------------------------------------- |
| `text` | string | 种子文本（可选，相同文本 + 参数生成相同波浪） |

留空则按默认参数生成；填不同种子文本会得到不同的层间扰动与相位。

## 选项

| 选项   | 默认值    | 范围 / 约束        | 说明             |
| ------ | --------- | ------------------ | ---------------- |
| 振幅   | `50`      | 10–150             | 波浪起伏高度     |
| 频率   | `2`       | 1–10               | 波浪周期数量     |
| 层数   | `3`       | 1–6                | 叠加的波浪层数   |
| 起始色 | `#3b82f6` | `#rgb` / `#rrggbb` | 第一层波浪颜色   |
| 结束色 | `#8b5cf6` | `#rgb` / `#rrggbb` | 最后一层波浪颜色 |

## 输出

- 右侧预览区：渲染后的 SVG 波浪图
- 复制 / 下载：SVG 源码（`.svg` 文件）

## 边界

- 振幅 / 频率 / 层数越界 → 中文报错
- 颜色非法（非 `#rgb` / `#rrggbb`）→ 中文报错
- 层数为 1 时不做渐变，整图使用起始色

## 示例

默认参数（振幅 50、频率 2、层数 3、蓝到紫渐变）即生成一组柔和的多层波浪。

## 数据流向

纯本地：SVG 由浏览器内纯函数生成，不上传到任何服务器。

# Wave Generator (English)

Generate layered sine-wave SVG art; each layer's amplitude/frequency varies slightly, colors gradient from `color1` to `color2` with semi-transparent fill. Copy or download the source (`.svg`).

## Purpose

- Produce wave textures for web headers / banners
- Tune amplitude, frequency, layer count and gradient colors for different looks
- Export SVG source for reuse in designs / pages

## Input

| Field  | Type   | Constraint                                            |
| ------ | ------ | ----------------------------------------------------- |
| `text` | string | Seed text (optional; same text + options → same wave) |

Leave empty for default options; different seeds produce different layer offsets.

## Options

| Option    | Default   | Constraint         | Description           |
| --------- | --------- | ------------------ | --------------------- |
| Amplitude | `50`      | 10–150             | Wave height           |
| Frequency | `2`       | 1–10               | Number of cycles      |
| Layers    | `3`       | 1–6                | Number of wave layers |
| Color 1   | `#3b82f6` | `#rgb` / `#rrggbb` | First layer color     |
| Color 2   | `#8b5cf6` | `#rgb` / `#rrggbb` | Last layer color      |

## Output

- Right preview panel: the rendered SVG wave
- Copy / download: SVG source (`.svg` file)

## Edge cases

- Out-of-range amplitude/frequency/layers → Chinese error
- Invalid color (not `#rgb` / `#rrggbb`) → Chinese error
- Single layer → flat color1, no gradient

## Data flow

Fully local: the SVG is generated by pure functions in the browser; nothing is uploaded.
