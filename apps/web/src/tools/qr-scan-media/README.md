# 二维码扫描

用摄像头实时扫描或上传图片，用 jsqr 在本地解码二维码内容。

> **与「二维码生成」器的区别**：仓库已有的 qrcode 工具是把文本「生成」成二维码图片；
> 本工具反过来，是从摄像头 / 图片里把二维码「扫描识别」出来解码成文本。两者不重复。

## 用途

快速读取海报、名片、票据上的二维码内容，无需掏出手机。

## 输入

| 字段   | 类型   | 约束 | 说明                                             |
| ------ | ------ | ---- | ------------------------------------------------ |
| `file` | File   | 图片 | 图片模式下通过「选择二维码图片」选取，**不上传** |
| `text` | string | —    | 左侧文本区仅作备注，不参与处理                   |

## 输出

| 字段   | 类型 | 说明                                   |
| ------ | ---- | -------------------------------------- |
| `text` | 文本 | 解码结果：字符数 / 内容 / 网址安全提示 |

## 选项

| 选项   | 类型 | 默认     | 说明                        |
| ------ | ---- | -------- | --------------------------- |
| `mode` | 下拉 | `camera` | 扫描来源：摄像头 / 上传图片 |

## 限制

- 摄像头模式需要 `getUserMedia` 权限；画面未就绪、权限拒绝时给出中文提示
- 未识别到二维码时提示把二维码置于画面中央、保持光线充足
- jsqr 按需动态加载：加载失败会提示检查网络后重试
- 内容疑似网址时会提示确认安全后再访问；全程本地解码，不上传

## 示例

```text
解码成功（24 个字符）：
https://example.com/qr
提示：内容疑似网址，请确认安全后再访问
```

## 数据流向

**纯本地处理。** jsqr 在浏览器内解码，`meta.api = false`，无需自备 API/Key。
