# MD5 哈希

计算文本的 MD5 摘要，支持大小写与 Base64 输出。

## 用途

算一段文本的 MD5，用于校验文件/内容是否被改动、生成缓存键、或对接只认 MD5 的老系统（如部分 CDN 回源校验、旧接口签名）。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

一段文本；按 UTF-8 编码参与计算，因此中文、emoji 的摘要与 `md5sum`、Node `crypto` 等实现一致。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 16 字节摘要的十六进制（默认）或 Base64。 |

## 选项

| 选项        | 取值         | 默认  | 说明                                    |
| ----------- | ------------ | ----- | --------------------------------------- |
| `uppercase` | 布尔         | false | 十六进制是否用大写字母                  |
| `format`    | hex / base64 | hex   | 摘要的输出编码；base64 是摘要字节的编码 |

## 限制

- **MD5 已不安全**：碰撞攻击早已被实际利用（2004 年王小云给出碰撞方法，2008 年出现伪造 CA 证书的碰撞），**不要**用于签名、口令存储或任何需要抗碰撞的场景
- 适用场景仅限：**完整性校验和（非对抗性）、缓存键、兼容只认 MD5 的遗留系统**
- 口令存储请用 #97 PBKDF2 / #99 Scrypt 这类慢哈希；通用哈希请用 #66 文本哈希（SHA-2）
- 摘要不可逆，「解密 MD5」只能靠查彩虹表，本工具不提供
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 文本只在浏览器内存里参与哈希计算，**不发送任何网络请求、不写入 localStorage、不上传服务端**。
计算完全由浏览器内的 `spark-md5` 完成，`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
abc
```

输出（默认 hex）：

```text
900150983cd24fb0d6963f7d28e17f72
```
