# 听力测试（Hearing Test）

WebAudio 播放 125–8000 Hz 共 7 个频率的正弦音，用户反馈是否听见，生成听力筛查总结。

## 功能

- 7 个标准筛查频率：125 / 250 / 500 / 1000 / 2000 / 4000 / 8000 Hz
- 每个频率可播放、标记「听见」/「没听见」
- 汇总：全部听见判通过，否则列出未听见的频率

## 重要说明

- 本测试为听力筛查小游戏，**仅供参考，不能替代医院的医学诊断**
- 建议佩戴耳机、在安静环境下测试
- 需要浏览器支持 Web Audio API，不支持时会有中文提示
- 纯前端工具，无网络请求
