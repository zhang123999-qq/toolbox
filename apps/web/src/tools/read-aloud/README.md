# 语音朗读

用浏览器内置的 Web Speech API（speechSynthesis）朗读文本：语速、音调、音量可调，可选择中文语音，长文本自动按句切分并依次加入朗读队列；浏览器不支持时给出中文提示。

## 用途

- 朗读文章、文档，解放双眼
- 为视障用户提供语音访问
- 预览 TTS 文本的分句效果

## 输入

| 字段   | 类型   | 约束         |
| ------ | ------ | ------------ |
| `text` | string | 待朗读的文本 |

在页面内设置：语速（0.5–2）、音调（0–2）、音量（0–1）、语音（默认语音或指定中文语音）。

## 说明

- 纯客户端能力，浏览器内置语音引擎，**无网络请求**，不上传任何文本。
- 可用语音取决于操作系统与浏览器；中文语音优先排在列表前面。
- 长文本按中英文句末标点分句，调用 speechSynthesis 原生队列依次朗读。
