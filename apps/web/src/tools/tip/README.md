# 小费计算

按账单金额和小费比例算出小费、总计，并支持多人平摊人均。

## 用途

- 境外就餐：按当地习惯比例（10% / 15% / 20%）快速算小费
- 聚餐 AA：多人平摊时直接得出人均金额

## 输入

| 字段   | 类型   | 约束                                      |
| ------ | ------ | ----------------------------------------- |
| `text` | string | 账单金额（必须大于 0），最大 200,000 字符 |

## 输出

```text
账单金额：200.00 元
小费（15%）：30.00 元
总计：230.00 元
人均（1 人）：230.00 元
```

## 选项

| 选项     | 类型   | 说明                               |
| -------- | ------ | ---------------------------------- |
| `rate`   | select | 小费比例：`10` `15` `18` `20` `25` |
| `people` | text   | 人数（留空=1，必须为 ≥ 1 整数）    |

## 算法

- `小费 = 账单 × 比例 / 100`，`总计 = 账单 + 小费`，`人均 = 总计 / 人数`
- 金额保留 2 位小数；比例用 12 位有效数字格式化（去浮点尾巴）

## 边界

- 空输入 → 输出空串
- 账单非数字 / ≤ 0 → 中文报错
- 小费比例非数字 / ≤ 0 / > 100 → 中文报错「小费比例应在 0 到 100 之间」
- 人数非数字 / 非整数 / < 1 → 中文报错「人数应为大于等于 1 的整数」
- 人数留空 → 默认 1

## 示例

账单 `200`，小费比例 `15`，人数 `1`：

```text
账单金额：200.00 元
小费（15%）：30.00 元
总计：230.00 元
人均（1 人）：230.00 元
```

## English

A tip calculator: compute the tip, total and per-person share from a bill amount, tip rate and headcount. Input: `text` (bill amount). Output: e.g. `小费（15%）：30.00 元` / `人均（1 人）：230.00 元`.
