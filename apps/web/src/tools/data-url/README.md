# Data URL

生成与解析 Data URL，支持 Base64 与百分号编码。

## 用途

把一小段内容（SVG、JSON、纯文本、图片字节）塞进单个 URL 字符串里直接内联到 HTML/CSS/Markdown，
或反过来把别人给的 Data URL 拆开——看它到底是什么 MIME 类型、用的什么字符集、载荷是不是二进制。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

- 生成方向：要内联的**文本**内容
- 解析方向：一条完整的 Data URL（`data:` 开头）

## 输出

| 字段   | 类型   | 说明                                                |
| ------ | ------ | --------------------------------------------------- |
| `text` | string | 生成方向输出 Data URL；解析方向输出拆解后的可读结果 |

解析方向输出形如：

```text
MIME 类型: text/plain
字符集: utf-8
Base64: 是
内容:
工具库
```

内容无法按 UTF-8 解成文本时，改为输出十六进制预览，并补一行提示：

```text
MIME 类型: application/octet-stream
字符集: 未指定
Base64: 是
提示: 内容共 1 字节，不是合法的 UTF-8 文本，以下为十六进制预览
内容:
ff
```

## 选项

| 选项        | 取值             | 默认       | 说明                                                |
| ----------- | ---------------- | ---------- | --------------------------------------------------- |
| `direction` | encode / decode  | encode     | 生成或解析                                          |
| `mode`      | base64 / url     | base64     | 生成时的载荷写法（解析时以输入里的 `;base64` 为准） |
| `type`      | 任意 MIME 字符串 | text/plain | 生成时写入的 MIME 类型；留空回落到 `text/plain`     |

`mode = url` 用的是百分号编码的纯文本形式（非 base64），适合手写、可读、便于局部修改。
只有 `text/*` 类型会自动追加 `;charset=utf-8`，`image/png` 这类不会塞进无意义的字符集参数。

## 限制

- 生成方向只接受**文本**输入；图片等二进制文件需要文件输入能力，模板尚未支持
- 解析方向能处理 base64 与百分号编码两种载荷；base64 的换行会被忽略，缺失的 `=` 会自动补齐
- 二进制内容不做「强行解成文本」，而是明确标注并给十六进制预览（预览最多 256 字节）
- 解析方向不读 `type` 选项：MIME 类型一律以输入里声明的为准

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（默认选项：encode / base64 / text/plain）：

```text
工具库
```

输出：

```text
data:text/plain;charset=utf-8;base64,5bel5YW35bqT
```

其他实算结果：

| 输入                                                | 选项                        | 输出                                                        |
| --------------------------------------------------- | --------------------------- | ----------------------------------------------------------- |
| `工具库`                                            | encode / url                | `data:text/plain;charset=utf-8,%E5%B7%A5%E5%85%B7%E5%BA%93` |
| `Hi`                                                | encode / base64 / image/png | `data:image/png;base64,SGk=`                                |
| `data:text/plain;charset=utf-8;base64,5bel5YW35bqT` | decode                      | 见上文「解析方向输出」示例                                  |
