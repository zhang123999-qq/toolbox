# XML 转义

XML 五个预定义实体与数字实体转义，可选 CDATA 段。

## 用途

把文本嵌进 XML / RSS / SVG / SOAP 报文时，`<`、`&` 这些字符会破坏文档结构，
必须先转义；反向则用于把配置文件、接口返回里的 `&lt;`、`&#x27;` 还原成
人能读的文字。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                                    |
| ------ | ------ | --------------------------------------- |
| `text` | string | 转义后为实体串或 CDATA 段；还原后为原文 |

## 选项

| 选项        | 取值                     | 默认   | 说明                                   |
| ----------- | ------------------------ | ------ | -------------------------------------- |
| `direction` | escape / unescape        | escape | 转义或还原                             |
| `mode`      | entity / numeric / cdata | entity | 命名实体 / 十进制数字实体 / 整段 CDATA |

## 限制

- XML 规范**只预定义五个实体**：`&amp;` `&lt;` `&gt;` `&quot;` `&apos;`。
  其余字符（含中文、emoji）在 XML 里本来就是合法文本，不需要也不能靠命名实体表达
- 与 **HTML 实体编解码**（本域另一个工具）的区别：
  - html-entity 收录约 70 个 HTML 命名实体（`&copy;` `&nbsp;` `&hellip;` …），
    XML 只有上面这五个，多出来的在 XML 里不是合法实体引用
  - html-entity 的 numeric 模式会把非 ASCII 一并数字实体化；本工具只转义那五个字符
  - 本工具提供 CDATA 模式，html-entity 没有（CDATA 是 XML 专有语法）
  - 两者都遵循「未识别实体原样保留」，因此 `&nbsp;` 在 XML 模式下不会被吃掉
- `cdata` 模式整段包进 `<![CDATA[ ... ]]>`，内容不做逐字符转义；
  文本里出现 `]]>` 时会自动断开成多段，保证不会提前结束 CDATA
- 还原时 CDATA 段无论是否被拆开都能拼回；数字实体的码点超过 0x10FFFF 会报错

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
<a href="x">工具库</a>
```

输出（entity）：

```text
&lt;a href=&quot;x&quot;&gt;工具库&lt;/a&gt;
```

输出（cdata）：

```text
<![CDATA[<a href="x">工具库</a>]]>
```
