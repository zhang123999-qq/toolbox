# 前后缀添加

批量给每行加前后缀。

## 用途

批量给每行挂上固定前后缀：一键把清单变成 Markdown 列表、给每行 SQL 加逗号分号、给配置行加引号或注释符。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

多行文本。前缀与后缀按原样拼接，不会自动补空格或去重。

## 输出

| 字段   | 类型   | 说明                         |
| ------ | ------ | ---------------------------- |
| `text` | string | 加了前后缀的文本，行数不变。 |

## 选项

| 选项        | 取值        | 默认   | 说明               |
| ----------- | ----------- | ------ | ------------------ |
| `prefix`    | 任意字符串  | `- `   | 每行开头追加的内容 |
| `suffix`    | 任意字符串  | （空） | 每行结尾追加的内容 |
| `skipEmpty` | 勾选 / 取消 | 勾选   | 空行是否跳过       |

## 限制

- 纯字符串拼接，不支持按行号、正则或模板变量（变量替换请用「模板变量替换」#25）
- 不会自动加空格：需要 `- item` 就填前缀 `- `（结尾带空格）
- 不做去重与排序：需要请先过一遍「文本去重」#28 或「文本排序」#29
- 前后缀上限各 200 字符
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
苹果
香蕉
橙子
```

输出：

```text
苹果
香蕉
橙子
```
