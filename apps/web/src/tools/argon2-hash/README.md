# Argon2 哈希

Argon2id 口令哈希的生成与校验，WASM 按需加载。

## 用途

生成符合 PHC 格式（`$argon2id$v=19$m=…,t=…,p=…$…`）的口令哈希，或校验某段口令是否匹配已有哈希。
Argon2 是 2015 年密码哈希竞赛的 winner，也是当前 OWASP 推荐的口令存储方案。

## 输入

| 字段   | 类型   | 约束              | 说明                         |
| ------ | ------ | ----------------- | ---------------------------- |
| `text` | string | 最大 200,000 字符 | 口令（哈希时）或待验证的口令 |
| `hash` | string | PHC 串            | 仅校验方向使用               |

## 输出

| 字段   | 类型   | 说明                                              |
| ------ | ------ | ------------------------------------------------- |
| `text` | string | PHC 哈希串，或校验结论（`校验通过` / `校验失败`） |

## 选项

| 选项          | 取值                 | 默认  | 说明               |
| ------------- | -------------------- | ----- | ------------------ |
| `direction`   | hash / verify        | hash  | 生成哈希或校验口令 |
| `iterations`  | 1 / 2 / 3            | 2     | 时间代价 t         |
| `memory`      | 8192 / 19456 / 32768 | 19456 | 内存代价 m（KiB）  |
| `parallelism` | 1 / 2                | 1     | 并行度 p           |

## 限制

- 变体固定为 **Argon2id**（`type=2`），这是当前推荐变体；Argon2i / Argon2d 不提供
- 底层是 Emscripten 编译的 WASM（约 30 KB），**首次点「运行」才会下载**，
  未触发运行前不会占用首屏体积
- 浏览器里 m=32768 需占用约 32 MiB 内存，低端设备可能失败
- 盐是随机生成的，同一口令每次哈希结果都不同
- `verify` 方向要求 PHC 串严格合法，否则报错而不是给出「校验失败」的假结论
- 单测里用桩件替换 WASM（Node 环境无法加载它），浏览器 E2E 跑真实实现

## 数据流向

**纯本地处理。** 口令只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（哈希方向）：

```text
P@ssw0rd-demo
```

输出（t=2 / m=19456 / p=1，每次不同）：

```text
$argon2id$v=19$m=19456,t=2,p=1$c2FsdHNhbHRzYWx0c2FsdA$…
```

## 元信息

| 项       | 值                               |
| -------- | -------------------------------- |
| 全局编号 | #100                             |
| 域       | `encoding`（编码 / 加密 / 安全） |
| 大组     | `dev`                            |
| 优先级   | P2                               |
| 可行性   | B（WASM，按需加载）              |
| 模板     | T2（双栏）                       |
