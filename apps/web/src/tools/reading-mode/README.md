# 阅读模式

从 HTML 中提取正文并渲染干净的阅读视图：移除 script / style / nav / header / footer / aside 等噪音元素，优先取 article / main，取不到时按文本长度与段落数打分选择正文容器；输出标题、段落、字数与预估阅读时长，阅读视图的字号、行高、浅色 / 墨色 / 深色主题可调。

## 用途

- 把杂乱的网页正文变成干净的阅读视图
- 统计文章字数与预估阅读时间
- 为视障或阅读困难用户提供舒适的排版

## 输入

| 字段   | 类型   | 约束                 |
| ------ | ------ | -------------------- |
| `text` | string | 待提取正文的 HTML |

在页面内设置：阅读字号（12–32px）、行高（1.2–2.5）、主题（light / sepia / dark）。

## 说明

- 纯前端解析（DOMParser），无网络请求，零依赖。
- 字数统计：中文按字计、英文按词计；阅读时长按 400 字/分钟向上取整。
- 提取不到有效段落时给出中文提示。
