# 字体位图（#796）

把文本逐字渲染为位图字体数据：可调字体与字号，自动裁剪空白边，导出 JSON 或 C 数组格式，供游戏引擎使用。

## 功能

- **逐字光栅化**：每个字符渲染为二值位图（alpha > 128 判定为前景）
- **自动裁剪**：裁剪字符四周空白，输出紧凑的 w×h 位图
- **重复去重**：相同字符只渲染一次
- **两种导出**：JSON（结构化数据）；C 数组（每行 MSB 优先打包为字节，附字符注释）
- **字号范围**：8~128px

## 说明

- C 数组格式示例：`const unsigned char FONT_0[1] = {0x80};`
- 纯前端本地处理，不发送任何网络请求
