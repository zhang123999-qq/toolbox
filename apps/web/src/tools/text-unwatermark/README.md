# 文本去水印

移除零宽水印。

## 用途

把文本里的零宽与方向控制字符清干净——这类字符肉眼不可见，却会让复制出来的内容带上隐藏信息、或让排版出现莫名其妙的空隙。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

一段可能含隐藏字符的文本。

## 输出

| 字段   | 类型   | 说明                                                             |
| ------ | ------ | ---------------------------------------------------------------- |
| `text` | string | 清洗后的文本（`strip`），或把隐藏字符换成 `␣` 的文本（`mark`）。 |

## 选项

| 选项   | 取值             | 默认    | 说明                        |
| ------ | ---------------- | ------- | --------------------------- |
| `mode` | `strip` / `mark` | `strip` | 直接移除 / 换成可见标记 `␣` |

## 限制

- **会一并清掉排版真正需要的零宽字符**：如 U+200D 零宽连接符（拼 emoji 家族与部分印度语系文字要用）、阿拉伯语等双向文本的方向控制字符
- `mark` 模式不修改内容，只把隐藏字符显形；确认位置后再切回 `strip` 删除
- 只处理零宽与方向控制字符，不处理不换行空格（U+00A0）、软连字符（U+00AD）等其他不可见字符——那些归 #41 不可见字符管
- 无法判断被清掉的字符原本是水印还是排版需要，需要判断请先用 #42 零宽字符看位置与类型
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
普通␣文␣本␣带␣隐藏字符（四个 ␣ 依次是 U+200B / U+200C / U+200D / U+2060）
```

输出：

```text
普通文本带隐藏字符
```
