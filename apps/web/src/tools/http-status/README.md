# HTTP 状态码

内置标准 1xx-5xx 状态码表（约 65 条）。输入三位码号精确查询，或输入关键词
（英文名片段 / 中文释义）模糊搜索，输出码号 + 英文名 + 中文释义 + 分类。

## 用途

看接口返回 `429`、`502`、`451` 时不用现搜：直接输码号或关键词，立刻知道含义与归属。

## 输入

| 字段   | 类型   | 约束                                |
| ------ | ------ | ----------------------------------- |
| `text` | string | 三位码号或关键词，最大 200,000 字符 |

- 输入纯三位数字 → 精确查该码
- 否则 → 在英文名 / 中文释义里模糊匹配，最多列出前 20 条

## 输出

| 输入   | 输出                                |
| ------ | ----------------------------------- |
| 码号   | 单行：`码 英文名（中文释义）— 分类` |
| 关键词 | 匹配计数 + 前 20 条列表             |

```text
404 Not Found（资源不存在）— 4xx 客户端错误
```

## 五大分类

| 范围 | 分类       | 含义                     |
| ---- | ---------- | ------------------------ |
| 1xx  | 信息       | 请求已接收，继续处理     |
| 2xx  | 成功       | 请求已成功处理           |
| 3xx  | 重定向     | 需要进一步操作           |
| 4xx  | 客户端错误 | 请求有错，服务器无法处理 |
| 5xx  | 服务端错误 | 服务器处理时出错         |

## 常见坑

- **401 vs 403**：401 是「没登录 / 凭证失效」，403 是「登录了但没权限」
- **301 vs 302 vs 307/308**：301/302 浏览器可能把 POST 改成 GET；307/308 保持原方法
- **422 vs 400**：400 是语法烂，422 是语法对但业务语义不对（表单校验失败常用）
- **429**：触发限流，需退避重试；别用 503 冒充

## 限制

- 仅收录常见标准码，未覆盖实验性 / 厂商私有码
- 关键词匹配最多返回 20 条
- 空输入返回空串；未命中抛中文错误

## 数据流向

**纯本地处理。** 内置表查询，不发送网络请求。`meta.api = false`。

## 示例

输入：

```text
429
```

输出：

```text
429 Too Many Requests（触发限流（频率过高））— 4xx 客户端错误
```
