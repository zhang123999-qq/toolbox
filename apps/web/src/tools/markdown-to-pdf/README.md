# Markdown 转 PDF

将 Markdown 文本排版为 PDF：标题分级字号、列表缩进、代码块等宽字体，自动换行、自动分页，纯本地生成后下载。

## 用途

写好的 Markdown 文档（报告、说明、笔记）一键转成可打印/分发的 PDF，不经过任何服务器。

## 输入

| 字段   | 类型   | 约束              | 说明          |
| ------ | ------ | ----------------- | ------------- |
| `text` | string | 最大 100,000 字符 | Markdown 源码 |

支持的语法（行级解析）：

- `#` ~ `######` 六级标题（字号逐级加大、加粗）
- `-` / `*` / `+` 无序列表（统一渲染为 `-`），`1.` / `2)` 有序列表（保留序号），前导空格表示嵌套
- ` ``` ` 代码围栏（等宽 Courier、缩进；行内加粗/斜体等语法**不支持**，原样输出）
- `> ` 引用（加深缩进）
- `---` / `***` / `___` 分割线
- 空行表示段间距

## 输出

| 字段   | 类型       | 说明                          |
| ------ | ---------- | ----------------------------- |
| `file` | PDF 二进制 | A4 纵向 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「下载」按钮下载的是 Markdown 源文本（`.md`）。

## 选项

| 选项       | 取值         | 默认 | 说明           |
| ---------- | ------------ | ---- | -------------- |
| `fontSize` | 10 / 12 / 14 | 12   | 基准字号（pt） |
| `margin`   | 36 / 54 / 72 | 54   | 页边距（pt）   |

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts`（Helvetica / Courier）使用 WinAnsi 编码，
  无法绘制中文字符。输入含中文（或 emoji 等非 Latin-1 字符）时会直接报错
  「暂不支持中文字符：pdf-lib 内置字体仅支持 Latin-1 编码，请使用英文内容」，
  不会生成乱码 PDF。如需中文排版请使用系统打印为 PDF 等方式。
- 超长单词不断词：单个单词超过行宽时独占一行（允许轻微溢出）。
- 代码块内不做语法高亮，只用等宽字体区分。
- 文件全程在浏览器内存里生成，不发任何请求。

## 数据流向

**纯本地处理。** 输入文本与生成的 PDF 都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```markdown
# Quarterly Report

## Highlights

- Revenue grew 12%
- New users: 5400
```

输出：A4 PDF（标题 22pt 加粗、二级标题 19pt、列表 `- ` 缩进 18pt），输出区显示如
`已生成 PDF：1 页，3.2 KB`。
