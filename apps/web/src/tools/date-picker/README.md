# 日期选择器

一个日历小部件：翻月、今天高亮、点选某天后立刻给出 ISO 日期、时间戳和星期。

## 用途

需要「挑一个日期 → 拿到它的 ISO 串 / Unix 时间戳 / 是周几」时用，不用手动心算。
全部在浏览器本地运行。

## 操作方式

| 控件     | data-testid | 作用               |
| -------- | ----------- | ------------------ |
| 上一月   | `dp-prev`   | 翻到上个月         |
| 下一月   | `dp-next`   | 翻到下个月         |
| 日期格子 | `dp-day-日` | 选中该天           |
| 信息区   | `dp-info`   | 显示选中日期的详情 |

- 今天用**描边圆圈**高亮，选中日用**实心色块**标出。
- 日历按周一开头排列。

## 输出

选中某天后，下方信息区显示：

```text
2026-09-28（周一） 时间戳 1790572800（1790572800000 毫秒）
```

包含：

- **ISO 日期**：`YYYY-MM-DD`
- **星期**：中文
- **时间戳**：Unix 秒 + 毫秒

## 纯逻辑说明

月历网格生成、闰年判断、当月天数、ISO 格式化都是 `utils.ts` 里的纯函数：

- `isLeapYear(year)`：四年一闰、百年不闰、四百年再闰。
- `daysInMonth(year, month)`：含闰年二月。
- `buildCalendar(year, month)`：返回周一开头的周数组，月外用 `null` 占位。

## 限制

- 只输出公历信息，不计算农历。
- 时间戳取当天本地 00:00:00（选中日的零点）。
- 输入框仅为模板占位，不参与功能。

## 数据流向

**纯本地处理。** 日历计算与格式化都是纯函数，不发网络请求。`meta.api = false`。
