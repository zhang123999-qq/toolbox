# 纯文本转 PDF

将纯文本原样排版为 A4 PDF：字号与页边距可调，自动换行、自动分页，纯本地生成后下载。

## 用途

会议纪要、日志、纯文本文档快速转成可打印/分发的 PDF，不经过任何服务器。

## 输入

| 字段   | 类型   | 约束              | 说明   |
| ------ | ------ | ----------------- | ------ |
| `text` | string | 最大 100,000 字符 | 纯文本 |

文本原样输出：保留换行与行首空格（不做 Markdown 解析）；空行转为段间距。

## 输出

| 字段   | 类型       | 说明                          |
| ------ | ---------- | ----------------------------- |
| `file` | PDF 二进制 | A4 纵向 PDF，点击按钮直接下载 |

输出区会显示生成结果的页数与体积；模板自带的「下载」按钮下载的是源文本（`.txt`）。

## 选项

| 选项       | 取值         | 默认 | 说明         |
| ---------- | ------------ | ---- | ------------ |
| `fontSize` | 10 / 12 / 14 | 12   | 字号（pt）   |
| `margin`   | 36 / 54 / 72 | 54   | 页边距（pt） |

## 限制

- **暂不支持中文字符**：pdf-lib 的 `StandardFonts` 使用 WinAnsi 编码，输入含中文（或 emoji
  等非 Latin-1 字符）时会直接报错，不会生成乱码 PDF。
- 超长单词不断词：单个单词超过行宽时独占一行（允许轻微溢出）。
- 文件全程在浏览器内存里生成，不发任何请求。

## 数据流向

**纯本地处理。** 输入与生成的 PDF 都不离开浏览器，`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
Meeting Notes

- Review Q3 roadmap
- Assign owners for each milestone
```

输出：A4 PDF；输出区显示如 `已生成 PDF：1 页，2.1 KB`。
