# 关键词密度

计算关键词占比，SEO 参考。

## 用途

检查页面文案里关键词的占比是否过高或过低，作为 SEO 与内容自查的参考。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本，中英混排均可。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                                 |
| ------ | ------ | ---------------------------------------------------- |
| `text` | string | 每行一条：关键词、出现次数、密度（占总词数百分比）。 |

## 选项

| 选项   | 取值        | 默认 | 说明                 |
| ------ | ----------- | ---- | -------------------- |
| `topN` | 5 / 10 / 20 | 10   | 最多返回多少个关键词 |

## 限制

- 默认过滤停用词（虚词），因此密度分母仍是**全部**词数，而分子只统计实词
- 中文按连续汉字块切分，未做分词，短语不会被拆分
- SEO 没有统一的「最佳密度」，本工具只给数据，不做好坏判断

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
cat cat dog
```

输出：

```text
在线工具库提供在线工具，在线工具全部在本地运行，本地运行不上传数据。
```
