# 正则替换

正则表达式替换，支持分组。

## 用途

用正则表达式做一次带结构的替换：交换字段顺序、提取并重组片段、批量加包裹符，比逐条字面替换更省事。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

待处理的文本。

## 输出

| 字段   | 类型   | 说明           |
| ------ | ------ | -------------- |
| `text` | string | 替换后的文本。 |

## 选项

| 选项          | 取值        | 默认          | 说明                                      |
| ------------- | ----------- | ------------- | ----------------------------------------- |
| `pattern`     | 正则表达式  | `(\w+)@(\w+)` | 查找用的正则                              |
| `replacement` | 替换串      | `$2@$1`       | 支持 `$1`、`$&`、`$<name>` 等 JS 原生引用 |
| `global`      | 勾选 / 取消 | 勾选          | g：替换所有匹配                           |
| `ignoreCase`  | 勾选 / 取消 | 取消          | i：忽略大小写                             |
| `multiline`   | 勾选 / 取消 | 取消          | m：`^` `$` 匹配每行首尾                   |

## 限制

- 用的是 JS 正则语法，不支持后行断言以外的 Perl 扩展；部分旧浏览器不支持后行断言
- 不提供 s（dotAll）、u（Unicode）等开关，需要 unicode 模式请写 `\p{...}` 并自行确认环境支持
- 替换串只支持字符串引用，`$1` 等按 JS 规则解析；不支持函数式替换与大小写转换
- 非法正则会在输出区显示错误信息，不会中断页面
- 输入上限 100,000 字符；超大文本上的复杂正则可能触发回溯，请缩小范围

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
alice@example.com bob@test.org
```

输出：

```text
alice@example.com bob@test.org
```
