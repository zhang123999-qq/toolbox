# 随机抽样 | Random Sampling

从输入总体中随机抽取样本：支持**有放回 / 无放回**两种模式，可设样本量与随机种子；相同种子抽出的样本完全一致（可复现）。

Draw a random sample from a population, with or without replacement. An optional seed makes the draw fully reproducible.

## 用途 | Purpose

- 问卷 / 实验中随机抽取受访者、样本
- 抽奖、随机分组、随机点名
- 需要可复现随机过程的教学演示（固定种子）

## 输入 | Inputs

| 字段         | 类型   | 约束                                  |
| ------------ | ------ | ------------------------------------- |
| `text`       | string | 总体：每行一个元素，最大 200,000 字符 |
| `sampleSize` | string | 样本量（须为 0–100000 的整数）        |
| `seed`       | string | 随机种子（可空；空 = 真随机）         |

## 输出 | Output

```text
抽样方式：无放回
总体规模：5
样本量：3
种子：42
抽样结果：
1. 橙子
2. 苹果
3. 西瓜
```

## 选项 | Options

| 选项      | 类型    | 说明                              |
| --------- | ------- | --------------------------------- |
| `replace` | boolean | 有放回抽样（默认 false = 无放回） |

## 算法 | Algorithm

- **PRNG**：mulberry32（Tommy Ettinger 2017 年公开的公有领域 32 位算法）；
  字符串种子先经 FNV-1a 哈希压缩为 32 位整数再喂给 PRNG。
- **无放回**：Fisher–Yates 部分洗牌后取前 n 个，时间 O(n)。
- **有放回**：每次独立均匀取索引，同一元素可被重复抽中。

## 边界 | Edge cases

- 总体留空 → 空态，不报错
- 样本量为空 / 非数字 / NaN / Infinity / 小数 / 负数 → 中英双语报错
- 样本量 > 100000 → 报错（防内存爆炸）
- 无放回且样本量 > 总体规模 → 报错；有放回无此限制
- 样本量 = 0 → 返回空样本（合法）
- 总体含重复元素 → 按位置独立看待，允许抽中

## 限制 | Limits

- 纯前端本地计算，数据不上传
- 无种子时每次渲染/运行都会重新随机；要可复现请填写种子

## 数据流向 | Data flow

全部在浏览器本地完成，无网络请求。

## 示例 | Example

总体（每行一个）：`苹果 / 香蕉 / 橙子 / 葡萄 / 西瓜`，样本量 `3`，种子 `42`，无放回 →
输出 3 个不重复的水果，再次运行结果相同。
