# 摄像头测试（#836）

摄像头硬件检测：枚举摄像头设备，申请权限后实时预览画面，支持多摄像头与分辨率切换。

## 功能

- 自动枚举 `videoinput` 设备（多摄像头下拉选择）。
- 点击"开始预览"申请摄像头权限并实时显示画面。
- 分辨率下拉（QVGA / VGA / HD 720p / FHD 1080p），预览中切换会自动重建视频流。
- "停止预览"释放摄像头占用。

## 权限与局限

- 需要浏览器支持 `MediaDevices`（`getUserMedia` + `enumerateDevices`），且页面运行在 HTTPS 或 localhost 下；HTTP 非安全上下文会被浏览器拒绝。
- 权限被拒绝时请在浏览器地址栏的站点设置中允许摄像头后重试。
- 实际可用的分辨率取决于摄像头硬件，`ideal` 约束不保证精确匹配。
