# 文本排序

按行排序，支持数字、长度、字典序。

## 用途

把清单、日志、关键词表按规则排序：字典序整理名单、按数字排序带编号的行、按长度排序做对齐检查。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

多行文本。换行符统一按 LF / CRLF 识别，输出统一用 LF。

## 输出

| 字段   | 类型   | 说明                                                     |
| ------ | ------ | -------------------------------------------------------- |
| `text` | string | 排序后的文本。排序稳定：键值相同的行保持原来的相对顺序。 |

## 选项

| 选项         | 取值                                                               | 默认   | 说明                   |
| ------------ | ------------------------------------------------------------------ | ------ | ---------------------- |
| `sortBy`     | `text`（字典序） / `number`（行内第一个数字） / `length`（字符数） | `text` | 排序依据               |
| `descending` | 勾选 / 取消                                                        | 取消   | 降序排列               |
| `ignoreCase` | 勾选 / 取消                                                        | 取消   | 字典序比较时忽略大小写 |

## 限制

- 字典序按 **Unicode 码点序**比较，不是中文拼音序，也不是 locale 感知的排序
- 数字模式取「行内第一个数字」，一行有多个数字时只用第一个；没有数字的行统一排在最后（不受升降序影响）
- 长度按 Unicode 码点数计，中日韩字符与拉丁字母都算 1
- 不提供按列排序：需要按某一列排序请先用「文本分列」（#38）或「表格转文本」（#22）
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
banana
apple
cherry
```

输出：

```text
banana
apple
cherry
```
