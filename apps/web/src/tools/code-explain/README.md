# 代码解释 Code Explanation（#606）

BYOK 模式：粘贴一段代码，请大模型用中文解释它的功能、
关键逻辑与注意事项，支持选择代码语言（默认自动识别）。

## 使用方法

1. 左侧粘贴代码；
2. 右上角选择代码语言（默认自动识别）；
3. 右侧配置接口地址、模型名、API Key；
4. 点「开始解释」，解释文本展示在下方（功能概述 / 关键逻辑 / 注意事项三段）。

## BYOK 说明

- API Key 只保存在内存中，刷新/关闭页面即清除，不写 localStorage；
- Key 只出现在请求头中，本站不经手、不记录；
- 接口需兼容 OpenAI 的 `POST {baseURL}/chat/completions` 格式。

## 错误处理

- 代码为空 / 超长显示中文错误；
- 401 / 403 / 404 / 429 / 5xx 翻译为中文提示。
