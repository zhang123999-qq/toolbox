# 关卡编辑（#801）

关卡**对象层**编辑工具：放置敌人 / 道具 / 出生点 / 出口 / 触发器等关卡对象，校验关卡合法性，导出 / 导入关卡 JSON。

与 #788 tilemap 的差异：tilemap 负责**瓦片层绘制**（地形格子），本工具负责**对象层**（ gameplay 实体），两者互补。

## 对象结构

```json
[
  { "id": "spawn1", "type": "spawn", "x": 10, "y": 10 },
  { "id": "exit1",  "type": "exit",  "x": 90, "y": 90 },
  { "id": "slime1", "type": "enemy", "x": 50, "y": 50, "props": { "hp": 100 } }
]
```

- `type`：`enemy` / `item` / `spawn` / `exit` / `trigger`
- `props`：可选，自定义属性对象

## 校验规则

1. 出生点（spawn）恰好只能有 1 个
2. 至少存在 1 个出口（exit）
3. 所有对象坐标不得超出关卡宽高（越界逐项中文报错）

## 说明

纯前端本地计算，不发送任何网络请求。输入框即关卡 JSON 的导出/导入格式。
