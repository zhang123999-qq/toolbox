# Excel 转 JSON

把 **XLSX 工作表**或 **CSV/TSV 文本**转成 JSON：首行可作为字段名（对象数组），
否则输出二维数组；单元格做轻量类型推断。纯本地转换，不引入新依赖。

## 用途

把表格数据喂给接口 / 脚本 / mock：上传或粘贴表格，得到规整的 JSON。
`.xlsx` 的 zip/XML 最小解析复用姊妹工具 Excel 转 CSV（`DecompressionStream`，只读第一张工作表）。

## 输入

| 入口   | 说明                                                              |
| ------ | ----------------------------------------------------------------- |
| 文本框 | 粘贴 CSV / TSV（分隔符按首个非空行自动猜测），上限 5,000,000 字符 |
| 文件   | `.xlsx` / `.csv` / `.tsv` / `.txt`，上限 20 MiB                   |

## 输出

| 字段   | 类型   | 说明                               |
| ------ | ------ | ---------------------------------- |
| `text` | string | 缩进 2 空格的 JSON；空输入返回空串 |

## 选项

| 选项         | 取值    | 默认   | 说明                                    |
| ------------ | ------- | ------ | --------------------------------------- |
| `withHeader` | boolean | `true` | 首行作为字段名；关闭后输出 `string[][]` |

## 转换规则

- 有表头：`[{ 表头: 值, … }]`；空白表头用 `_N`，重名表头追加 `_2/_3` 去重
- 单元格推断：空 → `null`；`true/false/TRUE/FALSE` → 布尔；整数 / 小数 / 科学计数 → number；
  **前导零（`007`、邮编）保留为字符串**；其余保持字符串
- `.xlsx` 正确处理共享字符串、内联字符串、布尔与数字单元格

## 限制

- `.xlsx` 只读取**第一张工作表**，不处理多 sheet 选择、公式结果之外的公式、样式、合并单元格、日期序列号（日期会显示为数字）
- 不支持 `.xls`（老版 BIFF 二进制）、加密 / 受密码保护的工作簿；不依赖 `xlsx` 库
- 类型推断是启发式的：形如数字但语义是编号的列可能被转成 number，需要时请关闭推断自行处理
- 文件上限 20 MiB，依赖浏览器 `DecompressionStream`（不支持时改用 CSV/TSV）

## 数据流向

**纯本地处理。** 文件与文本只在浏览器内解析，不上传、不写服务端。`meta.api = false`。

## 示例

输入：

```csv
id,name,active,score
1,工具库,true,870.5
2,表格,false,
```

输出：

```json
[
  { "id": 1, "name": "工具库", "active": true, "score": 870.5 },
  { "id": 2, "name": "表格", "active": false, "score": null }
]
```
