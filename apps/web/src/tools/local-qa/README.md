# 本地问答 Local QA（#598）

基于你粘贴的多篇文档做**抽取式问答**：用 TF-IDF 检索与问题最相关的句子，
拼接成回答并列出证据句（含文档编号与相关度）。纯 JS 实现，**不联网**、
不调用任何模型 API。

## 使用方法

1. 在「知识文档」区粘贴文档，多篇文档之间用**空行**分隔；
2. 左侧输入问题，右侧自动作答；
3. 右上角可调整返回的证据句数（1 / 3 / 5）。

## 原理

1. 文档按空行切篇，按中英文句末标点切句；
2. 分词（英文小写切词 / 中文单字），以「句」为单位计算 TF-IDF 向量；
3. 问题向量与句向量做余弦相似度，取 topK 句拼接为回答。

## 局限（必读）

- 这是**关键词匹配的抽取式问答，不是语义理解**：
  同义词（「电脑」vs「计算机」）、指代、多步推理都处理不好；
- 回答只是原文句子的拼接，不会改写成自然语言；
- 文档中没有相关内容时会明确告知「未找到」，不会编造答案；
- 单篇文档上限 50,000 字符、最多 50 篇，问题上限 2,000 字符。
