# 语音识别

语音命令词识别匹配：你先预设一组命令词（每行一个），点「开始监听」后对着麦克风说话，
识别结果命中了哪个命令词就高亮显示哪个并给出命中统计。

## 与「音频转文字」工具的区别

**本工具是命令匹配而非听写。** 它不把你说的话全文转写成文字，
只做一件事：判断你说的句子里出现了预设命令词中的哪一个并高亮。
想要「把说的话逐句记录成文字」请用「音频转文字」工具（#555，连续听写）。

## 用途

语音遥控原型、语音指令演示、关键词触发测试。

## 输入

| 字段         | 类型   | 说明                                         |
| ------------ | ------ | -------------------------------------------- |
| `microphone` | 音频流 | 点「开始监听」后从麦克风实时采集，**不上传** |
| `text`       | string | 左侧文本区仅作备注，不参与处理               |

## 输出

| 字段   | 类型   | 说明                                                                |
| ------ | ------ | ------------------------------------------------------------------- |
| `text` | string | 最新一句识别结果 + 命中摘要（如「命中 1/3 个命令词」），可复制/下载 |

界面同时显示：预设命令词标签、识别结果（命中部分红色高亮）、命中统计。

## 选项

| 选项   | 类型 | 默认                        | 说明                                             |
| ------ | ---- | --------------------------- | ------------------------------------------------ |
| 命令词 | 文本 | `打开灯/关灯/播放音乐/停止` | 每行一个，也可用逗号、分号、空格分隔，最多 50 个 |
| `lang` | 选择 | `zh-CN`                     | 识别语言：中文简/繁、粤语、英、日、韩等          |

## 限制

- 需要 Chrome / Edge 浏览器（Web Speech API），其他浏览器会给出中文提示
- 识别需要联网（浏览器把音频发给语音服务）；麦克风音频不经过本站服务器
- 匹配是子串查找：句子里包含命令词即算命中
- 浏览器可能因长时间静音自动结束识别，本工具会自动续上
- 识别出错（无语音/权限拒绝/网络异常）会给出中文提示

## 示例

预设命令词 `打开灯 / 关灯`，说「请打开灯」：

```text
请打开灯          ← 「打开灯」红色高亮
命中 1/2 个命令词
```

## 数据流向

识别由浏览器 Web Speech API 完成（`meta.api = false`，无需自备 Key）；
注意浏览器实现会把音频发往其语音服务，介意者请勿用于敏感内容。
