# 个税计算

输入月应纳税所得额（**应已扣除 5000 元起征点及专项附加扣除**），按中国个税月度税率表算出适用税率、速算扣除数与应缴个人所得税。

## 用途

- 工资条到手前先算个税，心里有数
- 年终奖 / 劳务报酬等一次性收入的个税估算
- 学习理解七级超额累进税率与速算扣除数的关系

## 输入

| 字段   | 类型   | 约束                                              |
| ------ | ------ | ------------------------------------------------- |
| `text` | string | 月应纳税所得额（元），必须 ≥ 0，最大 200,000 字符 |

> 输入的是**应纳税所得额**，不是税前工资：税前工资 − 五险一金个人部分 − 5000（起征点）− 专项附加扣除 = 应纳税所得额。

## 输出

```text
应纳税所得额：10000.00 元
适用税率：10%
速算扣除数：210.00 元
应缴个人所得税：790.00 元
```

## 选项

无。

## 算法

七级超额累进月度税率表，档位语义为「超过 X 至 Y」即 `(X, Y]`：

| 月应纳税所得额 | 税率 | 速算扣除数 |
| -------------- | ---- | ---------- |
| ≤ 3000         | 3%   | 0          |
| (3000, 12000]  | 10%  | 210        |
| (12000, 25000] | 20%  | 1410       |
| (25000, 35000] | 25%  | 2660       |
| (35000, 55000] | 30%  | 4410       |
| (55000, 80000] | 35%  | 7160       |
| \> 80000       | 45%  | 15160      |

- 应缴个税 = 应纳税所得额 × 税率 − 速算扣除数；所得额为 0 时个税为 0
- 金额格式化：`n.toFixed(2)`；税率以整数百分比展示，避免浮点尾巴

## 边界

- 空输入 → 输出空串
- 非数字 → 中文报错「请输入有效的数字」
- 负数 → 中文报错「应纳税所得额不能为负数」
- 输入 > 200,000 字符 → 报错

## 示例

输入 `10000`：

```text
应纳税所得额：10000.00 元
适用税率：10%
速算扣除数：210.00 元
应缴个人所得税：790.00 元
```

An individual income tax calculator using China's monthly tax brackets: enter the monthly taxable income (after the 5,000 CNY threshold and deductions) and get the applicable rate, quick deduction and tax payable. Input: `text` (taxable income in CNY). Output: e.g. `应缴个人所得税：790.00 元`.
