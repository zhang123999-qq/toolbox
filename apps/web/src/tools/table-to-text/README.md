# 表格转文本

表格数据转 Markdown、CSV、JSON。

## 用途

把从 Excel、数据库或网页里复制出来的分隔文本，转成 Markdown 表格、CSV 或 JSON——贴进文档用 Markdown，再导入用 CSV，交给程序用 JSON。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

分隔文本（TSV / CSV / 分号 / 竖线 / 多空格均可）。空行会被丢弃；单元格可用双引号包裹，引号内的分隔符不参与切分。

## 输出

| 字段   | 类型   | 说明                                                         |
| ------ | ------ | ------------------------------------------------------------ |
| `text` | string | 按所选格式输出的表格文本，值一律按字符串处理，不做类型推断。 |

## 选项

| 选项        | 取值                                                      | 默认       | 说明                              |
| ----------- | --------------------------------------------------------- | ---------- | --------------------------------- |
| `delimiter` | `auto` / `comma` / `tab` / `semicolon` / `pipe` / `space` | `auto`     | 输入分隔符，auto 按每行出现次数猜 |
| `format`    | `markdown` / `csv` / `json`                               | `markdown` | 输出格式                          |
| `header`    | 勾选 / 取消                                               | 勾选       | 首行是否作为表头                  |

## 限制

- 自动识别只看前 20 行、按「每行都出现且次数最多」猜；正文里逗号很多时可能猜错，请手动指定分隔符
- 不解析合并单元格、多行表头、公式等 Excel 专有结构，请先展平成普通二维表
- CSV 输出按 RFC 4180 的最小规则加引号（含逗号 / 引号 / 换行才加），不做类型转换
- JSON 输出的值全是字符串；表头重名时自动加 `_2`、`_3` 后缀
- 输入上限 100,000 字符，超出请分批

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
name	age	city
张三	28	北京
李四	31	上海
```

输出：

```text
name	age	city
张三	28	北京
李四	31	上海
```
