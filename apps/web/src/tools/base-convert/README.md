# 进制转换

整数在 2 / 8 / 10 / 16 / 32 / 36 进制之间互转。BigInt 累加解析，任意精度。

## 用途

- 十 / 十六 / 八 / 二进制互转
- 32 / 36 进制（短链接风格编码常用）互转
- 超长大整数精确转换

## 输入

| 字段   | 类型   | 约束                            |
| ------ | ------ | ------------------------------- |
| `text` | string | 待转换的整数，最大 200,000 字符 |

## 输出

```text
255 (10进制) = FF (16进制)
```

格式为 `<输入> (<from>进制) = <结果> (<to>进制)`，结果字母一律大写。

## 选项

| 选项   | 类型   | 可选值                    | 默认 |
| ------ | ------ | ------------------------- | ---- |
| `from` | select | 2 / 8 / 10 / 16 / 32 / 36 | 10   |
| `to`   | select | 2 / 8 / 10 / 16 / 32 / 36 | 16   |

## 算法

- **解析**：允许首字符 `-` 表示负数；`0x` / `0b` / `0o` 前缀仅在与 `from` 一致时自动剥离（16/2/8）；逐字符校验 `digit < from`，否则报错；BigInt 累加，任意精度
- **输出**：`BigInt.prototype.toString(to)` 后转大写
- 36 进制输入大小写不敏感（`zz` 与 `ZZ` 等价）

## 边界

- 空输入 → 输出空
- 某字符在源进制下非法 → 中文报错（如 `数字 "2" 在 2 进制下非法`）
- 仅整数：出现小数点直接报错
- `from` / `to` 不在 2/8/10/16/32/36 内 → 报错
- 输入 > 200,000 字符 → 报错
- 纯本地计算，不上传数据

## 示例

输入：`255`，选项从 `10` 到 `16`

输出：`255 (10进制) = FF (16进制)`

## English

Base converter: convert integers between bases 2/8/10/16/32/36 with arbitrary precision (BigInt).

Input: `text` (string, the integer to convert, max 200,000 chars). Options: `from` / `to` (select from 2/8/10/16/32/36, defaults 10/16). Output format: `<input> (<from>进制) = <RESULT> (<to>进制)`, letters uppercased.

Example: input `255`, from `10`, to `16` → `255 (10进制) = FF (16进制)`.
