# Git Diff

把 `git diff` 的粘贴输出解析成结构化摘要：变更文件数、增删总行数、每个文件的状态与 +/- 行数。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

粘贴 `git diff`（或 `git show <commit>`）的完整文本即可。

## 选项

| 选项 key  | 界面标签 | 说明                     |
| --------- | -------- | ------------------------ |
| `verbose` | 显示说明 | 在结果后追加解析口径注释 |

## 输出

```text
变更文件：2 个
新增行：+3
删除行：-1

文件 | 状态 | 新增 | 删除
--- | --- | --- | ---
src/a.ts | 修改 | +2 | -1
new.txt | 新增 | +1 | -0
```

## 解析口径

- 以 `diff --git a/x b/y` 识别文件边界，路径取 `b/` 侧
- `new file mode` → 新增；`deleted file mode` → 删除；其余 → 修改
- 以 `+` / `-` 开头的内容行计入增删；`+++` / `---` 表头行不计入
- 输入中既无 `diff --git` 也无 `@@` 时判定为非法 diff，报错

## 限制

- 只做行级统计，不输出高亮差异、不支持合并冲突 diff（`diff3`）
- 二进制文件只计文件名，不计行数

## 数据流向

**纯本地处理。** 不发送网络请求。`meta.api = false`。
