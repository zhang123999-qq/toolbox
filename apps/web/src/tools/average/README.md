# 平均数

求一组数字的算术平均数，附个数、总和、最小值与最大值。

## 用途

- 算平均分、平均销售额、日均步数等
- 一眼看到总和与最值，核对数据范围

## 输入

| 字段   | 类型   | 约束                        |
| ------ | ------ | --------------------------- |
| `text` | string | 一组数字，最大 200,000 字符 |

分隔符：空白（空格 / 换行 / 制表符）、逗号 `,` `，`、分号 `;` `；`、顿号 `、`，可混用。

## 输出

```text
个数：5
总和：150
算术平均数：30
最小值：10
最大值：50
```

## 选项

| 选项       | 取值                               | 说明                       |
| ---------- | ---------------------------------- | -------------------------- |
| `decimals` | `0` / `1` / `2` / `4` / `6` / `10` | 结果保留小数位数，默认 `4` |

## 算法

- 算术平均数 = 总和 ÷ 个数；最值一次遍历得出
- 显示层按 `decimals` 四舍五入并去掉无意义尾零（`2.5000` → `2.5`）

## 边界

- 非数字项 → 中文报错并指出该项
- 无有效数字 → 中文报错
- 输入 > 200,000 字符 → 报错

## 示例

输入 `10 20 30 40 50`：平均数 `30`，总和 `150`。

## 数据流向

纯前端本地计算，不调用外部接口、不上传数据。
