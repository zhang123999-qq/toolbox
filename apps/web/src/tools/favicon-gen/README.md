# Favicon 生成 Favicon Multi-Size Generator（#628）

上传一张图片（PNG / JPG / SVG，建议正方形），生成 16 / 32 / 48 / 180 / 192 / 512
六种标准尺寸的 favicon PNG：可打包下载 ZIP，也可单独下载某个尺寸。

> 与 #386「Favicon 生成」（favicon）的区别：#386 是从字母/渐变/几何样式**设计**图标；
> 本工具是把**已有图片**转成多尺寸 favicon 套装。

## 使用方法

1. 点击选择图片（或点「示例」用内置示例图）；
2. 自动生成六种尺寸，右侧逐个预览；
3. 点「打包下载 ZIP」一次拿走全部，或点单个尺寸旁的「PNG」单独下载。

## 错误处理

- 非图片文件、图片加载失败、PNG 编码失败时显示中文错误；
- 生成过程中按钮置灰防重复点击。

## English

Upload an image to generate six standard favicon PNG sizes (16/32/48/180/192/512):
download them all as a zip or grab individual sizes. Differs from #386 favicon,
which designs icons from letter/gradient/geometric styles — this tool converts
an existing image into a multi-size favicon set.
