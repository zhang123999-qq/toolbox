# 代码转图片

用浏览器原生 canvas 把代码绘制为 PNG 图片（数据 URL），支持明暗主题与字号。

## 用途

把一段代码截图成图片发到群里 / 博客，省去系统截图工具。语法高亮靠内置的轻量 tokenizer。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明                                                                 |
| ------ | ------ | -------------------------------------------------------------------- |
| `text` | string | PNG 数据 URL（`data:image/png;base64,...`）；canvas 不可用时给出提示 |

## 选项

| 选项 key   | 界面标签 | 说明                    |
| ---------- | -------- | ----------------------- |
| `theme`    | 主题     | dark / light            |
| `language` | 语言     | js / css / html / plain |
| `fontSize` | 字号     | 12 / 14 / 16 / 20 px    |

## 实现说明

- 纯函数 `splitLines` / `tokenizeLine` 负责切行与语法高亮（关键字 / 字符串 / 数字 / 注释）
- 浏览器里用 `document.createElement('canvas')` 逐行绘制，`toDataURL('image/png')` 输出
- jsdom / 无 canvas 环境下退化为一行提示，不报错

## 限制

- 不做真正的多行语法高亮（CSS / HTML 只做粗粒度标记）
- 图片宽度固定 800px，不自动按最长行扩展
- 字体用系统等宽字体，不加载 webfont
- 输入上限 200,000 字符

## 数据流向

**浏览器本地 canvas。** `meta.api = false`，不发送任何网络请求。
