# BMI 计算

输入身高（cm）与体重（kg），算身体质量指数（BMI）与健康分级（中国标准），并给出健康体重范围。

## 用途

- 体检 / 日常健康管理的体重评估
- 健身计划的起点参考

## 输入

| 字段    | 类型   | 约束                                  |
| ------- | ------ | ------------------------------------- |
| `text`  | string | 身高（cm），50–300，最大 200,000 字符 |
| `textB` | string | 体重（kg），>0 且 ≤1000               |

## 输出

```text
身高：175 cm　体重：70 kg
BMI：22.9
分级：正常
健康体重范围：56.7 – 73.5 kg
```

## 选项

无。

## 算法

- `BMI = 体重(kg) / (身高(m))²`
- 分级（中国标准）：`<18.5` 偏瘦 / `18.5–24` 正常 / `24–28` 超重 / `≥28` 肥胖
- 健康体重范围：`18.5 × 身高(m)² ～ 24 × 身高(m)²`
- BMI 与体重范围保留 1 位小数（`toFixed(1)`）

## 边界

- 身高留空 → 输出空串
- 身高非数字 → 中文报错「身高请输入有效的数字」
- 身高 <50 或 >300 → 中文报错「身高应在 50–300 cm 之间」
- 体重非数字 → 中文报错「体重请输入有效的数字」
- 体重 ≤0 → 中文报错「体重必须大于 0」
- 体重 >1000 → 中文报错「体重超出合理范围」
- 输入 > 200,000 字符 → 报错

## 示例

身高 `175`，体重 `70`：

```text
身高：175 cm　体重：70 kg
BMI：22.9
分级：正常
健康体重范围：56.7 – 73.5 kg
```

## English

A BMI calculator using the Chinese classification standard (<18.5 underweight / 18.5–24 normal / 24–28 overweight / ≥28 obese), with a healthy weight range. Input: `text` (height in cm), `textB` (weight in kg). Output: e.g. `BMI：22.9` + classification.
