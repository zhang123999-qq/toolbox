# 生日倒计时

输入生日（月日，可选年份），算出距下一次生日还有多久、那天星期几，以及届时满多少周岁。

## 用途

- 提醒自己 / 朋友的生日还有几天
- 知道下一次生日落在星期几，好安排聚餐
- 输入出生年份可同时看到届时周岁

## 输入

| 字段   | 类型   | 约束                    |
| ------ | ------ | ----------------------- |
| `text` | string | 生日，最大 200,000 字符 |

支持两种格式：

- `MM-DD` / `MM/DD`：只给月日（如 `05-20`）
- `YYYY-MM-DD` / `YYYY/MM/DD`：带出生年份（如 `1990-05-20`），会额外输出届时周岁

## 输出

```text
生日：05-20（1990 年生）
下一次生日：2027-05-20（星期三）
倒计时：236 天 08 时 12 分 33 秒
届时将满 37 周岁
```

## 选项

本工具无选项。

## 算法

1. 解析月日（可选年）。
2. 取今年的生日；若今年生日已过（含今天之前），改取下一年。
3. 用「现在」与下一次生日的毫秒差，拆成天 / 时 / 分 / 秒。
4. 星期几由 `Date.getDay()` 映射。

## 边界：2 月 29 日生日

闰年出生的人，平年没有 2 月 29 日。本工具统一策略：

- **平年按 2 月 28 日庆祝**（与 date-calc 的「2-29 加年回退 2-28」一致）
- 输出会加一行「注：2 月 29 日生日，平年按 2 月 28 日庆祝」
- 遇到闰年（如 2028）则正常在 2 月 29 日庆祝

## 其他边界

- 今天就是生日 → 输出「就是今天！生日快乐！」，不再给倒计时
- 越界日期（02-30、13-01）→ 中文报错
- 非法格式 → 报错
- 输入 > 200,000 字符 → 报错
- 倒计时为静态快照（打开页面时算一次），不每秒跳动

## 示例

输入：`2-29`

若今年是 2026（平年），下一次生日显示为 `2026-02-28`，并附说明。
