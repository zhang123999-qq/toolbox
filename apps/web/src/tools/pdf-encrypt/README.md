# PDF 加密（#489）

为 PDF 设置打开密码，生成**真正的标准加密 PDF**，可用 Adobe Reader / Chrome / pdf.js 等任意阅读器输入密码打开验证。

## 功能

- 上传单个 PDF（上限 50MB），设置**用户密码**（打开密码，必填）
- **所有者密码**选填：留空则默认与用户密码相同
- **密钥长度**：256-bit（默认，AES-256，推荐）/ 128-bit（兼容很老的阅读器）
- **权限开关**：打印 / 复制内容 / 修改 / 注释，默认全部允许；关闭后写入 PDF 权限位
- 已加密的 PDF 会被识别并明确拒绝（不支持二次加密）

## 技术路线

- pdf-lib 1.17.1 既不能写入加密 PDF，也不能解密，因此改用 `@neslinesli93/qpdf-wasm`
  （qpdf 12.2.0 编译的 WASM，ISC 许可证），经共享封装 `src/lib/qpdf.ts` 的 `runQpdf` 调用
- 默认生成 **AES-256**（AESV3）标准加密，与 Adobe 加密规范兼容
- 128-bit 使用 RC4，qpdf 12 默认拒绝弱加密，调用时自动加上 `--allow-weak-crypto`
- 权限映射（以 `qpdf --help=encryption` 实测为准）：
  打印 → `--print=full|none`；复制 → `--extract=y|n`；
  修改 → `--modify=all|none`；注释 → `--annotate=y|n`

## 隐私与安全

- **全程本地处理**：PDF 文件与密码不上传任何服务器
- **密码只保存在内存**（React state）：加密完成后自动清空；也可用「清空密码」按钮随时清除
- 密码框为 `type="password"`，密码原文绝不出现在控制台日志与错误消息中
- 注意：权限位是"君子协定"，部分阅读器可能不完全遵守；忘记密码则文件无法恢复，请务必牢记

## 限制

- 输入已加密的 PDF 不支持再次加密
- 加密是 CPU 密集的 WASM 同步调用，大文件处理时页面会有短暂 busy，属正常现象
