# 可读性分析

Flesch、Gunning Fog 等可读性评分。

## 用途

评估英文文案的阅读难度，判断是否需要拆分长句、替换复杂词；也用于对照不同版本的改写效果。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

英文为主；中英混排可算，但会附口径提示。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                                                                            |
| ------ | ------ | ----------------------------------------------------------------------------------------------- |
| `text` | string | Flesch 易读度（含等级）、Flesch-Kincaid 年级、Gunning Fog、ARI，以及词数/句数/复杂词/平均句长。 |

## 选项

该工具无选项。

## 限制

- 四项公式均以英文为基准，中文按 1 音节/词参与计算，混排结果仅供参考
- 音节数按元音组估算，专有名词与缩写可能误判
- 句数按中英文句末标点切分，整段无标点时记为 1 句

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
The cat sat on the mat. It was warm.
```

输出：

```text
The toolbox runs entirely in your browser. Nothing is uploaded, so your data stays on your device. Every tool is a plain function you can test.
```
