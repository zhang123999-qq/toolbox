# 跳转链接

生成"跳转到主要内容"的跳过链接（skip link）HTML 与配套 CSS：默认视觉隐藏、键盘聚焦时显示；也可粘贴页面 HTML，检测是否已有跳过链接及其目标是否存在。

## 用途

- 为网站添加键盘用户直达主要内容的跳过链接
- 检查存量页面是否缺失跳过链接

## 输入

| 字段   | 类型   | 约束                  |
| ------ | ------ | --------------------- |
| `text` | string | 待检测的 HTML（可空） |

另可在页面内设置：跳转目标 id、链接文案。

## 说明

- 纯前端生成与检测，无网络请求。
- 使用方法：将生成的 HTML 放在 `<body>` 的最前面，并确保页面有对应 id 的主内容区（如 `<main id="main-content">`）。
- 跳转目标 id 须以字母开头，可含字母、数字、下划线、连字符、点、冒号。
