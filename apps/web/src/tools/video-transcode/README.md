# 视频转码

上传视频，用 ffmpeg.wasm 在浏览器本地转换容器 / 编码 / 分辨率。

## 用途

视频格式不兼容播放器、需要换容器或降分辨率：选目标容器与分辨率，一键转码后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择视频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

## 输出

| 字段    | 类型   | 说明                                            |
| ------- | ------ | ----------------------------------------------- |
| `video` | 视频   | 转码后的视频，可预览并下载                      |
| `text`  | string | 处理报告：目标容器 / 编码器 / 分辨率 / 输出大小 |

## 选项

| 选项         | 类型 | 默认     | 说明                                              |
| ------------ | ---- | -------- | ------------------------------------------------- |
| `format`     | 下拉 | mp4      | 目标容器：mp4 / webm / mov / mkv                  |
| `resolution` | 下拉 | original | 目标分辨率：original（保持）/ 1080p / 720p / 480p |

编码器映射：mp4 / mov / mkv → H.264 + AAC；webm → VP9 + Opus。

## 限制

- 转码在浏览器本地完成（ffmpeg.wasm），首次使用需从 CDN 下载 wasm 内核
- 文件全程留在浏览器内存里，不发任何请求

## 示例

`movie.mp4` → webm 720p：

```text
输入：movie.mp4
目标容器：WEBM（视频 libvpx-vp9 / 音频 libopus）
目标分辨率：高度 720px
输出大小：xxx MiB
```

## 数据流向

**纯本地处理。** 转码在浏览器内完成，`meta.api = false`，无需自备 API/Key。
