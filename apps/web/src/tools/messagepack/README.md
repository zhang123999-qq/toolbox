# MessagePack

MessagePack 编解码：JSON 与 MessagePack 字节互转，输出 hex / base64 与 JSON 预览。

编码与解码都是本工具自己实现的纯 TS 代码，不依赖 `msgpackr` 之类的第三方库。

## 用途

- 看一个 JSON 打成 MessagePack 后到底占几个字节（对比 JSON 的体积收益）
- 拿到一段 MessagePack 字节流（日志、缓存、RPC 抓包），还原成可读的 JSON
- 学习 MessagePack 的 `fixint` / `fixstr` / `fixmap` 等紧凑编码

## 输入

| 字段   | 类型   | 约束                                                                  |
| ------ | ------ | --------------------------------------------------------------------- |
| `text` | string | 编码模式为 JSON；解码模式为字节串（hex 或 base64）；最大 500,000 字符 |

## 输出

| 字段   | 类型   | 说明                                                                            |
| ------ | ------ | ------------------------------------------------------------------------------- |
| `text` | string | 编码结果（hex/base64 + JSON 预览）或解码结果（JSON + 类型统计）；空输入返回空串 |

## 选项

| 选项     | 取值                | 默认     | 说明                                       |
| -------- | ------------------- | -------- | ------------------------------------------ |
| `mode`   | `encode` / `decode` | `encode` | 编码（JSON → 字节）还是解码（字节 → JSON） |
| `format` | `hex` / `base64`    | `hex`    | 编码结果用哪种形式展示                     |

## 特殊类型（编码时用这三个标记键）

| 标记   | 写法                                                      | 说明                         |
| ------ | --------------------------------------------------------- | ---------------------------- |
| `$bin` | `{"$bin": "0a0b"}`                                        | 二进制数据（十六进制字符串） |
| `$ext` | `{"$ext": {"type": 1, "data": "0a"}}`                     | 扩展类型（type 取 -128–127） |
| `$ts`  | `{"$ts": 1700000000}` 或 `{"$ts": {"sec": 1, "nsec": 0}}` | 时间戳（ext type -1）        |

解码时这三类会被还原成同样的标记对象；其余类型直接对应 JSON 原生值。

## 限制

- **不是官方实现的完整校验**：不校验 UTF-8 字符串合法性（非法字节由 `TextDecoder` 按替换字符处理）
- 数字编码只区分「整数 / 浮点」：整数按最小宽度存放（fixint → uint8/16/32/64 → int8/16/32/64），**非整数一律用 float64**，不会自动选 float32
- 整数的绝对值超过 `2^53` 时，编码端无法表达（JSON 里没有 BigInt）；解码端遇到 64 位大整数会输出字符串以免丢精度
- 时间戳只支持 ext type `-1` 的 32 / 64 / 96 位三种形式；其他 ext 原样保留字节
- 不支持 `never used`（0xc1）这类保留标记，遇到会报「未知的 MessagePack 标记」
- 嵌套上限 64 层；输入上限 500,000 字符，超出或格式非法抛出 `MessagePackError`（中文提示）

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入（编码模式）：

```json
{ "a": 1 }
```

输出：

```
# MessagePack 编码

hex   : 81a16101
字节数: 4

分组视图：
  81 a1 61 01

解码回读（JSON 预览）：
{
  "a": 1
}
```

（同样内容用 JSON 存是 7 字节，MessagePack 只要 4 字节。）
