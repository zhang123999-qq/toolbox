# 结构化数据校验

提取网页 HTML 中的 `JSON-LD` 并逐块校验：JSON 合法性、`@type`、`@context` 缺失提醒；
也支持直接粘贴 JSON-LD 文本校验。

## 用途

给页面加了 Schema.org 结构化数据后，验证 JSON 有没有写错、关键字段有没有漏，
避免搜索引擎无法识别。

## 输入

| 字段   | 类型   | 约束                                         |
| ------ | ------ | -------------------------------------------- |
| `text` | string | 网页 HTML 或 JSON-LD 文本，最大 500,000 字符 |

## 选项

| 选项     | 取值                         |
| -------- | ---------------------------- |
| 输入来源 | `网页 HTML` / `JSON-LD 文本` |

## 输出

```text
来源：网页 HTML
共 2 块 JSON-LD：2 通过 / 0 失败

[#1] 通过
  @type：Article
  @context：https://schema.org
[#2] 通过
  @type：（缺失 @type）
  @context：https://schema.org
  备注：缺少 @type，搜索引擎可能无法识别，建议补全
```

## 与 json-ld（#625）的区别

- `json-ld`：**生成器**——填表单生成 JSON-LD 代码
- `structured-data`：**校验器**——从已有页面提取并校验 JSON-LD 是否合法

## 限制

- 只校验 JSON 语法与 `@type` / `@context` 存在性，不校验 Schema.org 词表的语义正确性
  （如 `Article` 是否允许该字段）
- JSON 报错位置为尽力提示，以编辑器实际报错为准

## 数据流向

**纯前端本地计算（A 类）。** 内容不上传，校验全在浏览器内完成。
