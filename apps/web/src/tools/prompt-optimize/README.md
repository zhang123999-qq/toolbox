# 提示词优化 Prompt Optimizer（#592）

BYOK（Bring Your Own Key）模式的提示词优化工具：把粗糙的提示词发给大模型，
改写为包含「任务 / 背景 / 约束 / 输出格式」四部分的结构化高质量提示词，
并在界面上并排展示优化前后对比。

## 使用方法

1. 在左侧输入框粘贴粗糙的提示词（或点「示例」载入）。
2. 在右侧填入自己的 **API Key**（密码框）、接口地址（默认 OpenAI 官方地址）、模型名。
3. 点「开始优化」，等待模型返回结构化提示词。

## BYOK 说明

- Key 只保存在你的浏览器 localStorage（且仅在勾选「记住 Key」后），请求直接从浏览器发往你配置的接口地址；
- 本站服务器不经手、不记录、不打印你的 Key；
- 点「清除 Key」可一键删除本地保存的 Key；
- 接口需兼容 OpenAI 的 `POST {baseURL}/chat/completions` 格式。

## 错误提示

- 401：Key 无效或过期；403：无权限；404：检查 baseURL / 模型名；429：频率过高或配额不足；
- 超过 60 秒无响应会报超时。

## 局限

- 优化质量取决于所选模型；超长提示词（> 20000 字符）会被拒绝，请先自行精简。
