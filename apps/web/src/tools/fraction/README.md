# 分数计算

分数四则运算，用 fraction.js 做精确计算（无浮点误差），输出分数、带分数与精确小数。

## 用途

- 分数加减乘除：`1/2 + 1/3` → `5/6`（而不是 0.8333333333333334）
- 带分数输入：`1 1/2 + 0.5` → `2`
- 带括号的混合运算与整数乘方

## 输入

| 字段   | 类型   | 约束                          |
| ------ | ------ | ----------------------------- |
| `text` | string | 分数表达式，最大 200,000 字符 |

表达式语法：数字（分数 `1/2`、带分数 `1 1/2`、小数 `0.5`、整数）、运算符 `+ - * / ^`、括号 `()`。`^` 指数必须为整数。

## 输出

```text
表达式：1/2 + 1/3
分数：5/6
带分数：5/6
小数（10 位）：0.8333333333
```

## 选项

| 选项       | 取值                          | 说明                        |
| ---------- | ----------------------------- | --------------------------- |
| `decimals` | `2` / `4` / `6` / `10` / `16` | 小数形式保留位数，默认 `10` |

## 算法

- 词法分析把 `1/2`、`1 1/2` 识别为单个数字 token，再用递归下降解析（优先级：括号 > 一元符号 > `^` > `*` `/` > `+` `-`）
- 全部运算经 fraction.js 的 BigInt 分数完成，结果恒为最简分数
- 小数展开用 BigInt 长除法精确到指定位数（四舍五入），尾零自动去掉

## 边界

- 除数为 0 → 中文报错
- 非整数指数（如 `2^0.5`）→ 中文报错
- 无法识别的字符 / 括号未闭合 / 多余内容 → 中文报错
- 暂不支持隐式乘法（如 `2(1/2)` 请写成 `2*(1/2)`）与百分号
- 输入 > 200,000 字符 → 报错

## 示例

输入 `1/2 + 2/3`：输出分数 `7/6`、带分数 `1 1/6`、小数（10 位）`1.1666666667`。

## 数据流向

纯前端本地计算（fraction.js 在浏览器内运行），不调用外部接口、不上传数据。
