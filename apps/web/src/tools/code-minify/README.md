# 代码压缩

把带注释和换行的源码压成一行，支持 JS / CSS / HTML。

## 用途

替代 Terser 的轻量自研压缩：在浏览器本地去掉注释、合并多余空白，
不做混淆、不改量名，适合「交付前瘦身」这类轻量场景。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

## 输出

| 字段   | 类型   | 说明             |
| ------ | ------ | ---------------- |
| `text` | string | 压缩后的单行代码 |

## 选项

| 选项 key   | 界面标签 | 说明                  |
| ---------- | -------- | --------------------- |
| `language` | 语言     | `js` / `css` / `html` |

## 压缩规则

- **JS**：删除 `//` 行注释与 `/* */` 块注释，连续空白压成单空格；字符串内容原样保留
- **CSS**：删除 `/* */` 注释，压缩空白，去掉 `}` 前多余的分号
- **HTML**：删除 `<!-- -->` 注释，标签间不留空白

## 限制

- 不做变量名混淆、不删 `debugger`、不做作用域分析，压缩率远不如 Terser/esbuild
- 字符串内的空白与注释样文本会被保留（不误删）
- 输入上限 200,000 字符

## 数据流向

**纯本地处理。** 不发送任何网络请求。`meta.api = false`。

## 示例

输入：

```js
function add(a, b) {
  // 两行数之和
  return a + b
}
```

输出：

```text
function add(a, b) { return a + b; }
```
