# 音频裁剪

上传音频，按起止时间（秒）裁剪出片段，导出为 16 位 PCM WAV 文件。

## 用途

从录音、播客、音乐中截取需要的片段：设好起始 / 结束时间，试听确认后下载。

## 输入

| 字段   | 类型   | 约束         | 说明                                 |
| ------ | ------ | ------------ | ------------------------------------ |
| `file` | File   | 最大 200 MiB | 通过「选择音频文件」选取，**不上传** |
| `text` | string | —            | 左侧文本区仅作备注，不参与处理       |

文件用浏览器 Web Audio API 本地解码（支持 wav / mp3 / ogg / m4a 等浏览器可解格式）。

## 输出

| 字段    | 类型   | 说明                                                   |
| ------- | ------ | ------------------------------------------------------ |
| `audio` | WAV    | 裁剪后的音频，可试听并下载                             |
| `text`  | string | 处理报告：原时长 / 采样率 / 声道 / 裁剪区间 / 输出时长 |

## 选项

| 选项    | 类型 | 默认 | 说明                                               |
| ------- | ---- | ---- | -------------------------------------------------- |
| `start` | 数字 | 1.0  | 起始时间（秒），不能为负                           |
| `end`   | 数字 | 2.0  | 结束时间（秒），必须大于起始时间且不超过音频总时长 |

## 限制

- 起始时间 ≥ 结束时间、时间为负、结束时间超出音频时长，都会给出中文错误提示
- 空音频（0 秒）无法裁剪
- 输出固定为 16 位 PCM WAV；如需 mp3 等格式请用「音频格式转换」
- 文件全程留在浏览器内存里，不发任何请求

## 示例

载入示例音频（4 秒 440Hz 正弦波），默认裁剪 1.0–2.0 秒：

```text
输入：示例-440Hz正弦波.wav
原时长：4.00 秒　采样率：44100 Hz　声道：1
裁剪区间：1.00 秒 – 2.00 秒
输出时长：1.00 秒
```

## 数据流向

**纯本地处理。** 解码与裁剪都在浏览器内完成，`meta.api = false`，无需自备 API/Key。
