# 日期本地化

输入一个日期，并排对比它在多个语言区域（locale）下的本地化写法：日期、时间、日期时间三档，外加中文相对时间（如「3 天前」）。

## 用途

- 出海产品检查日期在各地区的展示是否符合当地习惯
- 对比阿拉伯语、希伯来语等 RTL 地区的日期写法
- 与 `date-format` 的区别：`date-format` 是按自定义格式串格式化单个日期，本工具是**多 locale 并排本地化对比**

## 输入

| 字段      | 类型   | 约束                       |
| --------- | ------ | -------------------------- |
| `text`    | string | 日期（`2026-09-28 15:30`） |
| `locales` | string | 逗号分隔的 locale 列表     |

## 说明

- 使用浏览器/Node 内置 `Intl.DateTimeFormat` 与 `Intl.RelativeTimeFormat`，无网络请求。
- 内置 23 个常用语言区域，可在选项中自由组合。
