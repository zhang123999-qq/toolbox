# 词频统计

统计词频并排序，支持停用词过滤。

## 用途

快速看出一段文本在讲什么：提取高频词，用于摘要前的素材梳理、SEO 用词检查、语料校对。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本，中英混排均可。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                             |
| ------ | ------ | ------------------------------------------------ |
| `text` | string | 每行一条：排名、词、出现次数、占总词数的百分比。 |

## 选项

| 选项           | 取值         | 默认 | 说明                     |
| -------------- | ------------ | ---- | ------------------------ |
| `topN`         | 10 / 20 / 50 | 10   | 最多返回多少条           |
| `ignoreCase`   | boolean      | true | 是否合并大小写           |
| `useStopWords` | boolean      | true | 是否过滤中英文常用停用词 |

## 限制

- 中文按「连续汉字块」切分，**未做中文分词**，短语不会被拆成词
- 占比的分母是切分后的总词数，开启停用词过滤后分母不变
- 同频次按字典序排列，中文按 localeCompare 排序

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
工具 工具 库
```

输出：

```text
工具库里的工具都在浏览器本地运行，工具的数据不会上传。
```
