# Base64 转文件

粘贴 Base64 文本，解码后按指定文件名下载为文件。

## 用途

API 返回了一段 Base64 图片、别人发来一段 Base64 文本让你还原成文件时，粘贴进来、起个文件名，直接下载。

## 输入

| 字段   | 类型   | 约束             | 说明                                    |
| ------ | ------ | ---------------- | --------------------------------------- |
| `text` | string | 最多 2000 万字符 | Base64 文本，可带 `data:…;base64,` 前缀 |

## 输出

| 字段   | 类型   | 说明                              |
| ------ | ------ | --------------------------------- |
| `file` | binary | 解码出的文件，点「下载」保存      |
| `text` | string | 解码报告：字符数 → 字节数、文件名 |

## 选项

| 选项        | 取值   | 默认      | 说明                                                   |
| ----------- | ------ | --------- | ------------------------------------------------------ |
| `filename`  | string | `decoded` | 文件名（不含扩展名）                                   |
| `extension` | string | 空        | 扩展名；不填时按 data: URL 的 MIME 猜，猜不出用 `.bin` |

## 限制

- **严格校验**：字符集错误、长度不是 4 的倍数、空输入都有中文报错
- 粘贴的文本可带换行（自动忽略空白字符）
- 超过 2000 万字符直接报错
- data: URL 前缀（如 `data:image/png;base64,…`）自动剥离，MIME 决定下载类型与默认扩展名
- 全程本地解码，不发任何请求

## 数据流向

**纯本地处理。** 文本只在浏览器内存里解码，`meta.api = false`，无需自备 API/Key。

## 示例

输入：`aGVsbG8gd29ybGQ=`，文件名 `decoded`。

输出：

```text
解码成功：16 字符 → 11 字节
文件名：decoded.bin

点「下载」把文件保存到本地。
```
