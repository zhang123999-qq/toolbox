# 敏感词检测

本地词库匹配敏感词并高亮。

## 用途

发布前自查文案是否含营销违规或不文明用词，并给出打码后的版本便于直接替换。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本。最大 100,000 字符。

## 输出

| 字段   | 类型   | 说明                                     |
| ------ | ------ | ---------------------------------------- |
| `text` | string | 命中词统计（词 × 次数）＋ 处理后的文本。 |

## 选项

| 选项   | 取值    | 默认 | 说明                                              |
| ------ | ------- | ---- | ------------------------------------------------- |
| `mask` | boolean | true | true 把命中词替换为等长星号；false 用【】包裹高亮 |

## 限制

- 词库是**内置示例清单**（营销违规与不文明用词各若干条），不是完整敏感词库，需按业务自行维护 `WORD_LIST`
- 只做整词子串匹配，不做变形、拼音、拆字等绕过手法的识别
- 重叠与嵌套命中按「先匹配先替换」处理，不做优先级仲裁

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
请加微信联系
```

输出：

```text
加微信领取免费额度，点击链接马上到账，名额有限。
```
