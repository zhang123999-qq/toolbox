# 音频转文字

实时语音听写：用浏览器 Web Speech API 把麦克风听到的说话内容逐句转成文字，支持多语言选择与临时候选显示。

## 与「语音识别」工具的区别

**本工具是连续听写（dictation）**：把你说的话原样逐句记录成文字，适合会议记录、口述笔记。
「语音识别」工具（#557）是**命令匹配**：你预设若干命令词，它只判断你说了其中哪一个并高亮触发，不做全文转写。

## 用途

口述笔记、会议速记、字幕初稿：说话即出文字，可复制下载。

## 输入

| 字段         | 类型   | 说明                                         |
| ------------ | ------ | -------------------------------------------- |
| `microphone` | 音频流 | 点「开始听写」后从麦克风实时采集，**不上传** |
| `text`       | string | 左侧文本区仅作备注，不参与处理               |

## 输出

| 字段   | 类型   | 说明                              |
| ------ | ------ | --------------------------------- |
| `text` | string | 听写全文（段落换行），可复制/下载 |

界面同时显示临时候选（灰色「识别中…」）与段数/字数统计。

## 选项

| 选项   | 类型 | 默认    | 说明                                    |
| ------ | ---- | ------- | --------------------------------------- |
| `lang` | 选择 | `zh-CN` | 识别语言：中文简/繁、粤语、英、日、韩等 |

## 限制

- 需要 Chrome / Edge 浏览器（Web Speech API），其他浏览器会给出中文提示
- 识别需要联网（浏览器把音频发给语音服务）；麦克风音频不经过本站服务器
- 浏览器可能因长时间静音自动结束识别，本工具会自动续上
- 标点主要靠识别服务返回，口述时可直接说出「逗号」「句号」
- 识别出错（无语音/权限拒绝/网络异常）会给出中文提示

## 示例

说「你好，今天天气不错」：

```text
你好
今天天气不错
```

下方显示 `共 2 段，10 字`。

## 数据流向

识别由浏览器 Web Speech API 完成（`meta.api = false`，无需自备 Key）；
注意浏览器实现会把音频发往其语音服务，介意者请勿用于敏感内容。
