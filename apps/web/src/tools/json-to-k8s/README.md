# JSON 转 K8s

把 K8s 资源对象的 JSON 校验后，输出格式化 JSON 与等价 YAML。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 200,000 字符 |

粘贴 K8s 资源对象 JSON（顶层必须是 object）。

## 校验项

`apiVersion` / `kind` / `metadata.name`。

## 输出

三段：`== K8s 校验结果 ==`、`== 格式化 JSON ==`（2 空格缩进）、`== 等价 YAML ==`（自研序列化，未引入 js-yaml）。

## 限制

- 只做必需字段存在性校验，不做 schema 校验
- YAML 序列化覆盖常见 map/list，不处理 anchor/flow 风格

## 数据流向

**纯本地处理。** `meta.api = false`。
