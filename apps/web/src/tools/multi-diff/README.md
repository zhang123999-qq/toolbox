# 多文件 Diff

多个文本文件差异对比。

## 用途

一次对比多个文本文件：以第一个文件为基准，逐个看其余文件和它差在哪，适合核对同一份配置或文案在多个环境里的版本。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

所有文件放在同一个输入框里，每个文件以**独占一行的 `=== 文件名`** 开头；第一个文件块作为对比基准。

## 输出

| 字段   | 类型   | 说明                                                          |
| ------ | ------ | ------------------------------------------------------------- |
| `text` | string | 基准信息 + 每个文件与基准的差异（+ 新增、- 删除、空格未变）。 |

## 选项

| 选项   | 取值                              | 默认   | 说明     |
| ------ | --------------------------------- | ------ | -------- |
| `mode` | `line`（行级） / `char`（字符级） | `line` | 对比粒度 |

## 限制

- 只做「首个文件 vs 其余每个文件」的星型对比，**不做两两之间的全组合对比**
- 文件名只作为标签使用，不涉及真实文件读写
- 正文里若本身含以 `=== ` 开头的行，会被误判为新文件块
- 输出是带标记的纯文本，不是可直接应用的补丁
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
=== a.txt
第一行
第二行
=== b.txt
第一行
第二行改了
```

输出：

```text
基准：a.txt（2 行）

--- 与 b.txt 的差异
  第一行
- 第二行
+ 第二行改了
```
