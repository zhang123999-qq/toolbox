# OCR后处理 OCR Post-processor（#599）

对 OCR 识别出的文本做**规则纠错**（纯本地，非 AI），四条规则可在右上角独立开关，
处理结果实时显示，并统计改动处数。

## 四条规则（按此顺序执行）

1. **全半角统一**：全角字母/数字/空格（Ａ-Ｚ ａ-ｚ ０-９ Ｕ+3000）→ 半角；
   中文标点（，。！？；：）不受影响；
2. **形近字纠错**（上下文感知）：
   - 字母之间的 `0` → `O`、`1` → `l`；
   - 数字之间的 `O`/`o` → `0`、`l`/`I` → `1`；
   - 孤立字符不动，避免误伤真实数字；
3. **多余空白清理**：删除中文字符之间的空格、多个连续空格/制表符合并为一个、
   去掉每行首尾空白；
4. **多余换行合并**：段落内的单换行合并为一行——连字符断行去 `-` 直连、
   中文之间直连、其余加空格；空行分隔的段落保留。

## 注意

- 这是**确定性规则纠错，不是 AI**：上下文相关的整词误识处理不了；
- 规则可能误伤（如小数点后的 `0` 被当作字母间的 `0`），重要文本请人工复核。
