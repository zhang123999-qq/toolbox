# OTP 二维码

生成 `otpauth://` 绑定地址，并渲染成字符画二维码。

## 用途

把共享密钥 + 账号信息打包成验证器认识的格式：Google Authenticator、1Password、
Authy 扫的就是这个 URI。也给不扫码的场景留了可以手抄的 URI 文本。

## 输入

| 字段      | 类型   | 约束              | 说明                             |
| --------- | ------ | ----------------- | -------------------------------- |
| `text`    | string | 最大 200,000 字符 | Base32 共享密钥                  |
| `issuer`  | string | 可选              | 签发者（服务名），如 `Toolbox`   |
| `account` | string | 可选              | 账户名，如邮箱                   |
| `counter` | string | 非负整数          | 仅 HOTP 使用，默认 0             |

## 输出

| 字段   | 类型   | 说明                                       |
| ------ | ------ | ------------------------------------------ |
| `text` | string | `otpauth://` URI + 空行 + 字符画二维码      |

## 选项

| 选项        | 取值                   | 默认   | 说明                       |
| ----------- | ---------------------- | ------ | -------------------------- |
| `type`      | totp / hotp            | totp   | 时间型或计数器型           |
| `digits`    | 6 / 8                  | 6      | 验证码位数                 |
| `period`    | 30 / 60                | 30     | 时间步长，仅 TOTP          |
| `algorithm` | SHA1 / SHA256 / SHA512 | SHA1   | HMAC 摘要                  |

## 限制

- 字符画二维码用的是全角块字符 `██`，**肉眼核对可以，扫码成功率取决于屏幕与字体**；
  要真拿去扫，请用验证器扫更可靠的来源（或直接用输出的 URI 手动添加）
- 静区按规范应为 4 个模块，这里取 2 个以控制字符画宽度
- 账户名与签发者至少要填一个：否则绑定后认不出这是哪个账号
- 只支持 Base32 密钥

## 数据流向

**纯本地处理。** 密钥只在浏览器内存里参与运算，不发送任何网络请求。
`meta.api = false`，无需自备 API/Key。**不要把真实账号的密钥粘贴到任何在线工具里。**

## 示例

输入（密钥 + `Toolbox` + `demo@example.com`）：

```text
JBSWY3DPEHPK3PXP
```

输出：

```text
otpauth://totp/Toolbox:demo%40example.com?issuer=Toolbox&secret=JBSWY3DPEHPK3PXP&algorithm=SHA1&digits=6&period=30

████████████████████████████████████████████
████████████████  ██  ██    ██    ██████████
…
```
