# 文案生成 Copywriting Generator（#610）

BYOK 模式：输入产品描述，选择文案类型（标题 / 口号 / 详情 / 朋友圈）
与语气（专业 / 活泼 / 幽默 / 正式 / 亲切），请大模型一次生成多条候选文案。

## 使用方法

1. 左侧输入产品描述；
2. 右上角选择文案类型与语气；
3. 右侧配置接口地址、模型名、API Key；
4. 点「生成文案」，候选列表展示在下方，可复制/下载。

## 按条拆分

提示词要求模型每条文案占一行；本站用 `parseListOutput` 去编号、
去符号、去空行后拆成列表展示。

## BYOK 说明

- API Key 只保存在内存中，刷新/关闭页面即清除，不写 localStorage；
- Key 只出现在请求头中，本站不经手、不记录；
- 接口需兼容 OpenAI 的 `POST {baseURL}/chat/completions` 格式。

## 错误处理

- 产品描述为空 / 超长显示中文错误；
- 401 / 403 / 404 / 429 / 5xx 翻译为中文提示。
