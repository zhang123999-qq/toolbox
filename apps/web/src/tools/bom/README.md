# BOM 处理

检测、添加、移除 BOM。

## 用途

处理 UTF-8 BOM：查一段文本开头有没有那个看不见的 U+FEFF，需要时加上或去掉——Windows 工具链、CSV 导入、脚本解析经常卡在这一个字符上。

## 输入

| 字段   | 类型   | 约束              |
| ------ | ------ | ----------------- |
| `text` | string | 最大 100,000 字符 |

任意文本。

## 输出

| 字段   | 类型   | 说明                                                                   |
| ------ | ------ | ---------------------------------------------------------------------- |
| `text` | string | detect 给出开头状态与全文出现次数；add / remove 直接给出处理后的文本。 |

## 选项

| 选项   | 取值                                                | 默认     | 说明     |
| ------ | --------------------------------------------------- | -------- | -------- |
| `mode` | `detect`（检测） / `add`（添加） / `remove`（移除） | `detect` | 处理方式 |

## 限制

- 只处理**开头**的 BOM：正文里的 U+FEFF 只报告数量，不清除（要清除请用「零宽字符」#42）
- 添加 BOM 时若开头已有则不重复加（幂等）
- 按字符处理而非字节：本工具面对的是浏览器里已经解码好的字符串，不涉及文件读写的字节层面
- UTF-16 的 BOM（U+FFFE 反序标记）不在处理范围内
- 输入上限 100,000 字符

## 数据流向

**纯本地处理。** 输入内容仅在浏览器内存中处理，不发送任何网络请求，不写入服务端。
`meta.api = false`，无需自备 API/Key。

## 示例

输入：

```text
﻿第一行
第二行（开头那个看不见的字符就是 BOM）
```

输出：

```text
开头有 BOM（U+FEFF）
全文 U+FEFF 出现次数：1
```
