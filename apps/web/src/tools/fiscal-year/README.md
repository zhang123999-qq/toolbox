# 财年查询

输入日期，选择财年起始月（默认 1 月），输出所属财年、财年起止、财年进度与距财年末天数。

## 用途

不同国家 / 企业的财年不一定从 1 月开始：日本与微软的财年从 4 月开始，澳大利亚与美国政府的财年从 7 月开始。本工具帮你把任意日期归到正确的财年区间。

## 输入

| 字段   | 类型   | 约束                                 |
| ------ | ------ | ------------------------------------ |
| `text` | string | 日期 `YYYY-MM-DD`，最大 200,000 字符 |

## 选项

| 选项 key     | 界面标签         | 值                     | 说明                 |
| ------------ | ---------------- | ---------------------- | -------------------- |
| `startMonth` | 类型（借用文案） | `1` / `4` / `7` / `10` | 财年起始月，默认 `1` |

> i18n 词典里没有「财年起始月」专用文案，本工具借用「类型」标签承载，含义以上表为准。

## 输出

```text
日期：2025-06-15
所属财年：FY2025
财年起止：2025-04-01 ~ 2026-03-31
财年进度：74.2%
距财年末：290 天
```

规则：

- 若日期月份 `m >= 起始月 s`：财年从当年 `s` 月开始，记为 `FY{当年}`
- 若 `m < s`：日期属于上一年 `s` 月开始的财年，记为 `FY{当年-1}`

常见对照：

| 起始月    | 代表                | 2025-06-15 所属财年 | 区间                    |
| --------- | ------------------- | ------------------- | ----------------------- |
| 1（默认） | 自然年              | FY2025              | 2025-01-01 ~ 2025-12-31 |
| 4         | 日本 / 微软         | FY2025              | 2025-04-01 ~ 2026-03-31 |
| 7         | 澳大利亚 / 美国政府 | FY2025              | 2025-07-01 ~ 2026-06-30 |

## 数据流向

**纯本地处理。** 不发送网络请求，`meta.api = false`。

## 示例

输入：

```text
2025-06-15
```

起始月选 `4` 时输出：

```text
日期：2025-06-15
所属财年：FY2025
财年起止：2025-04-01 ~ 2026-03-31
财年进度：74.2%
距财年末：290 天
```
