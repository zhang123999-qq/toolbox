## 二、表结构说明

每份分域表均为统一格式：

| 列 | 含义 |
|---|---|
| `#` | 全局编号，1–870 连续 |
| `工具名` | 中文展示名 |
| `slug` | URL 片段，全局唯一，kebab-case |
| `优先级` | `P0` 首发 / `P1` 第二批 / `P2` 第三批 / `P3` 差异化 |
| `可行性` | `A` 纯 JS / `B` WASM / `C` WebCrypto·WebCodecs / `D` 用户 API·Key / `E` 需后端 |
| `依赖` | 主要库或浏览器 API |
| `描述` | 一句话功能说明 |

## 三、使用方式

- **查工具**：按域打开对应文件，或用编辑器的全文搜索搜 slug / 工具名。
- **定优先级**：`P0` 共 148 条，是首发范围，见 [`../spec/07-路线图.md`](../spec/07-路线图.md) 阶段 1。
- **建工具目录**：`slug` 即 `src/tools/<slug>/` 的目录名，规范见 [`../spec/04-开发规范.md`](../spec/04-开发规范.md) §3。
- **注意无 P0 的域**：域 10/11/13/14/15/17/18/19/20 共 9 个域**无 P0 工具**，首发不覆盖，全部从 P1 起步。
