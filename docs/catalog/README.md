## 工具编号规则

- 全局编号 `1` – `870`，连续不跳号
- `slug` 全局唯一，用于路由（`/tools/<slug>`）
- 工具目录名 = `slug`（kebab-case）
- 一个 slug 对应 `src/tools/<slug>/` 一个独立文件夹

### slug 命名附加约束

- **不得与 npm 包名或技术术语裸重名**，必要时加语义后缀
  - ✅ `base64-encode`（不用 `base64`）、`cookie-parse`（不用 `cookie`）、`mime-lookup`（不用 `mime`）
  - ✅ `toml-parse`、`whois-lookup`、`sitemap-generate`、`svgo-optimize`、`semver-compare`
  - ❌ 原因：裸名易与依赖包、路由、搜索词冲突，且不利于 SEO 语义
