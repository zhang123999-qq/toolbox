## 1. 文本与内容处理

**子类：** 统计、转换、对比、生成、清洗、SEO 文本

**工具：**

- 统计：字数/字符/字节/行/段/词/句统计、中英文字数、阅读时间、可读性、词频、关键词密度、敏感词、情感分析（WASM/API）
- 转换：大小写、标题化、驼峰/下划线/中划线/常量、全半角、简繁、拼音、注音、Unicode 查询
- 转义：转义/反转义、Markdown 预览、Markdown↔HTML、HTML→Markdown、富文本→纯文本
- 表格：CSV/TSV 互转、表格→文本、文本→表格
- 生成/清洗：slug、模板变量、Lorem、乱序、去重、排序、缩进、行号、前后缀、批量替换、正则替换
- 对比：文本 Diff、多文件 Diff、Merge、分列、列提取
- 编码细节：编码检测、不可见字符、零宽字符、BOM、换行符、空白字符
- SEO/AI：文本摘要、改写、翻译（API/WASM）、标题生成、标签生成

**技术栈：** 纯 JS + `diff` + `markdown-it` + `turndown` + `pinyin-pro`；大文本入 Web Worker

## 2. 编码 / 加密 / 哈希 / 安全

**子类：** 编码、加密、哈希、密码、证书、安全检测

**工具：**

- 编码：Base64/32/58/85、URL 编码、HTML 实体、Unicode 转义、JS/CSS/SQL/XML 转义、Hex、二进制、八进制、Data URL、Punycode、Quoted-Printable、MIME、UUencode
- 加密：AES/DES/3DES、RSA/ECC/ECDSA/Ed25519、HMAC、PBKDF2、Bcrypt、Scrypt、Argon2
- Token：JWT 解析/生成、JWE/JWS、TOTP/HOTP、OTP 二维码
- 密钥：密钥生成、PEM/CSR、SSH 密钥、PGP
- 密码：密码强度、密码生成、密码短语、随机盐
- 哈希：MD5/SHA1/SHA256/SHA3、CRC、BLAKE2/3、xxHash、文件哈希、校验和
- 安全：CSP、CORS、安全头、SSL 检测、混合内容、XSS 转义、SQL 注入检测、密码泄露检测（API）

**技术栈：** WebCrypto 为主；兼容旧算法用 `crypto-js` / `forge`；JWT 用 `jose`；TOTP 用 `otpauth`
