## 三、工具目录规范

每个工具一个独立文件夹：

```text
src/tools/<tool-id>/
├── meta.ts        # id、slug、title、category、tags、priority、feasibility
├── Tool.tsx       # 工具 UI 入口
├── schema.ts      # Zod 输入/输出校验
├── utils.ts       # 纯函数，便于单测
├── worker.ts      # 可选：重任务放 Web Worker
├── wasm.ts        # 可选：WASM 模块加载
├── test.ts        # 单测/组件测试
└── README.md      # 使用说明、数据流向、限制
```

## 四、文件夹职责速查表

|---|---|---|
| `apps/web` | 静态主站，构建为纯静态文件 | `dist/` |

| `apps/web/src/lib` | 无状态基础能力 | crypto、worker、wasm、idb |

| `apps/web/src/services` | 存储、导出、API、PWA | storage、export、pwa |
| `apps/web/src/workers` | Web Worker | image、pdf、office、ai |
| `apps/web/src/wasm` | WASM 模块封装 | photon、ffmpeg、pdfjs |
| `packages/catalog` | 共享元数据与类型 | ToolMeta、Category |
| `packages/ui` | 设计系统 | shadcn/ui 封装 |

| `packages/search` | 搜索索引 | Orama/Fuse 适配 |

| `scripts` | 代码生成与检查 | generate-catalog |
| `docs` | 架构与贡献文档（三层：spec / catalog / tools） | `docs/README.md` |
| `deploy` | 部署配置 | Cloudflare、Nginx |
| `.github/workflows` | CI/CD | ci、deploy、lighthouse |

## 五、`features` 目录与 20 大域映射

| 域 | features 目录 | 域 | features 目录 |
|---|---|---|---|
| 1 文本与内容 | `text` | 11 AI/LLM | `ai` |
| 2 编码/加密/哈希 | `encoding` + `crypto` | 12 网络/SEO | `seo` |
| 3 数据格式 | `data-format` | 13 数据可视化 | `visualization` |
| 4 开发/运维 | `devops` | 14 Web3 | `web3` |
| 5 时间/日期 | `datetime` | 15 无障碍/国际化 | `a11y` + `i18n` |
| 6 数学/金融/生活 | `math` | 16 自动化/API/测试 | `automation` |
| 7 随机/生成/设计 | `random` | 17 浏览器扩展 | `extension` |
| 8 图片/图形 | `image` | 18 游戏开发 | `game` |
| 9 PDF/Office | `pdf` + `office` | 19 边缘计算 | `edge` |
| 10 音视频/媒体 | `media` | 20 教育/趣味 | `education` |
