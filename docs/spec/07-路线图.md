# 首发路线图

> 分批策略：P0 先上高频纯前端，P1 补日常需求，P2 补能力上限，P3 差异化
> 落地点：全部进入 `apps/web/src/tools/<slug>/`
>
> **工具全量清单：** [`../catalog/README.md`](../catalog/README.md) + [`../tools/`](../tools/) 20 份分域明细
>
> **实测分批数量：** P0 148 / P1 322 / P2 332 / P3 68（合计 870）
>
> **网页结构：** [`06-网页结构与信息架构.md`](06-网页结构与信息架构.md) —— 4 大组 + 20 域架构、6 种模板、三层搜索
>
> **开工前置：** [`08-待决事项.md`](08-待决事项.md) —— 8 项待拍板决策

## 阶段 0 · 架构骨架（开工第一步）

在写任何工具之前，先把地基搭好：

| 任务                                                  | 产物                                                      |
| ----------------------------------------------------- | --------------------------------------------------------- |
| 初始化 pnpm workspace + Turborepo                     | `pnpm-workspace.yaml`、`turbo.json`                       |
| 建 `apps/web`（Vite + React 19 + TS）                 | `vite.config.ts`                                          |
| 建 `packages/config`（eslint/tsconfig/tailwind 共享） | 共享配置包                                                |
| 建 `packages/catalog` + `apps/web/src/catalog`        | `categories.ts`、`groups.ts`、`schema.ts`、`loader.ts`    |
| 实现路由生成                                          | `router.tsx` 由 `routes.ts` 生成                          |
| **实现 4 大组 + 20 域三层导航**                       | `GroupNav`、`CategoryGrid`、`SubCategoryFilter`           |
| **实现 6 种工具页模板骨架**                           | `templates/T1`–`T6`                                       |
| **实现三层搜索**                                      | `SearchHero`（首页）+ `SearchDialog`（Cmd+K）+ 工具内搜索 |
| **实现搜索索引生成**                                  | `search-index.ts` + Orama（含拼音/别名/模糊）             |
| **实现响应式骨架**                                    | 移动端底部 TabBar + 抽屉 + 工具页双态切换                 |
| 建 `packages/ui`（shadcn/ui 封装）                    | Header、Sidebar、Card、Tabs                               |
| 写 `scripts/generate-catalog.ts`                      | 扫描 `tools/*/meta.ts`                                    |
| 写 `scripts/check-tools.ts`                           | 元数据完整性 + 重复检测 + **模板/大组归属校验**           |
| 写 `scripts/generate-sitemap.ts`                      | 生成 sitemap.xml                                          |
| 配 CI                                                 | `ci.yml`：lint + typecheck + check:tools + test + build   |

**验收标准：** 能注册 1 个示例工具（json-formatter），走 T2 模板渲染；4 大组导航可用；Cmd+K 搜得到；移动端布局正常；CI 全绿。
