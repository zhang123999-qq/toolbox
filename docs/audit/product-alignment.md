## 7. 错误边界与降级体验

| 场景                   | 处理策略                        | 用户感知                                      |
| ---------------------- | ------------------------------- | --------------------------------------------- |
| **工具运行时错误**     | `ToolErrorBoundary` 捕获        | 红色错误卡片 + 友好文案 + 重试按钮 + 重置按钮 |
| **异步工具失败**       | `runAsync` try-catch + 错误分类 | `wrongPassword`/`decryptFailed` 等分类文案    |
| **WASM 加载失败**      | 懒加载 + 捕获                   | 提示「WASM 加载失败，请刷新重试」             |
| **外部 API 超时/失败** | `AbortController` + 超时        | 提示「请求超时，请稍后重试」                  |
| **搜索无结果**         | 空状态组件                      | 「未找到匹配工具，尝试调整关键词」            |
| **网络离线**           | Service Worker 缓存             | 首页/已访问工具离线可用 (Workbox)             |
