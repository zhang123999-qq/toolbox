## 执行摘要

Toolbox 是一个成熟的纯前端单页应用工具库，采用 pnpm monorepo + Turborepo 架构，包含 799 个工具，覆盖 21 个域 / 5 大组。整体架构清晰，边界明确，符合现代前端工程最佳实践。

---

## 1. Monorepo 结构与包边界

| 包                 | 职责                               | 依赖方向     | 评估                |
| ------------------ | ---------------------------------- | ------------ | ------------------- |
| `@toolbox/catalog` | 工具元数据真源、路由派生、搜索索引 | 无内部依赖   | ✅ 单向依赖，零循环 |
| `@toolbox/search`  | Orama 搜索适配                     | 依赖 catalog | ✅ 单向依赖         |
| `@toolbox/config`  | 共享 TS/ESLint/Prettier 配置       | 无内部依赖   | ✅ 基础设施层       |
| `@toolbox/web`     | React 19 + Vite 8 应用             | 依赖上述三包 | ✅ 叶子节点         |

**循环依赖检测**：✅ 无循环依赖（`madge --circular` 验证通过）
