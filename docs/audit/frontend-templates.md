## 3. 类型安全与泛型设计

| 模板           | 泛型参数                                         | 约束                          | 类型安全评分 |
| -------------- | ------------------------------------------------ | ----------------------------- | ------------ |
| **TwoColumn**  | `<I extends { text: string }, O extends object>` | 输入必须含 `text`、输出为对象 | ⭐⭐⭐⭐⭐   |
| **MultiPanel** | 同上 + `renderOutput`/`toText` 函数签名          | 输出渲染与文本化分离          | ⭐⭐⭐⭐⭐   |

**关键优势**：

- 输入输出类型在工具层 `schema.ts` 中由 Zod 推导，端到端类型安全
- `optionDefs` 使用 `OptionDef<O>` 约束，选项键与类型强绑定
- `extraInputs`、`fileInput` 类型化，密码字段 `secret: true` 类型级区分
